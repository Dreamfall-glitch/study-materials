# 从零开始的具体搭建步骤

## 第一步：先宏观把握，建立初步路线

不要上来就啃教材。先通过快速速成课（不细做题，看字幕文件）有个印象，建立初步的路线。

速成课的作用是让你知道这门课到底在讲什么，主线大概是什么走向，有哪些大的板块。这一步不做笔记，就是看，脑子里有个地图。

看完速成课，在 Obsidian 里创建一个 Index 文件，把你能想到的主线大纲写下来，不用太细，就是骨架。我建议两点，第一是简洁，不扯废话和细节，第二是故事性，适当补充层层递进的文字和逻辑关系，初步建立连接和理解。

## 第二步：搜集 Raw

建立文件夹：`atom` `flash` `moc` `raw`

```bash
mkdir atom, flash, moc, raw
```

把手头所有的原始材料放进去：课件、教材、网课字幕文件、好的文献或文章，通通放在 Raw 目录里。这些是原始资料，不动它们，随时可以回去查。Karpathy 的 LLM Wiki 就是这个思路，原始材料全部保留。

## 第三步：逐个知识点打怪升级

不要统一学完再喂。先宏观把握之后，就逐个知识点像打怪升级那样学习、理解、投喂、整理。

具体操作是，拿一个知识点，自己去读教材、看网课对应段落，不懂的地方去查，去跟同学或老师讨论，做题或把自己的理解发给AI去校验。**直到你能说出自己对这个东西的理解**。如果说不出，说明掌握不到位，就继续结合资料问 AI，或者跟同学老师讨论，不断加强理解。

理解到位之后，语音输入（更快）自己的理解或做的题目。语音内容包含：

- 对单个知识点自己的理解与独特记忆方法
- 主线和支线的串联和逻辑
- 哪些不需要手写而且让 AI 整理的记忆部分

语音转成文本之后，建立这个知识点的文件。每个文件分成两个大部分：

- 如果记忆部分和理解部分分得比较开，就先进行抄书，把需要掌握的内容写好，再写我对这些知识点的理解使得记得更多更牢。

  ```markdown
  # 标题
  
  ## 记忆知识点
  
  ## 我的理解
  
  ```

- 如果没有分得很开，记忆和理解相辅相成，那就顺着思路梳理补充。

必要的习题，尤其是错题（如果不是为了考试或资料上没有就忽略）也要在形成自己的理解时去做，做完还要用自己的话落实到某些题型应该怎么做，插入到对应知识点文件作为例题而不是集中整理或整理全部。

这个知识点学完、记完、理解完，就算打掉一个怪了。然后 Index 文件里给这个知识点加上关联，补充故事性文字说明之类的。

## 第四步：让 AI 处理记忆部分的机械抄写工作

每个知识点里面，属于死记硬背或固定框架模板的部分，也就是记忆部分，不要自己手抄。通过 RAG，喂大模型原资源材料（课件或教材文字、截图，网课字幕），让 AI 整理后输出。这样我就不用自己抄一遍教材了。

## 第五步：整理MOC（Map of Content）

然后重新审查 Index 文件，通过知识点文件的关联（Obsidian 就是双中括号进行引用），像讲故事一样简洁干练地引用每个知识点，自然组织成主线和支线的庞大目录。通过 Markdown 的标题格式（#数量）等方式，把每个知识点的文件组织清楚。兼顾可读性、故事感。

## 第六步：后续维护

若后续新增或删减知识点，先增删改知识点文件，再增删改 Index 文件。做到像好的代码一样，提复用去耦合，化繁为简，衔接自然。

如果别的课程用到前面的知识，往往也就是某个知识点，而很少是对这门课某个线的引用。这样点线分离，使得 Obsidian 的知识网络也能很美观，引用很方便，相关好也互不影响。通过链接与反链接定位也很方便（例如 x 应用的原理，y 原理的应用，只需通过链接文件就能快速知晓和定位）。

[Obsidian配置](../../Obsidian配置.md) 需要，其中，通过`知识图谱`、和快捷键（Alt + K）的`反向链接`快速定位
