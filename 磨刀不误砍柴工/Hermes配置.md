# Hermes Agent 官方桌面版使用指南

## 一、前言

Hermes Agent 可以一键安装。现在界面可以设置中文。

现在在 Windows 上用 Hermes 官方桌面版，不需要再安装 WSL2 或者 Docker，可以直接原生运行。对于刚接触 AI 的朋友来说，我觉得可以直接从 Hermes 官方桌面版开始。安装简单，界面直观，配置也不复杂，基本就是点几下鼠标。

---

## 二、Hermes 与 Codex、ClaudeCode 的对比

三者都有桌面端 AI Agent，都可以读写你的文件，甚至控制你的电脑完成各种操作，但彼此之间有不少差异：

| 对比维度         | Hermes                                  | Codex                           | ClaudeCode                     |
| ------------ | --------------------------------------- | ------------------------------- | ------------------------------ |
| 开源情况         | 完全开源                                    | 闭源                              | 闭源                             |
| 模型支持         | 可随意切换，不被模型生态绑定                          | 倾向于使用自家模型，换模型需额外配置（如 cc-switch） | 倾向于使用自家模型，换模型效果可能下降            |
| 记忆体系         | 有长期记忆，解决问题后会自学习，记住操作习惯和偏好，自动创建 Skill 技能 | 主要依靠手动 md 记忆文件 + 自动记忆，以上下文方式注入  | 主要依靠手动 md 记忆文件 + 自动记忆，以上下文方式注入 |
| Profile 功能   | 支持多个独立 AI 智能体，彼此隔离                      | 不支持                             | 不支持                            |
| Computer Use | windows支持                               | 成熟支持                            | 成熟支持                           |
| 目标用户         | 新手友好、门槛低                                | 完成度高                            | 偏向专业开发者                        |

### 结论

- 如果已经在稳定使用 Codex 或 ClaudeCode，不建议第一时间切换过来
- 如果是第一次接触 AI Agent，或者想找一个门槛低、成本也不高的方案，Hermes 桌面版是个非常不错的选择

很多时候一个月会员的钱，就够你用 DeepSeek 跑很久了，而且不用担心账号被封或者订阅限制的问题。

## 三、安装步骤

1. 前往 Hermes 官网，下载对应系统的安装包
[Hermes Agent 中文社区桌面版 — 装上就能用的 AI Agent 桌面端](https://desktop.hermesagent.org.cn/)
2. 打开安装包，一键安装，各种依赖都会自动处理
3. 安装完成后打开软件

> 注：桌面版刚发布时安装总会报错，目前测试两次均可直接安装成功。

---

## 四、初始配置

### 4.1 连接大模型

1. 点击右下角，选择使用 API
2. 如果没有 API，可点击下方中间的"暂时跳过"，后续再到设置里添加
3. 找到 DeepSeek，把密钥粘贴进来，保存即可

### 4.2 切换中文界面

1. 点击"设置"
2. 选择左侧第三个选项
3. 在右侧语言选项里切换为中文

### 4.3 添加多个模型（含辅助模型）

在设置界面中：

1. 点击左侧的"提供方"，进入 API 密钥管理页面
2. 把拥有的各种 Key 都填进去并保存
3. 回到模型页面，主模型下方可配置辅助模型（如视觉模型），可自由更换，协同工作

### 4.4 其他实用设置

- **人格选择**：对话里的人格有多种选择
- **审批模式**（安全设置里，默认开启）：Hermes 执行任何操作前会征求同意，也可选择"智能"或直接关闭
- **记忆预算**（记忆与上下文里）：即上下文长度控制，一般不需要修改
- **语音配置**等功能，整体逻辑清晰

## 五、主界面功能

界面整体直观：

- **左侧**：会话和各种功能列表
- **右侧**：聊天区域和内容预览

### 5.1 消息平台功能

现已增加可视化配置界面。如需接入飞书，建议直接查阅官方文档，写得非常详细，基本照着做就行。

### 5.2 多任务并行

可同时开启多个对话：

- 点击"加号"选择项目文件夹，输入任务（如"帮我整理下载文件夹"）
- 点击"新建会话"选择另一个文件夹，输入另一个任务（如"把所有关于风景的视频剪成一条完整视频"）
- 多个任务可同时进行，左侧任务列表会实时显示状态，带动画效果的即为正在执行

### 5.3 会话置顶

右键某个会话，选择"置顶"，即可固定显示在顶部，方便长期使用。

---

## 六、Profile 功能（核心特色）

点击左下角房子图标旁边的加号，即可新建配置档案，输入名称和记忆文件后即创建完成。点击即可切换，整个过程很快。

每个 Profile 本质上都是一个独立的 AI 智能体，互相之间不会共享上下文，不会互相干扰。

**使用示例：**
- 一个 Profile 负责日常聊天和使用
- 另一个 Profile 专门部署各种服务

整体管理清晰，各司其职，有点 AI 团队的感觉。

---

## 七、产物（项目中枢）

无论是发送给 Hermes 的文件，还是 Hermes 生成过的文件或链接资源，全部会自动整理保存到顶部的"产物"中，供后续会话复用，有效解决 Agent 的"健忘"问题。

支持内容检索和搜索，需要时直接点击即可找到。

当你不知道怎么使用 Agent 的时候，你甚至可以直接去问 Agent 自己，让它教你怎么用它。
