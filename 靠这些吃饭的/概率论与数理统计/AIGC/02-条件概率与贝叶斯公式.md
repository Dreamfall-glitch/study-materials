# 02-条件概率、全概率公式与贝叶斯公式

## 知识地图

```
条件概率 P(B|A) = P(AB) / P(A)
    ↓
乘法公式：P(AB) = P(A)P(B|A)
    ↓
全概率公式         贝叶斯公式
    ↓                   ↓
"由因求果"          "执果溯因"
```

**本讲回答的核心问题**：当已知部分信息时，概率如何更新？如何从多个可能原因中推断最可能的那个？

---

## 1. 条件概率

### 1.1. 定义

设 $A, B$ 为两个事件，$P(A) > 0$，则**给定 $A$ 发生时 $B$ 发生的条件概率**（conditional probability）为：

$$
\boxed{P(B \mid A) = \frac{P(A \cap B)}{P(A)}}
$$

> **通俗理解**：条件概率就是"缩小样本空间"——已知 $A$ 已经发生，那么样本空间从原本的 $\Omega$ 缩小为 $A$，而 $B$ 只有在与 $A$ 的交集内才可能发生。所以概率就是 $P(AB)$ 除以 $P(A)$。

**条件概率的性质**（满足三条概率公理）：
- $0 \leq P(B \mid A) \leq 1$
- $P(\Omega \mid A) = 1$
- 若 $B_1, B_2, \cdots$ 两两互斥，则 $P\left(\bigcup B_i \mid A\right) = \sum P(B_i \mid A)$

### 1.2. 乘法公式

由条件概率定义直接可得：

$$
\boxed{P(AB) = P(A)P(B \mid A) = P(B)P(A \mid B)}
$$

推广到 $n$ 个事件：

$$
P(A_1 A_2 \cdots A_n) = P(A_1)P(A_2 \mid A_1)P(A_3 \mid A_1 A_2) \cdots P(A_n \mid A_1 \cdots A_{n-1})
$$

> **自己的话**：乘法公式就是用条件概率链"一步步"计算多个事件同时发生的概率——每次都在"已经发生了前序事件"的背景下考虑。

**例1**：一盒中有 5 个红球和 3 个白球，不放回地抽取两次，求两次都抽到红球的概率。

**解**：设 $A_1 = \{\text{第一次抽到红球}\}$，$A_2 = \{\text{第二次抽到红球}\}$。

$P(A_1) = \frac{5}{8}$，$P(A_2 \mid A_1) = \frac{4}{7}$。

$P(A_1A_2) = P(A_1)P(A_2 \mid A_1) = \frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14}$

## 2. 全概率公式

### 2.1. 完备事件组

若 $B_1, B_2, \cdots, B_n$ 满足：
1. $B_i \cap B_j = \varnothing$（两两互斥）
2. $\bigcup_{i=1}^n B_i = \Omega$（覆盖整个样本空间）
3. $P(B_i) > 0$

则称 $\{B_1, \cdots, B_n\}$ 是样本空间 $\Omega$ 的一个**完备事件组**（也称**划分**，partition）。

### 2.2. 全概率公式

设 $\{B_1, \cdots, B_n\}$ 是 $\Omega$ 的一个完备事件组，则对任意事件 $A$：

$$
\boxed{P(A) = \sum_{i=1}^n P(B_i)P(A \mid B_i)}
$$

**证明思路**：$A$ 可以按 $B_i$ 拆分为互不相交的部分：$A = A \cap \Omega = A \cap \left(\bigcup B_i\right) = \bigcup (A \cap B_i)$，再由概率的可加性和乘法公式即得。

> **自己的话**：全概率公式的核心思想是**"分情况讨论"**——有些事件的概率不能直接计算，但可以把它拆成若干互斥的"情况"，每种情况下计算条件概率，再加权求和。

**例2**：甲、乙、丙三个车间生产同一零件，产量分别占总产量的 $20\%, 30\%, 50\%$，次品率分别为 $0.05, 0.03, 0.02$。求从全部产品中任取一件是次品的概率。

**解**：设 $A = \{\text{取到次品}\}$，$B_1, B_2, B_3$ 分别表示取到甲、乙、丙车间的产品。

$P(B_1) = 0.2$，$P(A \mid B_1) = 0.05$
$P(B_2) = 0.3$，$P(A \mid B_2) = 0.03$
$P(B_3) = 0.5$，$P(A \mid B_3) = 0.02$

由全概率公式：

$P(A) = 0.2 \times 0.05 + 0.3 \times 0.03 + 0.5 \times 0.02 = 0.01 + 0.009 + 0.01 = 0.029$

即次品率为 $2.9\%$。

## 3. 贝叶斯公式

### 3.1. 公式

设 $\{B_1, \cdots, B_n\}$ 是 $\Omega$ 的一个完备事件组，$P(A) > 0$，则：

$$
\boxed{P(B_i \mid A) = \frac{P(B_i)P(A \mid B_i)}{\displaystyle\sum_{j=1}^n P(B_j)P(A \mid B_j)} = \frac{P(B_i)P(A \mid B_i)}{P(A)}}
$$

### 3.2. 先验概率与后验概率

- **先验概率**（prior probability）$P(B_i)$：在获得新信息之前对各个"原因"概率的初始判断
- **后验概率**（posterior probability）$P(B_i \mid A)$：观察到事件 $A$ 发生后，重新评估各个"原因"的概率

> **自己的话**：贝叶斯公式的本质是**"用结果反推原因"**——全概率公式是"由因求果"，贝叶斯公式是"执果溯因"。你观察到结果 $A$ 发生了，反过来问"最有可能是哪个原因导致的"。

**例3**（接例2）：从全部产品中任取一件，发现是次品，求该次品来自甲车间的概率。

**解**：由例2已经计算 $P(A) = 0.029$。

$P(B_1 \mid A) = \frac{P(B_1)P(A \mid B_1)}{P(A)} = \frac{0.2 \times 0.05}{0.029} = \frac{0.01}{0.029} \approx 0.3448$

即次品来自甲车间的概率约为 $34.48\%$。

类似可计算 $P(B_2 \mid A) \approx 0.3103$，$P(B_3 \mid A) \approx 0.3448$。

**例4**（经典疾病检测问题）：某种疾病的患病率为 $0.1\%$，检测方法的灵敏度和特异度均为 $99\%$（即患者检测为阳性的概率为 $99\%$，非患者检测为阴性的概率为 $99\%$）。若某人检测结果为阳性，求他真正患病的概率。

**解**：设 $D = \{\text{患病}\}$，$T = \{\text{检测阳性}\}$。

$P(D) = 0.001$，$P(\overline{D}) = 0.999$
$P(T \mid D) = 0.99$，$P(T \mid \overline{D}) = 0.01$（即误诊率 $1\%$）

由贝叶斯公式：

$$
P(D \mid T) = \frac{P(D)P(T \mid D)}{P(D)P(T \mid D) + P(\overline{D})P(T \mid \overline{D})} = \frac{0.001 \times 0.99}{0.001 \times 0.99 + 0.999 \times 0.01} \approx \frac{0.00099}{0.00099 + 0.00999} \approx \frac{0.00099}{0.01098} \approx 0.0901
$$

即检测阳性者真正患病的概率仅为 **$9\%$** 左右。

> **通俗理解**：准确率高达 $99\%$ 的检测，阳性结果下仍然只有 $9\%$ 的概率真正患病——这看上去违反直觉，但因为疾病的基准率（prevalence）极低（$0.1\%$），即使 $1\%$ 的误诊率也会产生大量"假阳性"。这个例子揭示了**基准率谬误**（base rate fallacy）的重要性。

## 4. 事件的独立性

### 4.1. 两个事件的独立性

事件 $A$ 与 $B$ 称为**相互独立**（independent），如果：

$$
\boxed{P(AB) = P(A)P(B)}
$$

由条件概率角度看：若 $P(A) > 0$ 且 $P(B) > 0$，则独立性等价于 $P(B \mid A) = P(B)$ 或 $P(A \mid B) = P(A)$——即 $A$ 的发生不影响 $B$ 的概率。

**独立 vs 互斥**：

| 类型 | 定义 | 能否同时发生 | 关系 |
|:----|:-----|:-----------|:-----|
| **互斥** | $AB = \varnothing$ | 不能 | $P(AB) = 0$ |
| **独立** | $P(AB) = P(A)P(B)$ | 可以 | $P(AB) = P(A)P(B)$ |

> **注意**：互斥且概率非零的事件**不可能**独立（因为 $P(AB) = 0 \neq P(A)P(B)$）。

### 4.2. 多个事件的相互独立

$n$ 个事件 $A_1, \cdots, A_n$ 称为**相互独立**，如果对其中任意 $k$ 个事件（$2 \leq k \leq n$），有：

$$
P(A_{i_1} A_{i_2} \cdots A_{i_k}) = P(A_{i_1})P(A_{i_2}) \cdots P(A_{i_k})
$$

即**所有子集**的乘积公式都成立。

## 本讲核心要点

1. **条件概率** $P(B \mid A) = P(AB)/P(A)$——缩小样本空间的思想
2. **乘法公式** $P(AB) = P(A)P(B \mid A)$——链式法则的基础
3. **全概率公式** $P(A) = \sum P(B_i)P(A \mid B_i)$——"分情况讨论"的数学表达，由因求果
4. **完备事件组**（划分）：两两互斥，并集为 $\Omega$
5. **贝叶斯公式** $P(B_i \mid A) = P(B_i)P(A \mid B_i) / P(A)$——执果溯因，后验概率更新
6. **先验概率** $P(B_i)$：初始判断；**后验概率** $P(B_i \mid A)$：观察数据后更新
7. **基准率谬误**：高精度检测下，极低基准率仍会导致大量假阳性——贝叶斯公式的经典应用
8. **独立性** $P(AB) = P(A)P(B)$——一个事件的发生不影响另一个事件的概率
9. **独立 ≠ 互斥**：互斥且非零的事件不可能独立
10. **多重独立性**：$n$ 个事件相互独立需要所有子集都满足乘积公式
