# 05-06-传统封装典型形式与分类

## 知识地图

前面几讲我们学习了芯片从晶圆到单个封装体的过程：减薄→划片→贴片→引线键合。但完成这些步骤之后，芯片仍然是"裸"的——它需要被**包封和保护**起来，才能可靠地工作。

```
前序工艺：                     本讲核心：                     后续演进：
贴片 → 引线键合         →   传统封装三大类型：             →    先进封装形式
(完成互连)                 塑料/金属/陶瓷封装                BGA/FC/2.5D/3D
	                             ↓
	                     密封技术 → 可靠性保障
```

本讲回答的核心问题：**芯片封装好之后，用什么材料把它"包"起来？如何确保它在各种环境下长期可靠工作？**

---

## 1. 塑料封装（Plastic Packaging）

### 1.1. 塑封概述

#### 1.1.1. 塑封的作用

**塑封（Molding）**：将芯片或器件覆盖模塑料进行保护的封装工艺。通过塑封，原本裸露的芯片、器件及连接线路通过外部塑封体得到保护，免于外界环境（特别是湿气）的侵袭。

目前超过**92%~95%** 的半导体封装采用塑料封装。

塑封广泛用于：TSSOP、DFN、QFN、SIP、BGA、LGA、FSCSP、WLCSP等封装形式。

随着扇出型封装的兴起，塑封又增加了新的功能——**重新构造圆片/面板，并增加芯片布线、布球的功能**。在扇出封装中，塑封成了关键工序。

#### 1.1.2. 塑封的两种方法

| 方法 | 原理 | 应用 |
|------|------|------|
| **注射式成型（Transfer Molding）** | 模塑料在压力下注入模具腔体 | TSSOP、DFN、QFN、BGA等传统封装。工艺成熟、可靠性高、UPH高 |
| **压缩式成型（Compression Molding）** | 塑封料在模具腔体内无流动，靠压力压实 | 存储器等多叠层超薄产品、LGA、WLCSP等。可实现无冲线塑封和超薄塑封 |

### 1.2. 塑封料的要求

半导体塑封料必须满足以下特性：

| 要求 | 说明 |
|------|------|
| **可成型性** | 避免损伤芯片和金线；减少溢料；避免空洞和不完全填充；快速固化 |
| **可靠性** | 耐湿性（防止电流泄漏和Al电路刻蚀）；抗热性（防止键合引线断裂和封装体破裂）；高温储存性 |

**塑封完整流程包括两个重要辅助步骤：**
- **塑封前**：等离子清洗（Ar+H₂混合气体）——清除表面微尘和污染物，活化表面，增加界面结合力，防止分层
- **塑封后**：后固化——提高热固化性塑封件的硬度，稳定分子结构，减少应力

### 1.3. 塑料封装的特点

| 优点 | 缺点 |
|------|------|
| 成本低（约为气密性封装的1/3~1/5） | 气密性差（抗潮湿、抗盐雾性能差） |
| 加工简便，一次模塑生产效率高 | 热性能差（导热差） |
| 重量轻、体积小，有利于小型化SMT | 热失配大 |
| 自身放射性少，减小辐射损伤 | 电磁屏蔽性能差 |
| 绝缘性能好 | 易自然老化 |

经过模塑料及工艺的改进，塑封电路的可靠性可达到部分军品的要求。

### 1.4. 框架塑料封装的完整工艺流程

```
芯片准备 → 装片（粘片）→ 引线键合 → 包封（Transfer Molding）
    →（后）固化 → 分割（切筋）→ 引线打弯 → 电镀
    → 测试与老化 → 成品 → 包装出厂
```

### 1.5. Transfer Molding（递模成型）详解

#### 1.5.1. 基本流程

```
1. 引线框架（L/F）置于模具中，每个die位于Cavity中，模具合模
2. 块状EMC放入模具孔中
3. 高温下，EMC开始熔化，顺着轨道流向Cavity中
4. 从底部开始，逐渐覆盖芯片
5. 完全覆盖包裹完毕，成型固化
```

**EMC（Epoxy Molding Compound，环氧模塑料）**：热固性材料，主要成分为酚醛树脂、环氧树脂、有机硅树脂等。

#### 1.5.2. 流动平衡问题

- 传统模具存在**不平衡流动**问题（Christmas tree效应）
- **多柱塞模具（Multi-Plunger Mold / Gang-Pot Mold）**可实现平衡流动，提高填充质量

#### 1.5.3. MoldFlow模拟

利用MoldFlow或Moldex3D等软件可对模塑过程进行流体仿真，对引线强度、焊盘节距影响很大。

### 1.6. 主要材料与设备

**主要材料**：芯片、引线框架、金丝、模塑料（EMC）、芯片粘结剂

**主要设备**：减薄机、划片机、粘片机、键合机、注塑机、电镀线、包封模具、切筋/打弯/成形机、测试分类设备、打印/包装设备

## 2. 金属封装技术

### 2.1. 金属封装基本工艺

```
金属外壳成型 → 外壳电镀 → 装片（粘片）→ 引线键合 → 管帽封接
    → 测试与老化 → 成品 → 包装出厂
```

金属封装通常用于**高可靠性**要求的场合（如航空航天、军事领域），具有优异的气密性和散热性能。

---

## 3. 陶瓷封装技术

### 3.1. 陶瓷封装基本工艺

```
陶瓷外壳成型 → 外壳电镀 → 装片（粘片）→ 引线键合 → 盖板封接
    → 测试与老化 → 成品 → 包装出厂
```

### 3.2. 陶瓷封装基本结构

陶瓷封装的关键结构要素：

- **陶瓷基座（Ceramic base）**：支撑芯片
- **玻璃密封（Glass seal）**：气密性封装
- **陶瓷盖板（Ceramic lid）**：盖封保护
- **金属引线（Metal lead）**：电气连接

## 4. 芯片密封技术

### 4.1. 密封的必要性

**芯片密封技术**：裸芯片与布线基板实现微互连后，需要通过密封技术将其密封在塑料、玻璃、金属或陶瓷外壳中，以确保其在各种恶劣条件下正常工作。

为什么必须密封？

| 风险 | 后果 |
|------|------|
| **湿气和氧** | 元件表面及布线导体图形被氧化和腐蚀，特性劣化 |
| **内侧引线凸点氧化** | 不能键合 |
| **导体电极氧化** | 不能钎焊 |
| **迁移现象** | 导体电路发生突然短路 |

### 4.2. 密封技术分类

```
密封技术
    ├── 气密性封装（金属/陶瓷封装）
    │   ├── 钎焊封接
    │   ├── 低熔点玻璃封接
    │   ├── 缝焊封接
    │   └── 激光熔焊封接
    └── 非气密性封装（塑料封装）
```

### 4.3. 塑料封装的吸潮问题

#### 4.3.1. 问题的严重性

塑料封装（环氧树脂基）是有机大分子结构，普遍存在**较高的吸湿性**。塑封器件的寿命 τ 与吸湿水汽的气压 P_H₂O 的关系满足：

**τ ∝ P_H₂O** —— 吸湿量越多，水汽压越高，器件寿命越短。

此外，塑封器件还会受到污染物（如Na⁺）和塑封料残存的离子性杂质（如Cl⁻）的影响。Cl⁻及湿气浸入后，会对芯片的Al电极产生局部腐蚀，形成疏松、脆性的Al化合物。

#### 4.3.2. 潮气引起的三种失效现象

| 现象 | 说明 |
|------|------|
| **湿应力破坏** | 吸湿引起封装体内部应力变化 |
| **爆米花效应（Popcorn Effect）** | SMD焊接时（215~240°C），壳体内水汽急剧膨胀，产生"爆米花"式开裂 |
| **金属腐蚀** | 湿气诱发电化学腐蚀 |

#### 4.3.3. "爆米花效应"的机理

SMD在再流焊或波峰焊时，整个器件经历215~240°C的高温。如果塑封壳体内充满湿气，焊接时水汽急剧膨胀，聚集形成较大水汽压，导致塑封壳体开裂。

大尺寸SMD和薄壳体器件尤其容易发生"爆米花"开裂现象。

#### 4.3.4. 吸潮开裂的对策

| 对策 | 方法 | 说明 |
|------|------|------|
| **结构改进** | 增加芯片四周和底部塑封料厚度 | 塑封料越厚，抗开裂能力越强 |
| **表面粗糙化** | 增加引脚上芯片键合区的表面粗糙度 | 提高与塑封料的结合力 |
| **烘烤除湿** | 加热烘烤塑封件"驱赶"水汽 | 降到0.1%以下(重量比)即可安全焊接 |

#### 4.3.5. 烘烤方法

| 方法 | 条件 | 优点 | 缺点 | 适用性 |
|------|------|------|------|--------|
| **高温烘烤** | 125°C，RH<50%，24h | 时间短 | 最多两次，引脚金属间化合物增厚 | 不适于塑料管式/编带包装 |
| **低温烘烤** | 40~45°C，RH<5%，196h（8天） | 可多次，不伤引脚 | 时间较长 | 适于管式/编带包装 |

### 4.4. 湿气特性表征手段

| 方法 | 设备 | 原理 |
|------|------|------|
| **湿膨胀系数测试** | DMA Q800 + 湿度附件 | 干燥样品在恒定温度下增加湿度，记录长度变化 |
| **水蒸气吸附** | 水蒸气吸附仪 | 高真空高温脱气后，控制水蒸气分压，实时监测质量变化 |
| **湿气扩散建模** | 有限元分析 | 模拟湿气在封装体内的扩散过程 |

### 4.5. 气密性封装技术

#### 4.5.1. 技术分类

| 方法 | 特点 | 适用性 |
|------|------|--------|
| **钎焊封接** | 用Sn63/Pb37共晶焊料钎焊（~240°C） | 常规气密性需求 |
| **低熔点玻璃封接** | 玻璃密封 | 陶瓷封装 |
| **缝焊封接（Seam Weld）** | 圆柱形电极滚动加压熔焊 | 薄金属盖板（~0.15mm） |
| **激光熔焊封接** | 激光束能量熔化焊接环和外盖 | **大型MCM**、复杂外形、高可靠性 |

#### 4.5.2. 气密性封装的核心要求

- 与空气隔绝，内部通常封入**He或N₂**等非活性气体
- 需进行**气体泄漏率检测**

#### 4.5.3. 气体泄漏率检测

| 方法 | 原理 | 检测灵敏度 |
|------|------|------------|
| **粗检测** | 将试样浸入125°C碳氟化合物，观察气泡 | 泄漏率 > 10⁻³ × 101kPa·mL/s |
| **细检测（氦检漏）** | 抽真空后检测He分子计数 | 10⁻² ~ 10⁻¹² × 101kPa·mL/s |

He气检漏是当前最灵敏的泄漏检测方法。对于内部封入N₂的情况，需先在He气氛加压釜中"浸泡"（2~4atm，2~4h），让He分子渗入后再检漏。

#### 4.5.4. 钎焊气密封接工艺

```
1. 多层布线基板四周形成金属化层（Al₂O₃陶瓷基板需在W导体上电镀Ni/Au）
2. 金属外壳选用可伐（Kovar）合金（CTE与Al₂O₃匹配），电镀Ni/Au或Sn改善浸润性
3. 预钎焊 → 清洗 → 电气检测
4. 约240°C再流焊（外壳需设Φ0.5~1.0mm小孔供空气逃逸）
5. 在He/N₂非活性气氛中，用共晶焊料密封小孔
```

#### 4.5.5. 激光熔焊封接工艺

```
1. 在多层布线板设定位置，由银焊料固定焊接环（Kovar）
2. 金属外壳扣在焊接环上，紧密接触
3. 激光束照射密接部位 → 焊接环与外壳金属同时熔化 → 冷却完成密封
```

激光熔焊法适合大型MCM以及外形复杂的MCM，是最高可靠性的气密封接方法之一。

### 4.6. 各类封装的耐湿性比较

| 封装类型 | 压力锅实验结果（121°C，2×101kPa） |
|----------|-----------------------------------|
| 塑封材料 | 约70h失效 |
| 传递模注塑封（较好）| 约200h |
| **气密性封装** | **无限长时间** |

## 本讲核心要点

1. **塑料封装占绝对主导地位**（>92%），以Transfer Molding为主要工艺。成本低、效率高，但吸潮是核心可靠性短板
2. **"爆米花效应"**是SMD塑封器件焊接时的典型失效模式——吸湿→焊接加热→水汽膨胀→开裂。对策包括结构增强、烘烤除湿和良好储存
3. **密封技术分为气密性与非气密性两大类**。气密性封装（钎焊/缝焊/激光熔焊）用于高可靠性场景
4. **烘烤驱湿**是塑封器件焊接前的重要工序——125°C/24h（高温）或40~45°C/8天（低温）
5. **氦检漏**是气密性封装最灵敏的泄漏检测方法，检测下限可达10⁻¹² × 101kPa·mL/s
6. **金属和陶瓷封装**虽然成本高，但在耐湿性、气密性和可靠性方面具有塑封不可替代的优势
