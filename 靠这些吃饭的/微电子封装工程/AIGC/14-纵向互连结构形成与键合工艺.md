# 14. 纵向互连结构形成与键合工艺

## 知识地图

前面各讲完成了 TSV（垂直通道）、RDL（横向布线）、减薄（薄晶圆拿持）——"路已修好"。本讲是最后一步：把各个芯片/层**键合**在一起，形成最终的电气和机械连接。

```
L11:TSV → L13:RDL → L12:减薄 → L14:键合
                                  ↓
                      基于凸点互连 → 无凸点直接互连
                      C4→C2/CuPillar → Cu-Cu→Hybrid Bonding
```

**本讲核心**：从 C4/C2 凸点互连到 Cu-Cu/Hybrid Bonding 无凸点互连，覆盖冶金学基础、Bumping 工艺、键合工艺和可靠性。

---

## 1. 互连对象与模式

### 1.1. D2D / D2W / W2W

键合对象的选择决定良率、吞吐量和工艺窗口。

| 类型 | 含义 | 典型材料/方式 | 主要优势 | 主要限制 |
|------|------|-------------|----------|----------|
| **D2D / C2C** | 单颗芯片对单颗芯片 | solder, IMC, polymer, metal bonding | 灵活性最高，可逐颗筛选 KGD，适合异质尺寸芯片 | 吞吐最低，逐颗对准，设备时间长，成本较高 |
| **D2W / C2W** | 已知良品芯片贴到整片晶圆 | microbump, Cu-Sn, Au-In, hybrid bonding | 可用 KGD，适合异质芯片，良率优于 W2W，灵活性较好 | 对准和贴装复杂，singulation 颗粒/边缘效应，吞吐低于 W2W |
| **W2W** | 两片晶圆整体对准并键合 | direct bonding, hybrid bonding, polymer/IMC | **吞吐最高**，适合规则阵列和同尺寸晶圆，有利于高量产 | **不能逐颗筛选 KGD**，坏 die 会成对损失，芯片尺寸/wafer 布局需匹配 |

### 1.2. 堆叠方向

**基本定义**：
**Face side**：含 FEOL 有源器件和 BEOL 互连的一面
**Back side**：硅衬底背面，通常需减薄、TSV reveal、背面 RDL 后才能参与互连

| 方式 | 互连路径 | 是否需要 TSV | 典型特点 |
|------|----------|-------------|----------|
| **F2F（Face-to-Face）** | 两个 BEoL/pad 面直接相对 | 至少一侧需 TSV 或后续背面引出 | 互连最短、密度最高，适合两层高密度连接 |
| **B2F（Back-to-Face）** | 一个芯片背面连到另一芯片正面 | 背面参与互连的层常需要 TSV | 常出现在减薄/背面加工后再键合，可用于多层堆叠，互连路径通过 TSV 延伸 |
| **B2B（Back-to-Back）** | 两个背面相对 | 通常两侧都要 TSV 或背面金属化 | 结构复杂，不常见 |

### 1.3. 键合方式的选择依据

| 维度 | 考虑因素 |
|------|----------|
| **互连密度** | bump pitch、pad pitch、I/O 数量 |
| **热预算** | 是否兼容 BEOL、low-k 介质、临时键合胶、已集成器件 |
| **良率与吞吐** | D2D / D2W / W2W 对设备产能和 KGD 策略影响很大 |
| **表面要求** | 平坦度、洁净度、氧化、颗粒、共面性 |

## 2. Bump 与 UBM 基础

### 2.1. Bump 的概念

Bump（凸点）可以指焊料凸点，也可以指铜柱微凸点（micro-bump / μbump）。Bump 同时承担**三类功能**：

1. **电连接**：连接 chip pad / RDL pad / interposer pad / substrate pad，提供信号、电源和地的导电通路
2. **机械连接**：支撑芯片；保持芯片与基板/中介层之间的间隙；承受热循环、翘曲和封装应力
3. **界面反应区域**：焊料与 UBM/pad 反应形成 IMC；决定界面强度、脆性和长期可靠性

### 2.2. Bump 在三维集成互连中的位置

| 位置 | 常用 bump 类型 |
|------|---------------|
| Die ↔ package substrate | C4 bump（传统倒装芯片互连） |
| Die ↔ Si interposer / RDL interposer | **C2 bump / Cu pillar bump**（2.5D 集成） |
| Die ↔ die | **Cu pillar microbump** 或 **hybrid bonding pad**（无 bump，3D 堆叠） |
| Interposer ↔ package substrate | C4 bump 或较大 pitch 焊球连接 |

### 2.3. C4 vs C2（Cu Pillar Bump）

| 对比项 | C4 Bump | C2 / Cu Pillar Bump |
|--------|---------|---------------------|
| 主体材料 | Solder（焊料） | Cu pillar + solder cap |
| 典型 pitch | ≥50 μm | **<50 μm** |
| 自对准能力 | **很好**（熔融焊料表面张力） | **很弱**（焊料少） |
| 热导率 | 焊料约 55~60 W/m·K | Cu 柱有效热导率更高 |
| 电阻率 | 焊料约 0.12~0.14 μΩ·m | Cu 柱有效电阻率更低 |
| 主要优势 | 工艺成熟 | 细 pitch、电热性能好 |
| 主要问题 | pitch 缩小受限 | 应力、共面性、TCB 窗口敏感 |

**C2 的优势**：
- pitch 可进一步缩小
- Cu 热导率和电导率更好
- stand-off 高度更可控
- 减少焊料体积 → 降低焊料横向塌陷和桥连风险

**C2 的挑战**：
- 焊料少 → 自对准能力弱
- Cu 柱较硬 → 对 low-k/ELK 介质应力更大
- 对共面性、对准和 TCB 工艺窗口更敏感

**实际产品中的 C2 和 C4**（以 Amkor Double POSSUM 为例）：
C4：grandma die to substrate；mother die to grandma die
C2：daughter die to mother die

### 2.4. UBM（凸点下金属化层）

UBM 通常为**粘附层 + 阻挡层 + 润湿层**组合：

| 功能层 | 作用 | 常见材料组合 |
|--------|------|-------------|
| **Adhesion layer（粘附层）** | 增强与 pad/passivation 粘附 | Ti, Cr, TiW |
| **Barrier layer（阻挡层）** | 阻挡 Sn/Cu/Al 互扩散 | TiW, Ni, Ta/TaN, TiN |
| **Wetting layer（润湿层）** | 改善焊料润湿 | Cu, Ni, Au |
| **Seed layer（种子层）** | 为电镀 Cu 或焊料提供导电通路 | Cu |
| **Surface finish（表面处理）** | 防氧化、改善键合 | Au, ENIG, ENEPIG |

UBM 的整体要求：
- 与 chip pad 低接触电阻
- 与 passivation/dielectric 良好附着
- 与焊料或 Cu pillar 良好润湿/连接
- 阻挡 Sn/Cu/Al/Ni 等元素不受控扩散
- 为电镀提供连续导电种子层
- 在热循环和装配应力下保持界面稳定

### 2.5. Cu Pillar Bump 的考量

**采用 Cu pillar 的原因**：
- 支持更细 pitch，降低焊料桥连风险
- Cu 柱提供稳定 stand-off
- Cu 热导率高、电阻率低
- 焊料主要承担润湿和连接，而非全部支撑
- 有利于控制焊点几何形状和高度

**带来的新问题**：
- Cu 柱较硬，应力更容易传递到芯片表面
- 焊料体积小，IMC 比例高
- 对 UBM、Ni barrier、solder cap 厚度控制要求提高
- TCB 时对压力、温度和位移更敏感

### 2.6. Bump 尺寸缩微趋势

100μm → 40μm → 20μm → 10μm → 5μm

Bump 尺寸持续缩小，驱动互连密度不断提升。

## 3. μBump 冶金学基础

在传统 C4 焊点中焊料体积较大，冶金反应只占一小部分。在 3D 集成微凸点中，bump 尺寸和 pitch 持续缩小，**IMC 占比升高**——少量 IMC 增厚、空洞或裂纹即可影响整个接头。

### 3.1. 钎焊基本原理

**基本过程**：加热 → 焊料熔化 → 润湿 UBM/pad → 界面反应 → 冷却凝固 → 形成接头

焊接需同时满足的 5 项要求：
1. 形成低电阻电连接
2. 提供足够机械强度
3. 保持可控的界面反应
4. 兼容芯片 BEOL 和封装材料热预算
5. 避免过度腐蚀母材或生成过厚脆性 IMC

### 3.2. 焊料的润湿

接触角 θ < 90°：润湿较好；θ > 90°：润湿不良（可导致接触面积不足甚至开路）。

**影响润湿的因素**：UBM/pad 表面材料、表面氧化膜和污染、flux 或表面活化、焊料成分、温度和保温时间

改善润湿的方向：提高 γ_SV（固-气界面张力）、降低 γ_SL（固-液界面张力）或降低 γ_LV（液-气界面张力）

### 3.3. 焊料的选择

**选择条件**：液相线温度低于母材、良好润湿、有限母材侵蚀速率、无削弱接头的成分或杂质。

**常见 Sn 基焊料体系**：

| 体系 | 共晶温度 | 特点 | 意义 |
|------|----------|------|------|
| **Sn-Pb** | 183°C | 共晶温度低，润湿性好 | 传统体系，受 RoHS 限制 |
| **Sn-Ag** | 221°C | 润湿性可接受，共晶温度较高 | 无铅体系基础之一 |
| **Sn-Bi** | 139°C | 低温共晶 | 低温工艺可选，Bi 脆性需注意 |
| **Sn-Ag-Cu (SAC)** | 217°C | 综合性能较好 | **最常用无铅焊料体系** |
| **Sn-Cu** | 227°C | 成本较低，反应简单 | 常见界面反应研究体系 |

### 3.4. 界面反应与 IMC

金属材料接触反应可能形成：两相混合物 → 固溶体 → **金属间化合物（IMC）**

IMC 由两种或多种金属按特定化学计量比结合，具有混合的金属键/共价键/离子键特征，通常导电、**硬而脆**。

**Cu-Sn 体系**（微凸点中最关键的焊接反应之一）：
Cu + Sn → Cu₆Sn₅ → 再与 Cu 反应 → Cu₃Sn

**工程影响**：
- 适量 Cu₆Sn₅ → 良好冶金连接
- Cu₆Sn₅ 及 Cu₃Sn 持续生长 → 脆性和 Kirkendall void 风险
- μbump 中焊料体积小 → Cu-Sn 反应可能快速消耗焊料
- IMC 厚度和形貌影响剪切强度、疲劳和电迁移可靠性

**Ni-Sn 体系**：
Ni + Sn → Ni₃Sn₄
Ni 与 Sn 反应远比 Cu 慢 → 在 Cu pillar μbump 中常用 Ni 作为润湿及扩散阻挡层

**IMC 生长动力学**：
d = k · tⁿ
其中 k = A·exp(-E/RT)
n ≈ 0.5：扩散控制；n ≈ 1：界面反应控制
**温度指数影响 IMC 增厚速率**——温度升高，IMC 快速生长

## 4. Bumping 工艺

### 4.1. Bumping 方法总览

| 方法 | 基本思路 | 优点 | 局限 | 适用场景 |
|------|----------|------|------|----------|
| **Stencil Printing** | 钢网印刷焊膏并回流 | 简单、低成本、不需光刻 | 难以细 pitch，体积收缩和高度差大 | 大 pitch、低成本 bump |
| **Solder Ball Placement** | 放置预成形焊球并回流 | 工艺直观，适合较大焊球 | 细 pitch 困难，设备/焊球尺寸受限 | BGA、较大 pitch 焊球 |
| **Evaporation** | 蒸发沉积焊料/金属（C4 路线） | 早期 C4 路线 | 成本高，材料利用率低 | 早期或特殊应用 |
| **Electroplating（电镀）** | 光刻开口后电镀 Cu/焊料 | 适合细 pitch 和高 I/O | 工艺复杂，需控制均匀性 | **C4、C2、Cu pillar 主流路线** |
| **C4NP** | 预制焊球/焊料转移 | 可控制焊料量 | 工艺专用性强 | 特定 C4 制造路线 |

### 4.2. Stencil Printing 流程

制备带开口的金属模板 → 焊膏通过模板印刷到 pad → 移除模板 → 回流形成焊料凸点 → 清洗与检测

尺寸越细小，越依赖**光刻 + 电镀**实现精确形貌控制。

### 4.3. Cu Pillar 电镀工艺

**电流密度均匀性问题**：电镀 bump 阵列时局部电流密度不均匀。
- PR 开口边缘：电流密度较高
- 中心区域：沉积较慢 → **鞍型轮廓**
- 影响因素：晶圆边缘与中心电场差异、PR 开口尺寸、图形密度、开口边缘电场集中、溶液传质和添加剂分布、电流波形（直流/脉冲/反向脉冲）

**共面性差的后果**：后续 TCB 中部分 bump 先接触 → 局部压力过高 → 部分 bump 未接触形成 open → joint shape 不一致 → 阵列良率下降

**电镀 bump 形貌调控**：
- 加速剂浓度影响沉积形貌（加速剂分子在 Cu 表面吸附）
- 电流密度影响沉积形貌
- 整平剂影响表面平坦化

### 4.4. Solder Cap（焊料帽）

Cu pillar 上方常采用 SnAg、SnAgCu 等 Sn 基合金，而非纯 Sn。

**合金化的三个作用**：
1. **降低 Sn whisker（锡晶须）风险**
2. **降低熔点**
3. **改善机械性能**

**两种焊料帽制备方法**：
- **多层沉积 + 回流合金化**：先后沉积 Sn、Ag 等金属层，回流时熔化/扩散/合金化
- **共沉积 + 回流合金化**：利用能斯特方程控制，通过络合剂调节游离金属离子活度，从而调节沉积电势

Sn-Ag 共沉积配方实例：CH₃SO₃H（支持电解质）+ L-半胱氨酸（Ag⁺络合剂）+ 2,2-二硫二苯胺（进一步抑制 Ag 沉积、调控合金成分）

**Solder cap 回流球化**：在助焊剂或甲酸等去氧化氛围中回流。
回流的三项作用：
1. 去除焊料表面氧化物层及污染物，形成低缺陷微观组织
2. 改善电镀/探针测试产生的高度差或表面起伏，形成光滑表面
3. 形成 Cu/焊料界面的牢固冶金结合（伴随 IMC 形成）

### 4.5. 微凸点小尺寸效应

随 bump 尺寸缩小至 10μm 以下：
1. **IMC 比例升高**，空洞率提高
2. **晶粒数量减少**，不均匀性增强
3. **制造精度挑战加大**（undercut/共面性）

## 5. 凸点键合工艺

### 5.1. 传统倒装回流工艺（Mass Reflow）

**7 步流程**：
```
	  1. Bumping 
    → 2. 基板焊盘/UBM 表面制作 
	→ 3. 涂覆助焊剂(Flux)
	→ 4. 芯片与基板对准放置 
	→ 5. 焊料熔化、润湿、塌陷形成接头
    → 6. 去除助焊剂残留 
    → 7. 底填和固化
```

**核心特点**：回流中的**自对准效应**——熔融焊料表面张力将芯片拉回正确位置。

### 5.2. Underfill（底部填充）

**作用**：
- 分担焊点中的热机械应力
- 增强芯片-基板整体刚度
- 改善跌落、弯曲和温循可靠性

**三种底填工艺**：

| 方法 | 原理 | 特点 |
|------|------|------|
| **Capillary underfill (CUF)** | 键合后从边缘毛细流入 | 成熟，但细间隙困难 |
| **Injection flow / Molding underfill (MUF)** | 压力辅助填充 | 适合特定结构 |
| **Compression flow underfill (NUF)** | 先布置底填料再压合 | 常称为 No-flow underfill |

### 5.3. 热压键合（TCB）

**Mass Reflow 的四项局限**：
1. **焊料体积减少** → 表面张力及自对准能力下降
2. **pitch 缩小** → 焊料桥连风险升高；助焊剂清洗困难
3. **芯片/Interposer 更薄** → 翘曲 → 接触高度不一致 → 局部开路及倾斜风险
4. **多层堆叠相互影响** → 前一层在后一层回流中被融化；误差和翘曲累积

**关键缺陷**：warpage、tilt、non-contact open、bridging

**TCB 基本过程（9 步）**：
```
1. 基板或下层芯片固定在加热 stage 上
2. Bond head 拾取上层 die
3. 视觉系统完成高精度对准
4. 键合工具头下降，使凸点与凸点/pad 接触
5. 施加受控压力
6. 快速升温至焊料熔点以上
7. 焊料润湿并形成接头
8. 控制位移和 stand-off
9. 冷却至固相后释放键合工具头
```

**TCB 核心工艺参数**：温度、压力、时间、位移

**TCB 的温度梯度**：键合工具头约 300°C，基板约 160°C → 局部加热，减少整体热影响

**TCB vs Mass Reflow 的间隙均匀性**：TCB 显著优于 Mass Reflow

### 5.4. TCB 工艺的 Underfilling

| 方案 | 应用方式 | 装配过程 | pitch 适应性 | 主要问题 |
|------|---------|----------|-------------|----------|
| **Water-soluble flux + CUF** | flux 先涂覆，键合后清洗，再 underfill | Flux→TCB→Cleaning→CUF | 较大 pitch | 细 pitch 下清洗和底填困难 |
| **No-clean flux + CUF** | 省去清洗 | Flux→TCB→CUF | 中等 | flux residue 需与 underfill 兼容 |
| **Epoxy flux / NCP** | 预置在 substrate 或 chip 上 | Dispense→TCB→Cure | >10 μm | 材料窗口复杂 |
| **NCF / B-stage film** | 贴膜或晶圆级层压 | Lamination→dicing→TCB | >10 μm | 颗粒/填料夹入、膜厚和流动控制 |

## 6. 无凸点键合技术

### 6.1. 从 Bump 到 Bumpless 的动机

C2 bump + TCB 路线面临瓶颈：
- 焊料体积持续减少 → IMC 体积分数升高 → solder bridging 风险增加
- self-alignment 能力下降 → bump stand-off 降低 → underfill 更困难
- 电阻、电感、电容等寄生参数难以继续降低

**Cu-Cu 键合的核心动机**：去除焊料凸点，缩短互连路径，提高 I/O 密度，降低寄生参数。

### 6.2. Cu-Cu 直接键合的原理

两个 Cu 表面在清洁、平坦和对准条件下直接接触，通过压力、温度、表面活化或扩散过程形成连续金属连接。

**微观过程**：
Cu 表面在压力下接触 → 表面微凸体发生局部塑性变形
→ 温度升高促进 Cu 原子扩散 → 原始界面附近发生晶粒长大
→ 界面逐渐消弭 → 由局部接触状态变化为连续 Cu 结构

### 6.3. Cu-Cu 键合的技术难点

**难点来源**：Cu 表面氧化、粗糙和不平坦 → 界面接触率低 → 对温度、压力、键合时间的要求升高

**四个改善方向**：
1. **提升表面宏观和微观平整度**
2. **采用一定缺陷的 Cu 提升再结晶驱动力**（nt-Cu、细晶粒 Cu）
3. **表面活化**：高真空中等离子活化 + 原位键合
4. **表面钝化**：在清洁 Cu 表面化学吸附单分子层（自组装单分子层 SAM），防止 Cu 氧化

### 6.4. Hybrid Bonding（混合键合）

**同时实现介电质键合 + Cu-Cu 键合**，是当前最高密度的永久键合技术。

常见介质：SiO₂、SiCN、Polyimide

**典型流程**：
```
1. Cu pad + dielectric surface fabrication
   → 在介质中形成嵌入式 Cu pad
2. CMP planarization
   → 控制介质粗糙度、Cu dishing 和 Cu recess（纳米级表面形貌）
3. Cleaning
   → 去除颗粒、有机残留、金属污染和氧化物
4. Surface activation
   → 增强介质表面反应活性和亲水性
5. Alignment and pre-bonding
   → 介质表面首先形成初始贴合（室温，氢键结合）
6. Annealing（>300°C）
   → Cu 热膨胀 → Cu-Cu 接触 → Cu 原子扩散 → Cu-Cu 连接形成
```

**关键控制点**：CMP 必须控制**纳米级 Cu recess**——Cu 过高或未 recess 充分会导致键合不良。颗粒是混合键合的大敌（亚微米颗粒即可导致键合空洞）。

**CMP 条件对比**：(a) Cu 过高或未 recess 充分 → (b) 降低 Cu 高度 → (c) 进一步优化

**应用实例**：
- **AMD 3D V-Cache**：CPU 计算 die 上堆叠 Additional 64MB SRAM L3 Cache IC，通过混合键合实现超高密度互连
- **Sony IMX260 / IMX400**：BSI CIS（背面照度图像传感器）的混合键合

### 6.5. 非键合方式的 Cu-Cu 互连（化学沉积互连）

不同于传统键合，这是一种**原位形成互连**的方法。

| 对比 | 传统混合键合 | 化学沉积互连 |
|------|-------------|-------------|
| 工艺温度 | >300°C | **<90°C** |
| 原理 | "先形成互连结构，再键合" | "原位形成互连" |
| 能量供应 | ~0.5 eV/atom（局部） | <0.1 eV/atom（全局） |
| 界面强度 | — | **>80 MPa** |
| 设备需求 | 高 | 低 |

**化学镀反应**：
Cu²⁺ + 2CH₂OH + 4OH⁻ → Cu↓ + 2HCOO⁻ + 2H₂O + H₂↑

**基本流程**：
互连溶液配制 → 芯片清洁 → 活化 → 对准粘合 → 微流道内实施互连 → 清洗

---

## 本讲核心要点

1. **键合是三维集成的最后工序**——决定最终的电气和机械连接质量
2. **互连演进路线**：C4 (≥50μm) → C2/Cu Pillar (<50μm) → Cu-Cu → Hybrid Bonding (pitch 可达 <1μm)
3. **Micobump 冶金学**中 IMC 控制是关键——Cu₆Sn₅/Cu₃Sn 适度生长是冶金连接，过度生长带来脆性和 Kirkendall 空洞
4. **Ni 作为阻挡层优于 Cu**——Ni 与 Sn 的反应速率远慢于 Cu
5. **TCB 替代 Mass Reflow**成为细 pitch 互连的主流方案，核心参数为温度/压力/时间/位移
6. **TCB underfill 四种策略**：水溶性flux+CUF、免洗flux+CUF、NCP、NCF——pitch 适应性和材料窗口不同
7. **Hybrid Bonding** 同时实现介质键合+Cu 键合，CMP 纳米级 Cu recess 控制是核心工艺难点；AMD 3D V-Cache 和 Sony CIS 是典型应用
8. **化学沉积 Cu-Cu 互连**作为新型路线可在 <90°C 下实现 >80MPa 界面强度
