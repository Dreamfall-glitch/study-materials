# 11-MEMS微细加工

```知识地图
MEMS概念 → 微系统基本特征与关键技术
    ↓
三大微细加工技术
    ├── 体微加工（湿法/干法刻蚀 + 刻蚀停止技术）
    ├── 表面微加工（结构层+牺牲层 + 释放）
    └── LIGA技术（X光光刻 + 电镀 + 塑铸）
    ↓
微系统材料（硅基/聚合物/功能/辅助材料）
    ↓
典型MEMS应用（压力传感器/加速度计/DMD/喷墨打印/生物芯片）
```

**本讲回答的核心问题**：MEMS与IC工艺有何异同？三大微细加工技术（体微加工、表面微加工、LIGA）分别如何实现微结构？微系统中有哪些关键材料？

## 1. MEMS概述

### 1.1. 不同地区的称呼

| 地区 | 名称 | 侧重点 |
|:----|:----|:------|
| 美国 | **MEMS**（Micro Electro-Mechanical Systems，微机电系统） | 基于IC工艺的延伸发展 |
| 欧洲 | **Micro-system**（微系统） | 强调系统统一集成 |
| 日本 | **Micro-machine**（微机械） | 突出精密机械加工的优势 |

**共同点**：微、系统、功能。**包容性**：微系统最佳。

**MEMS定义**：由电子和机械组成的集成微器件/微系统，采用与IC兼容的工艺制造，可批量生产；能将计算、传感与执行功能融为一体，尺度在μm与mm之间。

### 1.2. 微系统的主要特征

| 维度 | 特征 |
|:----|:------|
| **功能** | 包含信息采集（感知）、信号处理、执行、显示和控制；或作为承载物完成化学/生化反应 |
| **尺寸** | 系统尺寸mm级、功能元件尺寸μm级；系统以"宏方式"完成任务（如喷墨打印、安全气囊） |
| **加工** | 功能元器件大量采用IC与非IC微细加工 |
| **材料** | 功能材料与非功能材料 |
| **设计** | 创新、具体、专门化、系统级设计 |

### 1.3. MEMS的基本结构

```
微系统 = 传感器（感知） + 致动器（执行） + 信号处理单元（控制）+ 能量供给
```

| 单元 | 功能 | 示例 |
|:----|:-----|:-----|
| **微传感器** | 将外部信号（力/光/热/磁等）转为电信号 | 压力传感器、加速度计 |
| **微致动器** | 将电信号转为机械动作 | 微镜、微阀、微泵 |
| **信号处理** | 处理传感器信号、控制致动器 | IC电路 |
| **能量供给** | 为系统供能 | 电池、能量收集 |

## 2. 微系统制造技术

### 2.1. 总体分类

MEMS制造技术可分为两大类：

| 类型 | 来源 | 特点 |
|:----|:-----|:------|
| **IC基微细加工（2D）** | 光刻、薄膜、刻蚀等IC工艺 | 平面加工，与IC兼容 |
| **非IC微细加工（3D）** | 三种主流技术 | 可制作高深宽比、可动结构 |

### 2.2. 三大主流MEMS加工技术

| 技术 | 代表地区 | 核心思想 |
|:----|:--------:|:---------|
| **体硅微加工**（体微加工） | 美国 | 对硅衬底进行刻蚀形成三维结构 |
| **表面牺牲层工艺**（表面微加工） | 美国 | 淀积结构层+牺牲层→释放，不刻蚀衬底 |
| **LIGA工艺** | 德国 | 光刻+电镀+塑铸，实现高深宽比 |

## 3. 体微加工技术

体微加工（bulk micromachining）是对衬底材料进行刻蚀，形成独特的三维结构。主要在硅衬底上进行，但不限于硅。

### 3.1. 湿法腐蚀

#### (1). 各向同性腐蚀

各向同性腐蚀（isotropic etching）在所有方向的腐蚀速率相同，横向腐蚀与纵向近似相等。

**典型腐蚀液（HNA）**：

HF + HNO₃ + CH₃COOH/水（25:50:80）

**反应机理**：
- HNO₃将Si氧化为SiO₂
- HF将SiO₂溶解为可溶性H₂SiF₆
- 醋酸（CH₃COOH）防止HNO₃分解

总反应：18HF + 4HNO₃ + 3Si → 3H₂SiF₆ + 4NO + 8H₂O

#### (2). 各向异性腐蚀

各向异性腐蚀（anisotropic etching）的腐蚀速率**与晶面取向有关**。

**硅晶体各晶面原子密度**：（111）>（110）>（100）

因此腐蚀速率正是相反的顺序：（100）>（110）>（111）

**典型各向异性腐蚀液**：

| 腐蚀液 | 组成 | (100)/(111)速率比 | 掩膜材料 | 特点 |
|:------|:-----|:----------------:|:---------|:-----|
| **KOH** | 33% KOH @80°C，~1.4μm/min | 高达**400:1** | Si₃N₄几乎不刻蚀，SiO₂ 1-10nm/min | 最常用，速率比最大 |
| **EDP（EPW）** | 乙二胺+邻苯二酚+水 | ~35:1 | SiO₂、Si₃N₄、Au、Cr | 腐蚀表面光滑，但与CMOS不兼容 |
| **TMAH** | 四甲基氢氧化铵 | 较高 | 与CMOS兼容 | 环保 |
| **联氨（N₂H₄）** | N₂H₄+H₂O | 各向异性 | — | 危险（易燃、火箭燃料） |

**KOH各向异性腐蚀**：在（100）硅片上刻蚀时，腐蚀停止在（111）面——形成V型槽或梯形槽结构，是体微加工中最常见的腐蚀方式。

### 3.2. 干法刻蚀

干法刻蚀在MEMS中同样重要，包括物理刻蚀、化学刻蚀（等离子刻蚀）、RIE及**深反应离子刻蚀**（DRIE/ICP）：

- 可实现高深宽比的深刻蚀
- 各向异性好
- Bosch工艺（SF₆/C₄F₈交替）可实现垂直侧壁

### 3.3. 刻蚀停止技术

在体微加工中，要精确控制刻蚀深度非常困难，因此需要**刻蚀停止技术**：

#### (1). 薄膜自停止腐蚀

刻蚀终止于一层不会被刻蚀影响的薄膜（氧化硅、氮化硅、聚酰亚胺甚至金属）。需考虑刻蚀选择性和薄膜应力。

#### (2). 重掺杂自停止腐蚀

KOH对硅的腐蚀速率在掺杂浓度超过阈值 $N_0 \approx 5 \times 10^{19}\ \text{cm}^{-3}$ 时急剧下降。轻掺杂与重掺杂硅的腐蚀速率比可达数百倍。

| 腐蚀液 | 硼掺杂阈值 | 速率下降 |
|:------|:----------:|:--------:|
| KOH | $> 10^{20}\ \text{cm}^{-3}$ | 减小20× |
| EDP | $> 7 \times 10^{19}\ \text{cm}^{-3}$ | 减小50× |
| TMAH | $> 10^{20}\ \text{cm}^{-3}$ | 减小10× |

**缺点**：高掺杂硼与标准CMOS工艺不兼容，且引起高应力。

#### (3). （111）面自停止腐蚀

利用KOH对（100）和（111）面腐蚀速率的巨大差异（可达100~400倍），以（111）面作为停止面。在（100）硅片上腐蚀时，自然终止于（111）面。

### 3.4. 干法 vs 湿法腐蚀对比

| 参数 | 干法腐蚀 | 湿法腐蚀 |
|:----|:--------|:---------|
| 方向性 | 对大多数材料好 | 仅对单晶材料（深宽比可达100） |
| 选择性 | 相对差 | 非常好 |
| 临界尺寸控制 | 非常好（<0.1μm） | 差 |
| 装置成本 | 昂贵 | 便宜 |
| 腐蚀速率 | 0.1~6μm/min | 快（1μm/min以上） |
| 环境影响 | 低 | 高 |

## 4. 表面微加工技术

### 4.1. 基本原理

表面微加工（surface micromachining）**不刻蚀硅衬底本身**，而是通过在硅片表面淀积和刻蚀多层薄膜来制作微结构。

**核心概念**：

| 概念 | 说明 |
|:----|:------|
| **结构层**（structural layer） | 构成可动微结构的材料层，如多晶硅 |
| **牺牲层**（sacrificial layer） | 临时支撑层，最终被刻蚀掉以释放结构 |
| **释放**（release） | 选择性刻蚀掉牺牲层，使结构层悬空或可动 |

**表面微加工流程**：

```
裸片 → 淀积/图形化牺牲层 → 淀积/图形化结构层 → 释放（刻蚀牺牲层）→ 可动结构
```

### 4.2. 结构层与牺牲层常见组合

| 结构层 | 牺牲层 | 应用 |
|:------|:------|:-----|
| **多晶硅** | PSG（掺磷SiO₂） | **最常见组合** |
| 氮化硅 | PSG | 绝缘结构 |
| 金属 | 光刻胶（PR） | 金属微结构 |
| 有机聚合物 | PR或金属 | 微流控器件 |

### 4.3. 表面微加工的关键问题

| 问题 | 说明 |
|:----|:------|
| **薄膜应力** | 二氧化硅通常为**压应力**，氮化硅通常为**拉应力**（可通过提高硅比例改变为压应力）。应力过大会导致结构弯曲或破裂 |
| **粘连**（stiction） | 释放过程中，刻蚀液干燥时表面张力导致可动结构粘附在衬底上，是表面微加工的主要失效模式 |

### 4.4. 体微加工 vs 表面微加工

| 对比项 | 体微加工 | 表面微加工 |
|:------|:---------|:-----------|
| 加工对象 | 硅衬底本身被刻蚀 | 淀积薄膜，硅片不被刻蚀 |
| 结构尺寸 | 可达硅片厚度（几百μm） | 薄膜厚度（几μm） |
| 可动部件 | 容易实现 | 可以实现（但需释放） |
| IC兼容性 | 部分兼容 | **一般是IC兼容的** |

## 5. LIGA技术

### 5.1. 基本概念

**LIGA**是德文缩写，由三种工艺有机结合：

| 缩写 | 德文 | 英文 | 工艺内容 |
|:----|:----|:-----|:---------|
| **LI** | Lithographie | Lithography | **X光深层光刻** |
| **G** | Galvanoformung | Electroplating | **微电铸** |
| **A** | Abformung | Molding | **塑铸（注塑复制）** |

### 5.2. LIGA工艺的主要特点

| 特点 | 指标 |
|:----|:-----|
| 结构高度 | 数百至1000μm |
| 高宽比 | > 200 |
| 侧壁垂直度 | 亚微米级偏差 |
| 横向尺寸 | 小至0.5μm |
| 加工精度 | 可达0.1μm |
| 用材广泛 | 金属、合金、陶瓷、聚合物、玻璃 |

### 5.3. LIGA vs 硅微加工

| 对比项 | LIGA | 硅微加工 |
|:------|:-----|:---------|
| 深宽比 | 更大（>200） | 相对较小 |
| 材料种类 | 金属、陶瓷、塑料等 | 主要是硅和硅基材料 |
| IC兼容性 | **不可**实现片内机电集成 | 与IC兼容，可集成 |
| 光源要求 | 需要同步辐射X光源，设备昂贵 | 继承IC设备，成本较低 |

### 5.4. 准LIGA技术

用紫外光或激光光刻替代同步辐射X光深层光刻，可制作约100μm厚的微结构，但侧壁垂直度仅约85°。适用于对垂直度和深度要求不高的场合。

## 6. 微系统材料

### 6.1. 材料分类

| 分类 | 用途 | 典型材料 |
|:----|:-----|:---------|
| **结构材料** | 形成机械结构 | 单晶硅、多晶硅、氮化硅、氧化硅、金属（Au/Al/Ni/Cu） |
| **功能材料** | 实现传感或驱动 | 压电材料（PZT/PVDF）、形状记忆合金（NiTi）、磁致伸缩材料 |
| **辅助材料** | 加工辅助 | 光刻胶（PMMA/SU-8）、PDMS、牺牲层材料 |

### 6.2. 硅基材料

**硅作为衬底和结构材料的优势**：

| 特性 | 数值/说明 |
|:----|:----------|
| 力学性能 | 杨氏模量与钢相近，密度为不锈钢的1/3 |
| 强度 | 弯曲强度为不锈钢的3.5倍 |
| 熔点 | 1400°C（约铝的2倍） |
| 热膨胀系数 | 比钢小3倍，比铝小10倍 |
| 机械品质因数 | 高达$10^6$，滞后和蠕变几乎为零 |

**多晶硅材料特点**：

- LPCVD沉积（580~650°C，100~400mTorr，SiH₄），工艺成熟
- 低于570°C形成非晶，高于570°C形成多晶膜
- 可通过掺杂调整电阻率（绝缘体→半导体→导体）
- 可氧化、光刻、腐蚀——与IC平面工艺完全兼容

**硅化合物**：

| 材料 | 主要应用 |
|:----|:---------|
| **SiO₂** | 表面微加工牺牲层、电绝缘体、刻蚀掩膜 |
| **Si₃N₄** | 绝缘、表面钝化、刻蚀掩膜、机械结构、阻挡Na⁺扩散 |
| **SiC** | 高温（>200°C）环境下的MEMS器件 |

### 6.3. 功能材料

| 类型 | 材料 | 原理 | 应用 |
|:----|:-----|:-----|:-----|
| **压电材料** | PZT（锆钛酸铅）、PVDF、石英 | 压电效应（外力→电荷）/ 逆压电效应（电压→变形） | 传感器、微执行器、谐振器 |
| **形状记忆合金** | NiTi（最常用） | 温度诱发马氏体相变→形状恢复 | 微夹持器、人工肌肉、医疗植入物 |
| **磁致伸缩材料** | Terfenol-D（Tb₀.₃Dy₀.₇Fe₂） | 磁场→尺寸变化（磁致伸缩系数λs高达1500~2000×10⁻⁶） | 微致动器、声换能器 |

### 6.4. 聚合物材料

| 材料 | 性质 | 应用 |
|:----|:-----|:------|
| **PMMA** | X光光刻胶 | LIGA工艺用光刻胶 |
| **PDMS** | 弹性好、透光、无毒、易加工 | **微流控芯片**最主要材料 |
| **SU-8** | 负性环氧树脂光刻胶，近紫外曝光 | 超高深宽比厚膜结构 |
| **PVDF** | 压电聚合物 | 传感器、执行器 |

## 7. 典型MEMS应用

### 7.1. 压力传感器

最早成熟、最早产业化的MEMS产品：

| 类型 | 原理 | 精度 |
|:----|:-----|:-----|
| **压阻式** | 硅压阻效应 | 精度0.05%~0.01%，年稳定性0.1%/F.S |
| **电容式** | 电容变化 | 高灵敏度 |
| **谐振式** | 谐振频率变化 | 高精度 |
| **SOI型** | 耐高温 | — |

### 7.2. 微加速度计

汽车安全气囊系统的核心元件，如ADI公司的ADXL系列电容式微加速度计。

### 7.3. 数字微镜器件（DMD）

TI公司的数字微镜阵列芯片——每个微镜对应一个像素，尺寸仅16μm×16μm。单个DMD芯片包含130万个微反射镜，用于投影显示。

### 7.4. 微喷（喷墨打印头）

喷墨打印机喷墨头——无卫星液滴，0.5pL墨滴，30kHz频率，年产值数亿美元。

### 7.5. 生物MEMS

**微全分析系统**（μTAS / Lab-on-a-Chip）：将生物/化学领域的样品制备、反应、分离、检测等集成于几平方厘米的芯片上。

## 本讲核心要点

1. **MEMS三地称呼**：美国MEMS（基于IC）、欧洲微系统（系统集成）、日本微机械（精密加工）
2. **微系统构成**：传感器 + 致动器 + 信号处理 + 能量供给
3. **三大微细加工技术**：体微加工（刻蚀衬底）、表面微加工（牺牲层释放）、LIGA（光刻+电镀+塑铸）
4. **体微加工核心**：各向异性腐蚀中（100）>（110）>（111），KOH速率比高达400:1，利用不同晶面腐蚀速率差异实现三维结构
5. **刻蚀停止三种方法**：薄膜自停止、重掺杂自停止（硼>5×10¹⁹cm⁻³）、（111）面自停止
6. **表面微加工核心**：结构层（多晶硅）+ 牺牲层（PSG）+ 释放，不刻蚀衬底；关键问题为薄膜应力和粘连
7. **LIGA工艺**：同步辐射X光光刻 + 微电铸 + 塑铸复制，可实现高宽比>200、侧壁垂直度亚微米的金属/塑料/陶瓷微结构
8. **MEMS材料三大类**：结构材料（硅基）、功能材料（压电/形状记忆/磁致伸缩）、辅助材料（光刻胶/PDMS）
9. **MEMS与IC的关系**：起源于IC工艺、共享光刻/薄膜/刻蚀等加工手段，但在设计、制造（3D结构/可动件）、封装上差异巨大
10. **MEMS典型产品**：压力传感器（最早产业化）、微加速度计（安全气囊）、DMD（130万微镜）、喷墨打印头、生物芯片（μTAS）
