# 01-微电子制造绪论

## 知识地图

```
半导体物理与器件 → 器件的工作原理
    ↓
【微电子制造工程】—— 这些器件是怎么做出来的？
    ↓
晶体生长 → 氧化 → 光刻 → 刻蚀 → 掺杂 → 薄膜沉积 → 金属化 → 封装测试
```

**本讲回答的核心问题**：微电子制造工程学什么？芯片制造从 1947 年的点接触晶体管到今天数十亿晶体管的 SoC，经历了怎样的技术革命？微电子制造的核心工艺模块有哪些？

## 1. 微电子发展历程

### 1.1. 从晶体管到集成电路

| 年份 | 里程碑 | 机构/人物 | 意义 |
|:----:|:------|:---------|:-----|
| 1947 | **第一个点接触晶体管**（point contact transistor） | Bell Lab / Bardeen, Brattain, Shockley | 晶体管时代开端，1956 年诺贝尔奖 |
| 1958 | **第一个 Si 基 MOSFET** | Bell Lab / Atalla | MOSFET 成为 IC 主流器件 |
| 1959 | **第一个集成电路**（IC） | TI / Kilby（Ge 基，12 个器件） | 集成电路概念诞生，2000 年诺贝尔奖 |
| 1959 | **单片硅 IC**（monolithic IC） | Fairchild / Noyce | 奠定了现代 IC 的制造方式 |
| 1960 | **平面工艺**（planar technology） | Fairchild / Jean Hoerni | 彻底改变了 IC 的制造方法 |
| 1963 | **第一个 CMOS 电路** | Fairchild | 低功耗逻辑的起点 |
| 1965 | **摩尔定律**（Moore's Law） | Fairchild / Gordon Moore | 预言 IC 集成度每 2 年翻一番 |
| 1974 | **等比例缩小原则**（scaling rule） | IBM / Dennard | 为器件缩小提供理论指导 |

> **平面工艺**（planar technology）是 Jean Hoerni 于 1960 年在 Fairchild 发明的。其核心是通过氧化、光刻、扩散等步骤在硅片表面制造器件，所有器件在同一平面内——这是现代 IC 制造的基石。

### 1.2. 集成电路的集成度分类

| 缩写 | 英文全称 | 中文译名 | 晶体管数 | 示例时代 |
|:---:|:---------|:---------|:--------:|:--------:|
| **SSI** | Small-Scale Integration | 小型集成电路 | $10 \sim 10^2$ | 1960s |
| **MSI** | Medium-Scale Integration | 中型集成电路 | $10^2 \sim 10^3$ | 1960s~70s |
| **LSI** | Large-Scale Integration | 大规模集成电路 | $10^3 \sim 10^4$ | 1970s |
| **VLSI** | Very Large-Scale Integration | 超大规模集成电路 | $10^5 \sim 10^6$ | 1980s |
| **ULSI** | Ultra Large-Scale Integration | 特大规模集成电路 | $>10^6$ | 1990s |
| **GSI** | Giga-Scale Integration | 极大规模集成电路 | $>10^9$ | 2000s~ |

### 1.3. 摩尔定律与技术节点

**摩尔定律**（Moore's Law）：集成电路上可容纳的晶体管数目大约每 2 年翻一番。这一规律自 1965 年提出以来一直持续至今，推动了整个半导体产业的发展。

**技术节点**（technology node）通常以特征尺寸命名（如 28nm、14nm、7nm、5nm、3nm），但近年来节点的实际物理尺寸已与命名数字不完全对应，更多代表一代工艺的代称。

根据世界半导体贸易统计组织（WSTS）数据，2025 年全球半导体市场规模预计达 **7280 亿美元**（同比增长 15.4%）。

## 2. 国际半导体技术蓝图（ITRS）

**ITRS**（International Technology Roadmap for Semiconductors，国际半导体技术蓝图）是由 EECA（欧洲）、ESIA（欧洲）、JEITA（日本）、KSIA（韩国）、TSIA（中国台湾）和 SIA（美国）等半导体工业协会合作完成的技术发展路线图。目前已被 IRDS（International Roadmap for Devices and Systems）替代。

### 2.1. 等比例缩小原则

**Constant-field Scaling-down Principle**（恒电场等比例缩小原则）由 Dennard 于 1974 年提出：

| 参数 | 关系 | 缩小比例（$\times 1/k$） |
|:----|:----|:--------------------:|
| 器件几何尺寸（$L_g, W_g, t_{ox}, x_j$） | — | $1/k$ |
| 衬底掺杂浓度 $N$ | — | $k$ |
| 电源电压 $V_{DD}$ | — | $1/k$ |
| **器件速度** | $\propto k$ | $k$ |
| **芯片密度** | $\propto k^2$ | $k^2$ |

**效应**：器件尺寸缩小 $k$ 倍，速度提高 $k$ 倍，密度提高 $k^2$ 倍——这是集成电路产业持续发展的物理基础。

### 2.2. 技术发展的两条主线

1. **More Moore**（延续摩尔）：继续缩小晶体管特征尺寸，追求更高的集成密度和性能（28nm → 22nm → 14nm → 7nm → 5nm → 3nm）
2. **More than Moore**（超越摩尔）：在一个系统封装（SiP, System-in-Package）内整合不同类型的技术——包括 3D 封装、模拟器件、图像传感器、嵌入式非易失性存储器、智能功率器件、MEMS、量子技术等

## 3. 微电子器件制造技术的发展

### 3.1. 硅成为主流衬底的原因

与其他半导体材料相比，**硅**（Si, Silicon）之所以成为 IC 主流衬底，主要因为：

1. **Si/SiO₂ 界面特性优异**：硅可以生长高质量的二氧化硅绝缘层，且 Si/SiO₂ 界面态密度极低——这是 MOSFET 能够工作的基础
2. **地壳中硅含量丰富**：硅是地壳中含量第二高的元素（仅次于氧），原材料成本低
3. **单晶硅生长工艺成熟**：已能生长直径达 450mm（18 英寸）的单晶硅锭
4. **平面工艺的发展**：硅的平面工艺最成熟，可以实现高精度的图形化

### 3.2. 早期晶体管制造技术

**生长结晶体管**（grown junction transistor）：在晶体生长过程中通过改变掺杂形成 pn 结——精度低、不可控。

**合金结晶体管**（alloy junction transistor）：将掺杂小球熔合到半导体中形成 pn 结——精度仍有限。

**双扩散台面晶体管**（double-diffused mesa transistor）：通过气相扩散形成基区和发射区，然后腐蚀出台面结构——精度大幅提高，但需要图形化。

### 3.3. 平面工艺——里程碑式的创新

**平面工艺**（planar technology）由 Jean Hoerni 于 1958-1960 年在 Fairchild 发明，其基本流程：

1. **氧化**（oxidation）：在硅片表面生长 SiO₂ 层
2. **光刻**（photolithography）：用光刻胶和掩膜版在 SiO₂ 上定义图形
3. **刻蚀**（etching）：将图形转移到 SiO₂ 层
4. **掺杂**（diffusion/implantation）：通过窗口进行杂质扩散或离子注入
5. **薄膜沉积**（deposition）：蒸发或溅射金属形成互连

应用平面工艺可以实现**多个器件的单片集成**——这是大规模集成电路能够实现的关键技术突破。

### 3.4. IC 技术发展历程

| 年代 | 主流技术 | 关键技术 | 光刻版数量 |
|:----:|:--------|:---------|:---------:|
| **1960s** | BJT | 气相掺杂 + 外延、p-n 结隔离 | 6~8 块 |
| **1970s** | E/D NMOS | **LOCOS 隔离技术**（LOCal Oxidation of Silicon）、耗尽型 NMOS 减小面积 | 与 BJT 相近 |
| **1980s** | **CMOS** | 低功耗、高集成度 | 12~14 块 |
| **1990s** | **BiCMOS** | CMOS（高集成度内部电路）+ BJT（大驱动输出） | $>20$ 块 |
| **2000s~** | 深亚微米 CMOS | Cu 互连、low-k 介质、应变硅、HKMG | $\gg 20$ 块 |

### 3.5. 典型 CMOS 工艺示例

一个典型的 CMOS 工艺包含 **16 块光刻版**（2 层互连）、**超过 100 个工艺步骤**。整个工艺流程可以概括为：

**一条主线**：从硅片准备 → 阱形成 → 栅结构 → 源漏掺杂 → 接触孔 → 金属互连 → 钝化层

**几个核心工艺模块**：光刻（lithography）、氧化（oxidation）、扩散（diffusion）、离子注入（ion implantation）、淀积（deposition）、刻蚀（etching）、接触（contact）

## 4. 集成电路研制的五个阶段

完整的集成电路从设计到上市需经历以下阶段：

1. **电路系统设计**（circuit/system design）：功能定义、架构设计、逻辑设计、电路设计
2. **版图设计与优化**（layout design and optimization）：将电路转换为几何图形，考虑设计规则
3. **集成电路芯片制造**（wafer fabrication）：在硅片上通过一系列工艺步骤制造芯片
4. **封装**（packaging）：将芯片从划片、键合到封装成成品
5. **测试与分析**（testing and analysis）：功能测试、参数测试、可靠性分析

本课程聚焦于**第三步**——芯片制造。

## 本讲核心要点

1. **微电子制造工程**研究的是"芯片怎么造出来的"——从硅片到成品芯片的全部制造工艺。
2. **平面工艺**（planar technology）是整个 IC 制造的基础——通过氧化、光刻、刻蚀、掺杂在硅片表面制造所有器件。
3. **摩尔定律**预言 IC 集成度每 2 年翻一番，**等比例缩小原则**为器件缩小提供了理论指导。
4. **More Moore** 继续缩小晶体管，**More than Moore** 在封装层面整合多样化功能。
5. 硅成为主流衬底的四大优势：Si/SiO₂ 界面优异、地壳含量丰富、单晶生长成熟、平面工艺完善。
6. 从 BJT → NMOS → CMOS → BiCMOS 再到深亚微米 CMOS，每代技术的核心驱动是**功耗-速度-集成度**的权衡。
7. 一个典型的 CMOS 工艺需要 16+ 块光刻版、100+ 个工艺步骤——**光刻、氧化、扩散/离子注入、淀积、刻蚀**是五大核心工艺模块。
8. **ITRS/IRDS** 提供了整个半导体行业的技术发展路线图，指导从设备到工艺的研发方向。
9. 集成电路研制 = 设计 + 版图 + 制造 + 封装 + 测试——本课程聚焦制造环节。
10. 学习微电子制造，需要将各工艺模块（氧化/光刻/刻蚀/掺杂/淀积）的**原理**与**工艺流程**联系起来理解。
