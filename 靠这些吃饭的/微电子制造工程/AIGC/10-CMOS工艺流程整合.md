# 10-CMOS工艺流程整合

```知识地图
CMOS工艺 = 前段制程(FEOL) + 后段制程(BEOL)
    ↓
FEOL：在硅衬底上"建造"晶体管
    ├── 衬底准备 → 隔离(有源区定义) → 阱形成
    ├── 栅极制造（栅氧化层+多晶硅栅）
    └── 源漏制造（LDD→侧墙→重掺杂→Salicide）
    ↓
BEOL：将晶体管"连接"成电路
    ├── 层间介质 → 接触孔 → 金属互连
    └── 多层互连（通孔+上层金属）→ 钝化保护
```

**本讲回答的核心问题**：CMOS集成电路的完整工艺流程是怎样的？FEOL和BEOL分别包含哪些关键步骤？

---

## 1. 整体框架

CMOS制造工艺可分为两大阶段：

| 阶段 | 英文 | 内容 | 比喻 |
|:----|:----|:-----|:-----|
| **前段制程** | FEOL（Front End of Line） | 在硅衬底上制造晶体管（有源器件） | 建造房屋的"结构" |
| **后段制程** | BEOL（Back End of Line） | 制造金属互连将晶体管连接成电路 | 铺设房屋的"水电线路" |

本章先以基本N阱CMOS 9步流程建立整体概念，再以FEOL/BEOL框架展开现代CMOS工艺各步骤的详细说明。以下为典型N阱CMOS的完整剖面结构：

## 2. 基本N阱CMOS流程（9步概述）

以N阱CMOS反相器为例，包含以下9步，每步对应一张光刻版：

|  步骤   |    光刻版    | 核心操作                 | 生成结构              |
| :---: | :-------: | :------------------- | :---------------- |
| **1** |   版1 N阱   | 氧化→光刻→N型掺杂           | 在P衬底上形成N阱（用于PMOS） |
| **2** |  版2 有源区   | 淀积Si₃N₄→光刻→场氧→去Si₃N₄ | 有源区+场氧隔离，鸟嘴效应     |
| **3** |  版3 多晶硅   | 生长栅氧→淀积多晶硅→光刻        | 栅氧化层+多晶硅栅         |
| **4** |   版4 P⁺   | 光刻→P型离子注入            | PMOS源/漏（自对准）      |
| **5** | 版5 N⁺（反版） | 光刻→N型离子注入            | NMOS源/漏（自对准）      |
| **6** |  版6 接触孔   | 生长ILD→光刻→刻孔          | 源/漏/栅接触窗口         |
| **7** |   版7 金属   | 蒸发Al→光刻→刻蚀           | 金属互连线             |
| **8** |    钝化版    | 淀积钝化层→光刻→开压焊点        | 芯片保护层             |
| **9** |     —     | 中测→划片→封装→测试          | 成品IC              |

> **自对准效应**（第4、5步）：多晶硅栅对离子注入起掩模作用，栅下方区域未被掺杂→自动形成沟道，无需额外光刻，避免了套刻误差。

> **反版设计**（第5步）：N⁺版与P⁺版图形正好相反，简化了版图设计。

## 3. FEOL：前段制程（器件制造）

FEOL可进一步分为**衬底与隔离层 → 阱与栅极层 → 源漏与接触层**三个子层次，如同从地基开始逐层建造。

### 3.1. 第一层：衬底准备与隔离

**目的**：准备好洁净的硅表面，在每个晶体管之间建立电学隔离。

#### (1). 衬底选择

采用P⁺重掺杂硅晶圆（~725μm厚），上生长**P⁻轻掺杂外延层**（~2μm），器件制作在外延层中。外延层结晶质量更高、掺杂更精确。

#### (2). STI（浅槽隔离）——替代LOCOS

| 操作 | 说明 |
|:----|:------|
| ①生长垫氧化层 | SiO₂~20nm，缓解后续Si₃N₄应力 |
| ②淀积Si₃N₄ | ~250nm，CVD，作为CMP停止层 |
| ③光刻定义隔离区 | 涂胶→曝光→显影 |
| ④刻蚀Si₃N₄/SiO₂ | RIE（基于氟） |
| ⑤刻蚀Si浅槽 | RIE刻蚀硅，深度~250~500nm |
| ⑥去光刻胶 | 氧等离子体 |
| ⑦CVD SiO₂填充 | 填充隔离浅槽 |
| ⑧CMP平坦化 | 以Si₃N₄为停止层 |
| ⑨去Si₃N₄ | 热磷酸H₃PO₄湿法刻蚀，~180°C |

**STI vs LOCOS**：STI无鸟嘴效应、占用面积小、表面平坦，适用于深亚微米节点。

### 3.2. 第二层：阱与栅极

**目的**：形成不同导电类型的衬底区域，制作控制晶体管开关的核心结构——栅极。

#### (3). 阱形成

- **N阱**：光刻定义区域 → 高能磷（P）离子注入 → 形成N型区域（用于PMOS）
- **P阱**：光刻定义区域 → 高能硼（B）离子注入 → 形成P型区域（用于NMOS，双阱工艺）
- **退火**：600~1000°C，修复注入损伤+电激活杂质；RTP可减少扩散

#### (4). 牺牲氧化层

生长~25nm氧化层→HF去除。作用：捕获离子注入引入的硅表面缺陷，净化表面。

#### (5). 栅氧化层

**最关键步骤**——热氧化生长高质量SiO₂，厚度2~10nm，精度控制±1Å。直接决定阈值电压和可靠性。

#### (6). 多晶硅栅

CVD淀积多晶硅150~300nm → 光刻（使用DUV曝光） → RIE刻蚀 → 多晶硅再氧化（生长薄氧化层作后续缓冲层）

**栅长**由多晶硅栅的刻蚀精度决定，是晶体管速度的首要决定因素。

### 3.3. 第三层：源漏与接触硅化物

**目的**：形成晶体管的源/漏区，并降低其接触电阻。

#### (7). LDD衔接注入

在重掺杂源/漏之前，先进行低能量、低掺杂的浅注入，形成紧邻沟道的轻掺杂扩展区：

| 晶体管 | 注入离子 | 作用 |
|:------|:--------|:-----|
| NMOS | As⁻（砷） | 形成N⁻扩展区 |
| PMOS | BF₂⁺（氟化硼） | 形成P⁻扩展区 |

**目的**：削弱栅附近的热载流子效应（hot-carrier effect），改善短沟道特性。

#### (8). 侧墙（Spacer）形成

CVD Si₃N₄（120~180nm）→ RIE各向异性刻蚀（水平表面刻蚀掉，栅侧壁保留）

**作用**：侧墙精确定位后续重掺杂源/漏注入的边界，形成LDD-spacer结构。

#### (9). 源/漏重掺杂

- NMOS：As⁺离子注入（浅深度、重掺杂→N⁺）
- PMOS：BF₂⁺离子注入（浅深度、重掺杂→P⁺）
- RTP快速退火激活杂质

侧墙阻挡了栅区附近的注入——实现了自对准。

#### (10). Salicide（自对准硅化物）

1. **Ti淀积**：溅射20~40nm覆盖整个晶圆
2. **RTP退火**：800°C，N₂气氛——Ti与Si（多晶硅/源漏）接触区域反应形成TiSi₂
3. **湿法刻蚀**：NH₄OH+H₂O₂去除未反应Ti，保留TiSi₂

**作用**：降低源/漏/栅的接触电阻，提高速度。

## 4. BEOL：后段制程（互连制造）

BEOL将完成制造的晶体管通过金属导线连接成电路，从接触孔开始逐层向上搭建互连系统。

### 4.1. 层间介质与接触孔

#### (11). BPSG淀积

CVD淀积BPSG（硼磷硅玻璃，~1μm），高温回流平坦化。SiO₂中掺硼磷改善流动性，还可禁锢污染物（如Na⁺）。

→ CMP进一步平坦化。

#### (12). 接触孔

光刻定义接触孔位置 → RIE刻蚀BPSG（基于氟） → 暴露源/漏/栅的TiSi₂表面

#### (13). W塞填充

| 操作 | 说明 |
|:----|:------|
| TiN淀积 | 溅射~20nm，作粘附层+扩散阻挡层 |
| CVD W填充 | 厚度不小于接触孔直径的一半 |
| CMP | 去除表面多余W/TiN，留下钨塞 |

**W塞替代传统Al接触**：深亚微米下CVD W的台阶覆盖性远优于溅射Al。

### 4.2. 金属互连层

#### (14). Metal1

多层金属叠层结构（溅射）：

| 层次 | 材料 | 厚度 | 作用 |
|:----|:----|:----:|:-----|
| 底层 | Ti | 200Å | 电迁移阻挡层 |
| 第二层 | TiN | 500Å | 扩散阻挡层 |
| 主导体 | Al-Cu | 5000Å | 主要互连（加Cu提高抗电迁移） |
| 顶层 | TiN | 500Å | 抗反射层（减少光刻反射） |

→ 光刻→基于氯的RIE刻蚀→去胶

#### (15). 上层金属与通孔

**IMD**（金属间介质）：CVD SiO₂，填充金属线间空隙 → CMP平坦化

**通孔（Via）**：光刻→RIE刻蚀→TiN+CVD W填充→CMP，连接不同金属层

**Metal2**：比Metal1更厚更宽，承载更大电流；与Metal1垂直布线减小感应耦合

### 4.3. 钝化与压焊

#### (16). 钝化层

淀积钝化层（Si₃N₄/SiO₂/聚酰亚胺）→光刻打开压焊点（bond pad）区域→提供外界电接触

**至此，完整的CMOS管芯制造完成。**

## 5. 工艺流程总览

### 5.1. FEOL总览（从下至上三层）

```
第三层（源漏接触层）
    ┌─────────────────────────────────┐
    │ Salicide TiSi₂  │ 侧墙  │  TiSi₂ │
    │ N⁺源/漏    │ spacer│P⁺源/漏│
    │ N⁻ LDD     │       │P⁻ LDD │
    └─────────────────────────────────┘
第二层（栅极层）
    ┌─────────────────────────────────┐
    │    多晶硅栅     │    多晶硅栅     │
    │   栅氧化层      │   栅氧化层      │
    └─────────────────────────────────┘
第一层（衬底隔离层）
    ┌────────────┬───────────────────┐
    │  STI  │  P阱  │ STI │ N阱 │ STI │
    │       │  P⁻外延层         │     │
    │       │  P⁺衬底           │     │
    └────────┴───────────────────────┘
```

### 5.2. BEOL总览（从下至上）

```
    ┌─────────────────────────────────┐
    │         钝化层（Si₃N₄/SiO₂）      │
    ├─────────────────────────────────┤
    │        Metal2（更厚更宽）         │
    ├─────────────────────────────────┤
    │        IMD + Via + W塞          │
    ├─────────────────────────────────┤
    │        Metal1（Al-Cu叠层）        │
    ├─────────────────────────────────┤
    │        BPSG + W塞接触孔           │
    └─────────────────────────────────┘
    ┌───── FEOL 晶体管（如上） ──────┐
```

## 本讲核心要点

1. **CMOS工艺 = FEOL（造晶体管）+ BEOL（布互连线）**——FEOL从衬底开始逐层构建器件，BEOL从接触孔开始逐层搭建互连
2. **FEOL三层结构**：第一层（衬底+STI隔离）→ 第二层（阱+栅氧+多晶硅栅）→ 第三层（LDD+侧墙+N⁺/P⁺+Salicide）
3. **STI**（刻槽+SiO₂填充+CMP）替代LOCOS，消除鸟嘴效应，适用于深亚微米节点
4. **栅氧化层**是工艺最关键步骤——厚度2~10nm，精度控制±1Å，直接决定器件性能
5. **自对准**：多晶硅栅作为离子注入的天然掩模，自动定义沟道位置，避免光刻套刻误差
6. **LDD+侧墙**：轻掺杂扩展区抑制热载流子效应，侧墙精确定位重掺杂源/漏边界
7. **Salicide**：Ti→RTP→TiSi₂→去未反应Ti，降低源/漏/栅接触电阻
8. **W塞**替代Al接触：CVD W台阶覆盖性好，TiN作粘附+扩散阻挡层
9. **Al-Cu叠层金属**：Ti(电迁移阻挡)/TiN(扩散阻挡)/Al-Cu(导体)/TiN(抗反射)，多层结构兼顾电学与工艺要求
10. **九步流程 + 七张光刻版**：N阱版→有源区版→多晶硅版→P⁺版→N⁺版（反版）→接触孔版→金属版
