# 02-连续与离散系统的时域分析

## 知识地图

```
信号与系统基础（已学）—— 信号分类、LTI系统定义、卷积
    ↓
【时域分析】—— 直接在时间域求解系统对激励的响应
    ↓
频域分析（傅里叶）→ 复频域分析（拉普拉斯/Z变换）
```

**本讲回答的核心问题**：给定系统的微分方程（连续）或差分方程（离散）和输入信号，如何直接求出系统的输出响应？

---

## 1. 连续时间系统的时域分析

### 1.1. 线性常系数微分方程

连续时间 LTI 系统可以用 $n$ 阶线性常系数微分方程描述：

$$
\frac{d^n r}{dt^n} + a_{n-1}\frac{d^{n-1}r}{dt^{n-1}} + \cdots + a_0 r = b_m\frac{d^m e}{dt^m} + \cdots + b_0 e
$$

### 1.2. 经典法：齐次解 + 特解

微分方程的全解 = **齐次解**（齐次方程的解，由系统本身决定） + **特解**（与激励信号形式有关）：

$$
r(t) = r_h(t) + r_p(t)
$$

**齐次解 $r_h(t)$** 的求法（特征方程法）：

设 $r_h(t) = Ae^{\lambda t}$，代入齐次方程得特征方程：

$$
\lambda^n + a_{n-1}\lambda^{n-1} + \cdots + a_0 = 0
$$

根据特征根形式写出齐次解：

| 特征根情况 | 齐次解对应项 |
|:----------:|:------------|
| 单实根 $\lambda$ | $A e^{\lambda t}$ |
| $k$ 重实根 $\lambda$ | $(A_0 + A_1 t + \cdots + A_{k-1}t^{k-1})e^{\lambda t}$ |
| 共轭复根 $\lambda = \alpha \pm j\beta$ | $e^{\alpha t}(A\cos\beta t + B\sin\beta t)$ |

**特解 $r_p(t)$** 的求法（待定系数法）：

| 激励信号 $e(t)$ | 特解形式（待定系数） |
|:---------------:|:-------------------:|
| 常数 $E$ | $P$（常数） |
| $t^n$ | $P_n t^n + P_{n-1}t^{n-1} + \cdots + P_0$ |
| $e^{\alpha t}$（$\alpha$ 非特征根） | $P e^{\alpha t}$ |
| $e^{\alpha t}$（$\alpha$ 为 $k$ 重特征根） | $P t^k e^{\alpha t}$ |
| $\cos(\omega t)$ 或 $\sin(\omega t)$ | $A\cos(\omega t) + B\sin(\omega t)$ |
| $t^n e^{\alpha t}\cos(\omega t)$ | 多项式×指数×三角的组合 |

**求解步骤**：
1. 求特征方程，得到齐次解形式
2. 根据激励形式设特解，代入原方程确定系数
3. 全解 = 齐次解 + 特解
4. 利用初始条件（$r(0^+), r'(0^+), \dots$）确定齐次解中的待定系数

### 1.3. 零输入响应与零状态响应

将系统的完全响应分解为**零输入响应**（仅由初始状态引起）和**零状态响应**（仅由输入信号引起）：

$$
r(t) = r_{zi}(t) + r_{zs}(t)
$$

**零输入响应** $r_{zi}(t)$：
- 系统方程右端为 $0$，代入初始条件求解齐次方程
- 形式与齐次解相同，系数由 $0^-$ 时刻的初始储能决定

**零状态响应** $r_{zs}(t)$：
- 初始状态为 $0$（系统初始松弛），仅由输入激励产生
- $r_{zs}(t) = e(t) * h(t)$（卷积）

**自由响应与强迫响应**：
- **自由响应**：齐次解部分（由系统特征根决定，即使激励停止后仍可能存在）
- **强迫响应**：特解部分（与激励信号有相同的形式）

### 1.4. 冲激响应 $h(t)$

**冲激响应** $h(t)$ 是系统在零状态下对单位冲激信号 $\delta(t)$ 的响应。

$h(t)$ 的求法：
1. 令 $e(t) = \delta(t)$，$r(t) = h(t)$
2. 代入微分方程，利用 $\delta(t)$ 及其导数匹配系数
3. 或通过系统的特征根和 $n$ 与 $m$ 的关系直接写出形式

 **例2.2.2**：通过冲激响应求解系统的零状态响应和完全响应。
 
### 1.5. 卷积积分的计算

对任意输入 $e(t)$，系统的零状态响应为卷积积分：

$$
r_{zs}(t) = e(t) * h(t) = \int_{-\infty}^{\infty} e(\tau) h(t - \tau)\,d\tau
$$

**图解法步骤**（四步走）：
1. **反转**：将 $h(\tau)$ 反转为 $h(-\tau)$
2. **平移**：$h(-\tau)$ 向右平移 $t$（$t > 0$）得 $h(t - \tau)$
3. **相乘**：$e(\tau)$ 与 $h(t - \tau)$ 相乘
4. **积分**：对乘积在 $\tau$ 上积分

**卷积的常用性质**：
- $e(t) * \delta(t - t_0) = e(t - t_0)$
- $e(t) * u(t) = \int_{-\infty}^{t} e(\tau)\,d\tau$
- $\frac{d}{dt}[e(t) * h(t)] = \frac{de}{dt} * h(t) = e(t) * \frac{dh}{dt}$

**例2.6.4**：计算正弦信号与矩形脉冲的卷积。

## 2. 离散时间系统的时域分析

### 2.1. 线性常系数差分方程

离散时间 LTI 系统可以用 $N$ 阶线性常系数差分方程描述：

$$
r[n] + a_1 r[n-1] + \cdots + a_N r[n-N] = b_0 e[n] + b_1 e[n-1] + \cdots + b_M e[n-M]
$$

**前向差分 vs 后向差分**：在信号与系统中，通常使用**后向差分形式**（因为物理可实现系统通常是因果的，输出只依赖于过去的输入和输出）。

### 2.2. 经典法：齐次解 + 特解

**齐次解 $r_h[n]$**：设 $r_h[n] = A\lambda^n$，代入齐次差分方程得特征方程：

$$
\lambda^N + a_1\lambda^{N-1} + \cdots + a_N = 0
$$

| 特征根情况 | 齐次解对应项 |
|:----------:|:------------|
| 单实根 $\lambda$ | $A \lambda^n$ |
| $k$ 重实根 $\lambda$ | $(A_0 + A_1 n + \cdots + A_{k-1} n^{k-1})\lambda^n$ |
| 共轭复根 $\lambda = re^{\pm j\theta}$ | $r^n(A\cos n\theta + B\sin n\theta)$ |

**特解 $r_p[n]$**：根据激励序列 $e[n]$ 的形式设定，方法与连续系统类似。

### 2.3. 零输入响应与零状态响应

$$
r[n] = r_{zi}[n] + r_{zs}[n]
$$

**零输入响应 $r_{zi}[n]$**：系统方程右端为零，由初始条件（$n = -1, -2, \dots$ 时刻的输出值）确定系数。

**零状态响应 $r_{zs}[n]$**：初始状态为零，仅由激励序列产生——卷积和。

### 2.4. 单位脉冲响应 $h[n]$

**单位脉冲响应** $h[n]$ 是系统在零状态下对单位脉冲 $\delta[n]$ 的响应。

求解方法：令 $e[n] = \delta[n]$，代入差分方程，用递推或待定系数法求出 $h[n]$。

### 2.5. 卷积和的计算

对任意输入 $e[n]$，系统的零状态响应为卷积和：

$$
r_{zs}[n] = e[n] * h[n] = \sum_{k=-\infty}^{\infty} e[k] h[n - k]
$$

**图解步骤**（与连续类似）：
1. 将 $h[k]$ 反转为 $h[-k]$
2. 平移 $n$ 得 $h[n - k]$
3. 将 $e[k]$ 与 $h[n - k]$ 逐点相乘
4. 对 $k$ 求和

**列表法**适用于有限长序列的卷积和计算——将 $e[n]$ 和 $h[n]$ 排成行列，交叉相乘后沿斜线求和。

> **卷积和与卷积积分的对比**：
> - 连续：$r(t) = \int e(\tau)h(t-\tau)d\tau$——积分是连续的
> - 离散：$r[n] = \sum_{k} e[k]h[n-k]$——求和是离散的
> - 两者的数学结构完全对应，只是积分变为求和

## 3. 系统的因果性与稳定性

### 3.1. 因果性

**连续系统**：LTI 系统因果 $\iff h(t) = 0,\ \forall t < 0$

此时卷积积分的下限为 $0$：

$$
r(t) = \int_{0}^{\infty} e(t - \tau) h(\tau)\,d\tau = \int_{-\infty}^{t} e(\tau) h(t - \tau)\,d\tau
$$

**离散系统**：LTI 系统因果 $\iff h[n] = 0,\ \forall n < 0$

卷积和的下限为 $0$：

$$
r[n] = \sum_{k=0}^{\infty} e[n - k] h[k]
$$

### 3.2. BIBO 稳定性

系统**稳定**的充要条件：单位冲激响应（或单位脉冲响应）**绝对可积**（连续）或**绝对可和**（离散）。

**连续**：$\int_{-\infty}^{\infty} |h(t)|\,dt < \infty$

**离散**：$\sum_{n=-\infty}^{\infty} |h[n]| < \infty$

---

## 4. 连续与离散时域分析的对应关系

|     项目      |                   连续时间系统                    |                  离散时间系统                  |
| :---------: | :-----------------------------------------: | :--------------------------------------: |
|  **系统描述**   | 微分方程 $\sum a_k r^{(k)} = \sum b_k e^{(k)}$  | 差分方程 $\sum a_k r[n-k] = \sum b_k e[n-k]$ |
|  **特征方程**   | $\lambda^n + a_{n-1}\lambda^{n-1}+\cdots=0$ | $\lambda^N + a_1\lambda^{N-1}+\cdots=0$  |
|  **基元信号**   |               $\delta(t)$（冲激）               |             $\delta[n]$（脉冲）              |
| **冲激/脉冲响应** |                   $h(t)$                    |                  $h[n]$                  |
|  **零状态响应**  |             $e(t) * h(t)$（卷积积分）             |            $e[n] * h[n]$（卷积和）            |
|  **因果条件**   |               $h(t)=0,\ t<0$                |              $h[n]=0,\ n<0$              |
|  **稳定条件**   | $\int_{-\infty}^{\infty}\|h(t)\|dt<\infty$  | $\sum_{-\infty}^{\infty}\|h[n]\|<\infty$ |

---

## 本讲核心要点

1. **经典法**：微分/差分方程的全解 = **齐次解 + 特解**，齐次解形式由特征根决定，特解形式由激励决定
2. **零输入响应**由系统初始储能决定；**零状态响应**由外加激励决定——两者叠加得完全响应
3. **冲激响应 $h(t)$ / 单位脉冲响应 $h[n]$** 是系统的"指纹"——LTI 系统完全由其决定
4. **卷积**是时域分析的核心运算——连续是积分 $\int$，离散是求和 $\sum$，二者数学结构完全对应
5. **图解卷积四步法**（反转→平移→相乘→积分/求和）是理解卷积物理意义的有效工具
6. **因果性** $\iff h(t)=0\ (t<0)$；**BIBO稳定性** $\iff \int\|h\|<\infty$（连续）/ $\sum\|h[n]\|<\infty$（离散）
7. **连续与离散时域分析的对应关系**贯穿整个课程——微分↔差分，积分↔求和，$h(t)$↔$h[n]$
