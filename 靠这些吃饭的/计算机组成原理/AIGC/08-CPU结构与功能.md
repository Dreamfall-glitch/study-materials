## 1. CPU的功能

CPU（Central Processing Unit，中央处理器）是计算机硬件的核心部件，由运算器和控制器组成。早期运算器和控制器不在同一芯片上，现在的CPU内除含有运算器和控制器外，还集成了Cache。

CPU具有以下五大功能：

| 功能 | 含义 | 通俗理解 |
|:----|:-----|:---------|
| **指令控制** | 控制程序的顺序执行——取指令、分析指令、执行指令 | 程序的总指挥，保证各条指令按正确顺序执行 |
| **操作控制** | 产生完成每条指令所需的控制命令 | 发号施令的人——告诉每个部件该做什么 |
| **时序控制** | 对各种操作实施时间上的控制 | 节拍器——确保操作在正确的时间点发生 |
| **数据运算** | 对数据进行算术和逻辑运算 | 计算器——ALU干的就是这个 |
| **中断处理** | 处理各种异常和中断请求 | 应急处理员——遇到突发情况及时响应 |

## 2. CPU的组成与各部件的功能

### 2.1. 总体结构

CPU的内部结构框图如下：

CPU内部包含以下关键部件：

| 部件 | 作用 |
|:----|:------|
| **ALU**（算术逻辑单元） | 完成算术运算和逻辑运算 |
| **CU**（控制单元） | 产生各种微操作命令序列 |
| **寄存器组** | 包括专用寄存器和通用寄存器（存放操作数） |
| **中断系统** | 用于处理各种中断 |
| **内部总线** | 连接CPU内部各部件的数据通路 |

### 2.2. CPU的寄存器

#### 专用寄存器

每个寄存器都有其特定的用途：

| 寄存器 | 全称 | 作用 | 通俗理解 |
|:------|:-----|:-----|:---------|
| **PC** | 程序计数器（Program Counter） | 存放现行指令的地址，通常与MAR直接相连，提供取指令的地址 | "指路牌"——告诉CPU下一条指令在哪 |
| **IR** | 指令寄存器（Instruction Register） | 存放当前正在执行的指令 | "当前任务单" |
| **SP** | 堆栈指针（Stack Pointer） | 指示栈顶位置 | "栈顶标签" |
| **MAR** | 存储器地址寄存器（Memory Address Register） | 存放要访问的存储单元地址 | "目的地定位器" |
| **MDR** | 存储器数据寄存器（Memory Data Register） | 存放从存储器读出或写入的数据 | "中转站" |
| **PSW** | 程序状态字（Program Status Word） | 存放标志位（CF/ZF/SF/OF等） | "状态记录本" |

#### 通用寄存器

通用寄存器由程序员使用，用于存放操作数和中间结果。RISC架构通常有32个通用寄存器（如ARM、RISC-V），CISC架构通常较少（如x86的8个）。

### 2.3. 控制单元（CU）

**功能**：发出各种不同的控制信号。

**输入来源**：
- **时钟信号**——提供时序基准
- **指令寄存器的操作码字段**——决定当前指令需要什么操作
- **标志位**（如CF/ZF/SF/OF）——影响条件跳转等操作
- **来自系统总线的控制信号**——如中断请求、总线请求等

> **自己的话**：CU就像一个乐队的指挥——他拿着乐谱（指令操作码），跟着节拍器（时钟信号），看看听众反应（标志位），同时还要关注有没有突发事件（中断请求），然后指挥每个乐手（各部件）在正确的时间点演奏出正确的音符。

## 3. CPU的三个周期

### 3.1. 指令周期、机器周期和时钟周期

| 概念 | 定义 | 关系 |
|:----|:-----|:-----|
| **指令周期**（instruction cycle） | CPU取出并执行一条指令所需的全部时间 | 包含多个机器周期 |
| **机器周期**（machine cycle） | 所有指令执行过程中的一个基准时间，通常以存取周期作为机器周期 | 包含多个时钟周期 |
| **时钟周期**（clock cycle） | 时钟频率的倒数，也称节拍（T周期），是控制计算机操作的最小单位时间 | 最小时间单位 |

**三者关系图**：

**重要提示**：不能简单说CPU主频越快，计算机运行速度就越快。因为速度不仅与主频有关，还有以下因素：
- 机器周期中所含的时钟周期数
- 指令周期中所含的机器周期数
- 主存的速度
- 是否配备Cache
- 总线的数据传输率
- 硬盘的速度
- 是否采用流水技术
- 还可以用 MIPS 和 CPI 来衡量

### 3.2. 取指周期

**不论什么指令，取指周期都需执行下列微操作**（来自你的笔记p58）：

| 步骤 | 微操作 | 说明 |
|:---:|:------|:------|
| ① | **PC → MAR** | 现行指令地址送MAR |
| ② | **1 → R** | 命令存储器读 |
| ③ | **M(MAR) → MDR** | 现行指令从存储器中读至MDR |
| ④ | **MDR → IR** | 现行指令送IR |
| ⑤ | **OP(IR) → CU** | 指令的操作码送CU译码 |
| ⑥ | **(PC) + 1 → PC** | 形成下一条指令的地址 |

取指周期的数据流动路径：

```
PC → MAR → 存储器 → MDR → IR
                                      → OP(IR) → CU 译码
(PC) + 1 → PC
```

### 3.3. 执行周期

执行周期的微操作**因指令而异**——由操作码决定（不同指令有不同的操作序列）。CU根据指令译码结果，结合时钟信号和标志位，产生相应的控制信号序列。

> **执行周期具体做什么，取决于当前指令是什么**——加法指令执行加法，转移指令改变PC值，访存指令读写存储器。每条指令都有自己的微操作序列。

## 4. CPU的三种控制方式

### 4.1. 同步控制

任何一条指令或指令中任何一个微操作的执行都是事先确定的，并且都是受统一基准时标的时序信号所控制的方式。每一个操作出现的时间与基准时标保持一致。

**特点**：简单、有固定周期、速度较慢（按最慢的操作来设计周期）

**三种同步控制方案**（来自你的笔记p59）：

| 方案 | 说明 |
|:----|:------|
| **定长机器周期** | 一律以最长的微操作序列和最繁的微操作为标准，采用完全统一的节拍 |
| **不定长机器周期** | 大部分操作在较短周期完成，复杂操作延长周期或增加节拍 |
| **中央+局部控制** | 大部分指令统一在较短周期完成，少部分复杂操作（乘除、浮点）采用局部控制 |

### 4.2. 异步控制

不存在基准时标信号，没有固定的周期节拍和严格的时钟同步。微操作的时序由专门的**应答线路**控制——CU发出执行某一微操作的控制信号后，等待执行部件完成操作后发回"回答"或"结束"信号，再开始新的微操作。

**特点**：没有空闲状态（效率高），但结构比同步控制复杂。

### 4.3. 联合控制

同步控制和异步控制相结合。大部分统一操作（如取指、CPU内部操作）采用同步方式控制，少数时间难以确定的操作（如I/O操作）采用异步控制。

## 5. 从经典到现代：CPU架构的发展

### 5.1. Intel 8086（经典16位CPU）

8086是x86架构的起点，于1978年诞生：

**内部结构特点**：
- **BIU**（总线接口单元）和**EU**（执行单元）分工协作——BIU负责取指令和访存，EU负责执行指令，两者可**重叠工作**（早期的流水线思想）
- **分段存储**：段寄存器（CS/DS/SS/ES）+ 偏移地址 → 20位物理地址，寻址1MB空间
- **寄存器**：AX/BX/CX/DX（可拆分为高8位和低8位）+ SI/DI/BP/SP
- **标志寄存器**：9位标志位——CF（进位）、PF（奇偶）、AF（辅助进位）、ZF（零）、SF（符号）、OF（溢出）、IF（中断允许）、DF（方向）、TF（陷阱）

> **老资历**：8086的结构虽然看起来简单，但已经包含了现代CPU的核心要素——取指和执行分离、多种寻址方式、中断系统。它的寄存器模型影响了x86至今40多年。

### 5.2. 现代CPU的共同特征

| 技术 | 说明 |
|:----|:------|
| **超标量** | 每个时钟周期可发射多条指令（如Core架构4~6发射，Apple M1 FireStorm可达8发射） |
| **乱序执行** | 不按程序顺序执行，哪个指令数据准备好就先执行——提高执行单元利用率 |
| **分支预测** | 动态预测分支走向，正确率超95%——减少流水线清空损失 |
| **多级Cache** | L1（靠近核心，最快最小）→ L2 → L3（多核共享，较大较慢） |
| **多核** | 同一芯片集成多个CPU核心 |
| **指令集兼容** | 保持向前兼容（8086程序仍可在现代CPU上运行） |

### 5.3. CPU架构对比

| 对比项 | 8086（经典） | Intel Core（现代x86） | Apple M1（现代ARM） |
|:------|:----------:|:--------------------:|:-----------------:|
| 指令集 | CISC x86-16 | CISC x86-64 | RISC ARMv8-A |
| 发射宽度 | **单发射** | 4~6发射 | **8发射**（FireStorm） |
| 执行方式 | 顺序执行 | **乱序执行** | 乱序执行 |
| 通用寄存器 | 8个（16位） | 16个（64位） | **32个（64位）** |
| Cache | 无片内Cache | L1/L2/L3三级 | L1/L2两级 |
| 工艺 | 3μm | Intel 7（~10nm） | TSMC 5nm |
| 年代 | 1978 | 2022 | 2020 |

## 习题8：CPU结构与功能

### 8.1 概念题

1. **CPU有哪些功能？画出其结构框图并简要说明每个部件的作用。**

> **答**：CPU有五大功能——指令控制、操作控制、时序控制、数据运算、中断处理。CPU结构框图中包含：ALU（运算器）、CU（控制器）、寄存器（专用+通用）、中断系统。其中专用寄存器包括PC、IR、SP、MAR、MDR、PSW等。

2. **控制单元的功能是什么？其输入受什么控制？**

> **答**：控制单元发出的功能是发出各种不同的控制信号。其输入受**时钟信号**、**指令寄存器的操作码字段**、**标志位**和**来自系统总线的控制信号**的控制。

3. **什么是指令周期、机器周期和时钟周期？三者有何关系？**

> **答**：指令周期是CPU取出并执行一条指令所需的全部时间；机器周期是所有指令执行过程中的一个基准时间（通常以存取周期为基准）；时钟周期是主频的倒数，是最小时间单位。一个指令周期包含若干个机器周期，一个机器周期包含若干个时钟周期。

4. **能不能说CPU的主频越快，计算机的运行速度就越快？为什么？**

> **答**：不能。因为速度还与机器周期中的时钟周期数、指令周期中的机器周期数、主存速度、Cache配置、总线带宽、硬盘速度、是否采用流水线等多种因素有关。

5. **取指周期中需要完成哪些微操作？**

> **答**（来自你的笔记p58）：PC→MAR（送地址），1→R（读存储器命令），M(MAR)→MDR（读出指令到MDR），MDR→IR（指令送IR），OP(IR)→CU（操作码送CU译码），(PC)+1→PC（形成下条指令地址）。

### 8.2 简答题

6. **试比较同步控制、异步控制和联合控制的区别。**

> **答**：同步控制有统一时钟节拍——每个操作在固定时间点发生；异步控制无统一时钟——靠应答信号协调，没有空闲等待；联合控制是两者的结合——大部分操作同步，少数复杂/I/O操作异步。

7. **简述8086CPU的寄存器结构。**

> **答**（来自你的笔记p63~64）：8086有8个通用寄存器（AX/BX/CX/DX/SI/DI/BP/SP），其中AX/BX/CX/DX可拆分为高8位和低8位。段寄存器有CS/DS/SS/ES。标志寄存器有9位（CF/PF/AF/ZF/SF/OF/IF/DF/TF）。IP是指令指针（即PC）。

### 8.3 计算题

8. **某CPU主频为2.0GHz，指令周期平均包含4个机器周期，机器周期平均包含3个时钟周期，求每条指令平均执行时间。**

> **解**：时钟周期 = 1/(2.0×10⁹) = 0.5ns。每条指令时间 = 4×3×0.5 = 6ns。MIPS ≈ 1/(6×10⁻⁹)/10⁶ ≈ 167 MIPS。

## 本讲核心要点

1. **CPU五大功能**：指令控制、操作控制、时序控制、数据运算、中断处理
2. **CPU内部组成**：运算器（ALU）+ 控制器（CU）+ 寄存器组 + 中断系统
3. **专用寄存器各有分工**：PC（指令地址）、IR（当前指令）、SP（栈顶）、MAR/MDR（访存）、PSW（状态标志）
4. **取指周期六步微操作**：PC→MAR → 读指令 → MDR→IR → OP(IR)→CU → PC+1——任何指令都必做
5. **执行周期因指令而异**——到底做什么取决于操作码
6. **三级周期关系**：指令周期 ∋ 机器周期 ∋ 时钟周期，主频高≠速度快
7. **三种控制方式**：同步（固定节拍）、异步（应答信号）、联合（主同步+少异步）
8. **8086的贡献**：BIU+EU重心、分段寻址、寄存器模型——奠定了x86生态40年
9. **现代CPU共性**：超标量多发射、乱序执行、分支预测、多级Cache、多核
10. **指令集兼容的代价**：现代x86内部实际将CISC指令翻译为类似RISC的微操作执行——保持接口不变，内部翻天覆地
