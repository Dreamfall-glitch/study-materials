# 02-一维波动方程（直角坐标）

## 知识地图

```
弦振动模型 → 微元受力分析 → 一维波动方程 u_tt = a²u_xx
    ↓
d'Alembert公式 u = f(x-at) + g(x+at)（行波法，无限长弦）
    ↓
有限长弦 → 边界条件 → 分离变量法 u = X(x)T(t)
    ↓
本征值问题 X''+λX=0 → 本征函数 sin(nπx/L) → 通解叠加 → 初始条件定傅里叶系数
```

**本讲回答的核心问题**：一维波动方程如何从物理模型的受力分析中推导出来？行波法和分离变量法各适用于什么场景？为什么驻波和行波本质上是一回事？

---

## 1. 一维波动方程的物理推导

### 1.1. 弦振动模型

考虑一根长为 $L$、线密度为 $\rho$ 的均匀细弦，两端固定于 $x=0$ 和 $x=L$ 处。弦在平衡位置附近做微小横向振动，设 $u(x,t)$ 表示 $x$ 处在 $t$ 时刻的横向位移。

**基本假设**：
- 弦是均匀的，线密度 $\rho$ 为常数
- 弦是完全柔软的（只有张力，无弯曲刚度）
- 振动是微小的（$|u_x| \ll 1$），忽略高阶项
- 弦只在横向（垂直于 $x$ 轴方向）运动，无纵向运动

### 1.2. 微元受力分析

取弦上一小段微元 $[x, x+\Delta x]$，两端受张力 $T$ 作用。由于微小振动假设，张力大小 $T$ 可视为常数（张力变化为高阶小量）。

竖直方向（$u$ 方向）的合力：

左侧张力竖直分量：$-T \sin\alpha \approx -T \tan\alpha = -T u_x(x,t)$（因为 $\alpha$ 很小）
右侧张力竖直分量：$+T \sin\beta \approx +T u_x(x+\Delta x,t)$

竖直方向的合力：

$$
F_y = T[u_x(x+\Delta x, t) - u_x(x,t)] \approx T u_{xx}(x,t) \Delta x
$$

### 1.3. 运动方程

微元的质量为 $\rho \Delta x$，加速度为 $u_{tt}$。由牛顿第二定律 $F = ma$：

$$
\rho \Delta x \cdot u_{tt} = T u_{xx} \Delta x
$$

整理得：

$$
\boxed{u_{tt} = a^2 u_{xx}}, \quad a^2 = \frac{T}{\rho}
$$

其中 $a$ 是波速——弦越紧（$T$ 越大）或弦越轻（$\rho$ 越小），波传播得越快。

> **关键结论**：波动方程从物理上看，就是"加速度 = 波速平方 × 曲率"。曲率 $u_{xx}$ 越大的地方，恢复力越大，加速度也越大。

### 1.4. 定解条件

**初始条件**：$u(x,0) = \varphi(x)$（初始位移），$u_t(x,0) = \psi(x)$（初始速度）。

**边界条件**（两端固定弦）：$u(0,t) = 0$，$u(L,t) = 0$（第一类齐次 Dirichlet 条件）。

## 2. d'Alembert 公式（行波法）

### 2.1. 通解形式

对 $u_{tt} = a^2 u_{xx}$ 做变量代换。引入新变量：

$$
\xi = x - at, \quad \eta = x + at
$$

由链式法则：

$$
\frac{\partial}{\partial x} = \frac{\partial}{\partial\xi} + \frac{\partial}{\partial\eta}, \quad \frac{\partial}{\partial t} = -a\frac{\partial}{\partial\xi} + a\frac{\partial}{\partial\eta}
$$

代入原方程，经过计算得到 $u_{\xi\eta} = 0$。先对 $\eta$ 积分再对 $\xi$ 积分：

$$
u(\xi, \eta) = f(\xi) + g(\eta)
$$

回到原变量：

$$
\boxed{u(x,t) = f(x - at) + g(x + at)}
$$

### 2.2. 物理意义

- $f(x - at)$：以速度 $a$ 向右传播的行波（波形不变）
- $g(x + at)$：以速度 $a$ 向左传播的行波（波形不变）

**任意一维波动都可以分解为左行波和右行波的叠加**——这就是 d'Alembert 公式的核心。

> **通俗理解**：想象一根无限长的弦，你拨一下它，扰动会分成两部分向两侧传播——d'Alembert 公式告诉我们，这其实就是波动方程的全部本质。

### 2.3. 无限长弦的初值问题

对于无限长弦（无边界条件），由初始条件 $u(x,0)=\varphi(x)$、$u_t(x,0)=\psi(x)$ 可得：

$$
f(x) + g(x) = \varphi(x), \quad -af'(x) + a g'(x) = \psi(x)
$$

解得：

$$
\boxed{u(x,t) = \frac{1}{2}[\varphi(x-at) + \varphi(x+at)] + \frac{1}{2a}\int_{x-at}^{x+at} \psi(s)\,ds}
$$

这就是 **d'Alembert 公式**，适用于无限长弦的初值问题。

## 3. 分离变量法（有限长弦）

### 3.1. 应用分离变量法

对于有限长弦 $0 \leq x \leq L$，存在边界条件 $u(0,t) = u(L,t) = 0$。设 $u(x,t) = X(x)T(t)$：

代入波动方程 $X T'' = a^2 X'' T$，除以 $a^2 X T$：

$$
\frac{T''}{a^2 T} = \frac{X''}{X} = -\lambda
$$

得到两个 ODE：

$$
X'' + \lambda X = 0, \quad T'' + \lambda a^2 T = 0
$$

### 3.2. 本征值问题

边界条件 $u(0,t) = 0$ 给出 $X(0) = 0$；$u(L,t) = 0$ 给出 $X(L) = 0$。

这就构成了一个**Sturm-Liouville 本征值问题**：$\begin{cases} X'' + \lambda X = 0 \\ X(0) = X(L) = 0 \end{cases}$

对 $\lambda$ 的三种情况讨论（这是所有分离变量法的标准分析模板）：

| $\lambda$ 取值 | $X(x)$ 的形式 | 能否满足 $X(0)=X(L)=0$ |
|:--------------|:-------------|:---------------------|
| $\lambda < 0$ | $X = C_1 e^{\sqrt{-\lambda}x} + C_2 e^{-\sqrt{-\lambda}x}$ | 只能得到零解（平凡解） |
| $\lambda = 0$ | $X = C_1 + C_2 x$ | 只能得到零解 |
| $\lambda > 0$ | $X = C_1 \cos(\sqrt{\lambda}x) + C_2 \sin(\sqrt{\lambda}x)$ | $X(0)=0 \Rightarrow C_1=0$；$X(L)=0 \Rightarrow \sin(\sqrt{\lambda}L)=0$ |

由 $X(L) = C_2 \sin(\sqrt{\lambda}L) = 0$ 且 $C_2 \neq 0$（否则全是零解），得到：

$$
\sqrt{\lambda_n} L = n\pi \quad (n = 1, 2, 3, \cdots)
$$

**本征值**：

$$
\boxed{\lambda_n = \left(\frac{n\pi}{L}\right)^2}, \quad n = 1, 2, 3, \cdots
$$

**本征函数**（略去比例常数）：

$$
\boxed{X_n(x) = \sin\left(\frac{n\pi x}{L}\right)}
$$

### 3.3. 时间部分

将 $\lambda_n$ 代入 $T'' + \lambda_n a^2 T = 0$：

$$
T_n(t) = A_n \cos\left(\frac{n\pi a}{L}t\right) + B_n \sin\left(\frac{n\pi a}{L}t\right)
$$

### 3.4. 解的叠加

由线性叠加原理：

$$
u(x,t) = \sum_{n=1}^{\infty} \left[A_n \cos\left(\frac{n\pi a}{L}t\right) + B_n \sin\left(\frac{n\pi a}{L}t\right)\right] \sin\left(\frac{n\pi x}{L}\right)
$$

### 3.5. 初始条件定系数

利用初始条件 $u(x,0) = \varphi(x)$ 和 $u_t(x,0) = \psi(x)$：

**第一步**：$u(x,0) = \sum_{n=1}^{\infty} A_n \sin\left(\frac{n\pi x}{L}\right) = \varphi(x)$

这正是 $\varphi(x)$ 在区间 $[0,L]$ 上的**傅里叶正弦级数展开**。由三角函数的正交性：

$$
A_n = \frac{2}{L} \int_0^L \varphi(x) \sin\left(\frac{n\pi x}{L}\right) dx
$$

**第二步**：$u_t(x,0) = \sum_{n=1}^{\infty} \frac{n\pi a}{L} B_n \sin\left(\frac{n\pi x}{L}\right) = \psi(x)$

同样展开：

$$
B_n = \frac{2}{n\pi a} \int_0^L \psi(x) \sin\left(\frac{n\pi x}{L}\right) dx
$$

### 3.6. 驻波形式

将解改写为：

$$
u_n(x,t) = C_n \cos\left(\frac{n\pi a}{L}t - \delta_n\right) \sin\left(\frac{n\pi x}{L}\right)
$$

其中 $C_n = \sqrt{A_n^2 + B_n^2}$，$\tan\delta_n = B_n / A_n$。

$n$ 对应的就是第 $n$ 阶**驻波**（standing wave）或**简正模**（normal mode）：
- $\sin(n\pi x / L)$ 为空间部分：$n$ 条波节（节点）
- $\cos$ 为时间部分：以固有频率 $\omega_n = n\pi a / L$ 振动

> **行波 vs 驻波**：
> d'Alembert 公式将解表示为左行波和右行波之和。分离变量法将解表示为驻波的叠加。二者是等价的——两个反方向的行波叠加可形成驻波。弦两端固定时，行波不断反射，最终形成稳定的驻波图案。

**例题**：求解一端固定、另一端自由的弦振动问题，边界条件 $u(0,t)=0$，$u_x(L,t)=0$。

设 $u = X T$，$X$ 的边界条件变为 $X(0) = 0$，$X'(L) = 0$。

对于 $\lambda > 0$，$X = C_1 \cos(\sqrt{\lambda}x) + C_2 \sin(\sqrt{\lambda}x)$。

$X(0)=0 \Rightarrow C_1=0$；$X'(L) = C_2\sqrt{\lambda}\cos(\sqrt{\lambda}L) = 0 \Rightarrow \cos(\sqrt{\lambda}L) = 0$。

本征值：$\lambda_n = \left[\dfrac{(2n-1)\pi}{2L}\right]^2$，本征函数：$X_n = \sin\left(\dfrac{(2n-1)\pi x}{2L}\right)$。

> 一端固定一端自由的弦，其本征频率是两端固定弦的奇数泛音——这是音乐声学中开管和闭管音色差异的来源。

## 本讲核心要点

1. 一维波动方程 $u_{tt} = a^2 u_{xx}$ 从弦振动的牛顿第二定律推导而来，波速 $a = \sqrt{T/\rho}$。
2. d'Alembert 公式 $u = f(x-at) + g(x+at)$ 将任意一维波分解为左行波和右行波——适用于无限长或无界问题。
3. 有限长弦的定解问题用分离变量法：$u = X T$ → 本征值问题 → 叠加 → 初始条件定 Fourier 系数。
4. 本征值 $\lambda_n = (n\pi/L)^2$ 和本征函数 $\sin(n\pi x/L)$ 由边界条件唯一确定，对应第 $n$ 阶简正模。
5. 行波与驻波等价：两端固定时，行波反射形成驻波图案。
6. 不同的边界条件（固定/自由/弹性）产生不同的本征值和本征函数——这是分离变量法的关键一步，在后续所有坐标系中重复出现。
