# 01-计算机系统概论

```知识地图
计算机系统 = 硬件 + 软件
    ↓
冯·诺依曼体系（存储程序）
    ↓
五大部件：运算器 + 控制器 + 存储器 + 输入 + 输出
    ↓
层次结构：软件层 → 指令集 → 微架构 → 硬件
    ↓
性能度量：MIPS / CPI / FLOPS / Amdahl定律
```

**本讲回答的核心问题**：计算机系统由哪些部分组成？冯·诺依曼结构的核心思想是什么？如何衡量一台计算机的性能？加速一个部件能带来多大的整体提升？

## 1. 计算机系统的基本概念

### 1.1. 计算机系统 = 硬件 + 软件

计算机系统由**硬件**（hardware）和**软件**（software）两大部分组成：

- **硬件**：构成计算机的物理设备，如CPU、内存、硬盘、显示器等。看得见、摸得着的部分。
- **软件**：由人们事先编制的、具有各类特殊功能的程序（program）组成。软件分为**系统软件**（操作系统、编译器）和**应用软件**（Office、浏览器等）。

> **通俗理解**：硬件是计算机的"身体"——提供了执行计算的基础物理结构；软件是计算机的"灵魂"——告诉硬件具体要做什么。二者缺一不可。开发软件时通常将常用功能打包成库和操作系统，让程序员能构建更复杂的应用，这就像造房子时从地基和砖块起步，而不是从炼铁开始。

### 1.2. 计算机系统的层次结构

从程序员角度看，计算机系统是多层抽象（abstraction）的：

```
高级语言层（C/C++/Java）        ← 面向算法，最接近人的思维方式
    ↓ 编译（compile）
汇编语言层（assembly）             ← 机器语言的符号表示
    ↓ 汇编（assemble）
机器语言层（machine code）        ← 二进制代码，硬件可直接识别
    ↓ 解释执行
微架构层（microarchitecture）      ← 硬件的具体实现方式
    ↓
物理层（晶体管/电路）
```

**各层次的关系**：

| 层次 | 描述 | 例子 |
|:----|:-----|:-----|
| **高级语言** | 面向算法，接近自然语言，可移植性好 | `a = b + c;` |
| **汇编语言** | 用助记符（mnemonic）代替二进制指令，与机器一一对应 | `ADD R1, R2, R3` |
| **机器语言** | 二进制代码，CPU直接识别和执行 | `1000100111011000` |

> **自己的话**：高级语言编写的程序不能直接在硬件上运行，必须逐层翻译。编译器将高级语言翻译成汇编语言，汇编器将汇编语言汇编成目标程序（机器语言），然后才能被CPU执行。这就像一个国际会议——发言人说中文（高级语言），翻译成英文（汇编），最后由同传设备转换成电信号（机器语言）传给耳机。

### 1.3. 计算机组成与体系结构的区别

| 概念 | 侧重 | 比喻 |
|:----|:-----|:-----|
| **计算机体系结构**（architecture） | 指令集、数据表示、寻址方式——**程序员看到的属性** | 房屋的设计图纸 |
| **计算机组成**（organization） | 数据通路、控制信号、ALU实现——**具体如何实现** | 实际的砖瓦水管 |

> 同一种体系结构（如x86）可以有多种不同的组成（微架构），但程序员看到的指令集是一样的。好比同一张建筑设计图可以用不同的施工方法来实现。

## 2. 冯·诺依曼体系结构

### 2.1. 核心思想：存储程序

1945年，冯·诺依曼（John von Neumann）在EDVAC报告中提出了一种革命性的计算机设计思想——**存储程序**（stored program concept）：

> **将指令和数据以同等地位存放在存储器中，计算机可以按顺序自动执行指令。**

这一思想的核心意义：程序不需要通过改变硬件接线来切换功能，只需要改变存储器中的指令序列即可——这就是现代计算机"软件定义功能"的根源。

### 2.2. 冯·诺依曼体系的特点

1. **计算机由五大部件组成**：运算器、控制器、存储器、输入设备、输出设备
2. **指令和数据以同等地位存放在存储器中**，按地址访问
3. **指令和数据都用二进制表示**
4. **指令由操作码和地址码组成**
5. **存储程序控制**——指令在存储器中顺序存放，自动逐条取出执行
6. **以运算器（ALU）为中心**——输入输出设备与存储器之间的数据传送都经过运算器

### 2.3. 冯·诺依曼结构 vs 哈佛结构

在冯·诺依曼提出存储程序思想的同时，哈佛大学（Harvard University）的Mark I计算机采用了另一种思路——**哈佛结构**（Harvard architecture）。

| 对比项 | 冯·诺依曼结构（普林斯顿结构） | 哈佛结构 |
|:------|:-----------------------|:---------|
| **指令与数据的存放** | 同一个存储器，共用地址空间 | **分开存放**——指令存储器与数据存储器独立 |
| **总线** | 单一的地址总线+数据总线 | **独立的指令总线+数据总线** |
| **能否同时访问** | 不能——取指令和读写数据不能同时进行 | **可以**——指令和数据可并行访问 |
| **典型应用** | 通用计算机（PC、服务器） | 嵌入式处理器、DSP、单片机（如AVR、ARM部分版本） |
| **优点** | 存储利用率高，结构简单 | 指令和数据可重叠取址，性能更高 |
| **缺点** | 存在**冯·诺依曼瓶颈**（访存竞争） | 结构复杂，存储器利用率较低 |

> **通俗理解**：冯·诺依曼结构就像**一根水管**——要么进水，要么出水，不能同时进行。哈佛结构就像**双车道**——进水的车道和出水的车道分开，可以同时进行。现代处理器其实已经混合了这两种思想——例如CPU内部将指令Cache和数据Cache分开（哈佛），但对主存统一编址（冯·诺依曼）。

**冯·诺依曼瓶颈**（von Neumann bottleneck）：由于指令和数据共用同一总线，取指令和读写数据之间存在竞争，限制了系统的吞吐率。这是冯·诺依曼结构最大的固有弱点。

### 2.4. 现代计算机的结构演进

早期冯·诺依曼结构以**运算器为中心**，数据在各部件之间传送频繁经过运算器，效率较低。现代计算机已发展为以**存储器为中心**：

```
CPU: 运算器 + 控制器 + Cache（高速缓存）
    ↕  系统总线
主存（主存储器）
    ↕
辅存（磁盘/SSD）+ I/O设备
```

各部件功能：

| 部件 | 功能 |
|:----|:-----|
| **运算器**（ALU，Arithmetic and Logic Unit） | 完成算术运算（加减乘除）和逻辑运算（与或非） |
| **控制器**（CU，Control Unit） | 指挥各部件协调工作——取指令、分析指令、执行指令 |
| **存储器**（memory） | 存放程序和数据。分为**主存**（内存）和**辅存**（外存） |
| **输入设备** | 将外部信息转换为计算机能识别的数据 |
| **输出设备** | 将计算机处理结果以人类能理解的形式输出 |

### 2.4. 指令和数据的区分

由于指令和数据都存放在同一个存储器中，计算机如何区分它们？

> **自己的话**：这就像同一个邮箱里既有信件（数据）又有操作说明（指令）。计算机通过**时间**和**来源**两个维度来区分：
> 1. **阶段不同**：在取指令阶段（取指周期）从存储器取出的为指令；在执行指令阶段取出的为数据
> 2. **地址来源不同**：由**PC**（程序计数器）提供的地址取出的为指令；由指令地址码部分提供的地址取出的为操作数

### 2.5. 指令与程序

| 概念 | 定义 |
|:----|:-----|
| **指令**（instruction） | 计算机执行某种操作的**命令**——典型的指令由**操作码**（opcode，做什么）和**地址码**（address，操作数在哪）两部分组成 |
| **程序**（program） | 为解决某个问题而编排的**指令序列**——程序是众多指令的集合 |

## 3. 计算机的关键部件与工作原理

### 3.1. CPU内部主要寄存器

从你的笔记中提取的CPU内部关键寄存器（图解见笔记第2页）：

| 缩写 | 全称 | 作用 | 通俗理解 |
|:----|:-----|:-----|:---------|
| **ACC** | Accumulator | **累加器**——存放运算结果或操作数 | 运算器的"工作台" |
| **ALU** | Arithmetic and Logic Unit | **算术逻辑单元**——执行具体运算 | 计算机的"计算器" |
| **MQ** | Multiplier-Quotient Register | **乘商寄存器**——存放乘法/除法结果 | 专门给乘除法用的"草稿纸" |
| **PC** | Program Counter | **程序计数器**——存放当前正在执行的指令地址 | "指路牌"，告诉CPU下一条指令在哪 |
| **IR** | Instruction Register | **指令寄存器**——存放当前正在执行的指令 | CPU的"当前任务单" |
| **MAR** | Memory Address Register | **存储器地址寄存器**——存放要访问的存储单元地址 | 指向存储器的"定位器" |
| **MDR** | Memory Data Register | **存储器数据寄存器**——存放从存储器读出或写入的数据 | 数据进出的"中转站" |
| **CU** | Control Unit | **控制器**——发出控制信号协调各部件 | 计算机的"总指挥" |

### 3.2. 一条指令的执行过程（简化）

```
① 取指令（Fetch）：    PC → MAR → 存储器 → MDR → IR, PC+1
② 分析指令（Decode）： IR → CU（指令译码器）
③ 执行指令（Execute）： CU发控制信号 → ALU、存储器等
④ 结果写回（Write）： ACC → MDR → 存储器（或直接到目标位置）
```

> **自己的话**：CPU的工作循环就像流水线上的工人——①从传送带上取下"任务单"（取指令），②阅读任务单上的操作说明（分析指令），③按照说明操作工具（执行指令），④把加工好的产品放到指定位置（写回结果）。然后取下下一个任务单，周而复始。

### 3.3. 指令周期

| 概念 | 定义 |
|:----|:-----|
| **指令周期**（instruction cycle） | 从取指令到执行完一条指令所需的全部时间 |
| **机器周期**（machine cycle） | 通常指从一次访存到下一次访存的时间间隔 |
| **时钟周期**（clock cycle） | CPU的最小时间单位，由主频决定 |

关系：一个指令周期 = 若干机器周期 = 若干时钟周期

## 4. 计算机性能指标

### 4.1. 基本性能参数

| 指标 | 含义 | 公式/说明 |
|:----|:-----|:----------|
| **机器字长** | CPU一次能处理的二进制数据的位数 | 通常与运算器、寄存器的位数有关，如32位、64位 |
| **存储容量** | 存储器中可存放二进制代码的总量 | 通常主存、辅存容量分开描述 |
| **主频**（时钟频率） | CPU工作的时钟速率 | 单位Hz（赫兹），如3.0GHz |
| **存储周期** | 连续两次访问存储器所需的最短时间间隔 | 存储周期 = 存取时间 + 恢复时间 |

**三种字长的区别**：

| 字长类型 | 定义 |
|:---------|:-----|
| **机器字长** | CPU一次能处理的二进制数据位数（与运算器位数有关） |
| **存储字长** | 一个存储单元中二进制代码的位数 |
| **指令字长** | 一条指令的二进制代码位数 |

### 4.2. 速度指标

#### MIPS（Million Instructions Per Second）

每秒执行百万条指令数：

$$
\text{MIPS} = \frac{\text{指令条数}}{\text{执行时间} \times 10^6} = \frac{f}{\text{CPI} \times 10^6}
$$

其中 $f$ 为CPU主频（Hz），CPI为每条指令的平均时钟周期数。

#### CPI（Cycles Per Instruction）

执行一条指令所需的平均时钟周期数：

$$
\text{CPI} = \frac{\text{总时钟周期数}}{\text{执行指令的总条数}}
$$

#### FLOPS（Floating Point Operations Per Second）

每秒浮点运算次数——衡量科学计算能力，常用MFLOPS、GFLOPS、TFLOPS。

> **自己的话**：MIPS和CPI是"速度"的两种不同视角。MIPS看的是每秒干了多少活（条数），CPI看的是干一份活需要多长时间（周期数）。两者实际上是一体两面——主频固定时，CPI越小则MIPS越大。

### 4.3. CPU性能公式

CPU执行时间（CPU time）的基本公式：

$$
\text{CPU时间} = \text{指令条数} \times \text{CPI} \times \text{时钟周期时间} = \frac{\text{指令条数} \times \text{CPI}}{f}
$$

> 一条计算机性能的黄金公式：程序运行时间 = 指令数量 × 每条指令的周期数 × 每个周期的时间。提升性能的三种途径：减少指令条数（更好的编译器/算法）、降低CPI（更优的微架构）、提高主频（更先进的工艺）。

### 4.4. Amdahl定律（补充）

**Amdahl定律**（Amdahl's Law）是计算机系统设计的重要定量原理，1967年由IBM 360系列机的主设计者阿姆达尔提出。

**核心思想**：系统中对某一部件采用更快执行方式所能获得的系统性能改进程度，取决于**这个部件的使用频率**或**占总执行时间的比例**。

**公式**：

$$
S_n = \frac{T_0}{T_n} = \frac{1}{(1 - f_e) + \frac{f_e}{S_e}}
$$

其中：
- $S_n$ = 系统性能提升倍数（加速比）
- $f_e$ = 可改进部分占原执行时间的比例
- $S_e$ = 该部分改进后的加速倍数

> **通俗理解**：假设你上班通勤有"走路+坐地铁"两段。走路占全程的30%，地铁占70%。如果地铁速度提升10倍——全程时间缩短为原来的 $(1-0.7)+0.7/10=0.37$，加速比只有 $1/0.37 \approx 2.7$ 倍。即使地铁提速100倍，加速比也仅约 $1/0.3 \approx 3.3$ 倍。Amdahl定律的结论是：**整体性能提升受限于不可加速部分的比例**——那30%的走路时间就是天花板。

**例题**：假设某一部件的处理速度加快到10倍，该部件的原处理时间仅为整个运行时间的40%，则采用加快措施后能使整个系统的性能提高多少？

**解**：
$$f_e = 0.4, \quad S_e = 10$$
$$S_n = \frac{1}{(1-0.4) + 0.4/10} = \frac{1}{0.6 + 0.04} \approx 1.56$$

整个系统的性能提高约1.56倍。

## 习题1：计算机系统概论

### 1.1 概念题

1. **什么是计算机系统？计算机硬件和软件哪个更重要？**

> **答**：计算机系统由**硬件**（构成计算机的物理设备）和**软件**（由程序和数据组成）两大部分构成。硬件和软件同等重要、相辅相成——硬件提供了执行计算的物理基础，软件使硬件能够发挥作用。没有软件的硬件是"裸机"，无法完成任何有用任务；没有硬件的软件仅仅是代码，无法运行。二者缺一不可。

2. **如何理解计算机系统的层次结构？**

> **答**：计算机系统从底层到顶层依次为：物理层（晶体管/电路）→ 微架构层 → 机器语言层（二进制指令）→ 汇编语言层 → 高级语言层。上层是对下层的抽象，下层是上层的实现基础。每层只关心本层的接口，不关心下层的具体实现——这就是"分层抽象"的设计思想。例如程序员只需写出高级语言代码，编译器和汇编器自动将其翻译为机器指令。

3. **说明高级语言、汇编语言和机器语言的差别及其联系。**

> **答**：**机器语言**是二进制代码，计算机硬件能直接识别和执行；**汇编语言**用助记符（mnemonic）代替二进制指令，与机器语言一一对应；**高级语言**面向算法，接近自然语言，不依赖特定机器。三者的联系是：高级语言程序必须先编译成汇编语言，再汇编成机器语言，才能被CPU执行。从高级到低级，可移植性降低，执行效率提高。

4. **冯·诺依曼计算机的特点是什么？存储程序思想的本质是什么？**

> **答**：冯·诺依曼计算机的特点：(1) 五大部件组成（运算器、控制器、存储器、输入、输出）；(2) 指令和数据以同等地位存放在存储器中；(3) 指令和数据都用二进制表示；(4) 指令由操作码和地址码组成；(5) 存储程序控制——程序自动连续执行；(6) 以运算器为中心。**存储程序思想**的本质是将程序以二进制形式存放在存储器中，使计算机无需改变硬件即可执行不同程序——这是"软件定义功能"的根源。

5. **解释下列概念：主机、CPU、主存、存储单元、存储字、存储字长、机器字长、指令字长。**

> **答**：
> - **主机**：计算机硬件的主体部分，由CPU和主存储器（MM）合称主机
> - **CPU**：中央处理器（Central Processing Unit），计算机硬件的核心部件，由运算器和控制器组成；早期不在同一芯片上，现代CPU还集成了Cache
> - **主存**：计算机中存放正在运行的程序和数据的存储器，可随机存取，是计算机的主要工作存储器
> - **存储单元**：CPU访问存储器时的基本单位，每个存储单元都有一个唯一的地址
> - **存储元件**（存储基元/存储元）：存储一位二进制信息的物理元件，是存储器中最小的存储单位，不能单独存取
> - **存储字**：一个存储单元所存二进制代码的逻辑单位
> - **存储字长**：一个存储单元中二进制代码的位数
> - **机器字长**：CPU一次能处理的二进制数据的位数，通常与运算器位数有关
> - **指令字长**：一条指令的二进制代码位数

6. **指令和数据都存放在存储器中，计算机如何区分它们？**

> **答**：计算机通过以下两种方式区分：(1) **时间段不同**：在取指令阶段（或取指微程序）从存储器取出的为指令，在执行指令阶段取出的为数据；(2) **地址来源不同**：由PC（程序计数器）提供存储单元地址的取出的是指令，由指令地址码部分提供地址的取出的是操作数。

7. **什么是指令？什么是程序？**

> **答**：**指令**（instruction）是计算机执行某种操作的命令，典型的指令由**操作码**（opcode，做什么操作）和**地址码**（address，操作数的位置）两部分组成。**程序**（program）是软件开发人员根据用户需求开发的、用程序设计语言描述的、适合计算机执行的指令（语句）序列。——程序是众多指令的集合。

### 1.2 性能计算题

8. 某CPU主频为2.0GHz，执行某程序共需$2 \times 10^5$条指令，平均每条指令所需时钟周期数（CPI）为4，求该程序执行时间。

> **解**：时钟周期 $t = 1/f = 1/(2.0\times 10^9) = 0.5\text{ns}$
> CPU时间 = 指令数 $\times$ CPI $\times$ 时钟周期 = $2\times 10^5 \times 4 \times 0.5\text{ns} = 4\times 10^5\text{ns} = 0.4\text{ms}$

9. 假设某一部件的处理速度提高到原来的5倍，该部件原处理时间占整个运行时间的60%，采用加快措施后系统性能提高多少？

> **解**：$f_e = 0.6,\ S_e = 5$
> $S_n = 1/((1-0.6) + 0.6/5) = 1/(0.4+0.12) \approx 1.92$倍

### 1.3 简答题

10. **计算机组成与体系结构有何区别？** 试举例说明。

> **答**：体系结构是指程序员看到的计算机属性（指令集、数据表示、寻址方式等），计算机组成是指如何实现这些属性（数据通路、控制信号等）。例如x86是一种体系结构，而Intel Core i7和Pentium是不同组成（微架构）实现了同一体系结构。

11. **简述CPU的基本组成和工作原理。**

> **答**：CPU由运算器（ALU）和控制器（CU）组成，内部包含ACC（累加器）、PC（程序计数器）、IR（指令寄存器）、MAR（地址寄存器）、MDR（数据寄存器）等寄存器。基本工作循环为：取指令→分析指令→执行指令→写回结果。

## 本讲核心要点

1. **计算机系统 = 硬件 + 软件**，硬件是物理基础，软件是逻辑灵魂
2. **冯·诺依曼体系核心**：存储程序——指令和数据以同等地位存放在存储器中，程序顺序执行
3. **五大部件**：运算器、控制器、存储器、输入设备、输出设备。现代计算机以存储器为中心
4. **层次结构**：高级语言→汇编语言→机器语言→微架构→硬件，每层为上一层提供抽象
5. **指令与数据的区分**：取指阶段PC提供地址的为指令，执行阶段从指令地址码中取出的为数据
6. **CPU内部关键寄存器**：PC（指向下条指令）、IR（当前指令）、MAR/MDR（访存）、ACC（存放结果）
7. **性能三大指标**：MIPS（每秒百万指令）、CPI（每指令平均周期数）、FLOPS（每秒浮点运算次数）
8. **CPU性能公式**：CPU时间 = 指令数 $\times$ CPI $\times$ 时钟周期
9. **Amdahl定律**：系统加速比受限于不可加速部分的比例——整体性能提升不可能超过 $1/(1-f_e)$
10. **计算机体系结构与组成的区别**：体系结构是"做什么"（指令集接口），组成是"怎么做"（硬件实现）
