# 05-数据表示与运算方法

```知识地图
定点数表示：原码 / 反码 / 补码 / 移码
    ↓
浮点数表示：IEEE 754标准（符号位+阶码+尾数）
    ↓
定点加减运算：补码加减 + 溢出判断（双符号位/单符号位）
    ↓
浮点加减运算：对阶 → 尾数运算 → 规格化 → 舍入 → 判溢出
```

**本讲回答的核心问题**：计算机如何表示正负数和浮点数？四种编码方式各有什么特点？补码加法为什么能统一加减法？浮点数运算如何对阶和规格化？

## 1. 定点数的表示方法

### 1.1. 基本概念

**定点数**（fixed-point number）：小数点位置固定的数。计算机中通常将小数点固定在符号位之后（纯小数）或最低位之后（纯整数）。

### 1.2. 原码（Sign-Magnitude）

**定义**：符号位（最高位）+ 数值的绝对值。

| 类型 | 公式（n位，含1位符号位） | 示例 |
|:----|:----------------------|:-----|
| **定点小数** | $[x]_\text{原} = \begin{cases} x & 0 \leq x < 1 \\ 1 - x & -1 < x \leq 0 \end{cases}$ | $x=+0.1101 \to [x]_\text{原}=0.1101$ |
| **定点整数** | $[x]_\text{原} = \begin{cases} x & 0 \leq x < 2^{n-1} \\ 2^{n-1} - x & -2^{n-1} < x \leq 0 \end{cases}$ | $x=-0.1101 \to [x]_\text{原}=1.1101$ |

**特点**：
- 表示简单直观，与真值转换方便
- **有正零和负零**（$+0$和$-0$）
- 做加减运算时，需要判断符号，**电路复杂**

### 1.3. 补码（Two's Complement）

**定义**：正数的补码等于本身；负数的补码为"原码除符号位外各位取反，末位加1"（即 $2^n - x$ 的编码）。

| 类型 | 公式（n位） | 示例 |
|:----|:-----------|:-----|
| **定点小数** | $[x]_\text{补} = \begin{cases} x & 0 \leq x < 1 \\ 2 + x & -1 \leq x \leq 0 \end{cases} \pmod{2}$ | $x=-0.1101 \to [x]_\text{补}=1.0011$ |
| **定点整数** | $[x]_\text{补} = \begin{cases} x & 0 \leq x < 2^{n-1} \\ 2^n + x & -2^{n-1} \leq x \leq 0 \end{cases} \pmod{2^n}$ | — |

**运算规则**（模 $2^n$ 加法）：

$$
[x+y]_\text{补} = [x]_\text{补} + [y]_\text{补} \pmod{2^n}
$$

$$
[x-y]_\text{补} = [x]_\text{补} + [-y]_\text{补} \pmod{2^n}
$$

> **通俗理解**：补码的核心思想是"模运算"——就像时钟一样，3点可以看成15点（模12）。补码把减法转化为加法，只需一个加法器即可完成加减运算。

**特点**：
- **只有一个零**（000...0）
- **补码加减法统一**（符号位一起参加运算，结果也是补码）
- 负数表示范围比原码多一个（如8位补码：$-128 \sim 127$）
- 转换规则：$[x]_\text{补} \to [-x]_\text{补}$——**各位取反，末位加1**

### 1.4. 反码（Ones' Complement）

**定义**：正数的反码等于本身；负数的反码为原码除符号位外各位取反。

**特点**：
- **有正零和负零**
- 减法可用加法实现，但需要循环进位（end-around carry）
- 较少直接使用（被补码取代）

### 1.5. 三种码制的对比

| 对比项 | 原码 | 反码 | 补码 |
|:------|:---:|:---:|:---:|
| 符号位 | 最高位 | 最高位 | 最高位（参与运算） |
| 正零 | 0000 | 0000 | 0000 |
| 负零 | 1000 | 1111 | **无** |
| 负数绝对值 | 符号位+绝对值 | 原码取反 | 原码取反+1 |
| 加减运算 | 需判断符号 | 循环进位 | **可直接加** |
| 表示范围（4位） | -7~+7 | -7~+7 | **-8~+7** |

> **自己的话**：可以把这三种码制理解为三种"记录债务"的方式。原码就像记下"欠了多少钱"的绝对值；反码像把所有欠款用另一种标记方式表示；补码则用了模运算的思想——让减法变成加法，最符合计算机加法器的设计。

### 1.6. 移码（Excess/Bias Code）

**定义**：将真值加上一个固定偏置值（bias）。通常用于浮点数的**阶码**表示。

**公式**：

$$
[x]_\text{移} = x + 2^{n-1}
$$

其中 $2^{n-1}$ 为偏置值（如8位移码偏置128）。

**特点**：
- 移码的**大小顺序与真值一致**——便于比较
- 移码最小的数对应真值最小（全0最小）
- **移码和补码的数值位相同，符号位相反**

| 真值 | 补码（8位） | 移码（8位） |
|:---:|:----------:|:----------:|
| +127 | 01111111 | **11111111** |
| 0 | 00000000 | **10000000** |
| -128 | 10000000 | **00000000** |

> 注意：编码中从真值最小到最大，移码正好是"二进制自然数"的顺序——这就是为什么移码方便比较大小。

## 2. 浮点数的表示

### 2.1. 浮点数的基本格式

浮点数（floating-point number）由**阶码**（exponent）和**尾数**（mantissa/significand）两部分组成，形如：

$$
N = (-1)^S \times M \times r^E
$$

其中：
- $S$ = 符号位（0为正，1为负）
- $M$ = 尾数（有效数字部分）
- $E$ = 阶码（指数）
- $r$ = 基数（通常为2）

### 2.2. IEEE 754 标准

IEEE 754是目前最广泛使用的浮点数标准。

**单精度（float，32位）**：

```
| 1位符号位 S | 8位阶码 E（移码，偏置127） | 23位尾数 M（原码，隐含整数位1） |
```

**双精度（double，64位）**：

```
| 1位符号位 S | 11位阶码 E（移码，偏置1023） | 52位尾数 M |
```

**真值计算公式**：

当 $1 \leq E \leq 254$（规格化数）：

$$
N = (-1)^S \times 1.M \times 2^{E-127}
$$

当 $E = 0$（非规格化数，表示0或非常接近0的数）：

$$
N = (-1)^S \times 0.M \times 2^{-126}
$$

当 $E = 255$（特殊值）：
- 若 $M = 0$：表示 $\pm\infty$
- 若 $M \neq 0$：表示 NaN（Not a Number）

| 单精度格式 | 阶码 E | 尾数 M | 表示的值 |
|:---------|:-----:|:------:|:--------|
| 正零 | 00000000 | 000...0 | +0 |
| 负零 | 00000000 | 000...0 | -0 |
| 最小正规格化数 | 00000001 | 000...0 | $1.0 \times 2^{-126}$ |
| 最大正规格化数 | 11111110 | 111...1 | $(2-2^{-23}) \times 2^{127}$ |
| $+\infty$ | 11111111 | 000...0 | 无穷大 |
| NaN | 11111111 | 非全0 | 非数 |

### 2.3. 规格化

**规格化**（normalization）：使尾数的最高有效位为1，以最大化精度。

- 定点小数规格化：$1/2 \leq |M| < 1$
- IEEE 754：隐含整数位1（$1.M$），实际节省了一位精度

**规格化方法**：
- **左规**（向左规格化）：尾数每左移1位，阶码减1
- **右规**（向右规格化）：尾数每右移1位，阶码加1

> **通俗理解**：规格化就像科学计数法——$0.00123 \times 10^3$ 写成 $1.23 \times 10^0$。限制数字从"1.xxx"开始，充分利用了尾数的每一位来存储有效数字。

### 2.4. 浮点数表示范围

以IEEE 754单精度为例：

| 项目 | 值 |
|:----|:----|
| 最大正数 | $(2-2^{-23}) \times 2^{127} \approx 3.4 \times 10^{38}$ |
| 最小正规格化数 | $1.0 \times 2^{-126} \approx 1.18 \times 10^{-38}$ |
| 最小正非规格化数 | $2^{-23} \times 2^{-126} = 2^{-149}$ |
| 精度（有效十进制位数） | $23\text{位二进制} \approx 7\text{位十进制}$ |

## 3. 定点加减运算

### 3.1. 补码加法

**规则**：$[x+y]_\text{补} = [x]_\text{补} + [y]_\text{补} \pmod{2^n}$——符号位一起参加运算。

**示例**：$x=-0.1101,\ y=-0.0011$，求 $x+y$

**解**：
$[x]_\text{补} = 1.0011,\ [y]_\text{补} = 1.1101$

```
  1.0011
+ 1.1101
--------
  1.0000（模2丢弃进位1）
```

$[x+y]_\text{补} = 1.0000 \to x+y = -1.0$（但这对定点小数是溢出）

### 3.2. 溢出判断

溢出（overflow）是指运算结果超出了机器所能表示的范围。两种判断方法：

#### (1). 双符号位法（变形补码）

用两个符号位 $S_1S_2$ 表示（如00=正，11=负）：

| 运算后符号位 | 结果 |
|:----------:|:----:|
| 00 或 11 | **无溢出**（正常） |
| 01 | **正溢出**（上溢，正数太大） |
| 10 | **负溢出**（下溢，负数太小） |

**判断**：$V = S_1 \oplus S_2$（异或），$V=1$则溢出。

> **通俗理解**：双符号位就像放了两台温度计——如果两台温度计读数一致（00或11），说明温度正常；如果一台说正一台说负（01或10），说明温度计坏了——也就是计算溢出了。

#### (2). 单符号位法

$V = C_f \oplus C_{f-1}$，即进位位和符号位的进位相异或，结果为1则溢出。

**示例**（溢出情况）：

```
  0.1101（+0.8125）
+ 0.1011（+0.6875）
--------
  1.1000 → 符号位=1（正）但结果变负了！
  进位情况：符号位进位=0，最高位进位=1
  V = 0 ⊕ 1 = 1 → 正溢出
```

### 3.3. 补码加减运算流程

```
给定 [x]补 和 [y]补
    ↓
做加法：[x]补 + [y]补
    ↓
检查溢出（V=1则溢出，转溢出处理）
    ↓
结果即为 [x+y]补
```

减法：$[x-y]_\text{补} = [x]_\text{补} + [-y]_\text{补}$，其中 $[-y]_\text{补} = [y]_\text{补}$ 各位取反末位加1。

## 4. 浮点加减运算

### 4.1. 运算步骤

浮点加减运算分以下五步：

```
① 对阶：使两数阶码相等（小阶向大阶看齐）
    ↓
② 尾数加减：对阶后的尾数执行补码加减
    ↓
③ 规格化：如果尾数不符合规格化形式，执行左规或右规
    ↓
④ 舍入：尾数超出精度时进行舍入处理
    ↓
⑤ 判溢出：阶码溢出则报错
```

**最完整的浮点运算例题**（来自你的笔记例6.27）：

假设阶码取3位（含1位符号），尾数取6位（含1位符号），计算：
$$x-y,\quad\text{其中 } x = 2^{-3} \times \frac{13}{16},\ y = 2^{-4} \times (-\frac{5}{8})$$

**解**：

先写补码形式：
- $x$：$x = 2^{-3} \times 0.1101$，$[x]_\text{浮} = 1,101; 0.1101$（阶码用移码表示）
- $y$：$y = 2^{-4} \times (-0.1010)$，$[y]_\text{浮} = 1,100; 1.0110$

**① 对阶**：小阶向大阶看齐

$E_x - E_y = -3 - (-4) = +1$，$y$的阶码比$x$小1，需将$y$的尾数右移1位，阶码加1：

$[y]_\text{浮}' = 1,101; 1.1011$（右移时符号位扩展）

**② 尾数相减**：

$$
0.1101 - 1.1011 = 0.1101 + 0.0101 = 1.0010
$$

**③ 规格化**：$1.0010$不是规格化形式（定点小数规格化要求$S \neq M_1$），需左规。

左移1位：$[x-y]_\text{浮} = 1,100; 1.0100$

**④ 舍入**：本例无舍入。

**⑤ 判溢出**：阶码无溢出。

最终结果：$x-y = 2^{-4} \times (-0.1100)$

## 习题5：数据表示与运算方法

### 5.1 概念题

1. **简述原码、反码、补码、移码的定义及特点。为什么计算机中广泛使用补码？**

> **答**：原码=符号位+绝对值，直观但有加减运算复杂；反码=原码取反，有循环进位；补码=反码+1，加法器可直接实现加减法且无负零，因此广泛使用；移码=真值+偏置值，便于比较大小，用于浮点阶码。

2. **什么是规格化？为什么要规格化？**

> **答**：规格化使尾数最高有效位为1（$1/2 \leq |M| < 1$），最大化尾数的精度位数，避免有效数字丢失。

3. **什么是溢出？如何判断定点数加减运算是否溢出？**

> **答**：溢出指结果超出机器可表示范围。两种判断方法：双符号位法（符号位为01或10则溢出）和单符号位法（$V=C_f \oplus C_{f-1}$）。

### 5.2 计算题

4. 已知 $x=-0.1101,\ y=+0.1011$，用补码计算 $x+y$。

> **解**：$[x]_\text{补}=1.0011,\ [y]_\text{补}=0.1011$，$1.0011+0.1011=1.1110$，$x+y=-0.0010$。

5. **例6.27**：假设阶码取3位（含1位符号），尾数取6位（含1位符号），计算 $[2^{-3} \times (13/16)] - [2^{-4} \times (-5/8)]$。

> **解**：对阶→尾数加减→左规→得结果 $2^{-4} \times (-0.1100)$（完整过程见正文）。

6. **IEEE 754单精度表示**：将十进制数-12.75表示为IEEE 754单精度浮点数。

> **解**：$-12.75 = -1100.11_2 = -1.10011 \times 2^3$。符号位=1，阶码=3+127=130=10000010$_2$，尾数=10011000000000000000000。最终：`1 10000010 10011000000000000000000`。

## 本讲核心要点

1. **四种定点数编码**：原码（直观但加减复杂）、反码（循环进位）、补码（统一加法器，最常用）、移码（偏置值，用于阶码比较）
2. **补码的核心优势**：$[x+y]_\text{补}=[x]_\text{补}+[y]_\text{补}$，符号位直接参加运算，减法转为加法
3. **溢出判断**：双符号位法（01正溢出/10负溢出）或 $V=C_f \oplus C_{f-1}$
4. **IEEE 754浮点格式**：32位单精度 = 1位符号 + 8位阶码（移码偏置127）+ 23位尾数（隐含1）
5. **规格化**：使尾数为 $1.M$ 形式，左规尾数左移阶码减1，右规相反
6. **浮点五步运算**：对阶（小向大看齐）→ 尾数运算 → 规格化 → 舍入 → 判溢出
7. **特殊值**：IEEE 754中阶码全0表示非规格化数和0，全1表示无穷大和NaN
8. **补码负数求补**：$[-x]_\text{补} = [x]_\text{补}$ 取反加1——这同时也是补码转原码的规则
