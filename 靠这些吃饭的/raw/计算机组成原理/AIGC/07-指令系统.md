**本讲回答的核心问题**：一条指令由哪些部分组成？CPU如何通过不同的寻址方式找到操作数？CISC和RISC有何本质区别？

## 1. 指令系统概述

### 1.1. 什么是指令系统

**机器指令**（machine instruction）：每一条机器语言的语句，能准确表达某种语义。

**指令系统**（instruction set）：一台计算机中所有机器指令的集合。

> 指令系统是**计算机软硬件的界面**——程序员看到的是指令系统，硬件设计者实现的是指令系统。计算机就是连续执行每一条机器语句而实现全自动工作的。

### 1.2. 指令字长与机器字长

| 概念 | 定义 |
|:----|:-----|
| **指令字长** | 一条指令中二进制代码的总位数 |
| **机器字长** | CPU一次能处理的数据位数（与寄存器位数有关） |
| **存储字长** | 一个存储单元中存放二进制代码的总位数 |

三者可以相等，也可以不等，视不同机器而定。

## 2. 指令格式

### 2.1. 指令的基本组成

一条指令通常由两部分组成：

```
|  操作码（OP）  |  地址码（A）  |
```

- **操作码**（opcode）：指明指令要执行的操作（如加、减、传送、转移）
- **地址码**（address）：指明操作数的地址或操作数本身

### 2.2. 按地址码个数分类

#### 零地址指令

指令字中无地址码。有两种情况：
- 不需要操作数：如空操作（NOP）、停机（HLT）
- 操作数地址隐含：如子程序返回（RET）、中断返回（IRET）——操作数地址隐含在堆栈指针SP中

#### 一地址指令

格式：`OP  A₁`

一个操作数的地址由A₁给出，另一个操作数隐含（通常隐含在ACC中）。例如：
- `ADD X` → 将ACC与X单元的内容相加，结果放回ACC

#### 二地址指令

格式：`OP  A₁  A₂`

- A₁：目的操作数地址（dest）
- A₂：源操作数地址（src）

常见的语义：`A₁ ← A₁ OP A₂`，如 `MOV AX, BX`

#### 三地址指令

格式：`OP  A₁  A₂  A₃`

- A₁：目标地址
- A₂：第一操作数地址
- A₃：第二操作数地址

语义：`A₁ ← A₂ OP A₃`。三地址指令执行后操作数不会被破坏，但**指令字长较长**。

### 2.3. 操作码设计

#### 定长操作码

所有指令的操作码位数固定（如4位固定操作码，最多16种指令）。

**优点**：译码简单、速度快
**缺点**：指令种类受限（$2^k$种）

#### 扩展操作码（可变长操作码）

操作码的位数不固定——通过减少地址码的个数来增加操作码的位数。

**例题**（来自你的笔记p73）：指令字长16位，地址码6位：
- 若二地址指令有X种，零地址指令有Y种，求一地址指令最多有几种？

**解**：
- 二地址指令操作码4位（16-6-6=4），→ $X$ 种
- 一地址指令操作码10位（16-6=10）→ $(2^4 - X) \times 2^6$ 种
- 零地址指令操作码16位 → $[(2^4 - X) \times 2^6 - M] \times 2^6$ 种，其中 $M$ 为一地址指令数

所以一地址指令最多有：
$$
M = (2^4 - X) \times 2^6 - Y/2^6
$$

> **通俗理解**：扩展操作码就像"可变容量的箱子"——二地址指令的箱子小（4位操作码），省下空间给两个地址码；当需要更多操作码时，牺牲一个地址码来扩大操作码箱子（一地址指令10位操作码）；再需要时再牺牲一个地址码（零地址指令16位操作码）。关键是**每条指令的操作码不能相同**。

## 3. 寻址方式

**寻址方式**（addressing mode）是指确定本条指令的数据地址以及下一条将要执行的指令地址的方法。

### 3.1. 常见寻址方式

| 寻址方式        | 有效地址 EA              | 访问次数* | 特点                | 示例              |
| :---------- | :------------------- | :---: | :---------------- | :-------------- |
| **立即寻址**    | 指令本身含操作数             |   0   | 操作数在指令中，速度快，但值固定  | `MOV BX, 2A00H` |
| **直接寻址**    | EA = A               |   1   | 最简单，EA就是地址码本身     |                 |
| **寄存器寻址**   | 操作数在寄存器中             |   0   | 速度最快，不访问主存        | `MUL BX`        |
| **寄存器间接寻址** | EA = (Ri)            |   1   | 寄存器中存放操作数的地址      |                 |
| **变址寻址**    | EA = A + (IX)        |   1   | 变址寄存器IX，适用于数组遍历   |                 |
| **基址寻址**    | EA = A + (BR)        |   1   | 基址寄存器BR，适用于程序重定位  |                 |
| **相对寻址**    | EA = A + (PC)        |   1   | 与当前指令地址相关，用于跳转    |                 |
| **基址变址寻址**  | EA = A + (BR) + (IX) |   1   | 基址+变址             |                 |
| **间接寻址**    | EA = (A)             |  2+   | 地址码指向的单元存储着操作数的地址 |                 |

> \* 指访问存储器的次数（取指周期除外）

### 3.2. 寻址方式与访存次数

**不访问存储器**的寻址方式：寄存器寻址、立即寻址

**访问一次存储器**的寻址方式：直接寻址、寄存器间接寻址、变址寻址、基址寻址、相对寻址

**访问多次存储器的寻址方式**：间接寻址

> 包括取指在内共访存四次的指令：二重间址的一地址指令，或一重间址的二地址指令（当另一操作数采用直接/基址/变址/相对/寄存器间接寻址时）。

## 4. 指令分类

### 4.1. 数据传送指令

| 指令 | 功能 | 说明 |
|:----|:-----|:------|
| **MOV** | 传送 | `MOV A,B` → A ← B |
| **XCHG** | 交换 | `XCHG A,B` → A ↔ B |
| **PUSH** | 入栈 | 将寄存器内容压入堆栈 |
| **POP** | 出栈 | 从堆栈弹出内容到寄存器 |
| **LEA** | 取有效地址 | `LEA A,B` → 将B的有效地址送A |

### 4.2. 算术运算指令

| 指令 | 功能 | 对标志位影响 |
|:----|:-----|:------------|
| **ADD** | 加法 | 影响所有标志位（CF/OF/SF/ZF/PF/AF） |
| **ADC** | 带进位加法 | `A ← A + B + CF` |
| **INC** | 加1 | **不影响CF**，影响其他标志 |
| **SUB** | 减法 | 影响所有标志 |
| **SBB** | 带借位减法 | `A ← A - B - CF` |
| **DEC** | 减1 | **不影响CF** |
| **CMP** | 比较 | 做减法但结果不保存，只影响标志 |
| **NEG** | 取负 | `A ← 0 - A` |
| **MUL** | 无符号乘 | 影响CF、OF |
| **IMUL** | 有符号乘 | 影响CF、OF |
| **DIV** | 无符号除 | 不影响标志 |
| **IDIV** | 有符号除 | 不影响标志 |

### 4.3. 逻辑运算与移位指令

**逻辑运算**：AND（与）、OR（或）、XOR（异或）、NOT（非）、TEST（测试 = AND但不保存结果）

**移位指令**：
- **SHL/SHR**：逻辑左/右移（补0）
- **SAL/SAR**：算术左/右移（右移时符号位保持不变）
- **ROL/ROR**：循环左/右移
- **RCL/RCR**：带进位循环左/右移

### 4.4. 转移指令

| 指令 | 功能 |
|:----|:-----|
| **JMP** | 无条件跳转（段内/段间） |
| **JZ/JE** | ZF=1时跳转 |
| **JNZ/JNE** | ZF=0时跳转（最常用） |
| **JG/JNLE** | 大于（有符号）时跳转 |
| **JGE/JNL** | 大于等于（有符号）时跳转 |
| **JL/JNGE** | 小于（有符号）时跳转 |
| **JLE/JNG** | 小于等于（有符号）时跳转 |
| **JA/JNBE** | 高于（无符号）时跳转 |
| **JB/JNAE** | 低于（无符号）时跳转 |
| **LOOP** | 循环指令 — `CX=CX-1`，若CX≠0则跳转到标号处 |

### 4.5. I/O指令

| 指令 | 功能 |
|:----|:-----|
| **IN** | 从I/O端口读入数据到AL/AX |
| **OUT** | 将AL/AX中的数据写出到I/O端口 |

## 5. 指令周期

**指令周期**（instruction cycle）是CPU取出并执行一条指令所需的全部时间。

**机器周期**（machine cycle）是所有指令执行过程中的一个基准时间，通常以存取周期作为机器周期。

**时钟周期**（clock cycle）是机器主频的倒数，也称为节拍（T周期），是控制计算机操作的最小单位时间。

**三者关系**：
```
一个指令周期 ∋ 若干个机器周期 ∋ 若干个时钟周期
```

每个指令周期内的机器周期数可以不等，每个机器周期内的时钟周期数也可以不等。

> **注意**：不能简单说CPU主频越快，计算机速度就越快。速度还与机器周期所含时钟周期数、指令周期所含机器周期数、主存速度、是否配备Cache、总线带宽等因素有关。

## 6. CISC与RISC

### 6.1. CISC（复杂指令系统计算机）

**CISC**（Complex Instruction Set Computer）的设计思想是让硬件直接支持更多复杂操作，以减少指令条数。

**特点**：
- 指令条数多、功能复杂
- 指令字长不固定
- 寻址方式多
- 大多数指令可访问主存
- 通常采用**微程序控制**（微代码存储于ROM中）

**典型代表**：x86架构

### 6.2. RISC（精简指令系统计算机）

20世纪80年代，人们发现80-20规律——程序中**最常用的20%的简单指令**占据了80%的执行时间。由此引出RISC思想——精简指令系统，复杂指令功能由简单指令组合实现。

**RISC的主要特点**（来自你的笔记p72）：

1. 选取使用频度较高的简单指令，复杂指令由简单指令的组合实现
2. **指令长度固定**，指令格式种类少，寻址方式种类少
3. **只有取数/存数指令（LOAD/STORE）访问主存**，其余操作在寄存器内完成
4. CPU中有**多个通用寄存器**
5. **采用流水线技术**，大部分指令在一个时钟周期内完成
6. 控制器采用**组合逻辑控制**，不用微程序控制
7. 采用优化的编译程序

**典型代表**：ARM、RISC-V、MIPS

### 6.3. CISC vs RISC 对比

| 对比项 | CISC | RISC |
|:------|:----|:-----|
| 指令条数 | 多（200+） | 少（~50） |
| 指令字长 | **不固定** | **固定**（便于流水线取指） |
| 访存方式 | 大多指令可访存 | **只有LOAD/STORE访存** |
| 寄存器数量 | 少（~8个） | 多（~32个以上） |
| 控制方式 | **微程序控制**（ROM存微码） | **组合逻辑控制**（硬件直接实现） |
| 流水线 | 难以实现 | 易于实现，IPC高 |
| 设计周期 | 长 | 短 |
| 典型架构 | x86 | ARM、RISC-V |

### 6.4. RISC-V简介（补充）

**RISC-V** 是一个基于RISC原则设计的**开源指令集架构**（ISA），由加州大学伯克利分校于2010年推出。

**特点**：
- **开源免费**：与ARM（收费授权）和x86（Intel/AMD独占）不同，任何人都可以使用
- 模块化设计：基本整数指令集（RV32I）+ 可选扩展（乘除M、浮点F/D、原子操作A、压缩C）
- 简洁规整：32个通用寄存器，指令格式规整
- 已被广泛采用于嵌入式、AI加速器、云计算等领域

## 习题7：指令系统

### 7.1 概念题

1. **什么是指令字长、机器字长和存储字长？**

> **答**：机器字长指CPU一次能处理的数据位数（与寄存器位数有关）；指令字长指机器指令中二进制代码的总位数；存储字长指存储单元中存放二进制代码的位数。三者可等可不等。

2. **零地址指令的操作数来自哪里？在一地址指令中，另一个操作数的地址通常可采用什么寻址方式获得？**

> **答**：零地址指令无地址码，操作数地址隐含在堆栈指针SP中（如RET/IRET）。一地址指令中另一个操作数通常隐含在ACC（累加器）中。

3. **举例说明哪几种寻址方式在执行阶段不访问存储器，哪几种只需访问一次，哪几种需访问多次？**

> **答**：不访存——寄存器寻址、立即寻址；访存一次——直接寻址、寄存器间接寻址、变址/基址/相对寻址；访存多次——间接寻址。

4. **什么是RISC？简述其主要特点。**

> **答**：RISC即精简指令系统计算机。主要特点：指令少且长度固定、只有LOAD/STORE访存、多寄存器、流水线实现、组合逻辑控制、优化编译。

### 7.2 操作码设计题

5. **指令字长16位，地址码6位**：若操作码固定，零地址指令有P种，一地址指令有Q种，则二地址指令最多有几种？

> **解**：二地址指令操作码4位（16-6-6=4），固定操作码共2⁴=16种。二地址指令最多有16-P-Q种。

## 本讲核心要点

1. **指令格式三要素**：操作码（做什么）+ 地址码（操作数在哪），按地址码个数分零/一/二/三地址指令
2. **扩展操作码**：通过减少地址码个数增加操作码位数——4位→10位→16位可变长度编码
3. **九种寻址方式**：立即（0次访存）→寄存器（0次）→直接（1次）→变址/基址（1次）→相对（1次）→间接（多次）
4. **指令分类五大类**：数据传送（MOV/XCHG/PUSH/POP）、算术（ADD/SUB/MUL/DIV）、逻辑（AND/OR/XOR）、转移（JMP/JZ/LOOP）、I/O（IN/OUT）
5. **指令周期 > 机器周期 > 时钟周期**——三者层级嵌套，主频快≠整机快
6. **RISC五大特征**：指令少而固定、只有LOAD/STORE访存、多寄存器、流水线、组合逻辑控制
7. **CISC vs RISC本质区别**：微程序控制（灵活但慢）vs 硬件逻辑（快但固定），x86走CISC路线，ARM/RISC-V走RISC路线
8. **RISC-V**：开源指令集架构，模块化设计（基本集+扩展），正在改变处理器产业格局
