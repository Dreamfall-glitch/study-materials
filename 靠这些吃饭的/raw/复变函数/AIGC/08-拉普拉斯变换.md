# 08-拉普拉斯变换

## 知识地图

```
傅里叶变换(需绝对可积) → 乘e^{-σt}衰减 → 拉普拉斯变换 s=σ+iω
    ↓
正/逆变换定义 → 收敛域ROC → 性质(线性/时移/频移/微分/积分/卷积)
    ↓
逆变换方法(部分分式+查表 / 留数反演) → 解ODE/系统分析
```

**本讲回答的核心问题**：为什么要从傅里叶变换推广到拉普拉斯变换？收敛域（ROC）为什么是拉普拉斯变换的核心概念？如何用拉普拉斯变换将微分方程化为代数方程？

---

## 1. 从傅里叶到拉普拉斯

### 1.1. 傅里叶变换的局限

傅里叶变换要求 $f(t)$ 绝对可积：$\int_{-\infty}^{\infty} |f(t)| dt < \infty$。这排除了许多常见信号，如 $e^{at}$（$a > 0$）、$t^n$ 等。在数学物理中，这还意味着傅里叶变换无法直接处理许多实际方程的解。

### 1.2. 推广思路

核心技巧：给 $f(t)$ 乘一个指数衰减因子 $e^{-\sigma t}$，只要 $\sigma$ 足够大，就能压制任何多项式甚至指数增长，使乘积绝对可积：

$$
\int_{-\infty}^{\infty} |f(t) e^{-\sigma t}| dt < \infty
$$

对 $f(t) e^{-\sigma t}$ 做傅里叶变换：

$$
F(\sigma + i\omega) = \int_{-\infty}^{\infty} [f(t) e^{-\sigma t}] e^{-i\omega t}\,dt = \int_{-\infty}^{\infty} f(t) e^{-(\sigma + i\omega)t}\,dt
$$

令 $s = \sigma + i\omega$，得到**拉普拉斯变换**（Laplace transform）：

$$
\boxed{F(s) = \mathcal{L}[f(t)] = \int_{-\infty}^{\infty} f(t) e^{-st}\,dt}
$$

> **直观理解**：傅里叶变换分析的是虚轴 $s = i\omega$ 上的行为。拉普拉斯变换将分析扩展到整个复平面——$s$ 可以是 $\sigma + i\omega$ 上任意一点。多出来的"宽度"（$\sigma$ 维度）提供了处理发散信号的灵活性。

### 1.3. 收敛域（ROC）

$F(s)$ 仅在使积分收敛的 $s$ 值上有定义。这个 $s$ 的取值范围称为**收敛域**（region of convergence, ROC）。

ROC 的基本性质：
- ROC 是 $s$ 平面上由 $\operatorname{Re}(s) = \sigma_0$ 界定的半平面（或带状区域）
- ROC 内不能包含极点——极点是 ROC 的边界

**例题**：求 $f(t) = e^{-at} u(t)$（$u(t)$ 是单位阶跃函数）的拉普拉斯变换及 ROC。

$$
F(s) = \int_0^{\infty} e^{-at} e^{-st}\,dt = \int_0^{\infty} e^{-(s+a)t}\,dt = \frac{1}{s + a}
$$

积分收敛条件：$\operatorname{Re}(s + a) > 0$，即 $\operatorname{Re}(s) > -a$。

ROC 是 $s$ 平面上 $\operatorname{Re}(s) = -a$ 右侧的半平面。极点 $s = -a$ 正好在 ROC 的边界上。

### 1.4. 双边与单边拉普拉斯变换

**双边拉普拉斯变换**（bilateral）积分从 $-\infty$ 到 $\infty$，适用于一般信号分析。ROC 因信号在正负半轴的行为而异。

**单边拉普拉斯变换**（unilateral）积分从 $0^-$ 到 $\infty$，是工程中最常用的形式：

$$
F(s) = \int_{0^-}^{\infty} f(t) e^{-st}\,dt
$$

积分下限取 $0^-$ 可自动捕捉 $t=0$ 处的冲激和初始条件。单边变换在解初值问题时特别方便——微分性质中直接包含了初始条件。

> **数学物理 vs 信号系统**：数学物理课程强调双边变换（理论完整），信号系统侧重单边变换（实用，解ODE）。本章主要讨论单边变换。

## 3. 拉普拉斯变换的性质

| 性质 | 时域 | 拉氏域 | 说明 |
|:-----|:-----|:------|:-----|
| **线性** | $af + bg$ | $aF + bG$ | |
| **时移** | $f(t - t_0)u(t - t_0)$ | $e^{-st_0}F(s)$ | 延迟对应指数乘子 |
| **频移** | $e^{s_0 t}f(t)$ | $F(s - s_0)$ | $s$ 域平移 |
| **尺度** | $f(at)$ | $\frac{1}{a}F(s/a)$ | |
| **时域微分** | $f'(t)$ | $sF(s) - f(0^-)$ | 含初始条件 |
| **$n$ 阶微分** | $f^{(n)}(t)$ | $s^n F(s) - s^{n-1}f(0^-) - \cdots - f^{(n-1)}(0^-)$ | |
| **时域积分** | $\int_0^t f(\tau)d\tau$ | $\dfrac{F(s)}{s}$ | |
| **卷积** | $f * g$ | $F(s)G(s)$ | 与傅里叶一致 |

### 3.1. 微分性质的妙用

时域微分性质将微分方程转化为代数方程——这是拉普拉斯变换最强大的应用：

$$
\mathcal{L}[y'(t)] = sY(s) - y(0^-), \quad \mathcal{L}[y''(t)] = s^2 Y(s) - s y(0^-) - y'(0^-)
$$

初始条件自然地嵌入到代数方程中，不需要在最后单独处理。

**例题**：解 $y'' + 3y' + 2y = 0$，$y(0) = 1$，$y'(0) = 0$。

对两边取拉普拉斯变换：

$$
[s^2 Y - s \cdot 1 - 0] + 3[sY - 1] + 2Y = 0
$$

整理：

$$
(s^2 + 3s + 2)Y = s + 3 \quad \Rightarrow \quad Y(s) = \frac{s + 3}{(s+1)(s+2)}
$$

做部分分式：$Y(s) = \dfrac{2}{s+1} - \dfrac{1}{s+2}$。逆变换：

$$
y(t) = 2e^{-t} - e^{-2t}, \quad t \geq 0
$$

> 整个过程没有求过一次不定积分——拉普拉斯变换将 ODE 的初值问题变成了有理函数的部分分式分解，简洁优雅。

## 4. 拉普拉斯逆变换

### 4.1. 部分分式法

最常见的方法是将 $F(s)$ 分解为已知变换对的分式组合。核心公式：

$$
\frac{1}{(s + a)^n} \leftrightarrow \frac{t^{n-1}}{(n-1)!} e^{-at}
$$

$$
\frac{\omega}{(s + a)^2 + \omega^2} \leftrightarrow e^{-at} \sin(\omega t), \quad \frac{s + a}{(s + a)^2 + \omega^2} \leftrightarrow e^{-at} \cos(\omega t)
$$

### 4.2. 留数反演公式

这是复变函数论与拉普拉斯变换的交汇点。逆变换的积分形式为：

$$
f(t) = \frac{1}{2\pi i} \int_{\sigma - i\infty}^{\sigma + i\infty} F(s) e^{st}\,ds
$$

其中 $\sigma$ 大于所有极点的实部。通过复变围道积分和留数定理：

$$
f(t) = \sum \operatorname{Res}[F(s) e^{st}, s_k]
$$

其中 $s_k$ 是 $F(s)$ 的所有极点。**拉普拉斯逆变换 = $F(s) e^{st}$ 所有极点的留数之和**——复变函数论在实用中的完美体现。

## 5. 傅里叶与拉普拉斯对比

| 维度 | 傅里叶变换 | 拉普拉斯变换 |
|:-----|:---------|:----------|
| 积分核 | $e^{-i\omega t}$（纯振荡） | $e^{-st} = e^{-\sigma t} e^{-i\omega t}$（振荡+衰减） |
| 变量域 | 实频率轴 $\omega$ | 复 $s$ 平面 |
| 收敛要求 | 绝对可积 | 存在 $\sigma$ 使 $f(t)e^{-\sigma t}$ 绝对可积 |
| 适用范围 | 稳定信号 | 稳定 + 发散信号 |
| 初值处理 | 需单独处理 | 自然嵌入微分性质 |
| 主要应用 | 频谱分析、滤波、PDE | ODE 求解、系统稳定性、控制理论 |

> **一句话总结**：傅里叶变换是拉普拉斯变换在 $s$ 平面虚轴上的"截面"——拉普拉斯变换是傅里叶变换的全平面推广，因引入了衰减因子 $e^{-\sigma t}$ 而拥有更广的适用范围。

---

## 本讲核心要点

1. 拉普拉斯变换 = 傅里叶变换 + 指数衰减因子 $e^{-\sigma t}$，将分析从虚轴扩展到整个复 $s$ 平面。
2. 收敛域（ROC）是 $s$ 平面上的半平面（或带状区域），其边界由极点决定，ROC 内不能含极点。
3. 微分性质 $y' \leftrightarrow sY - y(0^-)$ 将 ODE 初值问题转化为代数方程——初始条件自动嵌入。
4. 逆变换的两条路径：部分分式 + 查表（工程常用），留数反演公式 $f(t) = \sum\operatorname{Res}[F(s)e^{st}]$（数学物理常用）。
5. 傅里叶与拉普拉斯是对偶工具：傅里叶看"稳态频谱"，拉普拉斯看"全复平面行为"，后者是前者的推广。
