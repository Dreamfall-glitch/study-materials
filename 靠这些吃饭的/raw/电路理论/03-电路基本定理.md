# 03-电路基本定理

## 知识地图

```
线性电阻电路分析方法（第二章）
    ↓
【电路基本定理】—— 从不同视角理解电路行为的"利器"
    ↓
动态电路分析 → 正弦稳态分析 → 后续各章
```

**本讲回答的核心问题**：除了列方程求解，还有什么更巧妙的方式理解线性电路的行为？叠加定理如何简化多电源电路？戴维南定理如何把复杂网络简化为一个电压源和一个电阻？

## 1. 叠加定理与齐性定理

### 1.1. 齐性定理（Homogeneity Theorem / Scaling Theorem）

**齐性定理**：在线性电路中，当所有独立源（电压源和电流源）同时扩大（或缩小）$K$ 倍时，电路中各支路的响应（电压、电流）也同比例扩大（或缩小）$K$ 倍。

> **通俗理解**：齐性定理说的就是"线性"的本质——输入翻倍，输出也翻倍。如果电池电压翻倍，而且电流源电流也翻倍，那么所有支路的电流和电压也都翻倍。

### 1.2. 叠加定理（Superposition Theorem）

**叠加定理**是线性电路最重要的定理之一：

**在线性电路中，任一响应（电压或电流）等于各独立源单独作用时在该处产生的响应的代数和。**

#### (1). 使用步骤

1. **保留一个独立源**，其余独立源"置零"：
   - 电压源置零 → **短路**（替换为导线）
   - 电流源置零 → **开路**（移除该支路）
2. **受控源始终保留**（不能置零，因为它们不是独立激励）
3. 计算该独立源单独作用时的分量响应
4. 重复步骤 1-3 对所有独立源
5. 将所有分量响应**代数相加**（注意参考方向的正负号）

#### (2). 适用注意事项

- **只适用于线性电路**（非线性电路不能叠加）
- **只适用于电压和电流**（功率不能叠加——因为 $p = i^2R$ 不是线性关系）
- 受控源不能单独作用也不能置零，始终保留在电路中

#### (3). 叠加定理示例

**例**：求下图电路中流过 $R_3$ 的电流 $i$。

```
     R1=2Ω      R3=4Ω
  +--/\/\---/\/\---+
  |        |        |
 12V      R2=3Ω    6A
  |        |        |
  +--/\/\---/\/\---+
```

**电压源单独作用**（电流源开路）：

$$
i' = \frac{U_s}{R_1 + R_2 + R_3} = \frac{12}{2 + 3 + 4} = 1.33\ \text{A}
$$

**电流源单独作用**（电压源短路）：

$$
i'' = I_s \times \frac{R_2 + R_1}{R_1 + R_2 + R_3} = 6 \times \frac{3 + 2}{2 + 3 + 4} = 3.33\ \text{A}
$$

**叠加**：$i = i' + i'' = 1.33 + 3.33 = 4.66\ \text{A}$

> **通俗理解**：叠加定理就像"多个人的声音叠加"——先听第一个人说了什么（其他人闭嘴），再听第二个人说了什么（其他人闭嘴），最后把每个人的声音加起来就知道整体效果了。但注意，每个人说话的声音（电压/电流）可以叠加，但"声功率"不能叠加。

### 1.3. 齐性与叠加的关系

齐性定理是叠加定理的一种特殊情况——当**所有**独立源按同一比例变化时。叠加定理则是齐性定理的推广——允许**不同独立源**独立变化，各自的响应分别计算后再叠加。

## 2. 替代定理（Substitution Theorem）

**替代定理**：在电路中，如果已知某支路的电压 $u_k$ 和电流 $i_k$，则可以用一个电压为 $u_k$ 的电压源或一个电流为 $i_k$ 的电流源来替代该支路，而不影响电路中其他部分的电压和电流。

### 2.1. 替代条件

- 替代前后的电路必须有**唯一解**
- 替代的支路与电路其他部分之间**无耦合**（如互感、受控源的控制关系）

### 2.2. 替代定理的应用

替代定理常用于：
- 电路证明中（如证明戴维南定理时使用）
- 将复杂网络中的已知部分用一个简单源代替，简化分析

> **通俗理解**：替代定理的意思是——如果你知道一个黑盒子的端口电压和电流，你可以把这个黑盒子扔掉，换成电池（电压源）或者恒流源，盒子外面的电路不会察觉到任何变化。

## 3. 戴维南定理

**戴维南定理**（Thevenin's Theorem）是电路分析中**最常用**的定理之一。

### 3.1. 定理内容

任何一个**线性含源二端网络**（linear active two-terminal network），对外电路而言，可以等效为一个**理想电压源 $V_{th}$ 串联一个电阻 $R_{th}$**。

- **戴维南电压 $V_{th}$**：开路电压（二端网络端口开路时的端口电压）
- **戴维南电阻 $R_{th}$**：网络中所有独立源置零后的等效电阻（电压源短路、电流源开路）

### 3.2. 求解步骤

1. **将待求支路（负载）从电路中移开**，形成二端网络
2. **求开路电压 $V_{th}$**：计算二端网络端口处的开路电压
3. **求戴维南电阻 $R_{th}$**：
   - **纯电阻网络**：独立源置零后直接计算等效电阻
   - **含受控源**：用外加电源法（外加电压源 $U$，求输入电流 $I$，$R_{th} = U/I$）
4. **画出戴维南等效电路**：$V_{th}$ 串联 $R_{th}$，接回负载
5. **求解负载电流/电压**

```
   复杂含源二端网络       戴维南等效电路
   ┌──────────┐          ┌──────────┐
   │          │          │  ┌─ Rth ─┤
   │  有源    │ o a      │  │       │ o a
   │  网络    │    =     │ Vth      │
   │          │ o b      │  │       │ o b
   └──────────┘          └──┴───────┘
```

### 3.3. 戴维南定理示例

**例**：求下图中负载 $R_L$ 两端的电压。

```
     R1=2Ω      R2=3Ω
  +--/\/\---/\/\---+
  |        |        |
 12V      R3=6Ω   R_L=4Ω
  |        |        |
  +--/\/\---/\/\---+
                a    b
```

**步骤 1**：移除 $R_L$，求开路电压 $V_{ab}$。

$$
V_{th} = V_{ab} = \frac{R_3}{R_1 + R_2 + R_3} \times U_s = \frac{6}{2 + 3 + 6} \times 12 = 6.55\ \text{V}
$$

**步骤 2**：独立源置零（电压源短路），求等效电阻 $R_{th}$。

$$
R_{th} = (R_1 \parallel R_3) + R_2 = \frac{2 \times 6}{2 + 6} + 3 = 1.5 + 3 = 4.5\ \Omega
$$

**步骤 3**：戴维南等效电路接回 $R_L$。

$$
U_L = V_{th} \times \frac{R_L}{R_{th} + R_L} = 6.55 \times \frac{4}{4.5 + 4} = 3.08\ \text{V}
$$

### 3.4. 诺顿定理（Norton's Theorem）

**诺顿定理**是戴维南定理的对偶形式：任何一个线性含源二端网络对外电路可等效为一个**理想电流源 $I_N$ 并联一个电阻 $R_N$**。

- **诺顿电流 $I_N$**：短路电流（二端网络端口短路时的端口电流）
- **诺顿电阻 $R_N$**：等于戴维南电阻 $R_{th}$（$R_N = R_{th}$）

戴维南等效与诺顿等效之间可通过**实际电源等效变换**互相转换：

$$
V_{th} = I_N \cdot R_{th} \quad \Longleftrightarrow \quad I_N = V_{th} / R_{th}
$$

### 3.5. 最大功率传输定理

**最大功率传输定理**（Maximum Power Transfer Theorem）：当负载电阻 $R_L$ 等于戴维南等效电阻 $R_{th}$ 时，负载获得的功率最大。

$$
P_{L,max} = \frac{V_{th}^2}{4 R_{th}}
$$

此时传输效率仅为 50%（电源内阻消耗一半的功率）。

> **通俗理解**：负载电阻和电源内阻要"匹配"才能获得最大功率——这就是为什么音响系统中喇叭的阻抗要和功放的输出阻抗匹配。但电力传输追求的是高效率而非最大功率，所以采用"低内阻 + 高负载"的方式（效率接近 100%）。

## 4. 特勒根定理（Tellegen's Theorem）

**特勒根定理**是电路理论中最具一般性的定理之一——它只依赖于 KCL 和 KVL（即电路的拓扑结构），而与元件的具体特性无关。

### 4.1. 特勒根定理 I（功率守恒定理）

对于任一电路，在任何时刻，所有支路吸收的功率代数和为零：

$$
\boxed{\sum_{k=1}^{b} u_k i_k = 0}
$$

其中 $u_k$ 和 $i_k$ 取**关联参考方向**（如果某个支路取非关联方向，公式中对应项取负号）。

**物理意义**：电路中所有元件吸收的功率之和等于所有元件发出的功率之和——功率守恒。

### 4.2. 特勒根定理 II（似功率守恒定理）

对于两个具有**相同拓扑结构**（相同的图）但元件不同的电路，在某一时刻，第一个电路的支路电压与第二个电路的对应支路电流的乘积之和为零：

$$
\sum_{k=1}^{b} u_k' i_k'' = 0
$$

其中 $u_k'$ 为电路 A 中支路 $k$ 的电压（取关联方向），$i_k''$ 为电路 B 中对应支路 $k$ 的电流。

> **通俗理解**：特勒根定理 I 说"功率守恒"——发多少电就用多少电，这是个物理事实。特勒根定理 II 说明使是两个不同的电路，只要连接方式一样，就会存在类似的"交叉守恒"关系——这是个纯拓扑结论，与元件无关。特勒根定理常被用于证明和导出其他电路定理。

## 5. 互易定理（Reciprocity Theorem）

**互易定理**描述的是线性无源网络的一种对称性质。

### 5.1. 定理内容

对于一个仅含**线性无源元件**（电阻、电感、电容，不含独立源和受控源）的二端口网络：

**情况一（电压源-电流响应互易）**：在端口 1 施加电压源 $u_s$，在端口 2 测得短路电流 $i_2$；若将该电压源移到端口 2（同样大小），则端口 1 的短路电流 $i_1$ 等于之前 $i_2$。

**情况二（电流源-电压响应互易）**：在端口 1 施加电流源 $i_s$，在端口 2 测得上开路电压 $u_2$；若将该电流源移到端口 2，则端口 1 的开路电压 $u_1$ 等于之前 $u_2$。

### 5.2. 数学表达

对于互易网络，其阻抗矩阵（或导纳矩阵）是对称的：

$$
Z_{12} = Z_{21} \quad \text{或} \quad Y_{12} = Y_{21}
$$

> **通俗理解**：互易定理的意思就是——"你推我，我也一样推你"。在无源线性网络中，如果 A 处加激励在 B 处产生了响应，那么把激励换到 B 处，在 A 处会得到完全相同的响应。这就像一条绳子——你在这头拉一下，那头会有反应；换到那拉一下，这头也会有同样的反应。

## 6. 对偶原理（Duality Principle）

### 6.1. 对偶原理的概念

**对偶原理**指出：如果电路中的某些量、定律或定理之间存在一一对应的关系（对偶关系），那么由其中的一个可以推出另一个。

### 6.2. 常见的对偶量

|       对偶项 A       |       对偶项 B       |
| :---------------: | :---------------: |
|      电压 $u$       |      电流 $i$       |
|      电阻 $R$       |      电导 $G$       |
|      电感 $L$       |      电容 $C$       |
|        开路         |        短路         |
| KVL（$\sum u = 0$） | KCL（$\sum i = 0$） |
|        串联         |        并联         |
|        网孔         |        节点         |
|       戴维南定理       |       诺顿定理        |
|        电压源        |        电流源        |

### 6.3. 对偶电路的画法

1. 原电路中的每个**网孔**对应其对偶电路中的一个**节点**
2. 原电路中的每个**节点**对应其对偶电路中的一个**网孔**
3. 原电路中串联网孔边界的元件 → 并联在对偶节点之间的元件
4. 原电路中并联在节点之间的元件 → 串联在对偶网孔边界的元件

> **通俗理解**：对偶就像"照镜子"——镜子中的电路和原电路有对应关系，知道其中一个就知道另一个。比如串联的电阻分压公式，通过对偶可以直接得到并联的电导分流公式，不需要重新推导。

---

## 本讲核心要点

1. **叠加定理**是线性电路最根本的定理——各独立源单独作用后叠加，受控源始终保留，功率不能叠加
2. **齐性定理**是叠加的特例——所有源按相同比例变化时响应同比例变化
3. **替代定理**——已知支路电压/电流后可用电压源/电流源替换该支路
4. **戴维南定理**是最实用的简化工具——任何含源二端网络→$V_{th}$ 串联 $R_{th}$，求解负载电流/电压非常方便
5. **诺顿定理**是戴维南的对偶——电流源并联电阻，$I_N = V_{th}/R_{th}$，$R_N = R_{th}$
6. **最大功率传输定理**——$R_L = R_{th}$ 时 $P_{max} = V_{th}^2/4R_{th}$，效率 50%
7. **特勒根定理**只依赖电路拓扑（KCL/KVL），与元件无关——I 说功率守恒，II 说交叉守恒
8. **互易定理**——无源线性网络中激励与响应位置互换后大小不变，阻抗/导纳矩阵对称
9. **对偶原理**——电压↔电流、串联↔并联、网孔↔节点、戴维南↔诺顿等一一对应
