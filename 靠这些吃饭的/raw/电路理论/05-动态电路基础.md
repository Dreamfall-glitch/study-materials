## 1. 动态电路元件

**动态元件**（dynamic element）是指其电压-电流关系涉及微分或积分的元件，包括电容（capacitor）和电感（inductor）。区别于电阻（当前状态立即响应），动态元件具有**记忆效应**——其当前状态与过去的历史有关。

### 1.1. 电容元件

#### (1). 定义

**电容**（capacitance）是表征导体储存电荷能力的物理量。一个电容器由两个导体中间夹以绝缘介质构成。

**电容的定义式**：

$$
q = C u
$$

其中 $q$ 为极板上的电荷量，$u$ 为两极板间的电压，$C$ 为**电容量**，单位 **法拉**（Farad, F）。

#### (2). 伏安关系（VCR）

在关联参考方向下（电流从电压正极流入），电容的伏安关系为**微分形式**：

$$
\boxed{i(t) = C \frac{du(t)}{dt}}
$$

**物理意义**：电容中的电流正比于电压的变化率——电压变化越快，电流越大。如果电压恒定不变（直流），则电流为 0（电容相当于开路）。

**积分形式**：

$$
\boxed{u(t) = \frac{1}{C} \int_{-\infty}^{t} i(\tau) d\tau = u(t_0) + \frac{1}{C} \int_{t_0}^{t} i(\tau) d\tau}
$$

其中 $u(t_0)$ 为初始时刻 $t_0$ 的电压（即**初始状态**）。

#### (3). 储能特性

电容储存的是**电场能**（electric field energy）：

$$
\boxed{W_C(t) = \frac{1}{2} C u^2(t)}
$$

电容是一个**无源元件**——它可以储存能量但不能产生能量。当电压增加时，电容从电路吸收能量并储存在电场中；当电压减小时，电容将能量释放回电路。

#### (4). 串并联等效

**电容串联**：

$$
\frac{1}{C_{eq}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots + \frac{1}{C_n}
$$

**电容并联**：

$$
C_{eq} = C_1 + C_2 + \cdots + C_n
$$

> **注意**：电容的串并联规律与电阻**相反**——电容串联等效值减小（类似电阻并联），并联等效值增大（类似电阻串联）。

> **通俗理解**：电容就像一个"电压惯性"的元件——它试图维持两端电压不变。电压要变化？必须给它充/放电流才行。电压变化越快，需要的电流越大。所以直流电路中，电容最终会充满电，电流为 0。

### 1.2. 电感元件

#### (1). 定义

**电感**（inductance）是表征载流导体产生磁通能力的物理量。一个电感器通常由导线绕制而成（线圈）。

**电感的定义式**：

$$
\Psi = N \Phi = L i
$$

其中 $\Psi$ 为磁链（总磁通），$N$ 为线圈匝数，$\Phi$ 为磁通，$i$ 为电流，$L$ 为**电感量**，单位 **亨利**（Henry, H）。

#### (2). 伏安关系（VCR）

在关联参考方向下，电感的伏安关系为**微分形式**：

$$
\boxed{u(t) = L \frac{di(t)}{dt}}
$$

**物理意义**：电感两端的电压正比于电流的变化率——电流变化越快，感应电压越大。如果电流恒定不变（直流），则电压为 0（电感相当于短路）。

**积分形式**：

$$
\boxed{i(t) = \frac{1}{L} \int_{-\infty}^{t} u(\tau) d\tau = i(t_0) + \frac{1}{L} \int_{t_0}^{t} u(\tau) d\tau}
$$

其中 $i(t_0)$ 为初始时刻 $t_0$ 的电流（即**初始状态**）。

#### (3). 储能特性

电感储存的是**磁场能**（magnetic field energy）：

$$
\boxed{W_L(t) = \frac{1}{2} L i^2(t)}
$$

电感也是**无源元件**——当电流增加时吸收能量储存在磁场中，当电流减小时释放能量。

#### (4). 串并联等效

**电感串联**：

$$
L_{eq} = L_1 + L_2 + \cdots + L_n
$$

**电感并联**：

$$
\frac{1}{L_{eq}} = \frac{1}{L_1} + \frac{1}{L_2} + \cdots + \frac{1}{L_n}
$$

> **注意**：电感的串并联规律与电阻**相同**——串联增大，并联减小。

> **通俗理解**：电感就像一个"电流惯性"的元件——它试图维持流过它的电流不变。电流要变化？必须给它两端施加电压才行。电流变化越快，需要的电压越大。所以直流电路中，电感最终成为"一条导线"，两端电压为 0。

### 1.3. 电容与电感的对偶性

电容和电感具有高度的**对偶关系**：

| 对偶项 | 电容 $C$ | 电感 $L$ |
|:------:|:--------:|:--------:|
| 物理量 | 电荷 $q$ | 磁链 $\Psi$ |
| 元件约束 | $q = Cu$ | $\Psi = Li$ |
| VCR 微分 | $i = Cdu/dt$ | $u = Ldi/dt$ |
| VCR 积分 | $u = u_0 + \int i dt / C$ | $i = i_0 + \int u dt / L$ |
| 储能 | $W_C = \frac{1}{2}Cu^2$ | $W_L = \frac{1}{2}Li^2$ |
| 直流特性 | 开路 | 短路 |
| 串联 | $\frac{1}{C_{eq}} = \sum\frac{1}{C_k}$ | $L_{eq} = \sum L_k$ |
| 并联 | $C_{eq} = \sum C_k$ | $\frac{1}{L_{eq}} = \sum\frac{1}{L_k}$ |
| 状态量 | 电压 $u$（不能突变） | 电流 $i$（不能突变） |

## 2. 动态电路核心概念

### 2.1. 电路状态与过渡过程

**电路状态**（circuit state）是指动态元件的储能状态——电容上的电压 $u_C(t)$ 和电感上的电流 $i_L(t)$ 是**状态变量**（state variable）。

**过渡过程**（transient process）是指当电路结构或参数发生突变（如开关动作）时，电路从一个稳态过渡到另一个稳态的过程。

> **通俗理解**：电路中的过渡过程就像"汽车不能瞬间从 0 加速到 100km/h"——电容的电压不能突变（充电需要时间），电感的电流不能突变（磁通建立需要时间）。这些"惯性"导致了过渡过程。

### 2.2. 换路定理与初始条件

**换路**（switching）是指在 $t = 0$ 时刻，电路中的开关动作或参数突然变化。

**换路定理**（switching law）：在换路瞬间（$t = 0$），电容上的电压和电感上的电流**不能突变**。

数学表述：

$$
\boxed{u_C(0^+) = u_C(0^-)}
$$

$$
\boxed{i_L(0^+) = i_L(0^-)}
$$

其中 $0^-$ 为换路前的瞬间，$0^+$ 为换路后的瞬间。

> **关键推论**：换路瞬间，电容可视为一个电压源（电压值为 $u_C(0^+)$）；电感可视为一个电流源（电流值为 $i_L(0^+)$）。利用这一点可以求解 $t = 0^+$ 时刻的初始条件。

**其他量的初始值**（如 $i_C(0^+)$、$u_L(0^+)$、$du_C/dt|_{0^+}$ 等）可能发生突变，需要通过换路后的电路方程求解。

### 2.3. 稳态与暂态分析

- **稳态**（steady state）：电路中的电压、电流趋于稳定（直流稳态）或周期性重复（交流稳态）
- **暂态**（transient state）：从换路开始到进入新稳态之间的过渡过程

动态电路的完整响应 = **暂态响应** + **稳态响应**

在直流激励下，经过足够长的时间（$t \to \infty$）后：
- 电容 → 开路（$i_C = 0$）
- 电感 → 短路（$u_L = 0$）

### 2.4. 时域分析与频域分析

#### (1). 时域分析（Time-Domain Analysis）

直接在时间域中建立和求解电路的微分方程。得到的结果是电压、电流随时间变化的函数 $u(t)$、$i(t)$。

**特点**：
- 物理意义直观，能直接看到随时间的变化过程
- 需要求解微分方程，对高阶系统较复杂
- 适用于分析暂态过程

#### (2). 频域分析（Frequency-Domain Analysis）

通过傅里叶变换或拉普拉斯变换，将时域的微分方程转化为频域的代数方程，求解后再反变换回时域。

**特点**：
- 将微分方程转化为代数方程，求解更简单
- 能更清晰地看到系统的频率特性
- 适用于分析稳态响应和系统函数

> **通俗理解**：时域分析就像"用录像机记录整个比赛过程"——能看到每个时刻发生了什么。频域分析像"用频谱分析仪看声音的组成"——不关心每个时刻的具体值，而是看整体上哪些频率成分占主导。两者是从不同角度观察同一个电路行为。

| 电路概念 | 信号与系统概念 |

## 本讲核心要点

1. **电容**的 VCR 是 $i = C du/dt$——电压不能突变，储能 $W_C = \frac{1}{2}Cu^2$
2. **电感**的 VCR 是 $u = L di/dt$——电流不能突变，储能 $W_L = \frac{1}{2}Li^2$
3. 电容和电感都具有**记忆效应**（历史依赖），区别于电阻的无记忆特性
4. **换路定理**：$u_C(0^+) = u_C(0^-)$，$i_L(0^+) = i_L(0^-)$，这是初始条件求解的根本依据
5. **换路瞬间**：电容等效为电压源（值 $u_C(0^+)$），电感等效为电流源（值 $i_L(0^+)$）
6. **直流稳态**下电容开路、电感短路
7. 动态电路分析的本质是**求解微分方程**，包含暂态（通解）和稳态（特解）两部分
8. 时域分析（微分方程）和频域分析（变换域）是两种互补的动态电路分析方法
9. 电容与电感具有**完美对偶性**，记住一个即可通过互换对应量推出另一个
10. 动态电路分析是**信号与系统**课程中 LTI 系统分析的基础
