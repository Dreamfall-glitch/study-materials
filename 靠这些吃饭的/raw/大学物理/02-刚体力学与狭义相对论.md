# 02-刚体力学与狭义相对论

## 知识地图

```
刚体定轴转动：θ → ω = dθ/dt → α = dω/dt
    ↓
转动惯量 J = Σmᵢrᵢ² → 平行轴定理
    ↓
转动定律 M = Jα → 动能 Ek = ½Jω²
    ↓
角动量 L = Jω → 角动量守恒(∑M外=0)
    ↓ ────────────────────────
狭义相对论
    ↓
洛伦兹变换 → 同时相对性 → 动钟变慢 → 动尺变短
    ↓
相对论动力学：E = γm₀c² → E² = p²c² + (m₀c²)²
```

**本讲回答的核心问题**：刚体转动中如何建立与平动对应的物理量？狭义相对论如何修正经典时空观？

---

## 1. 刚体定轴转动

### 1.1. 刚体运动的分类

| 类型 | 特征 | 描述方式 |
|:----|:-----|:--------|
| **平动** | 刚体内任意两点连线方向不变 | 用质心运动描述（质点力学） |
| **定轴转动** | 刚体绕固定轴转动 | 用角量描述（$\theta, \omega, \alpha$） |
| **一般运动** | 平动 + 转动 | 质心平动 + 绕质心转动 |

### 1.2. 角量与线量的关系

| 角量 | 与线量的关系 |
|:----|:------------|
| 角位移 $\Delta\theta$ | 弧长 $\Delta s = r\Delta\theta$ |
| 角速度 $\omega = \dfrac{d\theta}{dt}$ | 线速度 $v = \omega r$ |
| 角加速度 $\alpha = \dfrac{d\omega}{dt}$ | 切向加速度 $a_\tau = \alpha r$ |
| | 法向加速度 $a_n = \omega^2 r$ |

**匀速圆周运动**：$\omega = \text{常量}$，$v = \omega r$，$a_n = \omega^2 r$

**匀变速圆周运动**（$\alpha = \text{常量}$）：

$$
\begin{aligned}
\omega &= \omega_0 + \alpha t \\
\theta &= \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2 \\
\omega^2 &= \omega_0^2 + 2\alpha(\theta - \theta_0)
\end{aligned}
$$

> 与匀变速直线运动的公式形式完全对应。

### 1.3. 平动与转动的对应关系

| 平动（质点力学） | 转动（刚体力学） |
|:----------------|:----------------|
| 力 $\mathbf{F}$ | **力矩** $\mathbf{M} = \mathbf{r} \times \mathbf{F}$ |
| 质量 $m$ | **转动惯量** $J = \sum m_i r_i^2$ |
| 加速度 $\mathbf{a}$ | **角加速度** $\alpha$ |
| 牛顿第二定律 $\mathbf{F} = m\mathbf{a}$ | **转动定律** $\mathbf{M} = J\boldsymbol{\alpha}$ |
| 动量 $\mathbf{p} = m\mathbf{v}$ | **角动量** $\mathbf{L} = J\boldsymbol{\omega}$ |
| 动能 $E_k = \frac{1}{2}mv^2$ | **转动动能** $E_k = \frac{1}{2}J\omega^2$ |
| 动量定理 $\mathbf{F}dt = d\mathbf{p}$ | **角动量定理** $\mathbf{M}dt = d\mathbf{L}$ |
| 动量守恒 $\sum\mathbf{F}_{\text{外}} = 0$ | **角动量守恒** $\sum\mathbf{M}_{\text{外}} = 0$ |

### 1.4. 转动惯量的计算

**定义式**：$J = \sum_i m_i r_i^2$（离散分布）或 $J = \int r^2 dm$（连续分布）

**平行轴定理**：$J = J_C + m d^2$
- $J_C$：绕质心轴的转动惯量
- $d$：两平行轴间的距离

**常见刚体的转动惯量**：

| 刚体 | 转轴位置 | 转动惯量 |
|:----|:---------|:--------|
| 细圆环 | 过中心垂直环面 | $J = mR^2$ |
| 细圆环 | 沿直径 | $J = \frac{1}{2}mR^2$ |
| 圆盘/圆柱 | 过中心垂直盘面 | $J = \frac{1}{2}mR^2$ |
| 实心球体 | 沿直径 | $J = \frac{2}{5}mR^2$ |
| 细杆 | 过中心垂直杆 | $J = \frac{1}{12}mL^2$ |
| 细杆 | 过端点垂直杆 | $J = \frac{1}{3}mL^2$ |

### 1.5. 刚体转动的功和能

**力矩的功**：$dW = \mathbf{M} \cdot d\boldsymbol{\theta}$，$W = \int_{\theta_1}^{\theta_2} M\,d\theta$

**转动动能**：$E_k = \dfrac{1}{2}J\omega^2$

**刚体定轴转动的动能定理**：合外力矩的功等于转动动能的增量。

$$
W_{\text{合}} = \dfrac{1}{2}J\omega_2^2 - \dfrac{1}{2}J\omega_1^2
$$

## 2. 狭义相对论

### 2.1. 狭义相对论的基本原理

1. **相对性原理**：所有物理定律在所有惯性系中形式相同
2. **光速不变原理**：真空中光速在所有惯性系中都是常量 $c$

### 2.2. 洛伦兹变换

设 $S'$ 系沿 $x$ 方向以速度 $u$ 相对 $S$ 系运动，$t = t' = 0$ 时两原点重合：

**正变换**（$S \to S'$）：

$$
\begin{aligned}
x' &= \gamma(x - ut) \\
y' &= y \\
z' &= z \\
t' &= \gamma\left(t - \frac{u}{c^2}x\right)
\end{aligned}
$$

其中**洛伦兹因子** $\gamma = \dfrac{1}{\sqrt{1 - u^2/c^2}} \geq 1$

**逆变换**（$S' \to S$）：将 $u$ 替换为 $-u$，带撇与不带撇互换。

### 2.3. 狭义相对论的时空效应

#### 同时的相对性

在 $S$ 系中同时发生的两个事件（$\Delta t = 0$），在 $S'$ 系中不一定同时（$\Delta t' \neq 0$）：

$$
\Delta t' = \gamma\left(\Delta t - \frac{u}{c^2}\Delta x\right) = -\gamma\frac{u}{c^2}\Delta x
$$

#### 动钟变慢（时间膨胀）

在 $S'$ 系中静止的时钟（$\Delta x' = 0$），在 $S$ 系中观察其走时变慢：

$$
\boxed{\Delta t = \gamma \Delta \tau}
$$

- $\Delta \tau$：**固有时**（相对于时钟静止的参考系中测得的时间）
- $\Delta t$：**运动时**（相对于时钟运动的参考系中测得的时间）

**物理含义**：运动时钟变慢——"运动的钟走得慢"。

#### 动尺变短（长度收缩）

在 $S'$ 系中静止的杆（长度 $L_0$），在 $S$ 系中测量其长度沿运动方向收缩：

$$
\boxed{L = \frac{L_0}{\gamma}}
$$

- $L_0$：**固有长度**（相对于杆静止的参考系中测得的长度）
- $L$：**运动长度**（相对于杆运动的参考系中测得的长度）

**物理含义**：运动物体在运动方向上长度收缩——"运动的尺变短"。

> 自己的话：动钟变慢和动尺变短不是"看起来"的错觉，而是时空本身的特性。一对双胞胎——哥哥坐飞船高速旅行回来变年轻（双生子佯谬），是因为哥哥经历了加速过程，参考系不对称。

### 2.4. 相对论动力学

#### 相对论质量

质量随速度变化：

$$
\boxed{m = \gamma m_0}
$$

- $m_0$：**静质量**（物体静止时的质量）
- $m$：**相对论质量**（运动时的质量）

#### 相对论动量

$$
\mathbf{p} = m\mathbf{v} = \gamma m_0\mathbf{v}
$$

#### 相对论能量

**静能**：$E_0 = m_0c^2$

**总能量**：

$$
\boxed{E = mc^2 = \gamma m_0c^2}
$$

**动能**：$E_k = E - E_0 = (\gamma - 1)m_0c^2$

**低速近似**（$v \ll c$）：$E_k \approx \dfrac{1}{2}m_0v^2$（回到经典力学）

#### 能量-动量关系

**核心公式**：

$$
\boxed{E^2 = p^2c^2 + (m_0c^2)^2}
$$

**三种情形**：
- 静止粒子（$p = 0$）：$E = m_0c^2$
- 光子（$m_0 = 0$）：$E = pc$，$p = \dfrac{h}{\lambda}$

> 自己的话：相对论的 $E = mc^2$ 表明能量和质量是同一事物的两面——核反应中质量亏损转化为巨大的能量，就是依据这个公式。

#### 速度变换

相对论速度变换（一维情况）：

$$
v_x' = \frac{v_x - u}{1 - \dfrac{uv_x}{c^2}}, \quad v_x = \frac{v_x' + u}{1 + \dfrac{uv_x'}{c^2}}
$$

## 本讲核心要点

1. **刚体转动与质点平动一一对应**：$F \to M$，$m \to J$，$p \to L$，$v \to \omega$
2. **平行轴定理** $J = J_C + md^2$ 是计算转动惯量的核心工具
3. **转动定律** $M = J\alpha$ 是刚体转动的牛顿第二定律
4. **狭义相对论两条基本原理**：相对性原理 + 光速不变原理
5. **洛伦兹变换**同时修正时间和空间，$c$ 是极限速度
6. **动钟变慢** $\Delta t = \gamma\Delta\tau$：运动时钟走时变慢
7. **动尺变短** $L = L_0/\gamma$：运动物体在运动方向上长度收缩
8. **质能关系** $E = mc^2 = \gamma m_0c^2$：质量与能量等价
9. **能量-动量关系** $E^2 = p^2c^2 + (m_0c^2)^2$：相对论力学的核心公式
10. **光子**的静质量为零，动量 $p = h/\lambda$，能量 $E = pc$
