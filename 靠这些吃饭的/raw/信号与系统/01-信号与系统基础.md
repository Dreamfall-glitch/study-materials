## 1. 信号的基本概念

### 1.1. 信号的定义

**信号**（signal）从一般意义上讲就是信息的载体，它携带了关于某物理现象或系统状态的信息。数学上，信号表示为一个或多个自变量的函数。

**系统**（system）是具有某种特定功能的、相互作用相互依赖的若干组成部分结合成的稳定整体，它对输入信号进行处理并产生输出信号。

> 课件中的定义："信号从一般意义上讲就是信息的载体。信息的功能就是传送给接收者以消除对特定对象状态的不确定性。"

### 1.2. 信号的分类

| 分类标准 | 类别 | 说明 | 示例 |
|:--------:|:----|:----|:----|
| **自变量类型** | **连续时间信号** $x(t)$ | 时间 $t$ 连续变化 | 语音信号、温度曲线 |
| | **离散时间信号** $x[n]$ | 时间 $n$ 取整数离散值 | 数字音频、股票日数据 |
| **取值类型** | **模拟信号** | 振幅连续取值 | 传统模拟电视信号 |
| | **数字信号** | 振幅量化（有限个值） | 数字通信数据 |
| **周期性** | **周期信号** | $x(t+T)=x(t)$ | 正弦波 |
| | **非周期信号** | 不具有周期性 | 语音信号、瞬态信号 |
| **能量/功率** | **能量信号** | $E = \int_{-\infty}^{\infty} \|x(t)\|^2 dt < \infty$ | 脉冲信号 |
| | **功率信号** | $P = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} \|x(t)\|^2 dt < \infty$ | 周期信号、随机信号 |
| **确定性** | **确定信号** | 可精确表示为数学函数 | 正弦波 $A\sin(\omega t)$ |
| | **随机信号** | 不可精确预测 | 噪声信号 |

**能量信号 vs 功率信号**：能量有限的是能量信号（$P=0$），能量无限但功率有限的是功率信号。周期信号一定是功率信号。

### 1.3. 基本连续时间信号

**实指数信号**：$x(t) = Ae^{\alpha t}$
- $\alpha < 0$：衰减振荡（稳定电路响应）
- $\alpha > 0$：增长（不稳定）
- $\alpha = 0$：直流

**正弦信号**：$x(t) = A\cos(\omega_0 t + \phi)$
- $\omega_0 = 2\pi f_0 = 2\pi/T$，$T$ 为周期

**复指数信号**：$x(t) = e^{st} = e^{(\sigma + j\omega)t} = e^{\sigma t}[\cos(\omega t) + j\sin(\omega t)]$

> 复指数信号是所有 LTI 系统的**特征函数**——即复指数输入通过 LTI 系统后输出仍是同频率的复指数（仅幅值和相位变化）。这是傅里叶变换和拉普拉斯变换的理论基础。

**单位阶跃信号**（unit step function）：

$$
u(t) = \begin{cases}
1, & t > 0 \\
0, & t < 0
\end{cases}
$$

**单位冲激信号**（unit impulse function）$\delta(t)$：

$\delta(t)$ 不是一个普通函数，而是一个**广义函数**（分布），其定义由其与其他函数作用的结果（抽样性质）给出：

$$
\int_{-\infty}^{\infty} f(t)\delta(t - t_0)\,dt = f(t_0)
$$

**冲激信号的性质**（课件中列出）：
- $\delta(t) = \frac{d}{dt}u(t)$，$u(t) = \int_{-\infty}^{t} \delta(\tau)\,d\tau$
- $\int_{-\infty}^{\infty} \delta(t)\,dt = 1$
- $\delta(at) = \frac{1}{|a|}\delta(t)$（尺度变换性质）
- $\int_{-\infty}^{\infty} f(t)\delta'(t)\,dt = -f'(0)$（冲激偶性质）

 **例1.19**：计算含冲激函数的积分。 

### 1.4. 基本离散时间信号

**单位脉冲序列**（unit pulse / unit sample）：

$$
\delta[n] = \begin{cases}
1, & n = 0 \\
0, & n \neq 0
\end{cases}
$$

**单位阶跃序列**：

$$
u[n] = \begin{cases}
1, & n \geq 0 \\
0, & n < 0
\end{cases}
$$

关系：$\delta[n] = u[n] - u[n-1]$，$u[n] = \sum_{k=-\infty}^{n} \delta[k]$

**实指数序列**：$x[n] = A r^n$
- $|r| < 1$：衰减；$|r| > 1$：增长；$r$ 为负时交替振荡

**正弦序列**：$x[n] = A\cos(\Omega_0 n + \phi)$
- $\Omega_0$ 为数字角频率（弧度/样本），$\Omega_0 = \omega_0 T_s$

## 2. 信号的基本运算

### 2.1. 连续时间信号的运算

| 运算 | 数学表达 | 几何效果 |
|:----:|:--------|:---------|
| **平移** | $x(t - t_0)$ | $t_0 > 0$ 右移（延时），$t_0 < 0$ 左移（超前） |
| **反转** | $x(-t)$ | 关于 $t=0$ 对称翻转 |
| **尺度变换** | $x(at)$ | $a > 1$ 压缩，$0 < a < 1$ 扩展 |
| **压扩** | $x(at - b)$ | 先平移后尺度变换，或先尺度变换后平移 |

**运算顺序**：对于 $x(at - b)$，有两种等效操作顺序：
1. 先平移 $x(t-b)$，再尺度变换 $x(at - b)$
2. 先尺度变换 $x(at)$，再平移 $x(a(t - b/a))$

**例1.3.1**：按不同运算顺序画出信号变换过程图和结果图。

### 2.2. 离散时间信号的运算

| 运算 | 数学表达 | 说明 |
|:----:|:--------|:----|
| **平移** | $x[n - n_0]$ | $n_0 > 0$ 右移（延迟） |
| **反转** | $x[-n]$ | 关于 $n=0$ 翻转 |
| **尺度变换** | $x[kn]$（抽取）| 每 $k$ 点取一点（降采样） |
| | $x[n/k]$（插值）| 两点间插零（升采样）|

> 注意：离散信号的尺度变换是**抽取**和**插值**操作，与连续信号的 $x(at)$ 有本质区别——离散尺度变换会改变序列长度。

### 2.3. 信号的奇偶分解

任何信号 $x(t)$ 可以分解为偶分量和奇分量之和：

$$
x(t) = x_e(t) + x_o(t)
$$

其中：

$$
x_e(t) = \frac{x(t) + x(-t)}{2} \quad (\text{偶分量}), \qquad
x_o(t) = \frac{x(t) - x(-t)}{2} \quad (\text{奇分量})
$$

对于离散信号：$x_e[n] = (x[n] + x[-n])/2$，$x_o[n] = (x[n] - x[-n])/2$。

## 3. 信号的正交分解与相关

### 3.1. 信号的内积与正交

在信号空间中，两个信号的内积定义为：

$$
\langle x(t), y(t) \rangle = \int_{-\infty}^{\infty} x(t) y^*(t)\,dt
$$

若 $\langle x(t), y(t) \rangle = 0$，则称 $x(t)$ 和 $y(t)$ **正交**。

### 3.2. 相关系数与相关函数

**相关系数**衡量两个信号的相似程度：

$$
\rho_{xy} = \frac{\int x(t) y(t)\,dt}{\sqrt{\int x^2(t)\,dt \int y^2(t)\,dt}}
$$

**相关函数**描述两个信号在不同时移下的相似度：
- 互相关：$R_{xy}(\tau) = \int_{-\infty}^{\infty} x(t) y(t - \tau)\,dt = \int_{-\infty}^{\infty} x(t + \tau) y(t)\,dt$
- 自相关：$R_{xx}(\tau) = \int_{-\infty}^{\infty} x(t) x(t - \tau)\,dt$

> 相关函数与卷积的关系：$R_{xy}(\tau) = x(\tau) * y(-\tau)$。相关在信号检测、雷达、通信中有广泛应用。

## 4. 系统的基本概念

### 4.1. 系统的表示

系统对输入信号（激励）$e(t)$ 产生输出信号（响应）$r(t)$，记为：

$$
r(t) = T[e(t)]
$$

其中 $T$ 表示系统对输入信号的变换或映射。

连续时间系统的一般数学描述形式是**微分方程**：

$$
\frac{d^n r}{dt^n} + a_{n-1}\frac{d^{n-1}r}{dt^{n-1}} + \cdots + a_0 r = b_m\frac{d^m e}{dt^m} + \cdots + b_0 e
$$

离散时间系统的一般数学描述形式是**差分方程**：

$$
r[n] + a_1 r[n-1] + \cdots + a_N r[n-N] = b_0 e[n] + b_1 e[n-1] + \cdots + b_M e[n-M]
$$

> **电路系统建模**（课件中有RLC电路的例子，这里精简指出要点）：
> 通过 KCL、KVL 和元件约束（$v_R = Ri$，$v_L = L\frac{di}{dt}$，$i_C = C\frac{dv_C}{dt}$）建立电路的微分方程。

**例1.30**：RLC电路的微分方程建模与线性、时不变性证明。


### 4.2. 系统的分类

| 性质 | 数学条件 | 意义 |
|:----:|:---------|:-----|
| **线性** | $T[ae_1 + be_2] = aT[e_1] + bT[e_2]$ | 齐次性 + 叠加性 |
| **时不变性** | $T[e(t - t_0)] = r(t - t_0)$ | 系统参数不随时间变化 |
| **因果性** | $r(t)$ 只与 $t$ 时刻及之前的 $e(t)$ 有关 | 输出不超前于输入 |
| **稳定性** | $\|e(t)\| < \infty \implies \|r(t)\| < \infty$ | 有界输入产生有界输出（BIBO） |
| **无记忆性** | $r(t)$ 只与当前 $e(t)$ 有关 | 即时系统（如纯电阻网络） |

> **LTI 系统（线性时不变系统）**：同时满足线性和时不变性的系统。LTI 系统可以用**卷积**完整描述，是信号与系统课程的绝对核心。

**线性系统与非线性系统的判别**：
- 线性：满足叠加性 $T[e_1 + e_2] = T[e_1] + T[e_2]$ 和齐次性 $T[ae] = aT[e]$
- 非线性：不满足上述任意一条

**时变系统与时不变系统的判别**：
- 时不变：系统的响应特性不随时间改变——输入延时 $t_0$，输出也延时同样的 $t_0$
- 判别方法：输出表达式中若出现与时间 $t$ 有关的系数乘在输入信号上（如 $t \cdot e(t)$），则为时变

### 4.3. LTI 系统的时域描述

**连续时间 LTI 系统**：由**冲激响应** $h(t)$（系统对单位冲激 $\delta(t)$ 的响应）唯一确定。系统的零状态响应为**卷积积分**：

$$
r(t) = e(t) * h(t) = \int_{-\infty}^{\infty} e(\tau) h(t - \tau)\,d\tau
$$

**离散时间 LTI 系统**：由**单位脉冲响应** $h[n]$（系统对 $\delta[n]$ 的响应）唯一确定。系统的零状态响应为**卷积和**：

$$
r[n] = e[n] * h[n] = \sum_{k=-\infty}^{\infty} e[k] h[n - k]
$$

卷积的**图解计算步骤**（两个域通用）：
1. **反转**：将 $h(\tau)$ 反转为 $h(-\tau)$
2. **平移**：将 $h(-\tau)$ 平移 $t$ 得 $h(t-\tau)$
3. **相乘**：将 $e(\tau)$ 与 $h(t-\tau)$ 相乘
4. **积分/求和**：对乘积求积分（连续）或求和（离散）

> **卷积的性质**：
> - 交换律：$e * h = h * e$
> - 结合律：$(e * h_1) * h_2 = e * (h_1 * h_2)$
> - 分配律：$e * (h_1 + h_2) = e * h_1 + e * h_2$
> - 与冲激的卷积：$e(t) * \delta(t - t_0) = e(t - t_0)$（位移性质）

## 本讲核心要点

1. **信号**是信息的载体，**系统**是对信号进行变换的整体——$r(t) = T[e(t)]$
2. **连续信号** $x(t)$ 用微分方程描述，**离散信号** $x[n]$ 用差分方程描述——两种域的分析方法平行对应
3. **能量信号**有限能量零功率，**功率信号**无限能量有限功率——周期信号一定是功率信号
4. **$\delta(t)$（连续）** 和 **$\delta[n]$（离散）** 是最基本的"基元"信号——任何信号可以分解为移位冲激的加权和
5. **系统性质**（线性、时不变、因果、稳定）决定分析方法的选择——LTI 系统是课程的绝对核心
6. **卷积**是 LTI 系统的描述方式——连续为积分，离散为求和，两者数学结构完全对应
7. **LTI 系统的特征函数**是复指数信号 $e^{st}$——这是傅里叶和拉普拉斯变换的根本动机
