# 05-拉普拉斯变换与Z变换

## 知识地图

```
傅里叶变换（已学）—— 将信号分解为虚指数 $e^{j\omega t}$ 的加权和
    ↓
【拉普拉斯变换】—— 将信号分解为复指数 $e^{st}$（$s = \sigma + j\omega$）的加权和
【Z变换】—— 离散域对应拉普拉斯变换的复频域工具
    ↓
系统函数分析、稳定性判定、频响特性
```

**本讲回答的核心问题**：傅里叶变换只分析 $s = j\omega$ 轴上的信号特性，拉普拉斯变换将其推广到整个复平面——这对系统分析和稳定性判定意味着什么？离散域的等效工具 Z 变换如何对应？

---

## 1. 拉普拉斯变换的基本概念

### 1.1. 从傅里叶变换到拉普拉斯变换

傅里叶变换将信号分解为 $e^{j\omega t}$ 的加权和，要求信号绝对可积。但许多重要信号（如 $e^{at}u(t)$，$a>0$）不满足该条件。

**推广思路**：将信号乘以一个实指数衰减因子 $e^{-\sigma t}$，使其变得绝对可积：

$$\int_{-\infty}^{\infty} \left|f(t) e^{-\sigma t}\right| dt = \int_{-\infty}^{\infty} \left|f(t)\right| e^{-\sigma t} dt < \infty$$

只要 $\sigma$ 选得足够大，就能使积分收敛。然后对 $f(t) e^{-\sigma t}$ 求傅里叶变换：

$$F(j\omega) = \int_{-\infty}^{\infty} \left[f(t) e^{-\sigma t}\right] e^{-j\omega t} dt = \int_{-\infty}^{\infty} f(t) e^{-(\sigma + j\omega)t} dt$$

令 $s = \sigma + j\omega$，即得到**拉普拉斯变换**。

### 1.2. 双边拉普拉斯变换的定义

**正变换**：

$$
\boxed{F(s) = \mathcal{L}[f(t)] = \int_{-\infty}^{\infty} f(t) e^{-st}\,dt}
$$

**逆变换**：

$$
\boxed{f(t) = \mathcal{L}^{-1}[F(s)] = \frac{1}{2\pi j}\int_{\sigma - j\infty}^{\sigma + j\infty} F(s) e^{st}\,ds}
$$

### 1.3. 单边拉普拉斯变换

在实际工程中，物理信号通常有起始时间（因果信号），使用**单边拉普拉斯变换**更为方便：

$$
\boxed{F(s) = \int_{0^-}^{\infty} f(t) e^{-st}\,dt}
$$

**积分下限取 $0^-$** 的原因：可以包含在 $t = 0$ 处可能存在的冲激及其导数，从而自动包含系统的初始条件。

### 1.4. 收敛域（ROC）

**收敛域**（Region of Convergence, ROC）是使拉普拉斯变换积分收敛的 $s$ 的取值范围。ROC 通常由 $s$ 平面上的垂直边界（收敛坐标 $\sigma_0$）界定。

**常见信号的 ROC**：

| 信号 $f(t)$ | $F(s)$ | ROC |
|:-----------|:------|:----|
| $\delta(t)$ | $1$ | 全 $s$ 平面 |
| $u(t)$（单位阶跃） | $\frac{1}{s}$ | $\text{Re}[s] > 0$ |
| $-u(-t)$（左边指数） | $\frac{1}{s}$ | $\text{Re}[s] < 0$ |
| $e^{-at}u(t)$（右边因果） | $\frac{1}{s + a}$ | $\text{Re}[s] > -a$ |
| $-e^{-at}u(-t)$（左边反因果） | $\frac{1}{s + a}$ | $\text{Re}[s] < -a$ |
| $e^{-a\|t\|}$（双边指数） | $\frac{2a}{a^2 - s^2}$ | $-a < \text{Re}[s] < a$ |
| $\cos(\omega_0 t) u(t)$ | $\frac{s}{s^2 + \omega_0^2}$ | $\text{Re}[s] > 0$ |
| $\sin(\omega_0 t) u(t)$ | $\frac{\omega_0}{s^2 + \omega_0^2}$ | $\text{Re}[s] > 0$ |
| $e^{-at}\cos(\omega_0 t)u(t)$ | $\frac{s + a}{(s + a)^2 + \omega_0^2}$ | $\text{Re}[s] > -a$ |
| $e^{-at}\sin(\omega_0 t)u(t)$ | $\frac{\omega_0}{(s + a)^2 + \omega_0^2}$ | $\text{Re}[s] > -a$ |
| $t^n u(t)$ | $\frac{n!}{s^{n+1}}$ | $\text{Re}[s] > 0$ |
| $t^n e^{-at}u(t)$ | $\frac{n!}{(s + a)^{n+1}}$ | $\text{Re}[s] > -a$ |

### 1.5. ROC 的重要性质

1. **ROC 是 $s$ 平面上的平行于虚轴的带状区域**（不包含任何极点）
2. **右边信号**的 ROC 在极点的右侧（最右极点以右）
3. **左边信号**的 ROC 在极点的左侧（最左极点以左）
4. **双边信号**的 ROC 位于两个极点之间的带状区域（若存在的话）
5. **有限长信号**的 ROC 是整个 $s$ 平面（可能不包含 $s = \infty$）
6. ROC 内**不能包含极点**——极点是 ROC 的边界

> **区分右边和左边信号**：右边信号（因果信号）为 $f(t)u(t)$，左边信号（反因果）为 $f(t)u(-t)$。ROC 在极点的哪一侧，直接决定逆变换对应的是哪一类信号。

## 2. 拉普拉斯变换的性质

| 序号 | 性质 | 时域 $f(t)$ | 拉氏域 $F(s)$ | ROC |
|:---:|:----:|:-----------|:-------------|:----|
| 1 | **线性** | $af_1(t) + bf_2(t)$ | $aF_1(s) + bF_2(s)$ | $\text{ROC}_1 \cap \text{ROC}_2$ |
| 2 | **时移** | $f(t - t_0)u(t - t_0)$ | $e^{-st_0}F(s)$ | 不变（可能加减 $s=\infty$）|
| 3 | **频移/$s$ 域平移** | $e^{s_0 t} f(t)$ | $F(s - s_0)$ | 平移 $\text{Re}[s_0]$ |
| 4 | **尺度变换** | $f(at)$ | $\frac{1}{a}F\!\left(\frac{s}{a}\right)$ | 缩放 $a$ 倍 |
| 5 | **时域微分** | $\frac{d}{dt}f(t)$ | $sF(s) - f(0^-)$ | $\supseteq \text{ROC}$ |
| 6 | **时域二阶微分** | $\frac{d^2}{dt^2}f(t)$ | $s^2 F(s) - s f(0^-) - f'(0^-)$ | $\supseteq \text{ROC}$ |
| 7 | **时域积分** | $\int_{0^-}^{t} f(\tau) d\tau$ | $\frac{1}{s}F(s)$ | $\supseteq \text{ROC} \cap \{\text{Re}[s] > 0\}$ |
| 8 | **频域微分** | $(-t)^n f(t)$ | $\frac{d^n}{ds^n}F(s)$ | 不变 |
| 9 | **频域积分** | $\frac{f(t)}{t}$ | $\int_s^{\infty} F(\eta) d\eta$ | 取决于信号 |
| 10 | **时域卷积** | $f_1(t) * f_2(t)$ | $F_1(s) \cdot F_2(s)$ | $\text{ROC}_1 \cap \text{ROC}_2$ |
| 11 | **初值定理** | $\lim_{t \to 0^+} f(t) = \lim_{s \to \infty} sF(s)$ | — | $F(s)$ 为真分式 |
| 12 | **终值定理** | $\lim_{t \to \infty} f(t) = \lim_{s \to 0} sF(s)$ | — | $sF(s)$ 在 $j\omega$ 轴上解析 |

### 2.1. 时域微分性质（最重要性质之一）

$$\mathcal{L}\left[\frac{d}{dt}f(t)\right] = sF(s) - f(0^-)$$

**物理意义**：时域中的微分运算在 $s$ 域中变为代数乘法——这使得微分方程可以转化为 $s$ 域的代数方程来求解，大大简化了计算。**初始条件自动包含在变换中**，这是拉普拉斯变换相比于傅里叶变换用于系统分析的最大优势之一。

### 2.2. 初值定理与终值定理

**初值定理**：直接从 $F(s)$ 的极限得到 $f(t)$ 在 $t = 0^+$ 处的值，无需进行逆变换。

$$
f(0^+) = \lim_{s \to \infty} sF(s)
$$

**终值定理**：从 $F(s)$ 在 $s=0$ 附近的行为推断 $f(t)$ 在 $t \to \infty$ 时的稳态值。

$$
\lim_{t \to \infty} f(t) = \lim_{s \to 0} sF(s)
$$

> **注意**：终值定理仅在 $sF(s)$ 在 $j\omega$ 轴上（包括原点）解析时成立。若系统有虚轴上的极点（如纯正弦），终值定理不适用（信号不趋于稳态）。

## 3. 拉普拉斯逆变换

### 3.1. 部分分式展开法（最常用的方法）

将 $F(s)$ 展开为部分分式之和，然后利用基本变换对查表得到逆变换。

**基本思路**：$F(s) = \frac{N(s)}{D(s)}$（真分式）

**(1) 单极点**：$F(s) = \sum_{i=1}^{n} \frac{K_i}{s - p_i}$，$K_i = (s - p_i)F(s)\big|_{s=p_i}$

**(2) 共轭复极点**：$p = -\alpha \pm j\beta$，对应

$$\frac{K}{s + \alpha - j\beta} + \frac{K^*}{s + \alpha + j\beta} \longleftrightarrow 2|K|e^{-\alpha t}\cos(\beta t + \angle K) \cdot u(t)$$

**(3) 多重极点**：$p$ 为 $r$ 重极点，$F(s) = \frac{K_{11}}{(s-p)^r} + \frac{K_{12}}{(s-p)^{r-1}} + \cdots + \frac{K_{1r}}{s-p} + \cdots$

$$K_{1j} = \frac{1}{(j-1)!}\frac{d^{j-1}}{ds^{j-1}}\left[(s-p)^r F(s)\right]\big|_{s=p}$$

**例**：求 $F(s) = \frac{s + 3}{s^2 + 3s + 2}$ 的逆变换。

解：$D(s) = (s+1)(s+2)$，设 $F(s) = \frac{A}{s+1} + \frac{B}{s+2}$

$A = (s+1)F(s)\big|_{s=-1} = \frac{-1+3}{-1+2} = 2$

$B = (s+2)F(s)\big|_{s=-2} = \frac{-2+3}{-2+1} = -1$

所以 $F(s) = \frac{2}{s+1} - \frac{1}{s+2}$，逆变换 $f(t) = (2e^{-t} - e^{-2t})u(t)$。

### 3.2. 留数法

$$f(t) = \sum \text{Res}[F(s)e^{st}] \quad \text{在} \ F(s) \ \text{的各极点处}$$

对于单极点 $p_i$：$\text{Res} = (s-p_i)F(s)e^{st}\big|_{s=p_i}$

## 4. 用拉普拉斯变换求解微分方程

**标准步骤**：

1. 对微分方程两边取拉普拉斯变换（记得代入初始条件 $r(0^-), r'(0^-), \dots$）
2. 解出 $R(s)$
3. 对 $R(s)$ 做部分分式展开
4. 查表进行拉普拉斯逆变换，得到 $r(t)$

**例**：求解 $r''(t) + 3r'(t) + 2r(t) = e(t)$，$e(t) = u(t)$，$r(0^-) = 1$，$r'(0^-) = 0$。

第一步：取拉普拉斯变换

$$[s^2 R(s) - s\cdot 1 - 0] + 3[sR(s) - 1] + 2R(s) = \frac{1}{s}$$

第二步：解出 $R(s)$

$$(s^2 + 3s + 2)R(s) - s - 3 = \frac{1}{s}$$
$$R(s) = \frac{s^2 + 3s + 1}{s(s+1)(s+2)}$$

第三步：部分分式展开

$$R(s) = \frac{1/2}{s} + \frac{-1}{s+1} + \frac{1/2}{s+2}$$

第四步：逆变换

$$r(t) = \left(\frac{1}{2} - e^{-t} + \frac{1}{2}e^{-2t}\right)u(t)$$

## 5. 系统函数与系统分析

### 5.1. 系统函数（转移函数）

**系统函数**（转移函数）$H(s)$ 定义为系统零状态响应的拉普拉斯变换与输入激励的拉普拉斯变换之比：

$$
\boxed{H(s) = \frac{R_{zs}(s)}{E(s)}}
$$

也等于冲激响应的拉普拉斯变换：$H(s) = \mathcal{L}[h(t)]$。

### 5.2. 系统函数与系统特性

- **极点**（$H(s)$ 的分母零点）$\to$ 系统的**自然频率**（齐次解的形式）
- **零点**（$H(s)$ 的分子零点）$\to$ 影响系统对各频率的响应幅度
- **极点位置决定了系统的稳定性**（如下表）

### 5.3. 稳定性分析

| 极点位置（$s$ 平面） | 对应时域响应形式 | 系统稳定性 |
|:------------------:|:---------------:|:---------:|
| 左半平面（$\text{Re}[p] < 0$） | $e^{-\alpha t}$ 衰减 | **稳定** |
| 虚轴单极点（$\text{Re}[p] = 0$） | 等幅振荡 / 常数 | **临界稳定** |
| 右半平面（$\text{Re}[p] > 0$） | $e^{\alpha t}$ 增长 | **不稳定** |
| 虚轴重极点 | $t e^{\alpha t}$ 增长 | **不稳定** |

**BIBO 稳定性判据**：系统稳定的充要条件——系统函数 $H(s)$ 的所有极点都位于 $s$ 平面的左半开平面（不包含虚轴）。

### 5.4. 由系统函数求频率响应

令 $s = j\omega$，系统函数退化为频率响应：

$$H(j\omega) = H(s)\big|_{s = j\omega}$$

前提：系统稳定（$j\omega$ 轴在 ROC 内）。

## 6. Z 变换（离散域的系统函数分析）

### 6.1. 从拉普拉斯变换到 Z 变换

对采样信号 $x_s(t) = \sum_{n=-\infty}^{\infty} x_a(nT_s) \delta(t - nT_s)$ 取拉普拉斯变换：

$$X_s(s) = \sum_{n=-\infty}^{\infty} x_a(nT_s) e^{-snT_s}$$

令 $z = e^{sT_s}$，即得到 Z 变换。

### 6.2. Z 变换的定义

**双边 Z 变换**：

$$
\boxed{X(z) = \mathcal{Z}[x[n]] = \sum_{n=-\infty}^{\infty} x[n] z^{-n}}
$$

**单边 Z 变换**（工程中使用更多）：

$$
\boxed{X(z) = \sum_{n=0}^{\infty} x[n] z^{-n}}
$$

**逆 Z 变换**（围线积分）：

$$
\boxed{x[n] = \frac{1}{2\pi j} \oint_C X(z) z^{n-1} dz}
$$

### 6.3. 收敛域（ROC）

Z 变换的收敛域是 $z$ 平面上使级数 $\sum |x[n] z^{-n}|$ 收敛的区域。

**常见序列的 Z 变换**：

| 序列 $x[n]$                       | $X(z)$                                           | ROC            |
| :------------------------------- | :----------------------------------------------- | :------------- |
| $\delta[n]$                      | $1$                                              | 全 $z$ 平面    |
| $u[n]$                           | $\frac{1}{1 - z^{-1}}$                           | $\|z\| > 1$    |
| $-u[-n-1]$                       | $\frac{1}{1 - z^{-1}}$                           | $\|z\| < 1$    |
| $a^n u[n]$（$\|a\| < 1$）        | $\frac{1}{1 - a z^{-1}}$                         | $\|z\| > \|a\|$ |
| $-a^n u[-n-1]$                   | $\frac{1}{1 - a z^{-1}}$                         | $\|z\| < \|a\|$ |
| $n a^n u[n]$                     | $\frac{a z^{-1}}{(1 - a z^{-1})^2}$              | $\|z\| > \|a\|$ |
| $r^n \cos(\Omega_0 n) u[n]$      | $\frac{1 - r\cos\Omega_0 z^{-1}}{1 - 2r\cos\Omega_0 z^{-1} + r^2 z^{-2}}$ | $\|z\| > r$     |
| $r^n \sin(\Omega_0 n) u[n]$      | $\frac{r\sin\Omega_0 z^{-1}}{1 - 2r\cos\Omega_0 z^{-1} + r^2 z^{-2}}$     | $\|z\| > r$     |

### 6.4. Z 变换的性质

| 序号 | 性质 | 序列 | Z 变换 | ROC |
| :--: | :--- | :--- | :----- | :-- |
| 1 | **线性** | $ax_1 + bx_2$ | $aX_1 + bX_2$ | $\text{ROC}_1 \cap \text{ROC}_2$ |
| 2 | **时移（单边）** | $x[n - m]$ | $z^{-m}X(z) + \sum_{k=0}^{m-1} x[k-m] z^{-k}$ | 不变（可能增减 $z=0/\infty$） |
| 3 | **$z$ 域尺度** | $a^n x[n]$ | $X(a^{-1}z)$ | $\lvert a \rvert \cdot \text{ROC}$ |
| 4 | **时间反转** | $x[-n]$ | $X(z^{-1})$ | $1/\text{ROC}$（取倒数） |
| 5 | **时域卷积** | $x_1[n] * x_2[n]$ | $X_1(z) \cdot X_2(z)$ | $\text{ROC}_1 \cap \text{ROC}_2$ |
| 6 | **时域差分** | $x[n] - x[n-1]$ | $(1 - z^{-1})X(z)$ | $\supseteq \text{ROC} \cap \{ \lvert z \rvert > 0 \}$ |
| 7 | **时域累加** | $\sum_{k=-\infty}^{n} x[k]$ | $\frac{1}{1 - z^{-1}}X(z)$ | $\supseteq \text{ROC} \cap \{ \lvert z \rvert > 1 \}$ |
| 8 | **初值定理** | $x[0] = \lim_{z \to \infty} X(z)$ | — | $x[n]$ 为因果序列 |
| 9 | **终值定理** | $\lim_{n \to \infty} x[n] = \lim_{z \to 1} (1 - z^{-1})X(z)$ | — | 极点在单位圆内 |
| 10 | **频移/调制** | $e^{j\Omega_0 n}x[n]$ | $X(e^{-j\Omega_0} z)$ | 不变 |

### 6.5. 拉普拉斯变换与 Z 变换的对应关系

| 项目 | 拉普拉斯变换（连续） | Z 变换（离散） |
| :--: | :------------------: | :-------------: |
| **复变量** | $s = \sigma + j\omega$ | $z = re^{j\Omega}$ |
| **映射关系** | — | $z = e^{sT_s}$ |
| **正变换** | $F(s) = \int_0^{\infty} f(t)e^{-st}dt$ | $X(z) = \sum_{n=0}^{\infty} x[n] z^{-n}$ |
| **逆变换** | $f(t) = \frac{1}{2\pi j}\int_{\sigma-j\infty}^{\sigma+j\infty}F(s)e^{st}ds$ | $x[n] = \frac{1}{2\pi j}\oint X(z)z^{n-1}dz$ |
| **收敛域** | $s$ 平面的右半/左半/带状 | $z$ 平面的圆外/圆内/环状 |
| **稳定性条件** | 极点全在**左半平面** | 极点全在**单位圆内** |
| **频率响应** | $H(j\omega) = H(s)\big\vert_{s=j\omega}$ | $H(e^{j\Omega}) = H(z)\big\vert_{z=e^{j\Omega}}$ |
| **微分/差分** | $\frac{d}{dt} \longleftrightarrow s$（含初始条件） | $\nabla \longleftrightarrow 1 - z^{-1}$（差分算子） |
| **积分/累加** | $\int \longleftrightarrow 1/s$ | $\sum \longleftrightarrow 1/(1-z^{-1})$ |
| **卷积** | $f_1(t) * f_2(t) \longleftrightarrow F_1(s)F_2(s)$ | $x_1[n] * x_2[n] \longleftrightarrow X_1(z) X_2(z)$ |

### 6.6. $s$ 平面到 $z$ 平面的映射

$z = e^{sT_s}$ 将 $s$ 平面的区域映射到 $z$ 平面：

|       $s$ 平面       |           $z$ 平面            |
| :----------------: | :-------------------------: |
| 左半平面（$\sigma < 0$） | 单位圆内（$\lvert z \rvert < 1$） |
|  虚轴（$\sigma = 0$）  | 单位圆上（$\lvert z \rvert = 1$） |
| 右半平面（$\sigma > 0$） | 单位圆外（$\lvert z \rvert > 1$） |

这一映射关系直接对应了稳定性条件：
- **连续系统稳定**：极点全在左半 $s$ 平面
- **离散系统稳定**：极点全在单位圆内

### 6.7. 离散系统的系统函数

离散 LTI 系统的系统函数定义为：

$$H(z) = \frac{Y(z)}{X(z)} = \mathcal{Z}[h[n]]$$

从差分方程求 $H(z)$：对差分方程两边取 Z 变换（零状态），解出 $Y(z)/X(z)$。

**稳定性判据**：离散系统 BIBO 稳定 $\iff$ $H(z)$ 的所有极点都位于 $z$ 平面的**单位圆内**。

### 6.8. 用 Z 变换求解差分方程

与用拉普拉斯变换求解微分方程完全类似：

1. 对差分方程两边取单边 Z 变换（代入初始条件 $x[-1], y[-1], \dots$）
2. 解出 $Y(z)$
3. 部分分式展开
4. 查表进行逆 Z 变换

**逆 Z 变换的方法**：
- **部分分式展开法**（最常用）：将 $X(z)$ 展开为部分分式，查表
- **幂级数展开法**（长除法）：将 $X(z)$ 展开为 $z^{-1}$ 的幂级数，直接读出 $x[n]$
- **留数法**：围线积分

## 本讲核心要点

1. **拉普拉斯变换** $F(s) = \int_0^{\infty} f(t) e^{-st}dt$ 将信号分解为复指数 $e^{st}$ 的加权和——推广了傅里叶变换，使更多信号可分析
2. **收敛域 ROC** 决定拉氏变换的有效性和对应的时间函数类型——右边信号 ROC 在最右极点右侧，左边信号在最左极点左侧
3. **时域微分性质** $\mathcal{L}[f'(t)] = sF(s) - f(0^-)$ 将微分方程转化为代数方程——**初始条件自动包含**，这是拉普拉斯变换的核心优势
4. **部分分式展开法**是拉普拉斯逆变换最实用的方法——将 $F(s)$ 分解为基本项，查表得到时域解
5. **系统函数** $H(s) = R_{zs}(s)/E(s)$ 完全描述了系统的频域和时域特性
6. **极点位置决定稳定性**——稳定 $\iff$ 所有极点在 $s$ 左半平面
7. **Z 变换** $X(z) = \sum x[n] z^{-n}$ 是离散域的系统分析工具，与拉普拉斯变换通过 $z = e^{sT_s}$ 映射
8. **卷积定理**在 $s$ 域和 $z$ 域中都成立——时域卷积变为复频域乘法，简化系统分析
9. **拉普拉斯变换与 Z 变换平行对应**：微分/差分、积分/累加、$s$ 左半平面/单位圆内、$H(s)$/$H(z)$——理解这种对应关系是掌握两类系统分析的关键
10. **稳定性条件对应**：连续系统 $\to$ 极点左半 $s$ 平面；离散系统 $\to$ 极点单位圆内——由 $z = e^{sT_s}$ 映射统一
