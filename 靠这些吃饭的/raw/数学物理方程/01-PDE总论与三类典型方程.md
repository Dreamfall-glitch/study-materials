# 01-PDE总论与三类典型方程

## 知识地图

```
三类经典PDE：波动(双曲) → 输运(抛物) → 拉普拉斯/泊松(椭圆)
    ↓
定解条件：初始条件 + 边界条件(三类) → 适定性(存在+唯一+稳定)
    ↓
分离变量法框架：T·X分离 → 本征值问题 → 叠加积分 → 初始条件定系数
    ↓
四种坐标系：直角→极→柱→球(各引出特殊函数)
```

**本讲回答的核心问题**：物理中常见的偏微分方程有哪些共性？为什么同一种PDE在不同坐标系中解法完全不同？分离变量法背后的统一思想是什么？

---

## 1. 数学物理方程概览

### 1.1. 三种经典 PDE

数学物理方法研究的偏微分方程主要有三类，每一类对应一大类物理现象：

| PDE | 标准形式 | 类型 | 物理背景 | 笔记页码 |
|:----|:--------|:----|:--------|:--------|
| **波动方程**（wave equation） | $u_{tt} = a^2 \nabla^2 u$ | 双曲型 | 弦振动、膜振动、声波、电磁波 | Page 28-29 |
| **输运方程**（diffusion/heat equation） | $u_t = a^2 \nabla^2 u$ | 抛物型 | 热传导、扩散、粒子输运 | Page 30-32 |
| **泊松方程 / 拉普拉斯方程**（Poisson/Laplace） | $\nabla^2 u = -\rho / \varepsilon$ / $\nabla^2 u = 0$ | 椭圆型 | 静电场、稳态温度场、理想流体 | Page 38+ |

这三类 PDE 涵盖了数学物理中绝大多数问题。它们的求解构成了本课程的核心内容。笔记的组织方式正是围绕 **四种坐标系 × 三类/四类 PDE** 展开：

| 坐标系\PDE      | 波动方程 | 输运方程 | 泊松方程 | 拉普拉斯方程   |
| ------------ | ---- | ---- | ---- | -------- |
| 直角坐标 (2D/3D) | -    | -    | -    | -        |
| 极坐标 (2D)     | -    | -    | -    | -        |
| 柱坐标 (3D)     | -    | -    | -    | (→贝塞尔函数) |
| 球坐标 (3D)     | -    | -    | -    | (→勒让德函数) |

> 从这一表格可以看出，求解 PDE 的难点不仅在于方程本身，更在于坐标系的结构——不同坐标系引出不同特殊函数。

### 1.2. 二阶线性 PDE 的分类

二阶线性偏微分方程的一般形式为：

$$
A u_{xx} + B u_{xy} + C u_{yy} + D u_x + E u_y + F u = G
$$

根据判别式 $\Delta = B^2 - 4AC$ 分类（与二次曲线的分类完全一致）：

| $\Delta$ | 类型 | 典型方程 | 特征线 |
|:---------|:----|:--------|:------|
| $\Delta > 0$ | **双曲型**（hyperbolic） | 波动方程 $u_{tt} - a^2 u_{xx} = 0$ | 两条实特征线 |
| $\Delta = 0$ | **抛物型**（parabolic） | 热传导方程 $u_t - a^2 u_{xx} = 0$ | 一条实特征线 |
| $\Delta < 0$ | **椭圆型**（elliptic） | 拉普拉斯方程 $u_{xx} + u_{yy} = 0$ | 无实特征线 |

> **通俗理解**：双曲型方程有"方向性"（如波朝确定的两个方向传播），抛物型方程有"时间箭头"（热传导不可逆），椭圆型方程描述的是"静态"的稳态场（无时间变量）。

## 2. 定解问题

### 2.1. 定解条件的组成

要使 PDE 有唯一确定的解，需要补充两类条件：

**初始条件**（initial condition）：给出 $t=0$ 时函数的值和（对波动方程）时间导数的值：

$$
u(\mathbf{r}, 0) = \varphi(\mathbf{r}), \quad u_t(\mathbf{r}, 0) = \psi(\mathbf{r})
$$

注：输运方程只需要 $u(\mathbf{r}, 0)$，因为 $u_t$ 项是一阶的。

**边界条件**（boundary condition）：给出在区域边界 $\partial D$ 上的约束，分为三类：

| 类型 | 形式 | 含义 | 物理例子 |
| :--- | :--- | :--- | :------- |
| **第一类（Dirichlet）** | $u\big\vert_{\partial D} = f$ | 边界上的函数值已知 | 固定温度的边界 |
| **第二类（Neumann）** | $\left.\dfrac{\partial u}{\partial n}\right\vert_{\partial D} = g$ | 边界上的外法向导数已知 | 绝热边界（$g=0$） |
| **第三类（Robin）** | $\left.\left(\dfrac{\partial u}{\partial n} + \alpha u\right)\right\vert_{\partial D} = h$ | 边界上函数与导数的线性组合 | 热对流边界 |

### 2.2. 适定性

一个定解问题称为**适定的**（well-posed），如果它同时满足三个要求：
- **解存在**（existence）
- **解唯一**（uniqueness）
- **解稳定**（stability）：输入条件的微小变化只导致解有微小变化

## 3. 分离变量法思想框架

### 3.1. 基本思路

分离变量法（separation of variables）是求解线性 PDE 最根本的方法之一。它的核心思想是：

> 假设 PDE 的解可以写成**单变量函数的乘积**，代入 PDE 后通过分离常数将 PDE 分解为多个 ODE。

以一维波动方程为例：

$$
u_{tt} = a^2 u_{xx}
$$

设 $u(x,t) = X(x) T(t)$，代入得 $X T'' = a^2 X'' T$，两边除以 $a^2 X T$：

$$
\frac{T''}{a^2 T} = \frac{X''}{X} = -\lambda
$$

左边只依赖于 $t$，右边只依赖于 $x$，因此两边必须等于同一个常数 $-\lambda$（称为**分离常数**）。于是得到一个关于 $X$ 和 $T$ 的 ODE 组：

$$
\begin{cases}
X'' + \lambda X = 0 \\
T'' + \lambda a^2 T = 0
\end{cases}
$$

> **核心洞察**：分离变量法成功的关键在于 PDE 在所选坐标系中具有可加性结构——拉普拉斯算符 $\nabla^2$ 在不同坐标系中的表达式决定了解能否分离以及形态如何。

### 3.2. 分离变量法的标准流程

```
PDE + 边界条件
    ↓
设 u = X(x)·T(t)                        ← 乘积分离
    ↓
代入 PDE → 分离常数                     ← 化为 ODE 组
    ↓
由边界条件确定本征值 λ_n                ← Sturm-Liouville 问题
    ↓
解得本征函数 X_n(x) 和 T_n(t)
    ↓
叠加 u = Σ c_n X_n(x) T_n(t)           ← 线性叠加原理
    ↓
由初始条件定系数 c_n                    ← Fourier 展开
    ↓
得到定解
```

### 3.3. 不同坐标系中的分离

上述流程在四种坐标系中逐一进行时，每一步都是同一个模板，但拉普拉斯算符的具体形式不同：

- **直角坐标**（Cartesian）：$\nabla^2 = \partial_x^2 + \partial_y^2 + \partial_z^2$ → 分离为三角函数/双曲函数
- **极坐标**（polar）：$\nabla^2 = \frac{1}{r}\partial_r(r\partial_r) + \frac{1}{r^2}\partial_\theta^2$ → 径向引出贝塞尔方程
- **柱坐标**（cylindrical）：$\nabla^2 = \frac{1}{r}\partial_r(r\partial_r) + \frac{1}{r^2}\partial_\theta^2 + \partial_z^2$ → 贝塞尔函数
- **球坐标**（spherical）：$\nabla^2 = \frac{1}{r^2}\partial_r(r^2\partial_r) + \frac{1}{r^2\sin\theta}\partial_\theta(\sin\theta\,\partial_\theta) + \frac{1}{r^2\sin^2\theta}\partial_\phi^2$ → 勒让德多项式、球谐函数

> 这正是我们按**坐标系**组织知识的原因——数学结构随坐标系演进而丰富，值得分别展开。

### 3.4. 四种坐标系的 PDE 问题概览

后续章节将按以下顺序逐类展开：

| 章 | 坐标系 | 主要 PDE | 引入的特殊函数 |
|:---|:------|:--------|:-------------|
| 02-03 | 直角坐标（一维） | 波动方程、输运方程 | 三角函数（基本的 Fourier 级数） |

## 4. 齐次化与线性叠加原理

在开始求解之前，先明确两个最重要的基本工具：

**线性叠加原理**：若 $u_1, u_2$ 满足**线性齐次**PDE 且满足**齐次边界条件**，则它们的任意线性组合 $u = c_1 u_1 + c_2 u_2$ 也满足该 PDE 和边界条件。

**齐次化处理**：当 PDE 或边界条件非齐次（含非零自由项）时，常用两种方法：
- 令 $u = v + w$，将非齐次部分分离出去，使 $v$ 满足齐次 PDE + 齐次边界条件
- 或直接使用特征函数展开法

## 本讲核心要点

1. 三类经典 PDE（波动/输运/拉普拉斯）对应物理中的波动、扩散和稳态现象。按双曲、抛物、椭圆分类，决定解法特征。
2. 定解问题 = PDE + 初始条件（时间维度） + 边界条件（三类：Dirichlet、Neumann、Robin）。适定性要求存在、唯一、稳定。
3. 分离变量法是求解线性 PDE 的统一框架，核心是将 PDE 分解为 ODE 组 + 本征值问题 + 叠加定系数。
4. 本课程的组织逻辑：四种坐标系 × 三类 PDE = 十二种基本情形，每一类引入不同的特殊函数。
5. 拉普拉斯算符在不同坐标系中的表达式决定了分离变量后的 ODE 形式——这是按坐标系组织知识的根本原因。
6. 线性叠加原理是后续所有解法的基石，齐次化是处理非齐次问题的标准技巧。
