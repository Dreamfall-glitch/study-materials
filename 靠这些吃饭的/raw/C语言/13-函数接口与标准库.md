# 13-函数接口与标准库

## 知识地图


## 1. 函数接口设计

### 1.1. 传入参数与传出参数

函数通过参数向函数传递数据，通过返回值返回单个结果。如果需要返回多个值，需要用**传出参数**（指针）：

```c
/* 返回值：单个结果 */
int square(int x) { return x * x; }

/* 传出参数：通过指针返回多个结果 */
void min_max(int *arr, int n, int *min, int *max)
{
    *min = *max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < *min) *min = arr[i];
        if (arr[i] > *max) *max = arr[i];
    }
}
/* 调用方式 */
int min, max;
min_max(array, len, &min, &max);
printf("min=%d, max=%d\n", min, max);
```

**设计建议**：
- 仅用作传入的参数加 `const` 修饰——明确告诉调用者"我不会改它"
- 传出参数放在参数列表前面，和返回值概念上接近

### 1.2. 两层指针

当需要在函数中**修改指针本身**时，需要传指向指针的指针：

```c
void safe_malloc(void **pp, size_t size)
{
    *pp = malloc(size);
    if (*pp == NULL) {
        fprintf(stderr, "Memory allocation failed\n");
        exit(1);
    }
}

int main(void) {
    int *p = NULL;
    safe_malloc(&p, 100 * sizeof(int));    /* 修改了 p 本身 */
    p[0] = 42;
    free(p);
    return 0;
}
```

### 1.3. 返回指针——避免返回局部变量

```c
/* 错误：返回局部变量的地址 */
int *bad(void) {
    int x = 42;
    return &x;         /* x 在函数返回后已被销毁，悬空指针 */
}

/* 正确：返回堆上的内存 */
int *good(void) {
    int *p = malloc(sizeof(int));
    *p = 42;
    return p;          /* 堆上内存存活到 free */
}

/* 正确：返回静态变量 */
int *counter(void) {
    static int count = 0;    /* 静态变量：程序全程存活 */
    count++;
    return &count;
}
```

## 2. 回调函数

回调函数是把"一段行为"作为参数传递，实现通用算法的最简单方式。

```c
/* 通用遍历——对每个元素执行 fn */
void for_each(int *arr, int n, void (*fn)(int *))
{
    for (int i = 0; i < n; i++)
        fn(&arr[i]);
}

void double_it(int *x) { *x *= 2; }
void print_it(int *x)  { printf("%d ", *x); }

for_each(arr, 5, double_it);   /* 所有元素翻倍 */
for_each(arr, 5, print_it);    /* 打印所有元素 */
```

**标准库中的回调——qsort**：

```c
#include <stdlib.h>

int compare_int(const void *a, const void *b)
{
    int ia = *(const int *)a;
    int ib = *(const int *)b;
    return (ia > ib) - (ia < ib);    /* 防溢出写法 */
}

int arr[] = {5, 2, 8, 1, 9};
qsort(arr, 5, sizeof(int), compare_int);  /* arr = {1,2,5,8,9} */
```

## 3. 可变参数

`printf` 可以接受不同数量的参数，C标准库用 `stdarg.h` 提供可变参数机制：

```c
#include <stdarg.h>

int sum(int count, ...)     /* ... 表示可变参数 */
{
    va_list args;
    va_start(args, count);           /* 初始化 args，指向第一个可变参数 */

    int total = 0;
    for (int i = 0; i < count; i++)
        total += va_arg(args, int);  /* 每次获取一个 int 参数 */

    va_end(args);                    /* 清理 */
    return total;
}

printf("%d\n", sum(3, 10, 20, 30));  /* 60 */
printf("%d\n", sum(5, 1, 2, 3, 4, 5)); /* 15 */
```

**要点**：
- 必须至少有一个固定参数（`count`）来定位可变参数开始位置
- `va_arg` 的类型必须与实际参数匹配，否则行为未定义
- 没有编译时类型检查——调用者必须自己保证正确

## 4. C标准库常用函数

### 4.1. 字符串操作（string.h）

```c
size_t len = strlen(s);                 /* 长度（不含 \0） */
char *p = strcpy(dst, src);             /* 复制——不检查 dst 大小！ */
char *p = strncpy(dst, src, n);         /* 更安全：最多复制 n 个 */
int cmp = strcmp(s1, s2);               /* 比较：<0 0 >0 */
char *p = strchr(s, 'c');               /* 查找字符，返回指针或 NULL */
char *p = strstr(s, "abc");             /* 查找子串 */
if (strcmp(user_input, "quit") == 0)    /* 字符串内容比较——必须用 strcmp！ */
    exit(0);
```

**⚠️ 常见陷阱**：`if (s1 == s2)` 比较的是**指针**而不是内容！必须用 `strcmp` 或 `strncmp`。

### 4.2. 标准 I/O（stdio.h）

```c
/* 控制台 I/O */
printf("%s %d\n", "hello", 42);
scanf("%d %s", &n, buf);

/* 文件 I/O */
FILE *fp = fopen("data.txt", "r");      /* r:读 w:写 a:追加 */
if (fp == NULL) {
    perror("fopen");                     /* 打印错误信息 */
    return 1;
}
fprintf(fp, "value=%d\n", 42);
fscanf(fp, "%d", &n);
fgets(buf, sizeof(buf), fp);            /* 安全读取一行（指定最大长度） */
fclose(fp);                              /* 必须关闭！ */

/* 二进制 I/O */
size_t n = fread(buf, 1, sizeof(buf), fp);   /* 读 sizeof(buf) 字节 */
fwrite(buf, 1, n, fp);                       /* 写 n 字节 */
```

### 4.3. 数值转换（stdlib.h）

```c
int a = atoi("123");                    /* 字符串→int */
double d = atof("3.14");               /* 字符串→double */
long n = atol("123456");               /* 字符串→long */

/* 更安全的 strtol——可检测转换错误 */
char *end;
long val = strtol("0xFF", &end, 16);   /* 16进制→255 */

/* 格式化输出到字符串 */
char buf[100];
sprintf(buf, "%d items, $%.2f", count, price);  /* 类似 printf，但输出到 buf */
snprintf(buf, sizeof(buf), "%.2f", d);           /* 更安全：指定缓冲区大小 */
```

### 4.4. 内存管理（stdlib.h）

```c
/* malloc：分配 n 字节，内容未初始化 */
int *p = malloc(100 * sizeof(int));

/* calloc：分配并清零 */
int *q = calloc(100, sizeof(int));      /* 所有元素初始化为 0 */

/* realloc：调整大小（可能移动原数据） */
p = realloc(p, 200 * sizeof(int));      /* 扩大或缩小 */

/* free：释放 */
free(p);
p = NULL;   /* 防止悬空指针 */
```

**黄金法则**：
1. `malloc`/`calloc` 和 `free` 必须配对——每次分配都要有对应的释放
2. `free` 后立即将指针置 NULL，防止悬空指针
3. `realloc` 可能返回新的地址，用同一个指针接收可能泄漏旧地址

## 本讲核心要点

1. **传出参数**（指针）用来返回多个结果；不修改的参数加 `const`
2. **两层指针**用于在函数内修改调用者的指针本身
3. **不要返回局部变量的地址**——返回静态变量或堆内存
4. **qsort 使用函数指针实现通用排序**，第四个参数是比较函数
5. **可变参数**用 `va_list/va_start/va_arg/va_end` 处理，无类型检查
6. **字符串比较必须用 strcmp**，不能用 `==`
7. **fgets 比 gets 安全**——指定缓冲区大小防止溢出
8. **malloc/free 必须配对**，free 后置 NULL 防野指针
9. **snprintf 比 sprintf 安全**——避免缓冲区溢出

## 习题

**1. 用 qsort 对整数数组降序排序。**

```c
int cmp_desc(const void *a, const void *b) {
    int ia = *(const int *)a, ib = *(const int *)b;
    return (ia < ib) - (ia > ib);    /* 降序 */
}
qsort(arr, n, sizeof(int), cmp_desc);
```

**2. 实现一个安全的字符串复制函数。**

```c
char *safe_strcpy(char *dst, const char *src, size_t dst_size) {
    strncpy(dst, src, dst_size - 1);
    dst[dst_size - 1] = '\0';       /* 确保以 \0 结尾 */
    return dst;
}
```
