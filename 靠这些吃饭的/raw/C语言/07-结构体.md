# 07-结构体

## 知识地图

```
结构体：用 struct 将不同类型数据组合为新类型
├── . 运算符访问成员 / 可整体赋值（与数组不同）
    ↓
数据抽象：用函数隐藏存储细节，改动局限于一层
    ↓
enum（枚举常量）优于 #define：有类型检查、调试器可见
    ↓
嵌套：结构体含结构体、结构体含数组
```

**本讲回答的核心问题**：如何用结构体把相关数据打包成一个整体？什么是数据抽象，它为什么重要？枚举和 `#define` 有什么区别？

---

## 1. 复合类型与结构体

### 1.1. 编程语言的三要素

SICP（Structure and Interpretation of Computer Programs）指出，学习编程语言要关注三个方面：
1. **基本元素**（Primitive）：基本类型、基本运算符、表达式和语句
2. **组合规则**：如何将基本元素组合成复合类型、复杂表达式
3. **抽象机制**：数据抽象和过程抽象——把复杂的东西隐藏在一个简单的名字背后

结构体正是"组合规则"和"数据抽象"的集中体现。

### 1.2. 定义结构体

```c
struct complex_struct {
    double x, y;
};    /* 注意：分号绝对不能少！ */
```

- `complex_struct` 称为 **Tag**（标签），是这种结构体类型的名字
- `struct complex_struct` 整个是一个类型名，就像 `int` 或 `double` 一样
- `}` 后面的 `;` 是声明结束符，漏写是初学者常犯的错误

可以用三种方式定义变量：

```c
/* 方式1：先定义类型，再声明变量（推荐） */
struct complex_struct { double x, y; };
struct complex_struct z1, z2;

/* 方式2：定义类型的同时声明变量 */
struct complex_struct { double x, y; } z1, z2;

/* 方式3：匿��结构体（无法在别处使用这个类型） */
struct { double x, y; } z1, z2;    /* 不推荐 */
```

### 1.3. 访问成员

用 `.` 运算符（后缀运算符中优先级最高）：

```c
#include <stdio.h>

int main(void)
{
    struct complex_struct { double x, y; } z;
    double x = 3.0;       /* 普通变量x */

    z.x = x;              /* z.x 是结构体成员，x 是普通变量——不冲突 */
    z.y = 4.0;

    if (z.y < 0)
        printf("z = %f%fi\n", z.x, z.y);
    else
        printf("z = %f+%fi\n", z.x, z.y);
    return 0;
}
```

输出：`z = 3.000000+4.000000i`

**命名空间**：成员名和普通变量名在不同的命名空间中。上面的 `z.x` 中的 `x` 和普通变量 `x` 不会冲突——编译器通过 `.` 前面的表达式区分。

### 1.4. 结构体的初始化

```c
struct complex_struct { double x, y; };

/* 按顺序初始化 */
struct complex_struct z1 = { 3.0, 4.0 };        /* z1.x=3.0, z1.y=4.0 */

/* 数据比成员少，未指定的自动为0 */
struct complex_struct z2 = { 3.0 };              /* z2.x=3.0, z2.y=0.0 */
struct complex_struct z3 = { 0 };                /* z3.x=0.0, z3.y=0.0 */

/* C99: Memberwise Initialization（指定成员名初始化） */
struct complex_struct z4 = { .y = 4.0 };         /* z4.x=0.0, z4.y=4.0 */
```

**重要区分**：`{}` 语法只能用于初始化，不能用于赋值！

```c
struct complex_struct z;
z = { 3.0, 4.0 };              /* 错误！{} 不是表达式，不能赋值 */
```

### 1.5. 结构体的整体赋值

结构体变量之间可以**整体赋值**和**整体初始化**——这与数组完全不同：

```c
struct complex_struct z1 = { 3.0, 4.0 };
struct complex_struct z2 = z1;     /* 合法：用 z1 初始化 z2 */
struct complex_struct z3;
z3 = z1;                           /* 合法：整体赋值 */
```

结构体可以作为函数的参数和返回值：

```c
struct complex_struct add_complex(struct complex_struct z1,
                                   struct complex_struct z2)
{
    z1.x = z1.x + z2.x;
    z1.y = z1.y + z2.y;
    return z1;    /* 返回整个结构体 */
}
```

传参时，结构体的所有成员被**逐个复制**到形参中——仍然是传值调用，但复制的是整个结构体。

### 1.6. 结构体的运算限制

结构体类型**不能做**以下操作：
- 算术运算：`+` `-` `*` `/` 不适用于结构体
- 逻辑运算：`&&` `||` `!` 不适用于结构体
- 作为控制表达式：`if`、`while` 的条件不能是结构体类型

但 `z1 = z2` 这样的赋值是允许的——这是合法的例外。

> 可以做算术运算的叫**算术类型**（整型+浮点型），能做控制表达式或逻辑运算的叫**标量类型**（算术类型+指针类型）。结构体两者都不是。

## 2. 数据抽象

### 2.1. 完整复数运算程序

**直角座标做加减方便，极座标做乘除方便。** 我们可以通过函数隐藏这种内部差异：

**存储表示层**（访问结构体内部成员）：

```c
#include <math.h>

struct complex_struct { double x, y; };

double real_part(struct complex_struct z)  { return z.x; }
double img_part(struct complex_struct z)   { return z.y; }
double magnitude(struct complex_struct z)  { return sqrt(z.x*z.x + z.y*z.y); }
double angle(struct complex_struct z)      { return atan2(z.y, z.x); }

struct complex_struct make_from_real_img(double x, double y) {
    struct complex_struct z;
    z.x = x; z.y = y;
    return z;
}

struct complex_struct make_from_mag_ang(double r, double A) {
    struct complex_struct z;
    z.x = r * cos(A); z.y = r * sin(A);
    return z;
}
```

**运算层**（通过函数接口操作，不直接访问成员）：

```c
struct complex_struct add_complex(struct complex_struct z1,
                                   struct complex_struct z2) {
    return make_from_real_img(real_part(z1) + real_part(z2),
                              img_part(z1) + img_part(z2));
}

struct complex_struct mul_complex(struct complex_struct z1,
                                   struct complex_struct z2) {
    return make_from_mag_ang(magnitude(z1) * magnitude(z2),
                             angle(z1) + angle(z2));
}
```

### 2.2. 抽象的力量

**关键洞察**：`add_complex`、`mul_complex` 等运算函数**从未直接访问** `z.x` 或 `z.y`！它们只通过存储表示层提供的函数接口来获取坐标。

这意味着：**如果改变结构体的存储表示（比如改为用极坐标存储），运算层函数完全不需要修改！**

```c
/* 改为极坐标存储：结构体定义变了，但运算函数一行都不需要改 */
struct complex_struct { double r, A; };    /* 改用 r 和 A 存储！ */

double magnitude(struct complex_struct z)  { return z.r; }
double angle(struct complex_struct z)      { return z.A; }
double real_part(struct complex_struct z)  { return z.r * cos(z.A); }
double img_part(struct complex_struct z)   { return z.r * sin(z.A); }

/* add_complex, mul_complex 等完全不变！ */
```

**分层架构**：

```
应用层：使用复数进行各种计算
    ↓
运算层：add/mul/div（只知道"复数可以加减乘除"）
    ↓
存储表示层：real_part/img_part/make_from（知道内部是x,y还是r,A）
    ↓
struct { double x, y; }  ← 只有这层知道具体存储格式
```

> "计算机科学中的所有问题都可以通过增加一层抽象来解决。" —— Butler Lampson
>
> 通俗理解：抽象就是"提取公因式"。改动只局限在一层，不会波及整个系统。

## 3. 枚举类型与数据类型标志

### 3.1. 枚举（enum）

```c
enum coordinate_type { RECTANGULAR, POLAR };
/* RECTANGULAR = 0, POLAR = 1（默认从0开始） */

enum { MONDAY = 1, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY };
/* TUESDAY=2, WEDNESDAY=3，依次递增 */
```

**枚举 vs #define**：

| 特性 | `enum` | `#define` |
|------|--------|-----------|
| 处理阶段 | 编译阶段 | 预处理阶段（文本替换） |
| 类型检查 | 有（枚举类型） | 无（纯文本） |
| 调试器可见 | 是（调试器知道枚举常量名） | 否（替换后只剩数字） |
| 作用域 | 遵循C作用域规则 | 从定义处到文件末尾 |

优先使用 `enum` 定义整型常量组。

### 3.2. 用枚举做数据类型标志

同一个结构体可以表示两种不同的坐标格式：

```c
enum coordinate_type { RECTANGULAR, POLAR };

struct complex_struct {
    enum coordinate_type t;   /* 类型标志 */
    double a, b;              /* t=0时: a=x(实部) b=y(虚部)
                                  t=1时: a=r(模)  b=A(辐角) */
};
```

构造时打上标志：

```c
struct complex_struct make_from_real_img(double x, double y) {
    struct complex_struct z;
    z.t = RECTANGULAR;  z.a = x;  z.b = y;
    return z;
}

struct complex_struct make_from_mag_ang(double r, double A) {
    struct complex_struct z;
    z.t = POLAR;  z.a = r;  z.b = A;
    return z;
}
```

读数据时根据标志做不同处理——这样直角坐标和极坐标数据都可以存入同一结构体，不需要转换（避免浮点精度损失）。

## 4. 嵌套结构体

### 4.1. 结构体包含结构体

```c
struct segment {
    struct complex_struct start;
    struct complex_struct end;
};
```

初始化方式：

```c
/* 嵌套初始化 */
struct segment s1 = { {1.0, 2.0}, {4.0, 6.0} };

/* 平坦初始化（不推荐，可读性差） */
struct segment s2 = { 1.0, 2.0, 4.0, 6.0 };

/* C99 Memberwise 初始化 */
struct segment s3 = { .start.x = 1.0, .end.x = 2.0 };
```

访问嵌套成员——层层推进：

```c
s.start.x = 1.0;
s.start.y = 2.0;
s.end.x = 3.0;
s.end.y = 4.0;
```

### 4.2. 结构体包含数组

```c
struct polygon {
    struct complex_struct vertices[10];
    int n;    /* 实际顶点数 */
};
```

结构体和数组可以任意嵌套组合，表示复杂的数据结构。

## 本讲核心要点

1. **结构体定义**：`struct Tag { 成员列表 };`，注意末尾分号；成员和普通变量在不同命名空间
2. **成员访问**用 `.` 运算符，`.` 是优先级最高的后缀运算符之一
3. **初始化**：按顺序 `{3.0, 4.0}` / Memberwise `{.y=4.0}`；`{}` 只能初始化不能赋值
4. **结构体可以整体赋值**（`z1 = z2`），可以作函数参数和返回值——与数组完全不同
5. **数据抽象**：通过函数接口隐藏存储细节；改动局限在一层，不波及全局
6. **分层设计**：存储表示层（访问成员）→ 运算层（调用接口）→ 应用层（使用功能）
7. **枚举优于 #define**：编译阶段处理、有类型检查、调试器可见、遵循作用域规则
8. **数据类型标志**：用枚举区分同一结构体的不同语义，避免转换损失精度
9. **嵌套结构体**：结构体可以包含结构体和数组，初始化可嵌套或平坦

## 习题

**1. 实现打印复数的函数：`1.0`、`-2.0i`、`-1.0+2.0i`、`1.0-2.0i`（实部/虚部为0时省略）。**

```c
void print_complex(struct complex_struct z)
{
    double x = real_part(z), y = img_part(z);
    if (x == 0 && y == 0) { printf("0\n"); return; }
    if (x != 0) printf("%f", x);
    if (y > 0 && x != 0) printf("+");
    if (y != 0) printf("%fi", y);
    printf("\n");
}
```

**2. 实现有理数的结构体及加减乘除运算（要自动约分）。**

```c
struct rational { int num, den; };   /* 分子/分母 */

int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

struct rational make_rational(int n, int d) {
    int g = gcd(n, d);
    struct rational r = { n/g, d/g };
    return r;
}
```
