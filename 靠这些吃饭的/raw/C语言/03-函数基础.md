# 03-函数基础

## 知识地图

```
标准库函数（#include <math.h>，gcc -lm）
    ↓
自定义函数：类型 函数名(参数列表) { 函数体 }
    ↓
函数声明（原型）必须在调用之前出现
    ↓
参数传递：形参 = 实参的副本（传值调用）
    ↓
局部变量（函数内有效，调用分配→返回释放）
    ↓
全局变量（全程存活，不初始化默认为0）
    ↓
作用域遮蔽：同名时局部优先于全局
```

**本讲回答的核心问题**：什么是函数？如何定义和使用自己的函数？参数是怎样传递的？局部变量和全局变量有什么区别？

---

## 1. C标准库中的数学函数

### 1.1. 函数调用是一种表达式

在数学中 `sin(pi/2)=1`，在C语言中同样可以调用数学函数：

```c
#include <math.h>
#include <stdio.h>

int main(void)
{
    double pi = 3.1416;
    printf("sin(pi/2)=%f\nln1=%f\n", sin(pi/2), log(1.0));
    return 0;
}
```

编译运行（数学函数需要链接 `libm.so`，所以加 `-lm`）：
```
$ gcc main.c -lm
$ ./a.out
sin(pi/2)=1.000000
ln1=0.000000
```

C语言要求函数调用必须带括号（如 `log(1.0)`）。`log(1.0)` 是一个**函数调用表达式**：函数名 `log` 和括号中的实参组成，它的值是对数运算的结果，类型是 `double`。

### 1.2. 函数的副作用（Side Effect）

**函数有两种作用**：返回值和副作用。

- **纯数学函数**（如 `log`、`sin`）：调用它们是为了得到返回值，没有副作用
- **有副作用的函数**（如 `printf`）：调用它们是为了改变外部状态（打印到屏幕），返回值反而不重要

> 运算符也有类似区分：`a + b` 无副作用（纯计算），`a = b` 有副作用（改变了 `a` 的值）

### 1.3. 头文件与库文件

- `#include <stdio.h>`：包含标准I/O库函数的声明
- `#include <math.h>`：包含数学库函数的声明
- `-lm`：告诉编译器在 `libm.so` 库中查找数学函数的实现

头文件（`.h`）声明函数原型，库文件（`.so`）包含函数的机器码实现。几乎所有C程序都依赖于 `libc.so`（自动链接），数学程序额外需要 `libm.so`。

## 2. 自定义函数

### 2.1. 函数定义语法

```
函数定义 → 返回值类型 函数名(参数列表) { 函数体 }
```

C程序总是从 `main` 函数的第一条语句开始执行。除了名字特殊外，`main` 和别的函数没有区别。

```c
#include <stdio.h>

void newline(void)
{
    printf("\n");
}

int main(void)
{
    printf("First Line.\n");
    newline();          /* 调用自定义函数 */
    printf("Second Line.\n");
    return 0;
}
```

输出：
```
First Line.

Second Line.
```

### 2.2. void 的含义

- `void newline(void)`：第一个 `void` 表示函数没有返回值，第二个 `void` 表示函数不接受任何参数
- `void` 类型表达式不能参与任何运算（如 `newline() + 1` 非法）

### 2.3. 函数声明的层次调用

函数之间可以互相调用，形成调用链：

```c
void newline(void)   { printf("\n"); }
void threeline(void) { newline(); newline(); newline(); }

int main(void)
{
    printf("Three lines:\n");
    threeline();
    printf("Another three.\n");
    threeline();
    return 0;
}
```

**函数的意义**：
1. 将复杂操作封装为一个简单名字（抽象）
2. 避免重复代码（复用）
3. 修改一处，所有调用点都生效

### 2.4. 函数声明 vs 函数定义

```c
/* 函数声明（仅原型，无函数体）—— 告诉编译器函数的存在 */
void threeline(void);

/* 函数定义（带函数体）—— 编译器生成实际的机器指令 */
void threeline(void)
{
    newline(); newline(); newline();
}
```

函数声明必须出现在调用之前（先声明后使用原则）。可以用声明调整定义顺序：

```c
void newline(void);      /* 声明在前 */
void threeline(void);

int main(void) { ... }   /* main放最前，可读性好 */

void newline(void) { ... }
void threeline(void) { ... }
```

**隐式声明**：如果调用函数前既没有声明也没有定义，编译器会猜测返回类型是 `int`——这可能导致类型不匹配的Bug。绝不依赖隐式声明，始终保持函数声明在前。

## 3. 形参与实参

### 3.1. 带参数的函数

```c
#include <stdio.h>

void print_time(int hour, int minute)
{
    printf("%d:%d\n", hour, minute);
}

int main(void)
{
    print_time(23, 59);
    return 0;
}
```

注意：定义参数时必须逐个指定类型，不能合并写成 `int hour, minute`（这与变量声明不同）。

### 3.2. 传值调用（Call by Value）

**核心原理**：形参相当于函数内部定义的局部变量，调用函数时用实参的值来**初始化**形参。

```c
int main(void)
{
    int h = 23, m = 59;
    print_time(h, m);    /* 相当于执行: int hour = h; int minute = m; */
    return 0;
}
```

`main` 中的 `h` 和 `print_time` 中的 `hour` 是**两个不同的变量**，虽然它们的值相同。修改形参不会影响实参——这就是传值调用的含义。

### 3.3. 可变参数函数

`printf` 可以接受不同数量的参数，因为它的原型声明为：

```c
int printf(const char *format, ...);
```

`...` 表示可变参数（Variable Argument），后面章节会详细介绍。每个函数的参数个数和类型都在原型中明确规定，调用时必须匹配。

## 4. 全局变量、局部变量和作用域

### 4.1. 局部变量

在函数内部定义的变量（包括形参）称为**局部变量**（Local Variable），具有两个关键特性：

**(1) 隔离性**：一个函数中的局部变量不能被另一个函数访问。即使两个函数中有同名变量，它们也是完全独立的存储空间。

```c
/* main中的hour和print_time中的hour是不同的变量 */
void print_time(int hour, int minute) { ... }

int main(void)
{
    int hour = 23, minute = 59;
    print_time(hour, minute);
    return 0;
}
```

**(2) 生命周期**：局部变量在每次函数调用时分配存储空间，在函数返回时释放。因此以下代码中两次调用打印的 `i` 值是**不确定的**（不能依赖）：

```c
void foo(void)
{
    int i;             /* 未初始化，值不确定！ */
    printf("%d\n", i);
    i = 777;
}

int main(void)
{
    foo();             /* 第一调用：i的值不确定 */
    foo();             /* 第二调用：i的值也不确定（可能与第一次相同也可能不同） */
    return 0;
}
```

**重要规则**：局部变量不初始化时值是**不确定的**（不是自动为0），使用前必须先赋值。千万不要把必要条件当充分条件——某次运行恰好是0，不代表它就应该是0。

### 4.2. 全局变量

在所有函数体之外定义的变量称为**全局变量**（Global Variable）：

```c
#include <stdio.h>

int hour = 23, minute = 59;    /* 全局变量 */

void print_time(void)
{
    printf("%d:%d in print_time\n", hour, minute);
}

int main(void)
{
    print_time();
    printf("%d:%d in main\n", hour, minute);
    return 0;
}
```

全局变量的特点：
- 程序启动时分配存储空间，结束时释放
- 任何函数都可以访问
- 不初始化时默认值为 **0**（与局部变量不同）
- 初始化必须用**常量表达式**（编译时就能算出），不能用函数调用的结果

```c
double pi1 = 3.14 + 0.0016;     /* 正确：常量表达式 */
double pi2 = acos(-1.0);        /* 错误：函数调用在运行时才能求值 */
int minute = 360;
int hour = minute / 60;         /* 错误：minute/60不是常量表达式 */
```

**使用建议**：全局变量虽方便但会降低代码可读性和可维护性——任何函数都能修改它，出Bug时难以定位。能用参数传递的就不要用全局变量。

### 4.3. 作用域与命名遮蔽

**作用域**（Scope）：标识符的可见范围。全局变量从定义处开始直到文件末尾可见，局部变量仅在函数内部可见。

如果局部变量和全局变量同名，局部作用域会**遮蔽**（Shadow）全局作用域：

```c
int hour = 23, minute = 59;     /* 全局 */

int main(void)
{
    int hour = 10, minute = 30; /* 局部，遮蔽了全局的同名变量 */
    printf("%d:%d\n", hour, minute);    /* 打印 10:30（局部的） */
    return 0;
}
```

## 本讲核心要点

1. **函数调用是表达式**的一种，有值和类型；调用C标准库数学函数需 `#include <math.h>` 并加 `-lm`
2. **函数可以没有返回值**（`void`），调用它纯粹为了副作用（如 `printf`）
3. **自定义函数**：`返回值类型 函数名(参数列表) { 函数体 }`；函数声明须在调用前出现
4. **函数定义产生机器指令**（占存储空间），**函数声明只提供类型信息**（不产生指令）
5. **传值调用**：形参是实参的副本，函数内修改形参不影响实参
6. **形参定义必须逐个指定类型**，不能像变量声明那样合并
7. **局部变量**：函数内部有效，每次调用分配→返回释放，不初始化值是不确定的
8. **全局变量**：所有函数可见，程序全程存活，不初始化默认为0，初始化须用常量表达式
9. **作用域遮蔽**：局部变量与全局变量同名时，函数内优先使用局部变量
10. **慎用全局变量**：能用参数传递就不该用全局变量，以保持代码的局部性和可维护性

## 习题

**1. 以下 `increment` 函数能否把 `main` 函数中的 `i` 增加？为什么？**

```c
void increment(int x)
{
    x = x + 1;
}

int main(void)
{
    int i = 1, j = 2;
    increment(i);    /* i 还是 1 吗？ */
    increment(j);    /* j 还是 2 吗？ */
    return 0;
}
```

**答**：不能。C语言采用**传值调用**，`increment(i)` 等价于 `int x = i; x = x + 1;`——修改的是形参 `x`，实参 `i` 完全不受影响。执行后 `i` 仍为1，`j` 仍为2。要让函数改变外部变量，需要使用指针（第12章）。

**2. 不含 `#include <stdio.h>` 而调用 `printf` 会发生什么？**

**答**：编译器会触发隐式声明，猜测 `printf` 返回 `int`，这与实际的 `printf` 原型不符，导致 `warning: incompatible implicit declaration`。虽然可能碰巧运行正确，但这种写法是不可靠的，必须显式包含对应的头文件。
