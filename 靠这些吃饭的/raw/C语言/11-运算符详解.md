## 1. 位运算

位运算直接操作整型数据的二进制位，效率很高，在嵌入式、网络协议、性能优化中大量使用。

| 运算符 | 名称 | 规则 | 示例 |
|:--:|------|------|------|
| `&` | 按位与 | 两个1=1 | `5 & 3 = 1`（101 & 011 = 001） |
| `|` | 按位或 | 有1得1 | `5 | 3 = 7`（101 | 011 = 111） |
| `~` | 按位非 | 0↔1 | `~5 = -6`（补码） |
| `^` | 异或 | 不同得1 | `5 ^ 3 = 6`（101 ^ 011 = 110） |
| `<<` | 左移 | 左移n位，右补0 | `5 << 1 = 10`（*2的效果） |
| `>>` | 右移 | 右移n位 | `5 >> 1 = 2`（/2的效果） |

### 实战模式

```c
/* 判断奇数——利用最低位 */
if (n & 1)   printf("odd\n");      /* 比 n%2 更快 */

/* 第k位置1 */
x |= (1 << k);

/* 第k位清零 */
x &= ~(1 << k);

/* 取指定位段 */
int bits = (x >> 2) & 0b111;       /* 取 x 的 bit4~bit2 */

/* 异或交换 */
a ^= b;  b ^= a;  a ^= b;          /* 不需要临时变量 */

/* 乘除2的幂 */
x <<= 3;    /* x *= 8  */
x >>= 2;    /* x /= 4  */

/* 取最低位的1（lowbit）——树状数组的核心操作 */
int lowbit = x & -x;               /* x=12(1100) → lowbit=4(0100) */
```

**右移的陷阱**：
- `unsigned` 数右移：左边补0（逻辑右移）
- `signed` 负数右移：左边补符号位（1）——**实现定义**，不可移植

## 2. 自动递增/递减

```c
/* 前置++：先加1，再用新值 */
int a = 5;
int b = ++a;           /* a=6, b=6 */

/* 后置++：先用原值，再加1 */
int a = 5;
int b = a++;           /* b=5, a=6 （常见于数组遍历 for(i=0;i<n;i++) a[i]=0;） */
```

**常见用法对比**：
- `for (i = 0; i < n; i++)` 写循环更直观（用后置++，虽然拷贝代价对 int 来说可忽略）
- `*p++` 是 C 语言中的一个经典表达式：先取 `*p` 的值，再让 p 指向下一个位置

## 3. 赋值运算符

### 3.1. 简单赋值

`=` 是赋值运算符，表达式的结果是**赋值后左操作数的值**：

```c
int a, b, c;
a = b = c = 0;        /* = 右结合：a = (b = (c = 0)) */
```

### 3.2. 复合赋值

```c
a += 5;     /* a = a + 5 */
a -= 5;     /* a = a - 5 */
a *= 5;     /* a = a * 5 */
a /= 5;     /* a = a / 5 */
a %= 5;     /* a = a % 5 */
a <<= 2;    /* a = a << 2 */
a &= 0xFF;  /* a = a & 0xFF */
a |= 0x80;  /* a = a | 0x80 */
a ^= 0x0F;  /* a = a ^ 0x0F */
```

复合赋值更简洁，且只求值一次左边的表达式（在涉及指针时可能有性能差异）。

## 4. sizeof、条件运算符与逗号

### 4.1. sizeof

`sizeof` 在**编译时**求值（VLA 除外），返回类型或变量占用的字节数（`size_t`）：

```c
printf("%zu\n", sizeof(int));           /* 4 */
printf("%zu\n", sizeof(a));             /* 数组总大小，如 40 */
printf("%zu\n", sizeof(a) / sizeof(a[0])); /* 数组元素个数 */

int *p;
printf("%zu\n", sizeof(p));             /* 8（64位）— 指针的大小 */
```

**注意**：对数组名使用 `sizeof` 得到的是**整个数组的大小**，它不会退化为指针！

### 4.2. 条件运算符（三元运算符）

```c
int max = (a > b) ? a : b;
/* 等价于：
if (a > b) max = a; else max = b; */
```

可嵌套但要谨慎——可读性会急剧下降。

### 4.3. 逗号运算符

依次计算左右表达式，返回**右边**的值：

```c
int a = (1, 2, 3);       /* a = 3 */

/* for 循环中的常见用法 */
for (i = 0, j = 10; i < j; i++, j--)
    ...

/* 故意利用逗号把多个操作挤在一行（不建议这样写） */
while (printf("loop\n"), i-- > 0) { ... }
```

### 4.4. 强制类型转换

```c
double avg = (double)sum / n;    /* 防止整数除法截断 */
int *p = (int *)malloc(n * sizeof(int));  /* void* → int* */
```

## 5. Side Effect 与 Sequence Point

**Side Effect（副作用）**：表达式求值过程中对存储的修改，比如 `i++` 改变了 i，`a = 5` 改变了 a。

**Sequence Point（序列点）**：程序中一个"截止点"，在此点之前的所有副作用必须完成。主要序列点：

| 序列点 | 示例 |
|--------|------|
| 分号 `;` | `a = 5; b = a++;` 之间是序列点 |
| `&&` `||` 的第一个操作数后 | `if (p != NULL && p->x > 0)` 中先确定左边，右边才执行 |
| `?:` 的第一个操作数后 | `a > 0 ? a : -a` 中先确定条件，再执行对应分支 |
| 函数调用时（所有参数求值后） | `f(a++, b)` 中 `a++` 的副作用在进入函数前完成 |

**未定义行为的陷阱**：

```c
int i = 5;
int a = i++ + i++;        /* 未定义！两个 ++ 之间没有序列点 */
int b = ++i + ++i;        /* 未定义 */

printf("%d %d\n", ++i, i++);   /* 参数求值顺序也是未定义的 */
```

**铁律**：不要在同一个表达式中**多次修改同一个变量**（除非两次之间有序列点）。

## 6. 运算符优先级与结合性

| 优先级 | 运算符 | 结合性 |
|:--:|--------|:--:|
| 最高 | `()` `[]` `.` `->` `++(后)` `--(后)` | 左→右 |
| ↓ | `++(前)` `--(前)` `+` `-` `!` `~` `*` `&` `sizeof` `(类型)` | **右→左** |
| ↓ | `*` `/` `%` | 左→右 |
| ↓ | `+` `-` | 左→右 |
| ↓ | `<<` `>>` | 左→右 |
| ↓ | `<` `<=` `>` `>=` | 左→右 |
| ↓ | `==` `!=` | 左→右 |
| ↓ | `&` | 左→右 |
| ↓ | `^` | 左→右 |
| ↓ | `|` | 左→右 |
| ↓ | `&&` | 左→右 |
| ↓ | `||` | 左→右 |
| ↓ | `?:` | **右→左** |
| ↓ | `=` `+=` `-=` `*=` 等 | **右→左** |
| 最低 | `,` | 左→右 |

**记忆口诀**：单目 > 算术 > 移位 > 关系 > 位运算 > 逻辑 > 条件 > 赋值 > 逗号

**不确定就加括号**——括号永远最优先，也最清晰。

**经典陷阱**：
```c
int a = 1 << 2 + 3;       /* 先算 2+3=5，再左移 → 32 */
int b = (1 << 2) + 3;     /* 先左移→4，再加3→7 */
```

## 本讲核心要点

1. **位运算**直接操作比特：`& 清零 | 置1 ^ 取反 << 乘2 >> 除2`
2. **++ 前置**：先加后用；**后置**：先用后加；`*p++` 是 C 语言的经典表达式
3. **复合赋值** `+=` 等更简洁，且只求值一次左表达式
4. **sizeof 对数组得总大小**（不退化指针），运行时对 VLA 例外
5. **逗号运算符**返回右边表达式的值，主要在 for 循环中使用
6. **Side Effect + 无序列点 = 未定义行为**：同一表达式不能多次修改同一变量
7. 优先级归纳：单目 > 算术 > 移位 > 关系 > 位 > 逻辑 > 赋值 > 逗号
8. **不确定就加括号**——清晰远比赛智力重要

## 习题

**1. 写一个函数判断一个整数是否为 2 的幂。**

```c
int is_power_of_two(unsigned int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
/* 原理：2的幂二进制只有一个1，减1后该位变0、之后全变1，相与为0 */
```
