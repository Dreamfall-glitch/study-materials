# 12-指针

## 知识地图

```
指针 = 存储地址的变量（type *p 声明，&取地址，*解引用）
    ↓
指针与数组：a[i] = *(a+i)，数组名退化为首元素指针
    ↓
指针与const：const int *p（指向常量）/ int *const p（指针常量）
    ↓
指针与结构体：p->member = (*p).member
    ↓
二级指针：int **p（指向指针的指针）
    ↓
函数指针：void (*fp)(int)（指向函数的指针，用于回调）
    ↓
动态内存分配：malloc / free（堆上分配/释放）
```

**本讲回答的核心问题**：指针是什么？为什么说"C语言的灵魂是指针"？数组和指针的关系是什么？函数指针用来做什么？

---

## 1. 指针的基本概念

### 1.1. 什么是指针

**指针**就是存储另一个变量地址的变量。每个变量在内存中都有地址，指针保存的就是这个地址。

```c
int a = 10;       /* 普通变量 a */
int *p = &a;      /* p 存储 a 的地址 */

printf("a = %d\n", a);       /* a = 10 */
printf("&a = %p\n", &a);     /* a 的地址，如 0x7ffc1234 */
printf("p = %p\n", p);       /* p = &a，同样的地址 */
printf("*p = %d\n", *p);     /* *p = 10，解引用：顺着 p 的地址读数据 */
```

三个关键运算符：
- `&`：取地址——"变量 a 存在哪？"
- `*`：解引用——"从地址 p 读/写数据"
- `type *`：声明指针类型

### 1.2. 通过指针修改数据

```c
int a = 10;
int *p = &a;

*p = 20;          /* 通过指针间接修改 a */
printf("%d\n", a); /* a = 20 —— 被指针修改了！ */
```

这解释了为什么 `scanf` 需要用 `&`：

```c
int n;
scanf("%d", &n);   /* scanf 需要通过地址来修改 n */
```

### 1.3. 空指针与野指针

```c
int *p = NULL;     /* 空指针——不指向任何有效地址 */
if (p != NULL)
    *p = 10;       /* 安全：先检查再使用 */

int *q;            /* 未初始化——野指针！值不确定，解引用则未定义行为 */
```

**规则**：指针一定要初始化（NULL 或有效地址），不要使用未初始化的指针。

## 2. 指针类型的参数和返回值

指针最大的威力在于：**让函数可以修改调用者的变量**。

```c
/* 错误的 swap——只交换了形参的副本 */
void swap_wrong(int a, int b) {
    int tmp = a; a = b; b = tmp;   /* 不影响调用者！ */
}

/* 正确的 swap——通过指针交换 */
void swap(int *pa, int *pb) {
    int tmp = *pa;
    *pa = *pb;
    *pb = tmp;
}

int main(void) {
    int x = 5, y = 10;
    swap(&x, &y);          /* x=10, y=5 */
    return 0;
}
```

## 3. 指针与数组

### 3.1. 下标 vs 指针运算

数组名在大多数表达式上下文中会**退化为指向首元素的指针**。`a[i]` 和 `*(a + i)` 完全等价：

```c
int a[5] = {10, 20, 30, 40, 50};

printf("%d\n", a[2]);        /* 30 */
printf("%d\n", *(a + 2));    /* 30 —— 等价！ */

/* 指针也可以加下标 */
int *p = a;
printf("%d\n", p[2]);        /* 30 —— 同样合法 */
```

### 3.2. 指针算术

```c
int a[5];
int *p = a;

p + 1;      /* 不是加1个字节，而是加 1*sizeof(int) = 4字节 */
p++;        /* p 指向下一个 int */
p--;        /* p 指向上一个 int */

int n = p - a;   /* 两个指针相差的元素个数 */
```

### 3.3. 把数组传给函数

```c
void print_array(int *arr, int n)   /* arr 是指针，不是整个数组 */
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);       /* 指针也可以用下标 */
}

int main(void) {
    int a[] = {1, 2, 3, 4, 5};
    print_array(a, 5);               /* a 退化为指针 */
    return 0;
}
```

函数声明中 `int arr[]` 和 `int *arr` 完全等价。

## 4. 指针与 const

const 在指针声明中的位置决定了"什么是只读的"：

```c
const int *p;        /* p 指向的内容是只读的（p 本身可变） */
int * const p;       /* p 本身是只读的（p 指向的内容可变） */
const int * const p; /* 两者都是只读的 */

int a = 10, b = 20;
const int *p = &a;
*p = 30;             /* 编译错误！不能通过 p 修改 a */
p = &b;              /* 合法：可以改变 p 指向别处 */

int * const q = &a;
*q = 30;             /* 合法：可以修改 a */
q = &b;              /* 编译错误！q 不能重新指向 */
```

**使用建议**：函数参数中，如果不修改传入的数组内容，应声明为 `const int *`，既防止意外修改又传达意图。

## 5. 指针与结构体

```c
struct point { int x, y; };

struct point p = {3, 4};
struct point *pp = &p;

(*pp).x = 5;          /* 通过指针访问成员 */
pp->x = 5;            /* -> 是 (*pp).x 的简写，常用 */
pp->y = 6;
```

链表的经典用法全靠 `->`。

## 6. 二级指针

二级指针存放的是"一级指针的地址"，用于需要修改指针本身的场景：

```c
void make_new(int **pp)    /* 要通过指针修改一个 int* 变量 */
{
    *pp = malloc(sizeof(int));    /* *pp 是调用者的 int* 变量 */
    **pp = 42;
}

int main(void) {
    int *p = NULL;
    make_new(&p);                /* 函数修改了 p 本身 */
    printf("%d\n", *p);          /* 42 */
    free(p);
    return 0;
}
```

---

## 7. 函数指针

函数名在表达式中会退化为指向函数的指针：

```c
int add(int a, int b) { return a + b; }

int (*fp)(int, int);    /* 声明函数指针：返回int，参数(int,int) */
fp = add;               /* 或 fp = &add; */
int result = fp(3, 4);  /* 通过函数指针调用，result = 7 */
```

**主要用途**：回调函数（Callback）——把"要执行的操作"作为参数传给另一个函数。

```c
/* qsort 的第四个参数是比较函数指针 */
int compare(const void *a, const void *b) {
    return *(int*)a - *(int*)b;
}
qsort(arr, n, sizeof(int), compare);

/* 自己实现一个"对数组每个元素执行某种操作"的函数 */
void for_each(int *arr, int n, void (*fn)(int *)) {
    for (int i = 0; i < n; i++)
        fn(&arr[i]);
}
```

## 8. 动态内存分配

栈上的变量在函数返回时自动释放，但有时需要手动控制生命周期——用堆：

```c
#include <stdlib.h>

int *p = malloc(100 * sizeof(int));  /* 分配100个int的空间 */
if (p == NULL) {
    /* 分配失败 */
    exit(1);
}
for (int i = 0; i < 100; i++)
    p[i] = i;

free(p);    /* 用完了，释放 */
p = NULL;   /* 防止野指针 */
```

**黄金法则**：`malloc` 和 `free` 必须配对。忘记 `free` 会导致**内存泄漏**；`free` 后继续用会导致**悬空指针**。

---

## 本讲核心要点

1. **指针 = 存地址的变量**，`&取地址` `*解引用` `type *声明` 是三个核心操作
2. **数组名退化为指针**：`a[i]` = `*(a+i)`，函数中 `int arr[]` = `int *arr`
3. **指针让函数可以修改调用者的变量**：传地址而不是传值
4. **const 位置决定谁只读**：`const int *` 内容只读，`int *const` 指针只读
5. **二级指针**用于在函数中修改指针本身（如 malloc 包装函数）
6. **函数指针**：把函数作为参数传递（qsort、回调）
7. **malloc/free 必须配对**，忘记释放=内存泄漏，释放后继续用=悬空指针
8. 指针算术按元素大小跳：`p+1` 跳 `sizeof(*p)` 字节

## 习题

**1. 实现 `strcpy`（字符串复制）的指针版本。**

```c
char *mystrcpy(char *dst, const char *src) {
    char *p = dst;
    while ((*p++ = *src++));
    return dst;
}
```

**2. 用函数指针实现一个简易计算器：传入操作和两个数，返回结果。**

```c
typedef int (*op_func)(int, int);
int compute(int a, int b, op_func op) { return op(a, b); }

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }

printf("%d\n", compute(3, 4, add));    /* 7 */
printf("%d\n", compute(3, 4, mul));    /* 12 */
```
