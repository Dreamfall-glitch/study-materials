# 02-C语言的数据与运算

## 知识地图

```
Hello World深入：注释 → 转义序列 → 格式化字符串
    ↓
常量（字符/整数/浮点/字符串）→ 类型
    ↓
变量：声明（类型 变量名）→ 赋值（= 是运算符，非等号）
    ↓
表达式：运算符 + 操作数 → 值 + 类型
├── 整数除法向零截断 / 运算符优先级与结合性
└── 左值（存储位置） vs 右值（值）
    ↓

```

**本讲回答的核心问题**：C语言如何表示和操作数据？变量和常量有什么区别？printf的格式化字符串怎么用？表达式的值和类型如何确定？

## 1. Hello World程序深入

### 1.1. 注释（Comment）

注释是写给程序员看的，编译器会忽略它们。C语言有两种注释：

```c
/* 多行注释：
   可以跨行，但不能嵌套。 */

// 单行注释（C99标准）：
// 从这里到行尾都是注释
```

注释不能嵌套，即 `/* a /* b */ c */` 会出错——编译器只把 `/* a /* b */` 当作注释，剩余 `c */` 无法解析。

> 编程中先写注释描述程序的意图和数据结构，然后再填充代码，是一种推荐的做法。

### 1.2. 转义序列（Escape Sequence）

C语言中某些字符有特殊含义（如 `"` 表示字符串边界，`\` 表示转义），要表示它们的字面值就需要**转义序列**。

**常用转义字符**：

| 转义序列 | 含义 |
|----------|------|
| `\n` | 换行（Line Feed） |
| `\t` | 水平制表符（Tab） |
| `\\` | 反斜线字面值 |
| `\"` | 双引号字面值 |
| `\'` | 单引号字面值 |
| `\r` | 回车（Carriage Return） |
| `\b` | 退格（Backspace） |

**编译时 vs 运行时**：转义序列在**编译时**被替换。例如源代码中的 `\n` 是两个字符，编译后变成可执行文件中的一个换行符字节。

**行分隔符差异**：Windows文本文件用 `\r\n` 分隔行，Linux/UNIX 用 `\n` 分隔行。

### 1.3. 空白字符

空格、Tab、换行在C程序中多数时候不影响编译结果，但适当的空白（缩进、空行）对代码可读性至关重要。`include` 指令必须单独占一行。

## 2. 常量

常量（Constant）是程序中最基本的元素，有四种类型：

| 常量类型 | 示例 | 说明 |
|---------|------|------|
| 字符常量 | `'}'`、`'\n'` | 单引号括起来，只能是一个字符 |
| 整数常量 | `34` | 没有小数点 |
| 浮点数常量 | `3.14` | 有小数点或指数形式 |
| 字符串字面值 | `"Hello"` | 双引号括起来，可包含多个字符 |

### 2.1. printf格式化字符串

`printf` 的第一个参数是**格式化字符串**，其中 `%` 开头的字符称为**转换说明**（占位符），用于指定后续参数的输出格式：

```c
printf("character: %c\ninteger: %d\nfloating point: %f\n", '}', 34, 3.14);
```

输出：
```
character: }
integer: 34
floating point: 3.14
```

**常用转换说明**：

| 转换说明 | 对应类型 | 含义 |
|---------|---------|------|
| `%c` | char | 字符 |
| `%d` | int | 十进制整数 |
| `%f` | double | 浮点数（小数形式） |
| `%s` | char* | 字符串 |

> 转义序列（`\n`）是**编译时**处理的，转换说明（`%d`）是**运行时**由 `printf` 处理的——这是两个完全不同的机制。

### 2.2. 常量的类型区分

初学者常混淆以下写法：

| 写法 | 实际类型 | 说明 |
|------|---------|------|
| `'5'` | char | 字符常量，ASCII码为53 |
| `5` | int | 整型常量 |
| `"5"` | 字符串 | 字符串字面值 |
| `5.0` | double | 浮点型常量 |

这三个 `5` 在计算机中的存储方式完全不同，赋值时类型必须匹配。

## 3. 变量

### 3.1. 变量的概念

**变量**（Variable）是计算机存储器中的一块命名空间，里面可以存储一个值，且这个值可以随时改变。变量的类型决定了它占多大存储空间以及如何解释这些存储空间的内容。

```c
char firstletter;      /* 字符型变量，占1字节 */
int hour, minute;      /* 整型变量，可一次声明多个 */
double temperature;    /* 双精度浮点型 */
```

### 3.2. 标识符命名规则

变量名（以及函数名、宏名等）统称为**标识符**（Identifier）：
- 必须以字母或下划线 `_` 开头，后跟字母、数字、下划线
- 不能使用C语言**关键字**（如 `int`、`return`、`if` 等）
- 应避免以下划线开头的名字（编译器或标准库可能已占用）
- 应起有意义的名字：`hour`、`minute` 好过 `h`、`m`

### 3.3. 声明与定义

**声明**（Declaration）告诉编译器标识符的类型信息，**定义**（Definition）是要求编译器分配存储空间的声明。目前所学的变量声明都是定义。

## 4. 赋值与初始化

### 4.1. 赋值语句

```c
char firstletter;
int hour, minute;

firstletter = 'a';     /* 把 'a' 存入变量 */
hour = 11;
minute = 59;
```

**等号的本质**：C语言中的 `=` 不是数学相等关系，而是**赋值运算符**——把右边的值存入左边的存储空间。在C中 `a = 7` 合法但 `7 = a` 非法。

### 4.2. 初始化

定义变量时可以同时给它赋初值：

```c
char firstletter = 'a';
int hour = 11, minute = 59;
```

初始化不是赋值语句，它是一种特殊的声明语法。初值必须与变量类型匹配，否则编译器报警告：

```c
int minute;
minute = "59";    /* 错误！字符串不能赋给整型 */
```

### 4.3. 变量的使用

定义了变量并赋值后，可以通过变量名取出它的值：

```c
printf("Current time is %d:%d\n", hour, minute);
```

变量名出现在等号左边表示**赋值**（写入），出现在 `printf` 或表达式中表示**取值**（读取）。

## 5. 表达式

### 5.1. 表达式的基本概念

**表达式**（Expression）由运算符和操作数组成。任何表达式都有两个属性：**值**和**类型**。

```c
int total_minute;
total_minute = hour * 60 + minute;    /* 表达式：值是hour*60+minute的结果，类型是int */
```

### 5.2. 运算符的优先级与结合性

| 运算符 | 优先级 | 结合性 |
|--------|-------|--------|
| `*` `/` | 高 | 从左到右 |
| `+` `-` | 低 | 从左到右 |
| `=` | 最低 | **从右到左** |

`=` 是右结合的，因此可以连续赋值：

```c
int a, b, c;
a = b = c = 0;    /* 等价于 a = (b = (c = 0)) */
```

### 5.3. 整数除法的截断

两个整数相除，结果仍为整数，小数部分直接截去（**向零取整**）：

```c
printf("%d\n", 59 / 60);    /* 输出 0 */
printf("%d\n", -59 / 60);   /* 输出 0（不是-1） */
```

如果需要精确结果，把其中一个操作数改为浮点数：

```c
printf("%f\n", 59 / 60.0);    /* 输出 0.983333 */
```

C语言的类型转换规则会自动把 `59` 转为 `double` 后再计算。

### 5.4. 左值与右值

- **左值**（lvalue）：可以出现在等号左边的表达式——表示一个存储位置（目前只有变量是左值）
- **右值**（rvalue）：只能出现在等号右边的表达式——表示一个值

```c
int a, b;
a = b;         /* 正确：a是左值，b是右值 */
a = a + 1;     /* 正确：a在左边是左值，在右边是右值 */
a + 1 = b;     /* 错误：a+1不能表示存储位置，不是左值 */
```

### 5.5. 表达式语句

在任意表达式后面加 `;` 就构成**表达式语句**。但不是所有表达式语句都有意义：

```c
hour * 60 + minute;    /* 合法但无意义：计算结果未保存 */
a = b + 1;             /* 有意义：计算结果赋给了a */
```

## 6. 字符类型与字符编码

### 6.1. 字符即整数

在C语言中，`char` 型本质上就是整数（取值范围较小的整数）。`char` 和 `int` 统称为**整数类型**（Integer Type）。

```c
printf("%c\n", 'a' + 1);    /* 输出 'b' */
```

`'a'` 的ASCII码是97，加1得98，对应字符 `'b'`。

### 6.2. ASCII码

目前最常用的字符编码是ASCII码（American Standard Code for Information Interchange），取值范围0~127。一些重要规律：

- `'a'`~`'z'` 连续（97~122）
- `'A'`~`'Z'` 连续（65~90）
- `'0'`~`'9'` 连续（48~57）
- 大小写字母之差为32：`'a' - 'A' = 32`

**注意区分**：`'0'`（字符零，ASCII码48）和 `'\0'`（NUL空字符，ASCII码0）是不同的。

### 6.3. ASCII码转义序列

可以用八进制或十六进制表示字符的ASCII码：

```c
char tab = '\11';     /* 八进制11 = 十进制9 = Tab */
char nul = '\0';      /* Null字符 */
char a   = '\x61';    /* 十六进制61 = 十进制97 = 'a' */
```

## 7. 编码风格初识

### 7.1. 缩进与空格

缩进用来体现代码的层级关系：

```c
/* 好：缩进清晰 */
int main(void)
{
    int a = 1;
    if (a > 0) {
        printf("positive\n");
    }
    return 0;
}

/* 差：毫无缩进 */
int main(void){
int a=1;
if(a>0){
printf("positive\n");
}
return 0;
}
```

**推荐写法**：
- 每级缩进用4个空格（或1个Tab设为4格）
- `{` 与上一行同行或在下一行（任选一种，全篇统一）
- 二元运算符两侧各留一个空格：`a = b + c`
- 逗号后留一个空格：`int a, b, c;`

### 7.2. 命名规范

**变量名**用有意义的英文单词，多个词用下划线分隔：

```c
int student_count;     /* 好 */
int sc;                /* 差：含义不清 */
int studentCount;      /* 也可（驼峰命名法），选一种风格并统一 */
```

**常量名**和**宏名**一般全大写：

```c
#define MAX_SIZE 100
```

### 7.3. 每行一条语句

每条语句独占一行，不要多条语句挤在一行：

```c
/* 好 */
a = 1;
b = 2;
c = a + b;

/* 差 */
a = 1; b = 2; c = a + b;
```

## 本讲核心要点

1. **注释**分多行（`/* */`）和单行（`//`），不能嵌套；先写注释再写代码是好的编程习惯
2. **转义序列**在编译时处理（如 `\n`→换行符），**转换说明**在运行时处理（如 `%d`→整数）
3. **常量**有字符（`'a'`）、整数（`34`）、浮点（`3.14`）、字符串（`"hello"`）四种，类型由写法决定
4. **变量**必须先声明后使用，声明指定类型和名字，类型决定了存储空间大小
5. **赋值**用 `=` 运算符，不是数学等号；`int a = 5` 是初始化（特殊声明），不是赋值语句
6. **表达式**有值和类型；整数除法向零截断，如 `59/60=0`
7. **左值**表示存储位置（可放等号左边），**右值**只表示值（只能放在右边）
8. **char 本质是整数**，`'a'+1='b'`；`'0'`（ASCII 48）和 `'\0'`（ASCII 0）不同
9. **编码风格**：缩进（4空格）、有意义的命名、每行一条语句、运算符两侧留空格

## 习题

**1. 两个正整数 x 和 n，表达式 x/n 取 Floor（向下取整）。如何写表达式实现 Ceiling（向上取整）？例如 x=17, n=4 时结果应为 5；x=16, n=4 时结果应为 4。**

**答**：

```c
/* 向上取整：当x/n有余数时+1，否则不加 */
int ceiling = (x + n - 1) / n;
```

**验证**：
- `(17 + 4 - 1) / 4 = 20 / 4 = 5` 正确
- `(16 + 4 - 1) / 4 = 19 / 4 = 4` 正确

原理：加上 `n-1` 后，只要原数有余数就会进位，恰好等于向上取整。

**2. 在 printf 中如何打印一个百分号 `%`？**

**答**：用 `%%`：

```c
printf("Discount: %d%%\n", 20);    /* 输出：Discount: 20% */
```
