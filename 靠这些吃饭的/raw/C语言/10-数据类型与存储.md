# 10-数据类型与存储

## 知识地图

```
计算机用二进制表示所有数据
    ↓
整型：char(8)/short(16)/int(32)/long(64) — signed vs unsigned
    ↓    补码存储，unsigned溢出回绕(signed溢出未定义)
浮点型（IEEE 754）：±1.xxx × 2^指数 — 不精确，不能用==
    ↓
类型转换：隐式提升（小→大） / 强制转换 (type)
    ↓    signed与unsigned混合：signed自动转unsigned（易错）
存储层次：寄存器 → Cache → 内存 → 磁盘
```

**本讲回答的核心问题**：整数和浮点数在计算机中如何存储？类型转换时发生了什么？为什么浮点数不能直接用==比较？

## 1. 计算机中数的表示

计算机由数字电路构成，只有两种稳定状态，因此采用二进制。

| 进制 | 基数 | C语言表示 |
|:--:|:--:|-----------|
| 二进制 | 2 | `0b1010`（gcc扩展） |
| 八进制 | 8 | `012`（0开头） |
| 十进制 | 10 | `42` |
| 十六进制 | 16 | `0x2A`（0x开头） |

**十进制→二进制**：反复除以2，余数逆序。`13₁₀ = 1101₂`

## 2. 整型

### 2.1. 整型的尺寸与范围

类型的大小**因平台而异**，用 `sizeof` 查询：

```c
printf("char:%zu\n", sizeof(char));           /* 始终=1 */
printf("short:%zu\n", sizeof(short));         /* 通常=2 */
printf("int:%zu\n", sizeof(int));             /* 通常=4 */
printf("long:%zu\n", sizeof(long));           /* 32位=4, 64位=8 */
printf("long long:%zu\n", sizeof(long long)); /* 至少=8 */
```

| 类型 | 典型范围（32位） | sizeof |
|------|----------------|:--:|
| `signed char` | -128~127 | 1 |
| `unsigned char` | 0~255 | 1 |
| `short` | -32768~32767 | 2 |
| `int` | -2.1×10⁹~2.1×10⁹ | 4 |
| `unsigned int` | 0~4.3×10⁹ | 4 |
| `long long` | -9.2×10¹⁸~9.2×10¹⁸ | 8 |

### 2.2. 补码表示

有符号整数用**补码**存储，核心好处：**加法器统一处理加减法**。

```
 3 的补码：0000 0011
-3 的补码：1111 1101（反码+1）
```

**补码求值**：最高位权重为负。`1111 1101` = -128 + 64+32+16+8+4+1 = -3

### 2.3. char 类型

`char` 本质上就是 8 位整数，分为 `signed char` 和 `unsigned char`。`char` 是 signed 还是 unsigned **由编译器决定**。

字符 `'A'` 在 ASCII 表中是 65，`'a'` 是 97。`'A' + 32 = 'a'`。

### 2.4. 整数溢出

```c
unsigned char uc = 255;
uc = uc + 1;            /* uc = 0（回绕，定义良好） */

signed char sc = 127;
sc = sc + 1;            /* 未定义行为！可能=-128也可能崩溃 */
```

**规则**：
- `unsigned` 溢出：按 2ⁿ 取模回绕——是可预测的
- `signed` 溢出：**未定义行为**——编译器可做任何事，绝不能依赖

### 2.5. sizeof 与数组大小

```c
int a[10];
printf("%zu\n", sizeof(a));           /* 40 = 整个数组大小 */
printf("%zu\n", sizeof(a[0]));        /* 4 = 单个元素 */
printf("%zu\n", sizeof(a)/sizeof(a[0])); /* 10 = 元素个数 */

int *p = a;
printf("%zu\n", sizeof(p));           /* 8（64位）— 指针大小！不是数组 */
```

## 3. 浮点型

### 3.1. IEEE 754

浮点数用科学计数法表示：`±1.xxxx × 2^指数`

| 类型 | 符号 | 指数 | 尾数 | 范围 |
|:--:|:--:|:--:|:--:|------|
| `float` | 1bit | 8bit | 23bit | ±3.4×10³⁸ |
| `double` | 1bit | 11bit | 52bit | ±1.8×10³⁰⁸ |

### 3.2. 精度问题——浮点数不是精确的

许多十进制小数在二进制中是无限循环的：

```c
float a = 0.1;
printf("%.20f\n", a);    /* 0.10000000149011611938 — 不精确！ */
double b = 0.1;
printf("%.20f\n", b);    /* 0.10000000000000000555 — 也不精确！ */
```

**铁律**：绝不直接用 `==` 比较浮点数！

```c
if (fabs(a - b) < 1e-9)   /* 正确：看差值是否在容差范围内 */
    printf("approx equal\n");
```

### 3.3. 特殊值

```c
double inf = 1.0 / 0.0;       /* 正无穷（Infinity） */
double nan = 0.0 / 0.0;       /* 非数（NaN, Not a Number） */
double neg_zero = -0.0;       /* 负零 */
```

## 4. 类型转换

### 4.1. 隐式转换

当表达式出现不一致的类型时，C 自动将"小"类型提升为"大"类型：

```
char → short → int → long → float → double → long double
```

```c
int a = 5;
double b = 2.5;
double c = a + b;         /* a 被转成 double → c = 7.5 */

double d = 5 / 2;         /* 陷阱！5/2 整数除得 2，再转 double → d = 2.0 */
double e = 5.0 / 2;       /* 正确：e = 2.5 */
```

### 4.2. 赋值转换

```c
double pi = 3.14159;
int i = pi;               /* i = 3，小数被截断 */

char c = 200;             /* 溢出截断：200 超出 signed char 范围 */
```

### 4.3. 强制类型转换

```c
double avg = (double)sum / n;       /* (double) 防止整数除法截断 */
int i = (int)3.9;                    /* i = 3 */
```

### 4.4. signed 与 unsigned 混合的陷阱

```c
unsigned int a = 5;
int b = -10;
if (a + b > 0)            /* 会成立！为什么？ */
    printf("大于\n");
```

**解释**：`-10`（signed）在与 `a` 比较时被隐式转为 `unsigned`，变为 4294967286。所以 `a + b > 0` 为真。

**修复**：

```c
if ((int)a > b)           /* 统一转为 signed */
if (a > (unsigned)b)       /* 统一转为 unsigned，但注意负数不可比较 */
```

## 5. 存储层次

计算机的存储系统是一个金字塔结构：

| 层次 | 大小 | 速度 | 成本 |
|:--:|:--:|:--:|:--:|
| 寄存器（Register） | 几十字节 | 0.3ns | 最高 |
| L1 Cache | 32KB | 1ns | ↑ |
| L2 Cache | 256KB | 3ns | ↑ |
| L3 Cache | 8MB | 10ns | ↑ |
| 主存（RAM） | 8~32GB | 100ns | ↓ |
| 磁盘（SSD/HDD） | 256GB~2TB | 0.1ms~10ms | 最低 |

**局部性原理**：程序倾向于访问相邻的数据（空间局部性）和最近访问过的数据（时间局部性）。Cache 正是利用这一原理提高访问速度。

## 本讲核心要点

1. C语言整型大小**因平台而异**，用 `sizeof` 查；C标准只规定最小范围
2. 有符号整数用**补码**存储（最高位权重为负），加减法统一处理
3. **unsigned 溢出回绕**是标准行为；**signed 溢出是未定义**，绝不能依赖
4. **浮点数不精确**，不能直接用 `==` 比较；用差值或容差判断
5. **隐式转换**将小类型提升为大类型；`int→unsigned` 可能导致负数变巨量
6. **整数除法向零截断**：`5/2=2`；想要小数用 `5.0/2` 或 `(double)5/2`
7. **强制转换** `(type)expr` 优先级高于算术运算符
8. **sizeof 对数组名得总大小**（不退化指针），对指针得 4 或 8

## 习题

**1. 以下代码存在什么问题？如何修复？**

```c
unsigned int a = 5;
int b = -10;
if (a > b) printf("a > b\n");
```

**答**：`b` 被隐式转为 `unsigned`（约 42.9 亿），所以 `a > b` 为假。修复：`if ((int)a > b)` 或避免 signed/unsigned 混合比较。

**2. 写出判断两个浮点数近似相等的宏。**

```c
#define FEQ(a, b) (fabs((a) - (b)) < 1e-9)
```
