# 09-基础算法与数据结构

## 知识地图

```
大O表示法：O(1) < O(log n) < O(n) < O(n log n) < O(n²)
    ↓
排序：插入排序（O(n²)，适合小规模）→ 归并排序（O(n log n)，分治）
    ↓
查找：线性查找（O(n)，无序）→ 折半查找（O(log n)，需已排序）
    ↓
栈（LIFO）push/pop → DFS、括号匹配、表达式求值
    ↓
队列（FIFO）enqueue/dequeue → BFS、任务调度
    ↓
环形队列：取模回绕，解决空间浪费
```

## 1. 算法与复杂度分析

### 1.1. 什么是算法

算法是解决特定问题的有限步骤序列。同一个问题（如排序）可以有多种算法，需要标准来比较优劣——这就是算法分析的意义。

### 1.2. 大O表示法

**时间复杂度**衡量算法随输入规模 n 增长时的运行时间增长趋势。用大O表示法描述"增长的上界"，忽略常数因子和低阶项。

| Big O | 名称 | n=10 | n=100 | n=10⁶ |
|-------|------|------|-------|-------|
| O(1) | 常数时间 | 1 | 1 | 1 |
| O(log n) | 对数时间 | ~3 | ~7 | ~20 |
| O(n) | 线性时间 | 10 | 100 | 1,000,000 |
| O(n log n) | 线性对数 | ~30 | ~700 | ~20,000,000 |
| O(n²) | 平方时间 | 100 | 10,000 | 10¹²（不可行） |

**理解要点**：大O不关心具体运行时间，只关心**增长趋势**。O(n) 的算法处理100万数据大约需100万步，而 O(n²) 需要10¹²步——完全不可行。

**常见复杂度推算**：
- 单层循环遍历 → O(n)
- 双层嵌套循环 → O(n²)
- 每次将问题规模减半（如折半查找）→ O(log n)
- 分治再合并（如归并排序）→ O(n log n)

## 2. 排序算法

### 2.1. 插入排序（Insertion Sort）

**思想**：像整理扑克牌，每次取一张牌（key），在已排序部分中找到正确位置插入。

```c
void insertion_sort(int a[], int n)
{
    for (int i = 1; i < n; i++) {
        int key = a[i];            /* 当前要插入的牌 */
        int j = i - 1;

        /* 在已排序部分中从右向左找插入位置，同时右移元素腾空间 */
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];       /* 比 key 大的往右移 */
            j--;
        }
        a[j + 1] = key;            /* 插入到正确位置 */
    }
}
```

**手动追踪**（排序 `[5, 2, 4, 6, 1, 3]`）：
```
初始: [5 | 2, 4, 6, 1, 3]    ← 已排序 | 未排序
i=1:  [2, 5 | 4, 6, 1, 3]    key=2, 插入到5前面
i=2:  [2, 4, 5 | 6, 1, 3]    key=4, 插入到2和5之间
i=3:  [2, 4, 5, 6 | 1, 3]    key=6, 已经在正确位置
i=4:  [1, 2, 4, 5, 6 | 3]    key=1, 插入到最前面
i=5:  [1, 2, 3, 4, 5, 6]     key=3, 插入到2和4之间
```

**复杂度**：最坏 O(n²)（逆序），最好 O(n)（已排序），**空间 O(1)**（原地排序）。

**适用场景**：数据量小（< 100），或数据基本有序时效率极高。

### 2.2. 归并排序（Merge Sort）

**思想**：分治法——将数组不断对半切分，各自排序后再合并。

```c
/* 合并两个已排序的子数组 */
void merge(int a[], int left, int mid, int right)
{
    int n1 = mid - left + 1;    /* 左半部分长度 */
    int n2 = right - mid;       /* 右半部分长度 */
    int L[n1], R[n2];           /* 两个临时数组 */

    for (int i = 0; i < n1; i++) L[i] = a[left + i];
    for (int j = 0; j < n2; j++) R[j] = a[mid + 1 + j];

    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2)
        a[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];

    while (i < n1) a[k++] = L[i++];    /* 左半剩余 */
    while (j < n2) a[k++] = R[j++];    /* 右半剩余 */
}

void merge_sort(int a[], int left, int right)
{
    if (left < right) {
        int mid = left + (right - left) / 2;   /* 防溢出 */
        merge_sort(a, left, mid);              /* 排序左半 */
        merge_sort(a, mid + 1, right);         /* 排序右半 */
        merge(a, left, mid, right);            /* 合并两个有序半 */
    }
}
```

**复杂度**：O(n log n)，空间 O(n)（需额外数组）。**稳定排序**——相等元素的相对顺序保持不变。

## 3. 查找算法

### 3.1. 线性查找

```c
int linear_search(int a[], int n, int target)
{
    for (int i = 0; i < n; i++)
        if (a[i] == target)
            return i;
    return -1;    /* 未找到 */
}
```

时间 O(n)，适合无序或小规模数据。不需要数据有序。

### 3.2. 折半查找（Binary Search）

**前提：数据必须已排序。** 每次比较中间元素，将查找范围减半。

```c
int binary_search(int a[], int n, int target)
{
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;    /* 防 (left+right) 溢出 */
        if (a[mid] == target)
            return mid;
        else if (a[mid] < target)
            left = mid + 1;      /* 目标在右半 */
        else
            right = mid - 1;     /* 目标在左半 */
    }
    return -1;    /* 未找到 */
}
```

**手动示例**（在 `[2, 5, 8, 12, 16, 23, 38, 56]` 中找 23）：
```
[2, 5, 8, 12, 16, 23, 38, 56]  mid=16 < 23 → 右半
                    [23, 38, 56]  mid=38 > 23 → 左半
                    [23]           mid=23 = 23 → 找到！
```

3 次比较找到，而线性查找需要 6 次。

## 4. 栈与队列

### 4.1. 栈（Stack）—— 后进先出（LIFO）

栈就像一摞盘子：最后放上去的（push），最先被取走（pop）。

```c
#define MAX 100
int stack[MAX];
int top = 0;    /* 栈顶指针，指向下一个空闲位置 */

void push(int x)    { stack[top++] = x; }          /* 压栈 */
int  pop(void)      { return stack[--top]; }        /* 弹栈 */
int  peek(void)     { return stack[top - 1]; }      /* 看栈顶但不弹出 */
int  is_empty(void) { return top == 0; }
```

**应用场景**：

1. **函数调用栈**：每次函数调用将返回地址和局部变量压栈，返回时弹栈——这就是递归的底层机制
2. **深度优先搜索（DFS）**：迷宫探索、图的遍历
3. **括号匹配**：遇到 `(` 压栈，遇到 `)` 弹栈配对
4. **表达式求值**：中缀表达式转后缀、后缀表达式计算

**括号匹配示例**：

```c
bool is_balanced(const char *expr)
{
    int top = 0;
    char stack[100];
    for (int i = 0; expr[i]; i++) {
        if (expr[i] == '(')
            stack[top++] = '(';
        else if (expr[i] == ')') {
            if (top == 0) return false;    /* 多了右括号 */
            top--;
        }
    }
    return top == 0;    /* 栈空 = 全部配对 */
}
```

### 4.2. 队列（Queue）—— 先进先出（FIFO）

队列就像排队：先来的先服务。

```c
int queue[MAX];
int head = 0, tail = 0;    /* 队头：出队端；队尾：入队端 */

void enqueue(int x)  { queue[tail++] = x; }
int  dequeue(void)   { return queue[head++]; }
int  is_empty(void)  { return head == tail; }
```

**应用场景**：

1. **广度优先搜索（BFS）**：最短路径、树的层次遍历
2. **任务调度**：轮流处理多个请求
3. **消息缓冲**：生产者-消费者模式

### 4.3. 环形队列

普通队列的问题：`head` 和 `tail` 只增不减，空间迟早"用完"。**环形队列**将数组首尾相连：

```c
#define MAX 8
int queue[MAX];
int head = 0, tail = 0;

void enqueue(int x) {
    queue[tail] = x;
    tail = (tail + 1) % MAX;    /* 下标绕回 */
}

int dequeue(void) {
    int x = queue[head];
    head = (head + 1) % MAX;
    return x;
}

/* 空: head == tail */
/* 满: (tail + 1) % MAX == head (牺牲一个位置来区分空/满) */
bool is_full(void) { return (tail + 1) % MAX == head; }
```

**环形队列的满/空区分**：
- `head == tail` 时：队列为空
- `(tail + 1) % MAX == head` 时：队列为满（用掉 MAX-1 个位置后判定为满，预留一个空位）

## 本讲核心要点

1. **大O表示法**衡量算法随输入增长的趋势，忽略常数和低阶项；O(log n) ≪ O(n²)
2. **插入排序** O(n²)，简单直观，适合小规模或基本有序数据，空间 O(1)
3. **归并排序** O(n log n)，分治法经典应用，稳定但需额外 O(n) 空间
4. **折半查找** O(log n)，必须数据已排序；每次将搜索范围减半
5. **栈 = LIFO**，用数组实现 `push`/`pop` 均为 O(1)
6. **队列 = FIFO**，用数组或链表实现 `enqueue`/`dequeue` 均为 O(1)
7. **环形队列**解决普通队列空间浪费问题，用取模实现下标回绕
8. DFS 用栈实现，BFS 用队列实现——数据结构的选择决定了算法行为

## 习题

**1. 实现栈的 push/pop/peek，并在 push 时检查栈满、pop 时检查栈空。**

```c
bool push(int x) {
    if (top >= MAX) return false;    /* 栈满 */
    stack[top++] = x;
    return true;
}

bool pop(int *val) {
    if (top == 0) return false;      /* 栈空 */
    *val = stack[--top];
    return true;
}
```

**2. 用栈实现：输入一个十进制正整数，打印其二进制表示。**

```c
void print_binary(int n) {
    int stack[32], top = 0;
    while (n > 0) {
        stack[top++] = n % 2;       /* 余数压栈 */
        n /= 2;
    }
    while (top > 0)
        printf("%d", stack[--top]); /* 倒序弹出 = 正确顺序 */
    printf("\n");
}
/* print_binary(13) → 1101 */
```
