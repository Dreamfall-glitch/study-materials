# 09-隔离技术

```知识地图
双极IC → PN结隔离（标准/对通/CDI）→ 介质-PN结混合隔离（LOCOS/多孔硅/多晶硅/V型槽）
    ↓
双极IC → 介质隔离（SiO₂-多晶硅/正沟槽）
    ↓
MOS IC → 自然隔离 + 寄生MOSFET问题 → LOCOS/全槽/半槽氧化
    ↓
SOI → SIMOX注氧隔离 → 硅片粘合 → 抗辐射应用
```

**本讲回答的核心问题**：集成电路中为什么需要隔离技术？双极IC和MOS IC的隔离方式有何不同？SOI技术如何从根本上解决隔离问题？

## 1. 隔离技术概述

集成电路中的各种元器件制作在同一块半导体衬底上。为了防止这些元器件之间通过衬底发生短路，必须使其在电学上**可靠隔离**。隔离技术是集成电路的重要技术之一。

### 1.1. 隔离技术的五个基本要求

一种实用有效的隔离技术应满足以下五个要求：

| 要求 | 说明 |
|:----:|:------|
| **(a) 可靠隔离** | 电学上真正隔离，确保各器件独立工作 |
| **(b) 工艺兼容性** | 隔离工艺必须与现有的标准平面工艺兼容 |
| **(c) 表面平坦化** | 隔离结构的表面应尽量平坦，有利于后续金属化布线 |
| **(d) 占面积小** | 占用尽可能少的芯片面积，满足集成度不断提高的要求 |
| **(e) 不产生不良影响** | 对整个IC的性能不应产生不良影响 |

### 1.2. 隔离技术的分类

| 分类 | 隔离方式 | 典型工艺 | 适用电路 |
|:----:|:--------:|:---------|:---------|
| **PN结隔离** | 反偏PN结 | 标准PN结隔离、对通隔离、CDI | 双极IC |
| **介质-PN结混合隔离** | 底部PN结+侧壁介质 | LOCOS、等平面氧化隔离 | 双极高速IC |
| **介质隔离** | 全介质包围 | SiO₂-多晶硅、正沟槽隔离 | 双极IC |
| **自然隔离** | 导电类型相反 | CMOS中P阱/N阱 | MOS IC |
| **场区隔离** | 厚氧+沟道终止 | LOCOS、STI | MOS IC |
| **SOI** | 完全介质隔离 | SIMOX、硅片粘合、SOS | 高性能/抗辐射IC |

## 2. 双极IC中的PN结隔离

PN结隔离利用**PN结在反向偏压下处于反向截止状态**来实现电学隔离。这是双极IC中最基本的隔离技术。

原理：将P⁺隔离墙接至电路中最低电位点，每个N型隔离岛被反偏的PN结包围，实现各隔离岛之间的电学隔离。

### 2.1. 标准PN结隔离（SBC）

**SBC**（Standard Buried Collector，标准埋层集电区工艺）是基本的PN结隔离工艺。

**工艺流程**：

1. **P型硅衬底**——作为CMOS器件的基础材料
2. **埋层掺杂**——在将要形成NPN晶体管集电区的位置进行N⁺埋层扩散，目的是减小集电区串联电阻
3. **N型外延生长**——在P型衬底上生长N型外延层，作为集电区
4. **隔离扩散**——进行P⁺深扩散，穿透外延层与P型衬底相连，将N型外延层分隔成一个个孤立的**隔离岛**

**NPN晶体管的结构特点**：

- N⁺埋层：位于集电极下方，提供低电阻电流通路
- N型外延层：作为集电区
- P型基区：扩散形成
- N⁺发射区：扩散形成
- P⁺隔离环：穿透外延层与衬底相连

**隔离原理**：将P⁺隔离墙（包括P型衬底）接至电路中最低电位点，每个隔离岛（N型外延层）与P型区域之间形成**反偏PN结**，从而将各个隔离岛中的器件在电学上彻底隔离。

> **集电区串联电阻**：从剖面图可以看到，如果没有N⁺埋层，集电区电流的路径非常狭长且需要经过电阻率较高的N型外延层，其串联电阻较大。引入低电阻率的N⁺埋层后，电流主要通过N⁺埋层流动，大大减小了集电区串联电阻。

**标准PN结隔离的缺点**：

| 缺点 | 原因 | 后果 |
|:----|:-----|:------|
| 横向扩散 | P⁺隔离掺杂深度大，不可避免地产生较大的横向扩散（见下示意图） | 占用较多芯片面积，不利于集成度提高 |
| 结电容大 | 隔离结面积大，PN结的耗尽层电容大 | 不利于电路的高频特性 |
| 击穿电压受限 | 隔离结存在击穿电压上限 | 影响电路工作电压范围 |

**优点**：工艺简单，采用标准的平面工艺即可完成。因此在要求不太高的双极IC中仍得到广泛应用。

### 2.2. PN结对通隔离

PN结对通隔离是针对标准PN结隔离的缺点而进行的改进。核心思想是将隔离分为**上隔离**和**下隔离**两次完成。

**工艺流程**：

1. **(a) 下隔离**：在P型衬底上先进行P⁺隔离扩散（注意，这**在外延之前**进行）
2. **(b) N⁺埋层掺杂**
3. **(c) 外延生长**：在N型外延生长的高温过程中，下隔离的P型杂质**同时向上、下方向扩散**
4. **(d) 磷穿透扩散**：在进行上隔离之前，通常进行一次**磷穿透扩散**（N⁺），目的是减少集电区串联电阻
5. **(e) 上隔离**：在P型基区掺杂的同时进行P⁺上隔离扩散
6. **(f) 上、下隔离对接**：上隔离与下隔离在垂直方向上对接，完成隔离

**关键改进点**：

- 上隔离与基区扩散**同时进行**，减少了外延以后的高温隔离扩散时间
- 由于隔离扩散时间缩短，**横向扩散宽度减小**，节省了芯片面积
- 在一定程度上克服了标准PN结隔离的缺点

**应用**：在电路速度和集成度要求较高的双极IC中得到广泛应用。

### 2.3. 集电极扩散隔离（CDI）

**CDI**（Collector Diffusion Isolation，集电极扩散隔离）是为了更好地克服标准PN结隔离的缺点而出现的另一种隔离方式。

**工艺流程**：

1. **(a)** 在P型衬底上进行N⁺埋层掺杂——N⁺埋层将作为NPN管的集电区
2. **(b)** 生长一层**薄P型外延层**
3. **(c)** 进行N⁺隔离扩散（从表面穿透P型外延层到达N⁺埋层），形成被N⁺区域包围的隔离岛
4. **(d)** 进行P型掺杂——形成NPN晶体管的基区

**关键特点**：

- 由于P型外延层中N⁺的掺杂浓度很高，**不会发生反型**（即P型基区扩散可直接进行，不需另做掩模）
- **发射区扩散不用光刻**——减少了一次光刻步骤
- 隔离占用的面积比标准PN结隔离小

**缺点**：集电结（N⁺埋层与P外延之间的结）击穿电压较低，因此适用于工作电压较低的IC。

### 2.4. PN结隔离方法对比总结

| 对比项 | 标准PN结隔离（SBC） | PN结对通隔离 | CDI |
|:------|:------------------:|:-----------:|:---:|
| 隔离扩散次数 | 一次（在外延后） | 两次（下隔离+上隔离） | 一次（在外延后） |
| 外延层类型 | N型 | N型 | **P型** |
| 横向扩散 | 大 | 较小（上隔离与基区同时） | 小 |
| 集成度 | 低 | 中高 | 高 |
| 击穿电压 | 较高 | 较高 | **较低** |
| 工艺复杂度 | 简单 | 中等 | 较复杂 |
| 光刻次数 | 标准 | 标准+ | **少一次** |
| 应用 | 一般双极IC | 高速/高集成度双极IC | 低压IC |

## 3. 双极IC中的介质-PN结混合隔离

介质-PN结混合隔离是指隔离岛的**底部仍为PN结隔离**，但**侧壁用绝缘介质隔离**。根据侧壁所用绝缘介质的类型和形成方式的不同，又有多种不同形式。

### 3.1. 等平面氧化隔离（LOCOS）

**等平面氧化隔离**是介质-PN结混合隔离中最重要的一种。由于氧化层因体积增大正好与硅原始表面共平面，因此称为"等平面"。

**工艺流程**：

1. **(a)** 在埋层掺杂和外延生长后，表面依次生长**SiO₂缓冲层**和**Si₃N₄（氮化硅）层**
2. **(b)** 光刻腐蚀掉隔离墙位置的SiO₂和Si₃N₄，再腐蚀掉**一部分硅**
3. **(c)** 进行高温氧化，氧化层穿透N型外延层，将N型外延层分成一个个隔离岛

**氮化硅的掩蔽氧化作用**（LOCOS的核心原理）：

- Si₃N₄的氧化速率比Si**慢得多**，因此只有未被Si₃N₄覆盖的区域被氧化
- 利用氧在Si₃N₄中扩散非常缓慢的性质，Si₃N₄作为**氧化物阻挡层**保持不变
- 这种用Si₃N₄掩蔽硅氧化的方法，称为**硅局部氧化**（LOCOS：LOCal Oxidation of Silicon）

**结构说明**：

- SiO₂缓冲层（pad oxide）：考虑到Si₃N₄与Si之间热膨胀系数差别较大，为了避免在硅表面产生**应力损伤**，在Si₃N₄和Si之间用一层薄SiO₂作为**缓冲层**（应力释放层）

**等平面氧化隔离的优点**：

| 优点 | 原因 |
|:----|:-----|
| 隔离面积小 | 侧壁为介质，无需像PN结那样留出横向扩散空间，集成度↑ |
| 频率特性好 | 隔离岛侧壁不存在隔离PN结电容，频率特性大大改善 |
| 表面平整度高 | SiO₂体积增大，与Si表面接近共平面，有利于金属化布线 |
| 工作电压不必太低 | 侧壁为SiO₂介质，击穿电压不受PN结限制 |

**等平面隔离的变体**：根据具体工艺结构的不同，分为**等平面I型、等平面Ⅱ型、等平面S型**等不同形式，适用于不同的应用场合。

> 等平面氧化隔离在双极型高速LSI中逐步取代了集电区扩散隔离工艺，但这是以**增加工艺复杂性**为代价的。

### 3.2. 多孔硅氧化隔离

利用电化学腐蚀将隔离墙位置的硅转化为多孔硅，然后进行氧化。多孔硅具有巨大的比表面积，氧化速率极快，可在低温下完成。

> 课件中提及该技术作为介质-PN结混合隔离的一种形式，但未展开详细说明。

### 3.3. 多晶硅隔离

在刻蚀出的隔离槽中填充多晶硅，然后氧化形成介质侧壁。

### 3.4. V型槽隔离

利用硅的各向异性腐蚀特性（KOH腐蚀液对⟨100⟩和⟨111⟩晶面腐蚀速率差异极大），在隔离墙位置腐蚀出V型槽，然后氧化填充。

## 4. 双极IC中的介质隔离

介质隔离是指隔离岛的**四周均为SiO₂介质**——不存在PN结，从根本上消除结电容和击穿电压限制。

### 4.1. 标准SiO₂-多晶硅介质隔离

这是最早的介质隔离方式。

**工艺流程**：

1. **(a)** 原始材料为**N型Si**（以后成为隔离岛）
2. **(b)** 氧化生长SiO₂层，表面**蒸铝**（Al对SiO₂起保护作用）
3. **(c)** 进行隔离光刻，腐蚀刻槽
4. **(d)** 去掉SiO₂
5. **(e)** 进行N⁺埋层扩散
6. **(f)** 生长SiO₂
7. **(g)** 生长较厚的**多晶硅层**（以后作为支撑衬底）
8. **(h)** 从背面研磨多晶硅到一定厚度
9. **(i)** 研磨单晶硅层直到露出SiO₂和多晶硅——形成被SiO₂介质包围的一个个N型隔离岛

**缺点**：

| 缺点 | 原因 |
|:----|:-----|
| 隔离墙占面积大 | 刻槽和研磨工艺需要较大余量，集成度↓ |
| 频率特性差 | 侧壁有N⁺埋层包围，导致较大寄生电容，频率特性↓ |

### 4.2. 正沟槽介质隔离

针对SiO₂-多晶硅介质隔离的缺点而出现的新型介质隔离方法。

**工艺流程**：

1. **(a)** N⁺单晶硅为原始材料——作为NPN集电区埋层
2. **(b)** 生长SiO₂，淀积多晶硅——多晶硅作为支撑衬底，翻转
3. **(c)** N⁺单晶层磨、抛、化学腐蚀至8~10μm
4. **(d)** 生长N型外延层
5. **(e)** 外延表面生长SiO₂，刻出隔离墙位置后对硅进行腐蚀刻槽
6. **(f)** 生长SiO₂，淀积多晶硅，去除多余的多晶硅——形成N型隔离岛

**优点**：

- 占用芯片面积**小**
- 集电结反向击穿电压**高**
- 集电结电容**小**

## 5. MOS IC中的隔离

### 5.1. 自然隔离

MOS IC与双极IC的隔离方式存在本质不同。无论哪一种MOS晶体管，都是在**导电类型相反的硅材料**上形成的：

- **NMOS晶体管**：做在P型硅衬底上
- **PMOS晶体管**：做在N型硅衬底上
- **CMOS**中的自然隔离：同一衬底上NMOS和PMOS之间由**反型衬底中的阱**自然隔离

**实际结构**：

| CMOS类型 | 衬底 | NMOS所在区域 | PMOS所在区域 |
|:---------|:----:|:------------|:------------|
| **P阱CMOS** | N型Si | P阱中 | 直接在N衬底上 |
| **N阱CMOS** | P型Si | 直接在P衬底上 | N阱中 |
| **双阱CMOS** | 轻掺杂 | P阱中 | N阱中 |

因此，在MOS IC中，同一衬底上的不同MOS晶体管之间已经**自然实现了电学隔离**——不需要像双极IC那样特意做P⁺隔离环。

> 自然隔离的本质：如果两个MOS管都是同一个导电类型，它们做在同一类型的衬底上，源/漏扩散区被反向偏置的PN结与衬底隔离。对于CMOS，NMOS和PMOS分别在不同导电类型的阱/衬底上，彼此天然隔离。

### 5.2. 寄生MOSFET问题与场区隔离

虽然MOS管之间存在自然隔离，但MOS IC中存在一个特殊问题——**场区寄生晶体管**引起的相邻MOS管间的隔离问题。

**问题的本质**：

考虑两个相邻的NMOS晶体管（源漏分别编号①、②、③、④）。场氧（field oxide）上面有金属走线，使得②、③号扩散区又成了以**场氧作为栅氧化层**的**寄生MOSFET的源漏**。

若寄生MOSFET的开启电压不高，当其导通时，②、③号扩散区间有寄生晶体管沟道电流通过，导致MOSFET1和MOSFET2之间的"短路"——这就是相邻MOS管之间的隔离问题。

**解决措施**：

为了保证相邻MOSFET间的隔离，必须使场区寄生MOSFET的开启电压很高——一般要求**比电源电压还要高10V以上**，确保在IC工作时寄生MOSFET不可能发生导通。

两项主要工艺措施：

| 措施 | 作用 | 说明 |
|:----|:-----|:------|
| **提高场区表面掺杂浓度** | 提高开启电压 | 又称为**沟道终止掺杂**（channel stop implantation） |
| **增加场区氧化层厚度** | 降低寄生MOSFET的栅控能力 | 一般是有源区MOS晶体管栅厚度的**7~10倍** |

**场区氧化隔离方法**：

目前MOS IC中都采用类似于等平面氧化隔离中的**硅局部氧化（LOCOS）**方法形成场区氧化层：

| 类型 | 工艺 | 特点 |
|:----|:-----|:------|
| **全槽氧化隔离** | 在场区腐蚀掉一部分硅后再氧化 | 场区氧化层全部在原始硅表面以下，表面更平坦 |
| **半槽氧化隔离** | 不腐蚀开槽，直接氧化 | 硅→SiO₂体积增大，场氧化层凸起形成"台阶"，只有一半位于原始表面以下 |

半槽氧化隔离由于**工艺简单**，在沟道长度不小于1.5μm的MOS IC中得到了广泛应用。为适应**亚微米**沟道长度MOS IC的需要，还需对LOCOS隔离方法进行改进（STI）。

### 5.3. MOS IC隔离技术小结

```
同一衬底上不同MOS管之间 → 自然隔离（导电类型相反）
同一衬底上同类型MOS管间 → 场区隔离（LOCOS）
    ├── 提高场区掺杂浓度（沟道终止）
    └── 增加场氧化层厚度（7~10倍栅氧）
```

## 6. 绝缘物上硅（SOI）技术

上节介绍的隔离技术大多含有反偏PN结隔离结构。这种结构存在以下不足：

| 不足 | 原因 |
|:----|:-----|
| **隔离击穿电压较低** | 一般小于40V |
| **结电容较大** | 影响了高速性能 |
| **辐射环境下隔离失效** | 辐射产生较大的瞬态光电流，导致逻辑状态翻转甚至闭锁 |

因此在要求比较高的高电压、高速、**强辐射**环境中应用的电路都采用**绝缘物上硅**（SOI：Silicon On Insulator）结构。

**典型SOI结构**——超薄SOI：

```
    ┌───────────────────┐
    │ 单晶硅薄层（~100nm）│  ← 器件层
    ├───────────────────┤
    │  SiO₂绝缘层（~1μm） │  ← 埋氧层（BOX）
    ├───────────────────┤
    │  体硅衬底          │  ← 支撑衬底
    └───────────────────┘
```

**特点**：工艺简单（可简化工艺30%）、封装密度高（可比体硅提高40%）、抗辐射性好、速度快。

### 6.1. SOI和SOS结构

早在20世纪60年代末期，为了满足军用IC的抗辐射要求，曾采用**SOS**（Silicon On Sapphire，蓝宝石上硅）结构。SOS将绝缘层和衬底材料合二为一——蓝宝石（Al₂O₃）本身就是绝缘体。

当IC特征尺寸小于0.35μm时，具有超薄单晶硅层的SOI结构成为制造VLSI的最佳选择。

**SOI技术的核心优势**：

| 优势 | 具体表现 |
|:----|:---------|
| **(a) 工艺简化** | 可简化常规工艺约30%（不需要复杂的阱隔离/STI） |
| **(b) 封装密度高** | 可比体硅IC提高40%的集成度 |
| **(c) 抗辐射特性好** | 消除CMOS中的**闩锁效应**（latch-up），抗单粒子效应能力强 |
| **(d) 速度快** | 利用SOI结构特点设计的器件新结构，超高速CMOS IC的速度可与ECL结构相媲美 |

### 6.2. SIMOX技术（注氧隔离）

**SIMOX**（Separation by Implantation of Oxygen，注氧隔离）是形成SOI结构的重要方法之一。

**典型工艺条件**：

- 选用常规VLSI工艺用的硅片为衬底
- **氧注入**：能量200keV，剂量 $2 \times 10^{18}\ \text{cm}^{-2}$
- **高温退火**：1300°C，6小时
- 结果：在**200nm厚的硅表层**下形成**400nm厚的埋层氧化物**（BOX）

这种"硅薄层-SiO₂-体硅衬底"的SOI结构又称为**离子注入隐埋层结构**。

**SIMOX的优点**：

| 优点 | 说明 |
|:----|:------|
| **(1) 精确控制厚度** | 表面超薄硅层厚度可 < 150nm，硅层-SiO₂界面不平整度 < 几纳米 |
| **(2) 抗辐射能力强** | 抗单粒子效应（SEU：Single Event Upset）能力比体硅IC提高约200倍 |
| **(3) 速度快** | 体硅→SIMOX，速度可提高30%~40%；若采用全耗尽型器件设计，速度提高2倍以上 |
| **(4) 工作温度高** | 可在300°C以上工作 |

> **速度对比实例**：用0.25μm设计规则制造的CMOS环形振荡器，工作在2.5V电压下，级延迟时间仅有20ps，与ECL接近，但功耗仅为ECL的十分之一。

**SIMOX的问题**：

| 问题 | 当前进展 |
|:----|:---------|
| (1) 绝缘层厚度不能任意调节 | 受注入能量限制 |
| (2) 注入和退火引入较多缺陷和杂质沾污 | 通过改进工艺控制，正得到较好解决 |
| (3) 注入时间长，成本高 | 影响大规模推广 |
| (4) 需要大剂量SIMOX注入机 | 制约批量生产 |

### 6.3. 硅片粘合技术

硅片粘合技术是80年代中期出现的另一种形成SOI结构的方法。

**典型工艺步骤**：

1. **(a)** 取两片常规VLSI硅片：
   - 一片作为**被粘合硅片**（将来形成硅单晶薄层），在其表面生长1μm厚的SiO₂层
   - 另一片作为**支撑衬底**（衬底硅片）
2. **(b)** 将衬底硅片与被粘合硅片的SiO₂层接触，**不加任何压力**，在**氮气中1100°C退火2小时**，两硅片便牢牢粘合在一起
3. **(c)** 采用**粗磨 → 细磨 → 化学机械抛光（CMP）**将被粘合硅片减至所需厚度

**关键技术问题**：

| 问题 | 当前水平 |
|:----|:---------|
| **控制硅薄层厚度及均匀性** | 可在100mm硅片上实现1μm厚硅薄层，不均匀性 < 0.2μm |
| **保证粘合强度** | 控制粘合面微小缺陷、清洗方法和超洁净环境，粘接强度可达体硅水平 |
| **超薄单晶硅层** | 需要进一步解决，以满足超高速IC需求 |

**硅片粘合技术的特点**：

| 特点 | 说明 |
|:----|:------|
| 硅单晶薄层是体硅 | **材料质量与体硅相同**，导电类型和电阻率可自由选定 |
| SiO₂绝缘层厚度可自由选择 | 不像SIMOX受注入能量限制 |
| 衬底硅材料参数可自由选择 | 可选用不同电阻率/导电类型的衬底 |

**需解决的问题**：如何获得厚度均匀的超薄单晶硅层，以满足超高速IC的需求。

### 6.4. SOI技术的辐射效应背景

在太空环境中，宇宙辐射不可避免，会对微电子器件造成损坏。微电子器件中的数字和模拟集成电路的辐射效应一般分为三类：

| 辐射效应 | 产生原因 | 主要破坏机制 |
|:---------|:---------|:-------------|
| **TID**（总剂量效应，Total Ionizing Dose） | γ光子、质子和中子照射 | 氧化层电荷陷阱 → 漏电流↑、MOSFET阈值漂移、双极管增益衰减 |
| **SEE**（单粒子效应，Single Event Effect） | 高能粒子（质子、中子、α粒子等）轰击PN结敏感区 | 产生电荷 → 单粒子翻转（SEU：软误差）、电路闭锁、元件烧毁 |
| **剂量率效应**（Dose Rate Effect） | 甚高速率γ或X射线在极短时间内作用 | 整个电路产生光电流 → 闭锁、烧毁、轨电压坍塌 |

**CPU工作温度等级**：

| 等级 | 温度范围 |
|:----|:---------|
| 商业级 | 0°C ~ 70°C |
| 工业级 | -40°C ~ 85°C |
| 军品级 | -55°C ~ 125°C |
| **宇航级** | 不亚于军品级 + **抗辐射要求** |

**抗辐射加固方法**：

- **设计加固**：通过电路设计（如冗余、纠错码）提高容错能力
- **工艺加固**：采用专用工艺，如SOI工艺、SOS工艺、小几何尺寸CMOS工艺
  - 单粒子加固：SOI工艺、SOS工艺
  - 总剂量加固：小几何尺寸CMOS工艺
  - 典型产线：IBM的45nm SOI工艺、Honeywell的50nm工艺、BAE外延CMOS工艺

## 本讲核心要点

1. **隔离技术五个要求**：可靠隔离、工艺兼容、表面平坦、少占面积、无不良影响
2. **PN结隔离利用反偏PN结的截止特性**——P⁺隔离墙接最低电位，隔离岛被反偏PN结包围
3. **标准PN结隔离（SBC）** 的缺点：P⁺扩散深度大导致**横向扩展**占面积多，隔离结电容不利于高频
4. **PN结对通隔离**将隔离分上/下两次完成，上隔离与基区同时扩散，减少横向扩散面积
5. **CDI集电极扩散隔离**用N⁺埋层作为集电区+N⁺隔离墙，发射区扩散不须光刻，但击穿电压较低
6. **介质-PN结混合隔离**（等平面/LOCOS）用Si₃N₄做氧化阻挡层，SiO₂侧壁为介质+底部为PN结，兼具高集成度和良好频率特性
7. **MOS IC中存在场区寄生MOSFET问题**——通过**沟道终止掺杂**（提高场区表面浓度）+**厚场氧**（7~10倍栅氧）提高寄生管开启电压，确保隔离
8. **全槽氧化 vs 半槽氧化**——全槽在场区预腐蚀再氧化（表面更平坦），半槽不腐蚀（工艺更简单），亚微米需STI改进
9. **SOI结构**由"硅薄层-SiO₂绝缘层-体硅衬底"三层构成——彻底消除闩锁效应、大幅提升抗辐射能力（SEU抗性提高约200倍）、速度提高30%~40%
10. **SIMOX注氧隔离**和**硅片粘合**是两种主要的SOI制备方法——SIMOX精度高但成本高，硅片粘合灵活性高且材料质量与体硅相同
