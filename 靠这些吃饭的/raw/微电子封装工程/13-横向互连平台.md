# 13-2.5D/3D中的横向互连

## 知识地图

TSV 打通了垂直方向的互连（Z 方向），但芯片之间的横向通信（X/Y 方向）还需要高密度的布线网络——这就是横向互连（RDL / Interposer / Bridge）要解决的问题。

```
L11: TSV（垂直导通）       L13: 横向互连平台
     ↓                          ↓
 打通上下层                  连接左右邻
 TSV解决"怎么垂直走"         RDL/Interposer解决"怎么水平连"
```

**本讲核心**：从 RDL 工艺到硅中介层、桥接、有机物中介层的多种横向互连平台，以及它们的工程选择。

---

## 1. 横向互连的概念和功能

### 1.1. TSV 垂直导通后的横向布线

通过 TSV 实现厚度方向导通后，在 2.5D/3D 集成中还需要通过 **RDL / Interposer** 完成横向互连布线。

**主要功能**：
- I/O 重新分配
- 芯片间横向通信（die-to-die）
- microbump / C4 / UBM 位置匹配
- 信号、电源、地线在封装内的重新组织

### 1.2. RDL 的定义与核心功能

**RDL（Redistribution Layer，重布线层）** 是封装级互连网络。

**核心功能**：
1. 将原始 pad 或 TSV landing 重新分配到目标互连位置
2. 实现 I/O pitch 转换（芯片细 pitch → 基板粗 pitch）
3. 支持 microbump、C4 bump、Cu pillar 等互连端点布局
4. 实现芯片间横向通信
5. 作为 fan-in、fan-out、interposer、bridge 等平台的基础布线层

**RDL 是跨平台技术**：

| 平台 | RDL 主要作用 |
|------|-------------|
| Fan-in WLCSP | 将芯片 pad 重分配到焊球阵列 |
| Fan-out WLP/PLP | 在重构晶圆/面板上形成封装级布线 |
| RDL-first fan-out | 先制造 RDL substrate，再贴装芯片 |
| Si interposer | 实现芯片间高速横向互连 |
| Organic/RDL interposer | 以较低成本替代部分硅中介层功能 |
| Bridge | 在局部区域提供高密度 die-to-die 互连 |

### 1.3. 横向互连的必要性

**传统封装基板的局限**：
- IC 密度提高 → pin-out 数量增加 → pad pitch 和 bump pitch 不断缩小
- 多芯片并排集成 → 要求高速 die-to-die 通信
- 传统有机基板的线宽/线距、过孔密度和层数受到限制
- 即使采用多层 build-up 结构，仍不足以支撑高 I/O FPGA 需求

**结论**：需要在芯片与封装基板之间引入更高密度的横向布线平台——如 passive TSV interposer 和多层 RDL。

## 2. 再布线层（RDL）

### 2.1. RDL 关键指标

| 指标 | 含义 | 对封装的影响 |
|------|------|-------------|
| **L/S（线宽/线距）** | 布线密度 | 决定布线密度 |
| **Layer count（RDL 层数）** | 多层叠加 | 决定逃逸布线（将密集 pad/bump 阵列中的信号/电源/地线可靠引出并重新分配）与芯片间连接能力 |
| **Cu thickness（铜线厚度）** | 影响电阻和电流承载 | 影响电阻、电流承载与可靠性 |
| **Dielectric thickness（介质厚度）** | 影响寄生电容和绝缘 | 影响寄生电容、绝缘和应力 |
| **Via size（层间通孔尺寸）** | 层间互连 | 影响层间互连密度和良率 |
| **Pad/bump pitch（节距匹配）** | 与后续 bumping 匹配 | 决定后续 bumping 和键合可行性 |
| **Planarity（平坦度）** | 光刻/CMP/键合基础 | 影响光刻、CMP 和键合质量 |

### 2.2. RDL 电学设计因素

RDL 需要同时承担**信号传输、供电和地回流**三种功能。

**信号线**：
- L/S 影响阻抗、串扰和传输损耗
- 高速信号需要长度匹配和参考地
- die-to-die 通信要求短路径、低寄生

**电源/地网络**：
- 电源 RDL 需要降低 IR drop
- GND 需要形成低阻抗回流路径
- 多层 RDL 常通过宽线、网格、via 阵列增强供电能力

**寄生参数**：
- Cu 厚度影响电阻
- 介质厚度和 Dk（介电常数）影响电容
- 线长、线宽、层间距共同决定 RC 延迟

**HBM ballout（焊盘布局）案例**：
- HBM micro-bumps 呈规则交错排布
- 典型 pitch：x 方向约 55 μm，y 方向约 96 μm
- 每个基本区域包含 44 个信号 + 4 个时钟
- 其余多为供电 bump，并按 VSS / VDDQ 交替模式布置
- 同一数据/地址总线中的走线长度应尽量短且彼此接近
- SoC 侧与 HBM 侧 ballout 最好保持一致，便于形成规则化、可复制的布线单元

**SI/PI 分析**：

RDL/Interposer 布线完成后需提取并分析：
- wire/via 的 RC 寄生参数
- micro-bump 模型
- I/O driver/receiver 模型
- package RLC 模型
- 电源网络的 IR drop 和动态电压降
- 高速信号的眼图（eye diagram）和 BER（误码率）裕量

**信号完整性要点**：trace 越长 → wire parasitics 越大 → RC 增大 → rise/fall time 变慢 → 眼图垂直开口减小；互感和封装电感可能引起边沿偏移与 ringing。高速 RDL 不仅要求连通，还要控制长度、寄生和耦合。

### 2.3. RDL 工艺路线

#### （1）Polymer + Cu Plating（聚合物+铜电镀）

**介质材料**：PI（聚酰亚胺）、BCB（苯并环丁烯）、PBO（聚苯并噁唑）

**金属层**：Ti/Cu 种子层 + Cu 电镀

**完整 11 步流程**：
```
（1）涂覆 PI/BCB/PBO
（2）固化
（3）光刻开 via
（4）聚合物刻蚀
（5）溅射 Ti/Cu 种子层
（6）光刻定义 RDL 图形
（7）电镀 Cu
（8）去胶
（9）种子层刻蚀
（10）重复（1-9）形成第 2 层 RDL
（11）重复（1）形成 UBM
```

**结构特点**：
- 介质层较厚（6~7 μm），机械缓冲能力较好
- Cu 层较厚（3~4 μm），电流承载能力较强
- 工艺相对封装化，可用于 fan-out 和 RDL interposer
- 主要挑战：翘曲、介质开裂、Cu 迁移、层间剥离和尺寸控制

#### （2）Cu Damascene（铜大马士革）

接近半导体 BEOL 的高密度 RDL 路线。

**基本流程**：
```
沉积无机介质（SiO₂/SiN）→ 光刻定义 via 或沟槽
    → RIE 刻蚀介质 → 沉积阻挡/种子层
    → Cu 填充 → CMP 去除过量 Cu 和种子层
    → 重复形成多层 RDL
```

**特点**：
- 结构更薄
- pitch 更细
- L/S 更小
- 平坦度要求更高
- 成本和设备门槛更高

**工程实例参数**：
最小 RDL line width：约 3 μm
RDL1 / RDL2 厚度：约 2.6 μm
RDL3 厚度：约 1.3 μm
RDL 之间 passivation 厚度：约 1 μm

#### （3）RDL 缺陷与良率控制

**典型缺陷**：

| 缺陷类型 | 说明 |
|----------|------|
| **颗粒导致光刻缺陷** | 外来颗粒污染 |
| **RDL 层间短路** | 两层间的钝化层 <1 μm 时极易发生 |
| **via 开孔不良** | 通孔未完全打开 |
| **种子层残留导致桥连** | 相邻导线短路 |
| **Cu overburden / CMP 残留** | 金属残留 |
| **介质裂纹或剥离** | 层间附着力不足 |
| **多层 RDL 叠加导致良率下降** | 每层良率相乘，层数越多累积良率越低 |

RDL 越细，颗粒、短路和绝缘缺陷的后果越严重。

## 3. 横向互连技术平台

### 3.1. Si Interposer（硅中介层）

**关键组成部分**：
Si 衬底 + TSV + RDL + UBM + μbump

**典型应用**：
- GPU + HBM（高带宽存储器）
- FPGA + HBM
- HPC / AI 加速器
- 大规模 Chiplet 集成

### 3.2. Bridge（桥接）——局部高密度互连

**核心思想**：不使用整片大面积 Si interposer，而是在芯片之间需要高速通信的**局部区域**嵌入一小块高密度互连结构。

**Intel EMIB（嵌入式多芯片互连桥）**：
- EMIB 嵌入有机封装基板中
- 硅桥内部具有 fine metal L/S RDL
- 用于相邻芯片之间的局部横向互连
- 可降低大面积硅中介层带来的成本、面积和良率压力

**实际产品**：Intel Agilex FPGA w/ EMIB

**桥接的扩展——与 FO 结合**：
SPIL FO-EB（Fan-Out Embedded Bridge）技术：将桥接技术扩展到扇出封装平台。

### 3.3. TSMC 横向互连平台谱系

#### CoWoS-S（经典 2.5D 平台）

Silicon Interposer 方案，用于 AI/HPC 等超高性能场景
硅中介层成本高，面积（最大 2500 mm²）受 reticle / 良率限制

#### CoWoS-R（RDL Interposer）

不采用整片高成本 silicon interposer
使用由 polymer dielectric + Cu trace 构成的 RDL interposer
通过多层 RDL 实现 chiplet / HBM 之间的横向互连
面积扩展潜力更高、成本控制更好、结构柔性更优

#### CoWoS-L（全局 RDL + 局部硅高密度互连）

以 RDL-based interposer 承担大面积封装级互连
在关键 die-to-die 互连区域嵌入 **LSI（Local Silicon Interconnect）** 提供局部高密度、低寄生互连
全局 RDL 负责较大面积扩展、供电和一般互连
突破单片 Si interposer 的面积/良率/成本限制

### 3.4. 横向互连平台完整对比

| 平台 | 关键特征 | 典型代表 | 适用逻辑 |
|------|----------|----------|----------|
| **Organic substrate** | 成熟、低成本、L/S 较粗 | FC-BGA | 常规芯片到系统承载 |
| **Thin-film substrate (2.1D)** | Build-up 基板表面形成薄膜细线化层 | — | 在基板上提高局部布线密度 |
| **Fan-out RDL** | 无硅中介层，封装级 RDL 扩展 | InFO, FOCoS | 中等密度封装级扩展 |
| **RDL interposer** | 大面积、较柔性、成本折中 | **CoWoS-R** | 中高性能 |
| **Si interposer** | TSV + 高密度 RDL | **CoWoS-S** | 超高 I/O、高带宽、经典 2.5D |
| **Local bridge** | 只在关键区域提供高密度互连 | EMIB, **LSI** | 降低大面积中介层的成本和良率压力 |
| **RDL + LSI** | 全局 RDL + 局部硅互连 | **CoWoS-L** | 面积扩展与局部高密度兼顾 |

## 本讲核心要点

1. **RDL 是横向互连的基础**——Polymer+Cu Plating（封装级，介质~6μm/Cu~3μm）和 Cu Damascene（BEOL 级，线宽~3μm）两条路线
2. **RDL 电学设计**需同时兼顾信号完整性（长度匹配/寄生控制）、电源完整性（IR drop/低阻抗回流）和工艺可行性
3. **HBM ballout 设计规则**：x pitch~55μm、y pitch~96μm，每区 44 信号+4 时钟，VSS/VDDQ 交替排布
4. **Si Interposer**（CoWoS-S）提供最高密度但成本最高、面积受限（2500mm²）
5. **Bridge 技术**（Intel EMIB）只在关键局部提供高密度互连，成本和良率优势明显
6. **TSMC CoWoS 三兄弟**：CoWoS-S（纯硅中介层）→ CoWoS-R（RDL 中介层，低成本）→ CoWoS-L（全局 RDL+局部 LSI，旗舰）
7. **7 大横向互连平台**各有适用场景，选择需平衡密度、成本和良率
