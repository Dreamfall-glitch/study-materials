# 03-贴片工艺技术

## 知识地图

芯片在完成减薄和划片后，变成了一颗颗独立的 die。但这时候的 die 只是"裸片"——它还不能直接焊到电路板上用。接下来的关键一步是：**把 die 固定到它的底座（载体）上**。

```
前面学过的：               现在要学的：                 后面的内容：
晶圆减薄 → 划片       →    贴片（Die Bonding）     →   引线键合/倒装
(解决厚度和分片问题)       (把die固定到载体上)           (实现电气连接)
```

贴片的核心问题可以归结为三个：

1. **怎么固定**——用什么材料把芯片粘在基座上？
2. **怎么传热**——芯片工作发热，粘结层要让热量顺利传导出去
3. **怎么导电**——有些芯片背面需要电气连接，粘结层必须是导电的

本讲将逐一介绍几种主流的贴片技术，从传统的环氧树脂到高温共晶焊，再到面向大功率器件的纳米银烧结。

---

## 1. 芯片粘接简介

### 1.1. 什么是芯片粘接？

**芯片粘接（Die Bonding / Die Attach / 贴片）** 是指将芯片/管芯（Die/Chip）固定在载体（引线框架、基板等）上的方法，通常采用粘结或焊接技术实现。

这一环节最基本的工艺考虑包括：

| 要求 | 说明 |
|------|------|
| **机械强度** | 粘结层必须有足够的力学支撑，抵抗振动和冲击 |
| **化学性能稳定** | 不与周围材料发生有害化学反应 |
| **导电性和导热性** | 根据需求选择绝缘或导电/导热的粘结方式 |
| **热匹配特性** | 粘结材料和芯片/载体的CTE要匹配，避免热应力开裂 |
| **低固化温度和易操作性** | 固化温度不能损伤芯片，操作过程要可控 |

### 1.2. 芯片粘接的主要技术类型

```
芯片粘接技术全景：

环氧树脂粘结 ── 塑料封装主流，绝缘性好
    ↓
导电胶粘结 ──── 加入银粉等导电填料，兼具粘接和导电
    ↓
共晶焊 ──────── Au-Si、Au-Sn合金，高温高可靠性
    ↓
焊料粘结 ────── Pb-Sn、Ag-Cu焊料，适用于陶瓷封装
    ↓
纳米银烧结 ──── 面向大功率器件，低温烧结高温服役
    ↓
低熔点玻璃粘结 ─ 气密封装特殊场合
```

## 2. 环氧树脂与导电胶粘结技术

### 2.1. 环氧树脂粘结

**应用场景**：主要应用于芯片与底座要求相互绝缘的情况，是塑料封装中最常用的方法。

| 项目 | 内容 |
|------|------|
| 组分 | 固化剂、固化促进剂、稀释剂、填充剂等 |
| 优点 | 易加工、高粘合力、稳定、绝缘特性好 |
| 缺点 | 耐高温性稍差、收缩性较差 |

点胶示意：在基板上的芯片安装区域涂布环氧树脂 → 放置芯片 → 加热固化

### 2.2. 导电胶粘结

在环氧树脂中加入金属粉粒（通常是银粉），使其兼具粘接和导电/导热的双重功能。

| 项目 | 内容 |
|------|------|
| 优点 | 工艺简单、成本低廉 |
| 典型固化温度 | 125~175°C |
| 特点 | 减小欧姆接触、改善导热性；热稳定性稍差但机械强度高 |
| 适用性 | 既用于导热，又用于电学连接 |

**操作要点**：必须遵循材料的操作手册和datasheet，不同厂商的导电胶配方差异很大，固化温度和时间的窗口需要严格控制。

## 3. 共晶焊技术

### 3.1. 共晶的基本概念

**共晶（Eutectic）**：一定成分的合金液体在共晶反应温度下，冷却、凝固、结晶为两种或更多致密晶体混合物的现象。

两个关键特征：
- **共晶温度**：该合金的最低熔化温度
- **组分比例**：共晶温度与组分比例密切相关——只有在特定比例下才能达到最低熔点

共晶焊的吸引力在于：可以在相对较低的温度下形成连接，但形成的连接层能承受更高的工作温度。

### 3.2. Au-Si 共晶焊

这是最经典的共晶焊技术之一：

```
基本原理：
芯片背面有金硅合金（Au-Si）
    +  底座/引线框架上镀有金属（银层）
    ↓
在超过共熔点温度（约400~440°C）下
    +  施加一定压力
    +  芯片与底座做相对超声频率擦动
    ↓
金属原子相互扩散 → 形成金硅共晶结构
```

**关键参数**：
- 烧结温度：400~440°C
- 气氛保护：氮气保护
- 需要芯片背面金属化（镀金）
- 导电导热性能都很好

**局限性**：适用于较小尺寸的芯片

### 3.3. 焊料共晶粘结

除了Au-Si共晶，还有基于焊料（solder）的共晶粘结技术：

| 焊料体系 | 特点 |
|----------|------|
| **Au-Sn**（金-锡） | 共晶温度约320°C，多用于陶瓷封装 |
| **Ag-Cu**（银-铜） | 无铅焊料，环保方向 |
| **Sn-Pb**（锡-铅） | 传统焊料，便于操作，强度稍低于共晶焊，导热性好 |

焊料共晶多用于陶瓷封装和塑封器件的芯片粘结。粘结强度稍低于Au-Si共晶焊，但操作更简便。

## 4. 纳米银（浆）烧结技术

### 4.1. 为什么需要纳米银烧结？

传统焊料和导电胶在**大功率器件**面前遇到了瓶颈——功率器件发热量大、工作温度高，传统粘结材料要么导热不够好，要么在高温下失效。

**纳米银烧结**正是为应对这一挑战而开发的。

### 4.2. 工作原理

```
纳米银颗粒（尺寸在纳米级）
    ↓  利用"尺寸效应"——纳米颗粒熔点远低于块体材料
在辅助一定压力下
    ↓
低温烧结（约240°C）
    ↓
烧结连接层为纯银（Ag）
    ↓
可在高温下服役（银的熔点高达961°C）
```

| 项目 | 说明 |
|------|------|
| 烧结温度 | ~240°C（低温烧结） |
| 服役温度 | 可高达数百度（高温服役） |
| 连接层材料 | 纯银 |
| 导电性 | 优秀 |
| 导热性 | 优秀 |
| 主要缺点 | **成本高** |

纳米银烧结的核心技术优势是"低温烧结、高温服役"——这是利用纳米材料的尺寸效应实现的。

## 5. 一级封装典型工艺温度对比

将各种贴片工艺的工艺温度进行对比，有助于理解不同技术的适用场景：

| 工艺 | 工艺温度 (℃) |
|------|:------------:|
| 环氧树脂 | 175 |
| 导电胶 | 125~175 |
| 纳米银（浆）烧结 | **240** |
| 焊料共晶（Sn-Pb） | 315 |
| Au-Sn共晶（80Au/20Sn） | 320 |
| Au-Si共晶（98Au/2Si） | **425** |
| 玻璃粘结 | 450 |

**趋势分析**：从环氧树脂（175°C）到Au-Si共晶（425°C），随着工艺温度的升高，连接层的可靠性和耐温能力也在提升，但同时工艺复杂度增加、热应力风险也更大。

## 6. 芯片粘结方法的选择逻辑

### 6.1. 载体决定方法

不同载体材料需要不同的粘结工艺：

```
载体类型 → 推荐粘结方法

塑料封装 ──→ 环氧树脂 / 导电胶（中低温工艺，与塑料兼容）
       │
陶瓷封装 ──→ Au-Si共晶 / Au-Sn焊料 / 导电胶
       │              （耐高温，与陶瓷CTE匹配）
       │
金属封装 ──→ Au-Si共晶 / 焊料（高可靠性要求）
```

### 6.2. 优缺点对比

| 方法 | 优点 | 缺点 | 适用封装 |
|------|------|------|----------|
| Au-Si共晶 | 导电导热好、可靠性高 | 温度高（425°C）、需背面金属化 | 陶瓷/金属封装 |
| Au-Sn/Pb-Sn焊料 | 便于操作、导热好 | 强度低于共晶焊 | 陶瓷/塑料封装 |
| 环氧树脂 | 工艺简单、成本低 | 绝缘、耐温差 | 塑料封装 |
| 导电胶 | 兼顾粘接和导电 | 热稳定性稍差 | 塑料/陶瓷封装 |

### 6.3. 热膨胀系数（CTE）匹配

**CTE（Coefficient of Thermal Expansion，热膨胀系数）**：量度固体材料热膨胀程度的物理量，单位长度/单位体积的物体，温度升高1°C时，其长度或体积的相对变化量。单位：μm/m/°C 或 ppm/°C。

**关键数据**：单晶硅在室温下的CTE约为 **2.6 ppm/°C**

CTE匹配在贴片环节至关重要——如果芯片、粘结层和载体的热膨胀系数差异过大，温度变化时会产生巨大热应力，导致：
- 粘结层开裂
- 芯片碎裂
- 焊点疲劳失效

## 7. 贴片设备简介

### 7.1. 芯片拾取原理

贴片设备从划片后的蓝膜（Blue Tape）上拾取芯片：

```
顶针 (Eject Needle)  从蓝膜下方将芯片顶起
    ↓
真空吸嘴 (Vacuum Pick-up Needle)  从上方吸附芯片
    ↓
拾取完成 → 转移到贴装位置
```

### 7.2. Die Bonder（贴片机）主要组成

贴片机的核心模块包括：

| 模块 | 功能 |
|------|------|
| **空气轴承XY平台（Air-Bearing X-Y Table）** | 高精度定位芯片和基板 |
| **焊晶机构/CCD摄像头** | 视觉对准和位置检测 |
| **晶圆框架输送系统** | 输送和定位晶圆 |
| **银胶分配系统** | 精确控制粘结剂的涂布量 |
| **送料轨道与加热炉** | 基板传送和固化加热 |
| **控制与示教盘** | 参数设定和操作控制 |

商业化设备型号较多，核心原理是通过精确的视觉定位和力控系统，将芯片以微米级精度放置在指定位置。

## 本讲核心要点

1. **贴片（Die Bonding）** 是芯片从晶圆切割成独立die之后的第一道封装工序——把die固定到载体上
2. **粘结方式的选择**取决于封装类型（塑料/陶瓷/金属）、散热需求和成本要求
3. **环氧树脂/导电胶**工艺简单、成本低，是塑料封装的主流方案，但耐温性不足
4. **共晶焊**（Au-Si、Au-Sn）形成金属间化合物连接，导电导热好、可靠性高，但工艺温度高（320~425°C）
5. **纳米银烧结**利用纳米尺寸效应实现"低温烧结、高温服役"，是功率器件封装的前沿方案，但成本高
6. **CTE匹配**是贴片工艺设计的关键考虑——芯片、粘结层、载体三者的热膨胀系数差异过大将导致热应力失效
