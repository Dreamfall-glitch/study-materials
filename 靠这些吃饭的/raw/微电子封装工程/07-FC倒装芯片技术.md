# 07-Flip Chip 倒装芯片技术

## 知识地图

前几讲我们学习了引线键合（WB）和载带自动焊（TAB）——这两种互连技术都是**芯片正面朝上**，用引线从芯片边缘连接到基板。但随着I/O数量的爆炸式增长，这种方法遇到了瓶颈。

```
WB（引线键合）         TAB（载带自动焊）         FC（倒装芯片）
  芯片朝上              芯片朝上                 芯片朝下（翻转）
  逐根引线键合           一次性载带键合            整个面阵列凸点
  线弧占用空间           引线平面占用空间          凸点占用面积最小
  I/O密度受限           中等密度                 最高密度
```

**本讲的核心问题**：如何把芯片"翻过来"，用整面的凸点代替边缘的引线，实现最高密度的互连？

---

## 1. 倒装芯片技术概述

### 1.1. 什么是倒装芯片？

二十世纪60年代，IBM发明了**C4技术（Controlled Collapse Chip Connection，可控塌陷芯片连接）**，以取代当时昂贵、可靠性差且生产率低下的手工引线键合技术。

"Flip" 意味着芯片被翻转——原本朝上的有源面朝下，通过凸点（bump）直接与基板连接。

### 1.2. 倒装芯片的互连结构

FC互连的基本结构：
- **芯片（Chip）**：有源面朝下
- **凸点（Bump）**：Solder、Cu、Au、In或导电胶
- **基板（Substrate）**：引线框架、有机基板、陶瓷、金属等

### 1.3. 倒装芯片互连的优点

| 优点 | 说明 |
|------|------|
| **高密度** | I/O数量远大于WB（面阵列 vs 周边阵列） |
| **短传输路径** | 信号路径最短，延迟小 |
| **低耦合电感** | 优良的噪音控制 |
| **薄外形** | 整体厚度更薄 |
| **面积效率高** | 封装面积仅为WB的1/3 |

### 1.4. 倒装芯片的关键因素

```
倒装芯片技术的四大关键要素：
1. UBM（Under Bump Metallurgy，凸点下金属化层）
2. 凸点成型（Bumping）技术——焊料凸点/Au凸点/Cu Pillar
3. 组装（Assembly）技术
4. 可靠性测试
```

### 1.5. 一级封装互连技术对比

| 特性参数 | 引线键合(WB) | 载带自动焊(TAB) | 倒装芯片(FC) |
|----------|------------|---------------|------------|
| 工艺成熟性 | 很好 | 好 | 很好 |
| 封装面积比 | 1（基准） | 1.33 | **0.33** |
| 封装重量比 | 1 | 0.25 | **0.2** |
| 封装厚度比 | 1 | 0.67 | **0.52** |
| 典型节距(μm) | 50~175 | 60~100 | 100~250 (焊料) / 更小(Cu柱) |
| I/O引出端数 | ≥300(外引脚) | 800~1000 | **>1000** |
| 每引出端成本($) | 0.001 | 0.003~0.01 | 0.002 |

## 2. UBM（凸点下金属化层）

### 2.1. UBM的结构

UBM是芯片焊盘与凸点之间的多层金属薄膜系统，通常由三层功能层组成：

```
        ┌──────────────────────────────────┐
        │    凸点（Solder/Au/Cu）           │
        ├──────────────────────────────────┤
Layer 3 │ 浸润层和防氧化层（Au/Ni/Cu）        │ ← 润湿焊料，防止氧化
        ├──────────────────────────────────┤
Layer 2 │ 扩散阻挡层（Ti/TiW/Ni/Cu/Pd/Pt）   │ ← 阻止凸点材料扩散到Al/Si
        ├──────────────────────────────────┤
Layer 1 │ 粘附层(Cr/Ti/TiW/V)               │ ← 与Al焊盘和钝化层结合
        ├──────────────────────────────────┤
        │  Al 焊盘 + 钝化层（SiN/SiO₂）      │
        └──────────────────────────────────┘
```

### 2.2. 各层功能详解

| 层次 | 功能 | 要求 | 常用材料 |
|------|------|------|----------|
| **粘附层** | 与Al焊盘及钝化层牢固结合 | 粘附性好、接触电阻小、CTE接近 | Cr, Ti, TiW(N), V |
| **扩散阻挡层** | 阻止凸点材料与Al/Si互扩散 | 避免形成有害IMC | Ti, TiW(N), Ni, Cu, Pd, Pt |
| **浸润层/防氧化层** | 润湿焊料+保护底层 | 良好浸润、不做为UBM种子层、防止氧化 | Au, Ni, Cu |

### 2.3. UBM的通用要求

1. **牢固结合力**：与焊区金属和钝化层（氮化物/氧化物/聚酰亚胺）牢固结合。钝化层不能有针孔
2. **良好欧姆接触**：沉积UBM前需去除Al焊盘表面的Al氧化物（溅射或化学刻蚀）
3. **焊料扩散阻挡层**：在焊料与焊盘之间提供扩散屏障
4. **可润湿表面**：最后一层直接接触凸点，必须能被焊料润湿
5. **氧化阻挡**：防止UBM在凸点成型过程中氧化
6. **低应力**：不能对硅片产生过大应力，否则导致底部开裂或硅片凹陷

### 2.4. 常见UBM体系

| 凸点类型 | UBM体系 |
|----------|---------|
| 高铅焊料（C4） | Cr-Cr:Cu-Cu |
| 共晶焊料 | Ti-Cu, TiW-Cu, Al-NiV-Au, 化学镀Ni(P)-Au |
| 无铅焊料 | Ti-Ni |
| 金凸点 | TiW-Au |

### 2.5. UBM的沉积方法

| 方法 | 原理 | 特点 |
|------|------|------|
| **溅射** | 溅射沉积薄膜 → 光刻 → 刻蚀 | 精度高，需真空设备 |
| **蒸镀** | 利用掩模选择性沉积 | 可与凸点成型用同一掩模 |
| **化学镀** | 在Al/Cu焊盘上选择性镀Ni | 无需真空和光刻设备，**低成本** |
| | （常用锌酸盐工艺处理Al表面） | |

### 2.6. 常用半导体金属化金属性能

| 金属 | CTE (×10⁻⁶/°C) | 热导率(W/cm°C) | 电阻率(×10⁻⁶ Ωcm) | 与Si/SiO₂浸润性 | 可焊性 |
|------|---------------|---------------|-------------------|----------------|--------|
| Al | 25 | 2.37 | 2.65 | 很好 | 很难 |
| Cu | 16.6 | 3.98 | 1.68 | 差 | 好 |
| Au | 14.2 | 3.15 | 2.24 | 很差 | 很好 |
| Ni | 13 | 0.899 | 6.84 | 较好 | 不很容易 |
| Ti | 8.5 | 0.2 | 42 | 很好 | 很难 |

## 3. 凸点成型技术

### 3.1. 主要凸点类型

```
凸点类型分类：
    ├── Sn基焊料凸点
    │   ├── 高铅焊料（Sn<5%）
    │   ├── 共晶焊料（Sn~63%）
    │   └── 无铅焊料（Sn>90%）
    ├── Au及Au基合金凸点（显示驱动芯片）
    ├── Cu柱凸点（Cu Pillar/Post，CPU封装）
    ├── Ni基凸点
    └── In（铟）凸点
```

### 3.2. 凸点成型方法

| 方法 | 原理 | 特点 |
|------|------|------|
| **蒸发（C4 Process）** | 通过掩模蒸镀 | IBM C4经典工艺，高铅焊料 |
| **钉头凸点（Stud Bump Bonding）** | 利用引线键合设备 | 以Au凸点为主，效率低（8bumps/s） |
| **电镀** | 电化学沉积 | 主要方法之一，可用于Solder/Au/Cu |
| **模板印刷** | 焊膏印刷 | 结合化学镀UBM |
| **激光（SB²）** | 激光再流焊植球 | 典型直径80μm（设备能力40μm） |
| **化学镀+印刷** | 化学镀UBM+焊膏印刷 | 低成本 |

### 3.3. 焊料凸点电镀成型流程

```
1. Wafer with Al pad（带Al焊盘的晶圆）
2. Sputter UBM（溅射UBM）
3. Coat with PR（涂覆光刻胶）
4. Pattern for bump（光刻开窗）
5. Electroplating Cu and solder（电镀Cu和焊料/蘑菇形生长）
6. Remove Resist（去除光刻胶）
7. Strip UBM（刻蚀UBM）
8. Reflow（再流焊 → 形成球形凸点）
```

### 3.4. 窄节距Cu柱凸点（Cu Pillar）工艺流程

Cu Pillar是目前高密度封装的核心技术，其完整工艺步骤如下：

```
Coming wafer structure
    ↓ Step 1: First passivation formation（第一次钝化层）
    ↓ Step 2: PVD 1 - Seed deposition（溅射种子层 Ti/Cu）
    ↓ Step 3: Litho RDL（光刻RDL图形）
    ↓ Step 4: RDL trace formation - Cu plating + PR strip + Seed etch（形成RDL布线）
    ↓ Step 5: Second passivation formation（第二次钝化层，PI或PBO）
    ↓ Step 6: PVD 2 - Seed deposition（第二次溅射种子层）
    ↓ Step 7: Thicker PR formation（厚胶光刻，形成电镀模具）
    ↓ Step 8: Pillar plating - Cu + Ni + Sn（电镀Cu柱、Ni阻挡层、Sn帽）
    ↓ Step 9: Pillar formation - PR strip + Seed etch + Reflow（去胶、刻蚀种子层、再流焊）
```

Cu Pillar关键材料：Cu（导电柱体）+ Ni（扩散阻挡层）+ Sn（焊接帽）

### 3.5. 金凸点成型工艺

- 最小节距可达70μm，最小间隙20μm
- 已应用于液晶驱动电路、光电器件（COG: Chip On Glass; COF: Chip On Film）
- 节距已达20~40μm
- 配合ACA（各向异性导电胶）实现互连

### 3.6. 凸点设计的关键约束

| 约束条件 | 说明 |
|----------|------|
| 回流焊温度 | 基底不能承受太高温度时，需采用低温焊料 |
| 周边/面阵列间距 | 周边最小80~130μm，面阵列最小110~150μm |
| 最大电流密度 | 焊料凸点约**4200 A/cm²** |
| 凸点高度公差 | 取决于焊盘间距，公差范围要小 |

## 4. 导电胶技术（非焊料互连）

### 4.1. 导电胶类型

| 类型 | 全称 | 导电方向 |
|------|------|----------|
| **ICA** | 各向同性导电胶 | 所有方向 |
| **ACA** | 各向异性导电胶 | 仅Z方向 |
| **ACF** | 各向异性导电膜 | 仅Z方向 |
| **NCA** | 非导电胶 | 不导电（靠机械接触） |

### 4.2. ICA导电机理

接触本征导电 + 隧道效应导电：导电填料粒子（Ag、Cu、Ni等）在树脂基体中形成导电通路。

### 4.3. ACF导电机理

Z方向的粒子与焊盘和凸点接触并受压，在Z向导电；其他位置和方向不导电。

### 4.4. 导电胶的技术驱动因素

| 因素 | 说明 |
|------|------|
| **环境** | 无助焊剂（Flux-Free）、无铅 |
| **经济** | 工艺步骤更少，可利用模板/钢网/点胶 |
| **技术** | 低温工艺、窄节距互连、比焊点更小、无塌陷、无金属间扩散问题 |

## 5. 倒装芯片组装

### 5.1. 焊料凸点组装流程

```
Bumping（凸点成型）→ 基板准备（表面金属化）→ Alignment（对位）
    → Reflow & Cleaning（回流及清洗）→ Underfill & Curing（底部填充及固化）
    → Molding（模塑，可选）
```

### 5.2. 回流焊接（Reflow）

焊料凸点通过回流，与焊盘金属化层形成**金属间化合物（IMC）**：
- 主要金属化层：Cu、Ni
- Sn基焊料与Cu形成 Cu₆Sn₅ / Cu₃Sn
- Sn基焊料与Ni形成 Ni₃Sn₄

**自对准（Self-alignment）**是焊球组装的重要特点——熔融焊料的表面张力会将芯片拉回到精确位置。

### 5.3. Cu Pillar组装方式

| 方式 | 说明 |
|------|------|
| Cu Pillar + Solder Cap by SLID | 固液互扩散键合（高温，扩散快） |
| Cu Pillar + Solder Cap + Solder Pad | 焊料帽+焊料焊盘 |
| **Cu-Cu直接键合** | 固固扩散（低温，扩散慢，需加压）/ 混合键合（Hybrid Bonding） |

### 5.4. 底部填充（Underfill）

**为什么需要底部填充？** 芯片与基板之间存在热膨胀系数（CTE）不匹配，在组装及使用过程中将带来热应力，需要通过底部填充来缓解。

**底部填充材料**：主要成分为环氧树脂和填充物。

**功能**：
- 缓解CTE不匹配产生的热应力
- 保护芯片表面，防止微尘、湿气侵入裂缝

**底部填充方法**：

| 方法 | 原理 |
|------|------|
| **毛细填充（Capillary Flow）** | 利用毛细力使胶水流入芯片底部 |
| **注入填充（Injection Flow）** | 加压注入 |
| **下压填充（Compression Flow）** | 将胶水预先涂布后压合 |

**底部填充材料的关键要求**：

| 要求 | 说明 |
|------|------|
| 无挥发性 | 否则导致芯片底部产生间隙 |
| 低应力失配 | 与凸点连接处的Z方向CTE要匹配 |
| 低固化温度 | 防止PCB热变形 |
| 高玻璃转化温度（Tg） | 耐热循环冲击 |
| 小填料粒子尺寸 | 适应窄间隙 |
| 高温下良好流动性 | 填充充分 |
| 高弹性模量和弯曲强度 | 互连应力小 |
| 高绝缘电阻 | 杂质离子（Cl⁻/Na⁺/K⁺）含量低 |
| 低α放射 | 对存储器和敏感元件至关重要 |

## 6. 检测与可靠性

### 6.1. 凸点组装的检测方法

| 方法 | 类型 | 目的 |
|------|------|------|
| **芯片拉力/剪切力测试** | 破坏性 | 凸点强度、凸点组装强度 |
| **金相截面分析** | 破坏性 | 组装界面微观组织分析 |
| **超声扫描显微分析（C-SAM）** | 无损 | 凸点组装完整性、底部填充完整性、分层 |
| **X-ray检测** | 无损 | 组装完整性、气泡、桥接 |

**X射线检测原理**：不同材料对X射线的吸收能力不同，形成黑白对比图像。

| 材料 | 不透明系数 | 在封装中用途 |
|------|-----------|-------------|
| Au | 非常高 | 引线键合 |
| Pb/Sn | 高 | 焊料 |
| Cu | 中等 | PCB印制线 |
| Si/塑料/Al | 极小 | 芯片/包装/引线/散热片 |

### 6.2. 可靠性：金属间化合物（IMC）

**IMC是焊料凸点组装的基本界面组织结构**：

| 体系 | 生成的IMC |
|------|-----------|
| TiW/Cu - Sn | Cu₆Sn₅, Cu₃Sn |
| Ni - Sn | Ni₃Sn₄ |

**IMC生长规律**：
- 固定温度下，IMC厚度 Z = (Dt)^1/2（扩散控制机理）
- Arrhenius公式：D = D₀ × exp(-Ea/RT)
- Cu-Sn IMC生长速度远高于Ni-Sn IMC
  - 相同条件下：Cu-Sn可超过10μm，Ni₃Sn₄不超过2μm

### 6.3. 柯肯达尔空洞（Kirkendall Void）

在Cu-Cu₃Sn界面尤其明显，由于元素扩散系数差异导致空洞形成，在服役时（电流+温度下），Cu继续向Cu₃Sn扩散，空洞进一步长大，导致脆性断裂。

对于Sn基无铅焊料凸点，**Cu不是优选的UBM**——因为Cu-Sn IMC生长快且易形成Kirkendall空洞。Ni是更好的选择（Ni的溶解速度仅为Cu的1/30~1/40）。

### 6.4. 热疲劳

热疲劳是倒装芯片凸点组装**最关键**的可靠性问题，源于CTE不匹配。

| 材料 | CTE (10⁻⁶/°C) |
|------|---------------|
| Si | 3.2 |
| 陶瓷 | 5.5 |
| Underfill | 24 |
| 有机基板 | 17.6 |
| 焊料 | 22 |

**底部填充可大幅提升热疲劳可靠性**——实验数据表明，有underfill的样品在1000次热循环后电阻几乎无变化，而无underfill的样品在不到100次循环后电阻就急剧增大。

### 6.5. 芯片-封装交互作用（CPI）

芯片工艺引入了相对脆弱的介质层（Low-K材料），微凸点组装过程中的应力等因素会对介质层产生影响。

### 6.6. 电迁移（Electromigration）

- 条件：大电流通过金属导体
- Sn基材料（体心四方BCT晶体结构）导致电迁移加剧
- **微凸点电迁移现象更为明显**（电流密度更高）
- **Cu Pillar可提升抗电迁移能力**——降低电流密度

### 6.7. 提高可靠性的途径

**热、机械、电对可靠性的影响是交互作用的。**

1. 凸点/微凸点组装的热机械应力（CTE不匹配）
   - 优化凸点材料的机械特性及微观组织结构
   - 优化组装工艺参数（温度等）
   - 提升前道介质层特性
   - 采用低膨胀系数基板
2. 凸点尺度缩小的电迁移风险
   - 降低电流密度
   - 利用Cu Pillar / Cu-Cu键合实现组装

## 本讲核心要点

1. **倒装芯片（FC）是互连技术的重大飞跃**——从"芯片朝上、边缘引线"到"芯片朝下、面阵列凸点"，I/O密度和电性能大幅提升
2. **UBM是FC的基础**——三层结构（粘附层+扩散阻挡层+浸润层）确保凸点与芯片焊盘的可靠连接
3. **凸点成型有多种方法**，电镀是主流；**Cu Pillar**正在成为高密度封装的核心选择（节距可达20μm）
4. **底部填充（Underfill）是FC可靠性的关键**——缓解CTE不匹配，可将热循环寿命提升10倍以上
5. **IMC和Kirkendall空洞**是主要的可靠性失效机理——Ni是比Cu更好的阻挡层选择
6. **一级封装互连技术的演进**：WB → TAB → FC，面积缩小到1/3，I/O数增加到3倍以上
