# 12-晶圆减薄及薄晶圆拿持

## 知识地图

L02 的传统减薄是将晶圆从 750μm 减到 200~300μm 用于常规封装。而三维集成中的减薄需减到 <100μm，还要进行 TSV 露出、背面 RDL 等工艺——晶圆越薄越易碎，拿持技术成为关键。

```
FEOL/BEOL完成 → 临时键合至载片 → 背面减薄 → 损伤去除/应力释放
    → TSV背面露出 → 背面钝化/RDL/UBM/微凸点 → 解键合 → 堆叠互连
```

**本讲核心**：三维集成中晶圆减薄的方法论（背磨/CMP/干法/湿法）与薄晶圆拿持技术（TAIKO/DBG/临时键合）。

---

## 1. 晶圆减薄的作用与要求

### 1.1. 减薄在三维集成工艺链中的位置

晶圆减薄是三维集成中连接**正面器件制造**与**背面互连形成/堆叠键合**的关键中间环节。

### 1.2. 晶圆原始厚度

| 晶圆直径 | 原始厚度 |
|----------|---------|
| 200 mm | ~725 μm |
| 300 mm | ~775 μm |

在前道硅基器件制造过程中，足够的晶圆厚度提供必要的机械稳定性、温度均匀性以及电学测试中探针接触所需的平整度。

### 1.3. 减薄的五个作用

| 作用 | 说明 |
|------|------|
| **(1) 改变力学特性** | <50μm 超薄芯片可弯曲而不断裂；但整体刚度下降→翘曲/裂纹/崩边→**必须配合拿持技术** |
| **(2) 降低热阻** | 缩短垂直热传导路径；但散热还取决于 TIM、基板、散热盖等系统级设计 |
| **(3) 减小封装厚度** | 满足薄型化、小型化和多芯片堆叠需求 |
| **(4) 改善电学性能** | 缩短 TSV 垂直互连路径，降低电阻、寄生参数和信号延迟 |
| **(5) 改善切割质量** | 划片去除厚度减小→降低切割负荷、提高良率 |

### 1.4. 减薄的厚度范围

```
背面减薄去除硅层厚度：500–700 μm
减薄后剩余硅衬底厚度：25–190 μm
有效电路层厚度：      5–10 μm
减薄后晶圆总厚度：    30–720 μm
```

常规制造与拿持条件下，晶圆可减薄到的实际厚度下限约为 **20–30 μm**。

### 1.5. 减薄质量指标

| 指标 | 对后续工艺的影响 |
|------|-----------------|
| **最终厚度** | TSV 是否正确露出、芯片是否具备足够强度 |
| **TTV / 厚度均匀性** | 全片 TSV 暴露一致性、背面 RDL 和键合一致性 |
| **翘曲** | 光刻对焦、键合对准、载片支撑和搬运稳定性 |
| **表面粗糙度** | 背面钝化层、RDL、UBM 或键合界面质量 |
| **亚表面损伤层** | 薄晶圆强度、裂纹扩展风险和长期可靠性 |
| **边缘缺陷与污染** | 解键合、切割、堆叠良率和器件电学可靠性 |

## 2. 晶圆减薄方法与典型工艺组合

### 2.1. 方法总览

晶圆减薄及后处理方法主要包括（共8种）：

磨削(Grinding)、研磨(Lapping)、化学机械平坦化(CMP)、干法抛光(Dry polishing)、电化学刻蚀(Electrochemical etching)、湿法刻蚀(Wet etching)、等离子体辅助刻蚀(Plasma-assisted etching)、常压下游等离子体刻蚀(ADPE)

工业中最常见的路线：**背磨快速去除大部分硅 + CMP/湿法刻蚀/干法去除损伤层**。

### 2.2. 典型工艺组合

晶圆减薄采用"粗减薄—精减薄—损伤去除—背面功能工艺"的组合路线：

| 阶段 | 目标 | 常用方法 | 关键控制 |
|------|------|----------|----------|
| **粗减薄** | 快速去除大部分 Si | Back grinding | 去除率、裂纹、热损伤 |
| **精减薄** | 接近目标厚度 | Fine grinding | 粗糙度、SDD（亚表面损伤深度） |
| **损伤去除** | 去除亚表面损伤 | CMP / wet etch / dry polish / plasma etch / ADPE | 残余应力、TTV |
| **TSV reveal** | 暴露 Cu TSV | CMP / etch + CMP | Cu protrusion、dishing |
| **后续背面工艺** | RDL / UBM / passivation / plating | 沉积/光刻/电镀 | 表面质量、污染控制 |

四条可选的工艺路线：
背面磨削 + CMP | 背面磨削 + 干法抛光 | 背面磨削 + 湿法刻蚀 | 背面磨削 + ADPE

### 2.3. 机械背磨（Grinding）

**背磨的核心特点**：
- 优点：加工效率高、成本较低、厚度和晶圆形貌控制好
- 缺点：引入表面和亚表面损伤（微裂纹、残余应力、损伤层降低薄晶圆强度）

**粗磨 vs 精磨**：

| 参数 | 粗磨 | 精磨 |
|------|------|------|
| 砂轮粒度/目数 | 300–600 | 1000–3000 |
| 金刚石磨粒尺寸 | 10–80 μm | 1–8 μm |
| 进给速度 | 2–12 μm/s | 0.2–1.5 μm/s |
| 结合剂结构 | 陶瓷 | 树脂，也有陶瓷 |
| 硅表面特征 | 粗糙 | 精细 |
| 表面粗糙度 Ra | <0.2 μm | <0.05 μm |
| 断裂载荷 | 约 8 N | 约 20 N |

粗磨后硅表面及亚表面形成**多层损伤结构**：非晶硅层 → 塑性变形层 → 弹性变形层 → 亚表面裂纹。精磨后损伤层深度显著降低，断裂载荷明显提高。

**背磨核心工具——金刚石砂轮**：
砂轮由金刚石磨粒、结合剂和孔隙组成。磨粒尺寸、结合剂类型和孔隙结构共同决定去除率、粗糙度、发热、磨损和损伤深度。

**常见砂轮结合剂**：

| 类型 | 特性 |
|------|------|
| **树脂结合剂** | 自锐性较好，适合较细表面加工 |
| **陶瓷结合剂** | 结合强度高，适用于 Si 或 Si/TSV 结构 |
| **金属结合剂** | 适配磨粒范围宽、磨削能力强，但发热和自锐性问题更明显 |

**磨削 vs 研磨（Grinding vs Lapping）**：

| 对比 | 磨削（Grinding） | 研磨（Lapping） |
|------|-----------------|----------------|
| 磨料形式 | 固定磨料砂轮 | 游离磨料研磨液或固定磨料 |
| 接触运动 | 砂轮-晶圆受控接触进给 | 研磨盘-晶圆持续接触 |
| 300mm 晶圆主流 | **单片式固定磨料背磨**（主流） | 曾较常用（200mm 晶圆） |

大尺寸晶圆对厚度均匀性、翘曲、损伤和洁净度控制要求更高，单片式磨削设备在成本、耗材和过程控制方面更具优势。

**背磨工艺参数**：

| 参数 | 影响 |
|------|------|
| **磨粒尺寸** | 自锐性、表面发热、砂轮磨损、表面粗糙度 |
| **砂轮转速** | 粗糙度、翘曲、砂轮磨损、磨削热 |
| **进给速度** | 产能、粗糙度、翘曲、发热、砂轮磨损 |

三者共同决定：材料去除率、TTV、表面粗糙度、亚表面损伤深度、残余应力和晶圆翘曲。

### 2.4. 化学及电化学减薄方法

**电化学腐蚀**：
利用 p 型硅和 n 型硅在特定晶向及腐蚀液中的不同极化行为实现选择性刻蚀。通过恒电位仪控制，可使腐蚀在 PN 结处自动停止。

| 优点 | 缺点 |
|------|------|
| 可获得较薄硅层 | 通常需要 PN 结或刻蚀停止结构 |
| 局部厚度均匀性较高 | 工艺适用范围较窄 |
| 适合选择性停止场景 | 全片 TTV 精确控制较难 |

**湿法刻蚀（HNA 混酸体系）**：

HNA = **HF**（氢氟酸）+ **HNO₃**（硝酸）+ **CH₃COOH**（乙酸）

HNO₃（氧化剂）：将 Si 氧化为 SiO₂
HF：溶解 SiO₂，生成可溶性氟硅酸盐
CH₃COOH（缓冲/稀释）：调节反应速率、黏度和润湿性

| 优点 | 缺点 |
|------|------|
| 去除速率高（5–40 μm/min） | 需要保护晶圆正面器件层 |
| 可去除磨削损伤层、降低残余应力 | 刻蚀速率和 TTV 控制较难 |
| 优化条件下可获得低粗糙度表面 | 安全、环保和废液处理要求高 |

### 2.5. 干法减薄

**等离子体辅助化学刻蚀**（非接触式表面修整）：
- 先测量晶圆局部厚度/平坦度，系统根据表面高低差调节 SF₆ 等离子体刻蚀时间和扫描速度
- SF₆ 产生的 F 自由基与 Si 反应生成挥发性 SiFₓ

| 优点 | 缺点 |
|------|------|
| 非接触式，机械损伤小 | 设备成本较高 |
| 可实现较高表面均匀性和纳米级修整精度 | 可能存在局部温升和化学污染风险 |
| 可去除磨削损伤层、降低残余应力 | 去除速率与均匀性依赖设备和扫描控制 |

**ADPE（常压下游等离子体刻蚀，Ar/CF₄）**：
- 降低直接离子轰击损伤
- 保持较低晶圆温度
- 实现非接触式损伤去除和应力释放
- 适用于背磨/研磨/CMP 后的**补充性表面修整**，而非取代高去除率的机械背磨

## 3. 化学机械抛光（CMP）

### 3.1. CMP 原理

CMP = 化学反应与机械磨耗的**协同**作用。

单纯化学刻蚀 → 对表面高低差缺乏选择性，难以实现有效平坦化
单纯机械磨削 → 可削平表面，但易引入较大的表面和亚表面损伤
**CMP** → 化学软化/反应 + 机械去除，在低损伤下获得低粗糙度表面

**优点**：表面粗糙度低，损伤较小
**缺点**：去除速率较低，加工压力和工艺成本较高

### 3.2. CMP 设备结构及工艺参数

- 浆料（Slurry）：含磨粒的胶体体系，具有化学腐蚀/反应作用
- 抛光垫（Pad）：直径通常大于晶圆直径
- 抛光头：对晶圆施加压力，塑料保持环限位固定
- 运动方式：抛光头与抛光垫绕不同轴心旋转 → 相对运动

**关键性能参数**：
Polish rate（抛光/去除速率）
Planarity（平坦化能力）
Selectivity（材料选择性）
Thickness uniformity（厚度均匀性）
Post-CMP ease of cleaning（CMP 后清洗难易程度）

### 3.3. CMP 抛光垫

**材料**：聚氨酯基复合材料或聚氨酯浸渍毡材料

**微凸体**：抛光垫表面由大量微凸体组成，实际参与抛光的是与晶圆发生接触的有效微凸体。微凸体高度分布、密度和变形行为决定了局部压力分布、浆料输运、磨粒作用和去除均匀性。

| 硬度 | 特点 |
|------|------|
| **较硬抛光垫** | 利于局部平坦化和 die 内均匀性 |
| **较软抛光垫** | 利于全片接触和 wafer 内均匀性 |

**CMP 界面的接触状态**：

| 模式 | 条件 | 磨损机制 |
|------|------|----------|
| **流体动力接触** | 高速度、低压力 | 浆料液膜作用明显，三体磨损为主 |
| **固-固接触** | 高压力、低速度 | 微凸体与晶圆接触增强，二体磨损为主 |

实际 CMP 过程通常处于**混合接触状态**。

### 3.4. CMP 浆料（Slurry）

**主要组成**：
水、磨粒纳米颗粒（SiO₂ / CeO₂ / Al₂O₃）、酸/碱及缓冲剂、氧化剂、腐蚀抑制剂、分散剂/抗团聚剂、表面活性剂

**主要功能**：
- 调节化学反应和机械磨耗
- 控制材料去除速率与选择性
- 防止划伤、腐蚀、颗粒残留等缺陷
- 带走反应副产物和磨屑

### 3.5. CMP 去除速率模型

**Preston 模型**：

$R = Kp · P · V$

其中 R 为材料去除速率，P 为加载压力，V 为晶圆与抛光垫之间的相对速度，Kp 为 Preston 系数（综合反映材料、浆料、抛光垫、表面状态和设备条件）。

实际 CMP 过程受浆料流动、抛光垫变形、磨粒接触和化学反应控制，常采用**经验修正**形式：

$R = Kp · P^m · V^n$

## 4. TSV 相关的减薄、CMP 与背面露出

### 4.1. TSV 正面 CMP

为了 TSV 孔的无空洞填充，电镀通常需要轻微过镀，会在晶圆正面留下 Cu 过镀层。正面 CMP 用于去除这些 Cu 过镀层及表面凹凸不平区域。

**主要要求**：
1. 较高的抛光/去除速率
2. 表面无凹陷缺陷
3. 表面平坦且无金属残留

**典型缺陷**：宽结构上 CMP 容易产生 **concave（凹陷）**。

### 4.2. TSV 背面 CMP（TSV Reveal）

晶圆背面减薄至接近 TSV 底部后，需要进一步精确去除少量 Si 以露出 TSV 中的 Cu。随后通过背面 CMP 对 Si、Cu 及介质层进行平坦化，并可通过少量 Si 回蚀调节 Cu 露出高度。

**去除深度控制**：
去除不足 → 介质层或残余 Si 覆盖 TSV → Cu 露出不完全
去除过度 → Cu 过度凸出、dishing 或背面形貌失控

**背面 CMP 对浆料的 7 项要求**：
1. 较高的 Si 去除速率
2. Si、Cu 与介质层去除速率合理匹配
3. 避免过高选择性导致台阶、dishing 或残留
4. 减小宽结构区域的 dishing
5. Si 和 Cu 表面粗糙度低
6. 划伤、颗粒和金属残留受控
7. 表面质量必须满足背面 RDL/堆叠互连需求（虽低于 CMOS 金属化标准）

### 4.3. 背面 Cu 露出工艺路线选择

| 路线 | 基本思路 | 适用特点 | 主要风险 |
|------|----------|----------|----------|
| **背磨/CMP 直接露出** | 在背磨或 CMP 中直接露出 Cu | 无源 interposer、低密度 TSV | Cu 拖尾、Cu 污染、表面残留 |
| **干法/湿法 Si 回蚀后露出** | 先刻蚀 Si 使 Cu 凸出或接近露出 | 逻辑芯片、存储芯片等对污染敏感的结构 | 回蚀深度差异→TSV 未完全露出、Cu 露出高度不均 |
| **介质覆盖 + CMP 再露出** | Si 回蚀后沉积钝化介质，再通过 CMP 打开 Cu | 需精确控制 Cu 露出高度 | 工艺步骤增加、成本提高 |

## 5. 减薄后的残余应力、翘曲与破片风险

### 5.1. 翘曲的主要原因

晶圆减薄后弯曲刚度显著降低——即使较小的膜层应力、热失配应力或背磨残余应力，也可能引起明显翘曲，影响搬运、光刻对焦、键合对准和解键合良率。

**薄膜热失配**（SiO₂/Si 案例）：
- PECVD 在 400°C 沉积 ~900nm SiO₂ 薄膜
- 冷却至室温时因 CTE 差异产生热失配应力
- CTE(SiO₂) ≈ 0.56×10⁻⁶/K vs CTE(Si) ≈ 2.33×10⁻⁶/K
- 减薄后晶圆弯曲刚度降低 → 对膜层应力和热失配应力更加敏感

**背磨损伤导致的负翘曲**：

背面磨削中金刚石磨粒与硅表面发生强机械作用 → 延性犁削、塑性变形和脆性断裂 → 背面损伤层（表面沟槽、非晶/塑性变形区、亚表面微裂纹、残余应力）。

背面损伤层通常表现为**较高压应力**
正面有源器件层/薄膜层可能表现为**拉应力**
上下表面应力不平衡 → 晶圆整体翘曲（负向翘曲）
晶圆越薄，对背磨残余应力越敏感

### 5.2. 翘曲与残余应力测量

**Stoney 方程**（经典）：

 $σ_f = (E_s · h_s² · κ) / (6h_f · (1-ν_s))$

其中 $σ_f$ 为薄膜应力，$E_s$ 为衬底杨氏模量，$h_s$ 为衬底厚度，$h_f$ 为薄膜厚度，$κ$ 为晶圆曲率，$ν_s$ 为衬底泊松比。

对背磨损伤层，可将其近似视为等效应力层，通过曲率变化估算残余应力水平。

### 5.3. 超薄晶圆破裂形式

| 失效形式 | 说明 |
|----------|------|
| **缺口（Notch）** | 边缘局部缺陷，易成为裂纹源 |
| **裂纹（Crack）** | 可在搬运或热/机械载荷下扩展 |
| **崩边（Chipping）** | 边缘碎裂，常由夹持、碰撞或切割引起 |

## 6. 薄晶圆拿持方法

### 6.1. 拿持方案选择依据

薄晶圆拿持方案的选择是在支撑能力、工艺兼容性、污染控制、解键合风险和成本之间取得平衡。

| 判断问题 | 优先方案 | 核心理由 |
|----------|----------|----------|
| 后续是否有背面光刻/沉积/刻蚀/RDL? | **临时键合到刚性载片** | 提供全片支撑、平整度和工艺稳定性 |
| 只是为了降低搬运破片？ | **TAIKO / 边缘支撑 / 胶带支撑** | 提高搬运稳定性，流程相对简单 |
| 希望避免整片超薄晶圆搬运？ | **DBG（先切割后减薄）** | 降低整片薄片搬运风险 |
| 后续有较高热预算？ | 高温稳定 TB/DB 材料或无胶支撑 | 防止胶层流动、分解和残留 |
| 对残胶、颗粒极敏感？ | 低残留释放层 / 激光解键合 / 无中间层支撑 | 降低界面污染和清洗负担 |
| 需要兼顾复杂背面工艺和极薄厚度？ | **临时键合/解键合** | 综合支撑能力最强，但成本和解键合风险更高 |

### 6.2. 传送与取片中的破片风险

- 超薄晶圆在晶圆盒中碰撞 → 边缘缺口和裂纹 → 传送设备需缓冲和限位设计
- 水平夹取 → 边缘集中受力 → 崩边风险
- **竖直夹取 / 真空吸附 / 支撑式搬运** → 降低破片率
- 晶圆盒适当倾斜放置 + 按顺序取片 → 减少碰撞

### 6.3. TAIKO 工艺（"太鼓"工艺）

仅减薄晶圆**中心区域**，保留周边厚边（类似鼓边），提高整体刚度。

**核心特点**：
- 中心区域减薄满足封装/背面工艺需求
- 边缘厚环提高搬运和传送稳定性
- 降低破片、崩边和翘曲风险
- 适合以搬运可靠性为主要问题的场景
- 对复杂背面工艺，仍需评估与临时键合/载片支撑的兼容性

### 6.4. DBG（Dicing Before Grinding，先切割后减薄）

**流程**：晶圆仍具较高机械强度时先进行半切割/预切割 → 背面磨削减薄 → 减薄到预切槽位置时芯片分离

**主要优势**：
- 减少整片超薄晶圆搬运需求
- 切割发生在晶圆较厚阶段 → 降低崩边和裂纹扩展
- 改善芯片边缘质量，提高分片良率
- 不必因超薄而易碎显著降低切割速度

**DBG 后处理**（提高芯片强度）：
- **干法抛光**：不使用酸性混合液/抛光浆料/水，降低耗材成本和湿化学废液；去除背磨损伤层、释放残余应力；显著提高芯片断裂强度；表面光洁度和加工速率接近部分 CMP
- **干法刻蚀**：去除芯片侧壁切割损伤；降低微裂纹扩展风险；进一步提高芯片三点弯曲强度

### 6.5. 临时键合/解键合（TB/DB）

**基本思想**：在背面减薄和后续工艺前，将器件晶圆临时固定到刚性载片上；背面加工完成后通过受控方式释放。

**TB/DB 完整流程**：
```
键合前准备（边缘修整、颗粒清洗、表面处理、载片处理和临时胶层涂覆）
    → 临时键合（将器件晶圆固定到刚性载片，提供平整度和机械支撑）
    → 背面加工（背磨减薄、损伤去除、清洗、背面钝化和 TSV 露出）
    → 解键合与清洗（释放器件晶圆，去除残胶和颗粒，载片回收）
    → 后续集成（薄晶圆贴膜切割、清洗，进入三维堆叠）
```

**TB/DB 材料组成**：

| 组成部分 | 常见材料 | 主要作用 | 关键要求 |
|----------|----------|----------|----------|
| **刚性载片** | Si、玻璃、硼硅玻璃、蓝宝石 | 提供机械支撑和平整基准 | 刚度高、热稳定、化学稳定、平整度好、可重复使用 |
| **键合层** | 热塑性材料、紫外固化材料、层压胶、金属键合层 | 临时粘结器件晶圆与载片 | 粘结强度、厚度均匀性、热稳定性、真空兼容性、低挥发 |
| **释放层（可选）** | 激光吸收层、牺牲层、可溶解层 | 实现受控解键合 | 释放窗口稳定、残留少、工艺复杂度和成本可接受 |

**解键合方式比较**：

| 方式 | 优点 | 主要限制 |
|------|------|----------|
| **激光释放** | 速度快、室温释放、机械应力低 | 需透明载片和激光吸收/释放层，设备成本高 |
| **溶剂释放** | 过程温和、设备相对简单 | 时间长、清洗压力大、残胶风险高 |
| **热滑移释放** | 适合热塑性材料，工艺成熟 | 需要加热，可能受热预算限制 |
| **机械剥离/抬离释放** | 流程相对简单 | 剥离应力大，薄晶圆崩边和裂片风险高 |

**解键合常见问题**：

| 问题 | 主要原因 | 后果 |
|------|----------|------|
| **崩边/裂片** | 边缘应力集中、解键合力过大 | 破片、良率下降 |
| **RDL/UBM 层脱落** | 金属层附着力不足或剥离应力过大 | 背面互连失效 |
| **残胶污染** | 键合层释放不完全、清洗不足 | 影响键合、电镀、焊接或可靠性 |
| **颗粒污染** | 解键合和清洗过程产生颗粒 | 引起缺陷、短路或界面空隙 |

**TB/DB 材料、工艺与缺陷控制**：

| 风险来源 | 典型触发环节 | 可能缺陷 | 控制要点 |
|----------|-------------|----------|----------|
| 粘结强度不足 | 背磨、CMP、清洗 | slip、局部脱粘、晶圆偏移 | 控制胶层厚度、键合压力和温度均匀性 |
| 粘结强度过高 | 解键合、剥离释放 | 崩边、裂纹、RDL/UBM 脱落 | 优化释放层，降低解键合应力 |
| 胶层不均/颗粒集中 | 键合与背面加工 | 空隙、TTV 误差、局部应力集中 | 加强清洗、涂布均匀性和脱泡控制 |
| 热稳定性/放气不足 | 高温或真空背面工艺 | 胶层流动、空洞、污染、膜层缺陷 | 匹配热预算，选用低放气材料并充分预烘 |
| 残胶难清洗 | 解键合后清洗 | RDL/UBM 污染、键合不良、颗粒残留 | 低残留材料、释放层与清洗工艺协同优化 |

**缺陷与控制目标总结**：

```
背磨压力 → 脱粘          ← 控制：支撑稳定
高温     → 空洞 + 热稳定  ← 控制：低应力释放
真空     → 崩边 + 放气
解键合   → 金属层脱落 + 残胶 ← 控制：低残留污染
清洗     → 污染
```

## 本讲核心要点

1. **三维集成减薄将晶圆从 725~775μm 减至 <100μm**（下限 20~30μm），比传统封装薄得多
2. **减薄采用组合路线**：粗磨→精磨→CMP/湿法刻蚀/干法/ADPE 去除损伤层
3. **CMP 的 Preston 模型** R = Kp · P^m · V^n，通过浆料（磨粒+氧化剂+抑制剂）和抛光垫（硬/软）的配合实现平坦化
4. **TSV 背面露出三种路线**：直接露出、Si 回蚀后露出、介质覆盖+CMP 再露出
5. **翘曲源于薄膜热失配和背磨损伤**——Stoney 方程 σ_f = (E_s·h_s²·κ)/(6h_f·(1-ν_s)) 用于估算应力
6. **四大薄晶圆拿持方案**：TAIKO（厚边环）、DBG（先切后减）、TB/DB（临时键合）、传送优化
7. **TB/DB 是支撑复杂背面工艺的核心技术**，四种解键合方式（激光/溶剂/热滑移/机械）各有优劣，解键合环节最容易影响良率
