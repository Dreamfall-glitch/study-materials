# 01-绪论与课程介绍

## 1. 集成电路产业发展回顾

### 1.1. 微电子学发展史：从量子论到集成电路

微电子的诞生经历了从**物理理论**到**器件发明**再到**集成电路**的渐进过程：

```
1900年 ──── 普朗克创立量子理论
    │
1928年 ──── 威尔逊提出固体能带理论（导体/半导体/绝缘体）
    │
1939年 ──── 肖特基、莫特、达维多夫提出"扩散理论"
    │
1946年 ──── 贝尔实验室成立固体物理学研究小组
    │
1947年 ──── 布拉顿和巴丁：发明锗三极管（点接触晶体管）
    │         肖克莱提出PN结型晶体管理论
    │
1950年 ──── 肖克莱等3人：锗NPN三极管（晶体管）
    │
1958年 ──── TI的基尔比提出集成电路的设想
    │
1959年 ──── TI申请第一个IC专利（2月6日）
    │         仙童的诺伊斯：硅平面工艺的集成电路
    │
    ▼
      ┌─────────────────────┐
      │  集成电路（IC）诞生   │
      └─────────────────────┘
```

### 1.2. 集成电路的定义

**集成电路（Integrated Circuit, IC）**：把一定数量的常用电子元件（电阻、电容、晶体管等）以及这些元件之间的连线，通过半导体工艺集成在一起的具有特定功能的电路。

关键特征：**尺寸小**，**集成度高**，**功耗低**，**性能优**
### 2.3. 摩尔定律与挑战

**摩尔定律（Moore's Law）**：集成电路上可容纳的晶体管数量大约每两年翻一番，性能也随之提升。

然而，随着工艺节点的不断微缩，摩尔定律正面临多重技术挑战：

#### 挑战一：缩微极限（物理极限）
- 光刻精度
- 短沟道效应
- 先进封装（3D packaging）成为延续摩尔定律的关键路径之一

#### 挑战二：速度极限
- 沟道迁移率
- 互联速度

#### 挑战三：功耗极限
- 功耗密度
- 能耗效率
- 解决方案：分布式架构、低功耗设计技术、**特殊封装和制造技术**


#### 产业发展路线

```
IC技术微缩              晶圆尺寸放大
┌─────────┐            ┌─────────┐
│ 缩小pitch│            │ 增大直径 │
│ 缩小栅长 │            │ 8"→12"  │
└────┬────┘            └────┬────┘
     ▼                      ▼
挑战：Litho(EUV)          挑战：重投资
     性能损失(寄生效应)         ROI验证
     功耗(泄漏电流)
     3D封装
```

## 3. 电子封装概述

### 3.1. 封装在半导体行业中的地位

**设计、制造和封装是集成电路产业发展的三大支柱。**
- 封装是芯片实用化的起点
- 在后摩尔时代，**先进封装技术成为新赛道**
- 设计、制造与封装正走向深度融合

> 带**先进**两个字的，一般都指的封装领域

### 3.2. 封装的基本定义

**封装（Package/Assembly）**：

- 将半导体（集成电路）芯片包封在某一种标准组件中的方法、结构、工艺。

- 通过这种包封，半导体芯片可以安装在PCB（系统）中实现应用。

- 封装是**连接芯片与系统的桥梁**。

### 3.3. 封装的作用

封装在芯片和系统之间扮演着多重角色：

| 作用 | 说明 |
|------|------|
| **保护芯片** | 不受外界环境影响，也不影响外环境（其他电路部分） |
| **互连（信号、电源）** | 功能保持（电、热、环境交互等） |
| **兼容** | 尺寸兼容、工艺方便、材料匹配（CTE、机械性质等） |
| **散热** | 导出芯片工作产生的热量 |
| **系统集成/功能融合** | 多功能（逻辑、射频、传感、存储、电源管理）；高性能（有源/无源埋入、interposer）；小型化（板级系统、子系统） |

直观来说，封装承担了以下核心任务：
- **信号传输**（互连）
- **电源分配**（互连）
- **机械支撑**（可靠性）
- **环境保护**（可靠性）
- **散热**（可靠性）
- **信号扇出**（密度）
- **系统集成**（功能）

### 3.4. 封装是一门多学科交叉工程

```
封装涉及的学科领域：

    │  微电子/电子技术               │
    │  - 系统设计                   │
    │  - 有源/无源器件              │
    │  - 电源与功率管理             │

    ├─────────────────────────────┤
    │  材料                        │
    │  - 封装体、基板、散热片        │
    │  - 互连材料（键合引线、焊料）   │
    │  - 材料交互作用、腐蚀、疲劳     │

    │  热学/力学                    │
```

## 4. 封装分类与技术演进

### 4.1. 封装的基本分类

**按组装方式：**
1. **通孔插装式（PTH, Pin Through Hole）**：引脚穿过PCB孔洞焊接

2. **表面安装式（SMT, Surface Mount Technology）**：器件贴装在PCB表面


**按气密性：**
- **气密封装**：金属封装、陶瓷封装（封装不与芯片表面接触，即"空封"）
- **非气密/准气密封装**：塑料封装（"实封"，封装材料与芯片表面接触）

>水汽的危害：
>器件漏电流增大、腐蚀焊盘及引线

### 4.2. 封装技术演进的四个阶段

```
第一阶段 (1970年前)
    ↓ DIP（双列直插封装）

第二阶段 (1970-1990)
    ↓ SOP、SOJ、PLCC、QFP、PGA

第三阶段 (1990-2000)
    ↓ BGA、CSP、Flip Chip

第四阶段 (2000至今)
    ↓ WLP、TSV、3D堆叠、SiP
```

**四个阶段详细解读：**

| 阶段 | 时间 | 代表技术 | 核心特征 |
|------|------|----------|----------|
| 第一阶段 | 1970年前 | **DIP** (Dual-in-line Package) | 直插型封装，引脚数一般少于50 |
| 第二阶段 | 1970-1990 | **SOP、SOJ、PLCC、QFP、PGA** | 表面贴装技术崛起 |
| 第三阶段 | 1990-2000 | **BGA、CSP、Flip Chip** | 球栅阵列、芯片尺寸封装、倒装芯片兴起 |
| 第四阶段 | 2000至今 | **WLP、TSV、3D Stacking、SiP** | 从二维向三维发展，系统封装涌现 |

### 4.3. 封装技术的发展趋势

| 趋势维度 | 从 → 到 |
|----------|---------|
| 与PCB互连 | PTH（通孔插装）→ **SMT**（表面安装） |
| 封装工艺 | 单芯片封装 → **Wafer Level Packaging**（晶圆级封装） |
| 芯片互连 | Wire Bonding（引线键合）→ **Flip Chip**（倒装芯片）→ **TSV**（硅通孔） |
| 封装密度 | 封装效率（Sd/Sp）不断提高，高度不断降低，引线节距不断缩小 |
| 引线布置 | 封装两侧 → 四周 → **底面** |
| 空间维度 | 二维 → **三维** |

### 4.4. 常见封装形式

| 缩写 | 全称 | 说明 |
|------|------|------|
| **TO** | Transistor Outline | 晶体管外形封装，如TO-3、TO-5、TO-220 |
| **DIP** | Dual-in-line Package | 双列直插封装（<50 pins） |
| **SOP** | Small Outline Package | 小外形封装 |
| **QFP** | Quad Flat Package | 四边扁平封装 |
| **LCC** | Leadless Chip Carrier | 无引线芯片载体 |
| **QFN** | Quad Flat No-leads Package | 四边扁平无引线封装 |
| **PGA** | Pin-grid Array | 引脚阵列封装 |
| **BGA** | Ball Grid Array | 球栅阵列封装（WBBGA/FCBGA） |

### 4.5. 先进封装 vs 传统封装

**为什么要发展先进封装？**
- 摩尔定律延续受物理极限、巨额资金投入等多重压力
- 片上系统（SoC）面临巨大挑战，需要另辟蹊径进行系统集成
- 国际半导体技术发展路线图（ITRS）和异质集成国际路线图（HIR）都强调了先进封装的重要性

### 4.6. 先进封装四要素

先进封装的核心技术可以归纳为四个要素：

```
    先进封装四要素
  ┌─────┬─────┬─────┬─────┐
  │Bump │ RDL │ WLP │ TSV │
  └──┬──┴──┬──┴──┬──┴──┬──┘
     │     │     │     │
     ▼     ▼     ▼     ▼
  凸点  重分布  晶圆级 硅通孔
  (互连) (布线) (封装) (垂直互连)
```

1. **Bump（凸点）**：芯片与基板之间的微小焊料凸点，用于电气互连
2. **RDL（Redistribution Layer，重分布层）**：将芯片周边的I/O焊盘重新分布到更宽松的位置
3. **WLP（Wafer Level Packaging，晶圆级封装）**：在晶圆上完成全部封装工艺后再划片
4. **TSV（Through Silicon Via，硅通孔）**：贯穿硅衬底的垂直互连通道

## 5. 前沿封装技术

### 5.1. 扇出型封装（Fan-Out Packaging）

- TSMC的扇出技术（InFO）成为苹果处理器A10-A12芯片的封装解决方案，带动了全球研发热潮
- 通过**重构晶圆**，在晶圆级实现多芯片系统集成
- 将从单芯片二维封装发展到多芯片三维集成

### 5.2. 2.5D/3D封装

- **2.5D封装**：通过硅中介层（interposer）和TSV实现芯片间的高密度互连，芯片并排放置在interposer上
- **3D封装**：芯片垂直堆叠，通过TSV直接互连

### 5.3. 混合键合技术（Hybrid Bonding）

- 铜-铜直接键合，无需焊料凸点
- 实现更细间距、更高密度的互连

### 5.4. Chiplet技术与异质集成

随着摩尔定律放缓，先进封装正成为将多个裸片集成到单个封装中的关键解决方案。**Chiplet（芯粒/小芯片）**方法允许：
- 将成熟制程节点与先进制程节点结合起来
- 在紧凑布局内实现具成本效益的多芯片集成
- 与传统封装相比，性能更为优越

### 5.5. 光电共封装技术（Co-Packaged Optics, CPO）

- 将网络交换芯片和光模块共同装配在同一个插槽上
- 缩短交换芯片和光引擎之间的距离
- 可减少尺寸、提高效率、降低功耗
- 两种主要方式：Co-packaged transceivers (CPT) 和 Co-packaged active optical cables (CP-AOCs)

### 5.6. 面板级封装（Panel Level Packaging, PLP）

- 在更大尺寸的矩形面板上进行封装，而非圆形晶圆
- 提高材料利用率，降低单位成本

## 7. 本讲小结

1. **一代器件一代封装**——封装技术伴随着芯片技术的发展不断演进
2. 小型化、多功能的复杂芯片（Chiplet）与系统集成是封装的主要驱动力
3. 在后摩尔时代，**先进封装技术成为系统集成的关键路径**
4. 先进封装加速了产业的垂直整合，倒装、2.5D/3D、扇出封装、混合键合技术发展迅速
5. 封装作为集成电路产业的核心环节，符合我国国情、技术趋势以及行业发展需求
6. 封装是一门综合工程技术，涉及多个学科
7. **封装与应用结合，选择最"适合"的封装**
