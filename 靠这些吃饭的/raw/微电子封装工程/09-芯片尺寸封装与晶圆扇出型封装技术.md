# 09-芯片尺寸封装与晶圆扇出型封装技术

## 知识地图

```
封装形式演进：
Lead Frame → BGA → Fan-in WLCSP → Fan-out WLP
  ↓            ↓         ↓              ↓
引脚框架    焊球阵列   芯片大小      可大于芯片
低密度      中密度    高密度(I/O受限)   超高密度
```

**本讲核心**：从CSP（封装≈芯片大小）到WLP（晶圆上完成封装），再到Fan-out（通过重构晶圆突破I/O限制）。

---

## 1. 封装的主要变化趋势

**高密度封装**成为封装的主要追求目标

**驱动力**：芯片I/O数量持续增长，pad pitch不断缩小，传统封装形式难以满足高密度、高性能需求。

---

## 2. CSP（芯片尺寸封装）

### 2.1. CSP的基本定义

**CSP（Chip Scale/Size Package，芯片尺寸封装）**：封装面积不超过芯片面积1.2倍的封装。

**EIAJ/JEDEC定义**：
- Package Size < 1.2 × Chip Size
- Package Size < Chip Size + 1mm
- Package Thickness < 1mm
- I/O Area Array Pitch ≤ 1mm（1mm, 0.8/0.75mm, 0.5mm）

**CSP分类**：
- **基本结构**：柔性衬底、刚性衬底、引线框架、**圆片级**
- **基板材料**：聚亚酰胺柔性基板、FR4、BT树脂、陶瓷
- **互连结构**：金丝键合、TAB键合、共晶倒装焊、金凸点热压

| 类型      | 主要结构                | 制造逻辑            | 主要优势            | 主要限制              |
| ------- | ------------------- | --------------- | --------------- | ----------------- |
| QFN/DFN | 引线框架、模封料、底部端子、裸露焊盘  | 先切割或条带加工，再塑封与切割 | 成本低、热焊盘可直接接 PCB | I/O 主要在外围，焊点可视性有限 |
| BGA-CSP | 小型有机/陶瓷基板、一级互连、底部焊球 | 基板完成 I/O 重新组织   | I/O 阵列化能力强于 QFN | 尺寸和厚度高于 WLCSP     |
| WLCSP   | 芯片表面介质、RDL、UBM、焊球   | 晶圆级完成主要封装步骤     | 最接近裸片尺寸，互连短     | 板级应变直接作用于焊点       |

### 2.2. QFN封装

**QFN（Quad Flat Nonleaded Package，四边无引线扁平封装）**：在类似引线框架的金属载体上制作，最终不含引线框架部件。

也被称为：LPCC（无引线塑料片式载体）、MLF（微引线框架）、MLP、SON

**关键参数**：
- 节距：0.4mm、0.5mm、0.6mm或0.8mm
- I/O端：周边排布

**QFN的典型特点**：

| 特点        | 技术说明                                                           |
| --------- | -------------------------------------------------------------- |
| **DAP裸露** | 芯片粘接区（Die Attach Pad）底部暴露，与接触焊盘在同一平面                           |
| **直接散热**  | DAP在SMT回流中直接与PCB导热焊盘焊接互连；PCB导热焊盘通过阵列化金属化过孔与内层金属平面相连，形成**散热热沉** |
| **优异电性能** | 无鸥翼状引线，导电路径短，自感系数和布线电阻低，**广泛用于RF应用**                           |

### 2.3. BGA-CSP封装

BGA-CSP 则通过小型基板组织 I/O。芯片可通过引线键合或倒装互连接入基板，基板底部以焊球阵列连接 PCB。

- 与 QFN 相比，BGA-CSP 牺牲一定厚度和封装面积，换取更灵活的 I/O 阵列和布线能力。

- 与 WLCSP 相比，它通过基板提供了一定热机械缓冲，但成本和结构复杂度更高。

**Chip Array BGA（Amkor）**
刚性基板（有机层压板或厚膜陶瓷板），一级互连为WB，二级互连为BGA焊球或无引线平面焊盘。封装尺寸比芯片宽1.5mm。

**Mini-BGA（IBM，1995）**
用于高速开关器件，1521个端子。采用C4倒装芯片技术，导热胶+盖板散热，多层Al₂O₃基板Mo/Mn金属化。焊球φ0.25mm、节距0.5mm。

## 3. WLP（晶圆级封装）

### 3.1. 传统封装 vs WLP

| 流程 | 传统封装 | 晶圆级封装（WLP） |
|------|---------|-----------------|
| 流程 | 圆片测试 → 划片 → 逐个封装 → 成品 | **在圆片上做封装**(RDL/凸点) → 划片 → 成品 |
| 效率 | 逐个芯片 | **整片批量制造** |
| 成本 | 与芯片数线性 | **芯片数越多，成本越低** |

### 3.2. WLP的分类

```
WLP
├── Fan-in WLP（扇入型）= WLCSP（晶圆芯片尺寸封装）
│   封装尺寸 ≈ 芯片尺寸
│   焊球/凸点分布在芯片边界内
│   I/O数量受芯片面积限制
│
└── Fan-out WLP（扇出型）= FOWLP
    封装尺寸 > 芯片尺寸
    通过晶圆重构将芯片重新埋置
    焊球/凸点可分布到芯片外部区域
```

### 3.3. WLP的五大优势

1. **轻、薄、短、小**
2. **工艺设备成熟，工艺兼容性好**
3. **以晶圆形式批量生产**，加工效率高
4. **芯片设计和封装设计可以统一考虑**，提高设计效率
5. **成本与晶圆上的芯片数成反比**——芯片越多，封装成本越低

### 3.4. WLP发展趋势

| 方向 | 内容 | 适用 |
|------|------|------|
| 减少布线层数 | 4M→3M→2M层，降低工艺成本 | 低I/O、小芯片 |
| 新材料导入 | 焊球：SnPb→SAC→Cu Pillar | 高I/O、大芯片 |
| | 介质：BCB→PBO→PI | |

## 4. WLCSP（Fan-in WLP）详细工艺

### 4.1. 结构组成

从结构上讲，WLCSP包括：
- **Silicon substrate**（硅衬底）+ **Al pad**（铝焊盘）
- **Re-passivation layer**（再钝化层/Polymer层）——加强钝化层、应力缓冲
- **Cu RDL**（重布线层）——重新定位焊区
- **2nd Polymer layer**（第二聚合物层）——平坦化、保护RDL
- **UBM**（凸点下金属化层）——阻止焊料扩散
- **Solder Ball / Cu Pillar**（焊球/铜柱）

封装尺寸一般不大于芯片的120%（即超出芯片不超过20%）

### 4.2. WLCSP完整14步工艺流程

**Step 1: Incoming Clean（来料清洗）**
Descum（去胶渣）+ Solvent Clean（IPA + Acetone + DI SRD）→ 100% AOI检测

**Step 2: PBO(PI) 1 Processing（第一层聚酰亚胺）**
PBO(PI)涂布（光敏型，需选型防Cu RDL腐蚀）→ Soft Bake → Exposure → Develop → Cure (O₂ Descum)
监控点：膜厚、Via开口、Via内残胶

**Step 3: RDL Seed Layer Deposition（RDL种子层沉积）**
PVD（物理气相沉积）：
- TiW ~1000Å（粘附层+保护Fuse结构）
- Cu ~3000Å（导电层）
Plasma Clean

**Step 4: Copper RDL Pattern（RDL光刻图形）**
PR涂布(正胶~11μm) → EBR（边缘去胶，为电镀准备）→ Soft Bake → Exposure → Develop → Descum(O₂)

**Step 5: Copper RDL Plating → PR Strip → UBM Etch（RDL电镀）**
Descum(镀前) → Cu Plating → Acetic Clean(防Cu氧化) → PR Strip → Descum(O₂防PR残留)
→ Cu Etch（厚度测量3~7μm）→ TiW Etch → Descum(CF₄) → Leakage测量

**Step 6: PBO(PI) 2 Processing（第二层聚酰亚胺）**
与PBO(PI) 1工艺相同

**Step 7: UBM Seed Layer Deposition（UBM种子层）**
与RDL种子层沉积类似，粘附层选择Ti或TiW

**Step 8: UBM Cap Define（UBM图形定义）**
与RDL光刻类似

**Step 9: UBM Cap Plating（UBM电镀）**
Cu Plating

**Step 10: PR Strip & UBM Etch（去胶+刻蚀）**
Descum(O₂ strip后) → Descum(CF₄ UBM etch后) — 去除PBO(PI)中的原子俘获

**Step 11: Barrier Layer & Oxidation Prevention（阻挡层+防氧化）**
- **Ni层 ~2μm**：阻挡Sn扩散到Cu层；回流后形成IMC
- **Au层 ~0.5μm**：防止Ni氧化；回流时扩散进入焊料

**Step 12: Flux Place（助焊剂涂布）**
使用Stencil丝网印刷助焊剂

**Step 13: Ball Placement（植球）**
Stencil定位 → 放球 → 球径控制（防用错球）
监控点：手动或自动球检（带扫描功能）

**Step 14: Reflow & Flux Clean（回流+清洗）**
Reflow曲线控制 → Hot DI Water清洗(SRD) → 2D & 3D Inspection → Ball Shear测试

### 4.3. WLCSP关键材料

| 材料 | 参数 |
|------|------|
| RDL Cu | 体电阻率~2.1μΩ·cm；3μm厚时薄层电阻~6.1mΩ/□ |
| UBM | Ti/Cu/Ni叠层 |
| 焊料 | SAC396 (Sn3.9%Ag0.6%Cu)*首选、SAC105、Sn37%Pb、Pb5%Sn |

### 4.4. WLCSP常见工艺问题

| 工艺环节        | 常见问题              | 原因                | 解决           |
| ----------- | ----------------- | ----------------- | ------------ |
| **涂胶**      | 箭影、沾污、渗镀          | 图形密集、表面润湿性差       | 优化光刻参数       |
| **曝光**      | 切割道线条、图形错位        | 光刻机跳距差异、Mark识别    | 补充offset值    |
| **显影**      | 显影不净              | 开口率不同，图形高低差异大     | 优化显影参数       |
| **湿法去胶/刻蚀** | 颜色不一致、金属peeling   | IPA残留、Ti层过刻、气液流速  | 改甩干/气体干燥工艺   |
| **电镀**      | 镀不均匀、缺镀、气泡        | 润湿不良、电镀密度不均       | 改善润湿性        |
| **化镀Ni**    | 背面整块镀上Ni          | Pd沉积在Si表面         | 背面贴隔离膜       |
| **薄膜沉积**    | 粘附力差、peeling、Sn渗透 | CTE差异、Ti粘附力       | Ta替代Ti、增加UBM |
| **BGA/回流**  | 焊球毛刺、塌陷、桥接        | Flux活性、曲线设置、助焊剂过多 | 调整回温工艺       |

### 4.5. 焊球/凸点成型方法规格

| 方法 | 最小间距 | 适用 |
|------|---------|------|
| 丝网印刷 | ~150μm | 大间距 |
| 电镀 | ~20μm | 高密度 |
| 植球 | ~100μm | BGA |

## 5. Fan-out WLP（晶圆扇出型封装）

### 5.1. 为什么需要Fan-out？

**Fan-in WLCSP的局限**：焊球/凸点只能分布在芯片边界内，I/O数量受芯片面积制约。当芯片面积小但I/O数量大时，I/O间距过小甚至无法布置。

**Fan-out的核心思想**：通过**晶圆重构**，将芯片重新布置到人工晶圆上，使焊球可以分布到芯片外部区域。

### 5.2. Fan-out的结构特点

- 芯片（Die）
- **塑封层（Mold Compound）**——包埋芯片，形成人工晶圆/面板
- **再布线层（RDL）**——扇出到芯片外部
- UBM焊盘 + BGA焊球
- **封装体不需要基板**（无基板设计）

### 5.3. Fan-out WLP与其他封装形式的对比

| 对比项 | Fan-out vs FC-BGA | Fan-out vs Fan-in WLP |
|--------|------------------|----------------------|
| 成本 | 低成本 | 利用KGD，高良率 |
| 外形 | 薄外形 | — |
| 基板 | **无封装基板** | — |
| 集成 | 多芯片可埋入无源器件 | 易于实现SiP和3D封装 |
| 组装 | 无FC组装、无Flux清洗 | — |
| 可靠性 | **较好的板级可靠性** | — |
| 性能 | 优异电性能、热性能 | — |

### 5.4. 三种Fan-out工艺路线

| 类型                         | 代表厂商     | 技术名称      | 特点                              |
| -------------------------- | -------- | --------- | ------------------------------- |
| **Chip-First (Face-Down)** | Infineon | **eWLB**  | 芯片面朝下贴在临时载片上→模塑→去载片→RDL         |
| **Chip-First (Face-Up)**   | TSMC     | **InFO**  | 芯片面朝上→模塑→RDL→植球；为Apple A10处理器开发 |
| **Chip-Last (RDL-First)**  | Amkor    | **SWIFT** | 先在载片上制作RDL→贴芯片（TSV-less技术）      |

**Chip-First (Face-Down)流程**：
```
1. KGD测试 → 划片
2. 临时金属晶圆载板贴双面胶（Nitto REVALPHA，170°C热释放）
3. KGD面朝下贴在双面胶上
4. Compression Molding模塑（KOZ法或Over-mold法）
5. 热释放去载片
6. 通过薄膜工艺实现RDL再布线
7. 植球
```

**临时键合载片材料选择**：

| 载片材料 | CTE (10⁻⁶/°C) | 杨氏模量(GPa) | 泊松比 |
|----------|---------------|--------------|--------|
| Silicon (0.76mm) | 2.6 | 168 | 0.28 |
| Glass-1 (0.76mm) | 3.2 | 73.6 | 0.3 |
| Glass-2 (1mm) | 7.6 | 69.3 | 0.3 |
| Stainless Steel 420 (1.5mm) | 10.5 | 200 | 0.3 |

**两种Compression Molding方法**：
- **KOZ法（Keep-Out-Zone）**：芯片周围预留无模塑区域
- **Over-mold法**：芯片完全被模塑料覆盖

## 6. via-last TSV技术（一种特殊WLCSP）

### 6.1. 基本原理

在已完成IC制造的晶圆上，从芯片**背面**制造TSV和金属互连，将正面电信号引到背面，制作BGA后通过FC安装到基板上。

**三种TSV工艺时序**：

| 类型         | 制作时机             | 特点              |
| ---------- | ---------------- | --------------- |
| Via-first  | IC制造前            | 高温工艺，互连密度极高     |
| Via-middle | IC制造中（接触孔后/金属化前） | **3D IC主流**     |
| Via-last   | IC制造完成后          | 本讲重点，用于CIS/MEMS |

### 6.2. via-last TSV制造关键工艺

**7个关键工艺站**：

| 工序 | 要求/参数 | 常见问题 |
|------|----------|----------|
| **TSV Litho** | 光刻胶AZ4620；Stepper曝光CD=30μm；**红外对位** | Mark识别困难（减薄后CMP清洗不到位） |
| **TSV Etching** | DRIE刻蚀（Bosch工艺） | 过刻蚀→footing；欠刻蚀→尖角 |
| **PR Strip** | 去胶 | **TSV孔内残胶**→影响Oxide刻蚀质量和电接触 |
| **Oxide Etching 1** | CF₄/C₄F₈气氛刻蚀SiO₂至Al pad露出 | **无法确定刻蚀完成**——无有效检测手段，需增加过刻蚀量 |
| **TSV Cleaning** | SC1兆声清洗（NH₄OH:H₂O₂:H₂O=1:1.5:5, 40°C, 5min, 45W） | Polymer残留→Si-SiO₂/SiO₂-Metal分层 |
| **PECVD SiO₂** | 覆盖率达20%；低温低应力；不peeling不爆硅；表面>4μm | Peeling/爆硅 |
| **Oxide Etching 2** | 既要刻净TSV底部Oxide，又要保持表面足够绝缘层厚度 | Al pad易被刻穿 |
| **PVD Ti/Cu** | 连续覆盖；粘附性好；覆盖率>4.7% | Seed层粘附性差→电镀后金属peeling |
| **Plating** | RDL/TSV Plating或Surface Plating；Conformal电镀>3μm | 电镀缺镀；金属过刻蚀 |
| **Metal Etching** | 干膜RDL制作；过刻蚀量10~15μm | BGA焊盘直径缩小20~30μm |
| **Passivation** | JSR5100 ~10μm | TSV孔上方鼓泡/爆开；边缘Cu层peeling |

**via-last TSV产品实例**：

| 参数 | 产品1 (CIS) | 产品2 (CIS) |
|------|------------|------------|
| 像素 | 120万 | 30万 |
| 封装尺寸 | 3.86×4.66mm | 2.7×2.7mm |
| 厚度 | 0.55mm | 0.55mm |
| TSV结构 | 3:1 | 2:1 |
| BGA数量 | 8×8 | 5×5 |
| TSV数量 | 55 | 30 |
| 良率 | 89% | 94% |
| TSV Diameter | 30μm | 50μm |
| TSV Height | 100μm | 100μm |

**via-last TSV技术能力**：
- 产品类型：MEMS, CIS, FP（指纹芯片）, CT（其他传感器）
- TSV深宽比：≤3:1
- TSV直径：30~60μm
- 线宽/线距：≥30μm/30μm

## 本讲核心要点

1. **CSP**使封装面积接近芯片本身，QFN因DAP散热结构和低寄生效应广泛用于RF
2. **WLP将封装工艺前移到晶圆阶段**，整批制造效率高、成本随芯片数递减
3. **WLCSP（Fan-in）**的完整14步工艺流程从Incoming Clean到Reflow，每一步都有监控点
4. **Fan-out WLP**通过晶圆重构（Reconstituted Wafer）将I/O引出到芯片外部，解决了Fan-in的I/O受限问题
5. **三种Fan-out工艺路线**：Chip-First Face-Down(eWLB/Infineon)、Face-Up(InFO/TSMC)、Chip-Last RDL-First(SWIFT/Amkor)
6. **via-last TSV**是WLCSP的特殊形式，广泛应用于CIS和MEMS封装，深宽比≤3:1
