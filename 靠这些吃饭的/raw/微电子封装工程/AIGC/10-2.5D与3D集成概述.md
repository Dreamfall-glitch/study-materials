# 10-2.5D与3D集成概述

## 知识地图

```
传统二维封装      → 2.5D集成      → 3D集成
  芯片并排放置    硅中介层连接    芯片垂直堆叠
  PCB长互连      TSV+微凸点     TSV/混合键合
  长延迟          较短互连        最短互连
```

**本讲核心**：封装从"保障性能"走向"系统赋能"，2.5D/3D集成是实现这一转变的核心路径。

---

## 1. 封装技术发展的新动态

### 1.1. 封装功能的发展与突破

封装仅仅是保障，还是额外赋能？

**传统封装**：以保障性能为主
- 核心任务：芯片保护、信号引出、供电分配、热量导出
- 目标：降低封装对芯片本征性能的**负面影响**（寄生参数、供电完整性、热阻）
- 更多体现为：避免限制芯片性能发挥，而非主动提升

**先进封装**：从性能保障走向系统赋能
- 突破了单芯片集成的边界，成为提升性能、扩展功能和实现异构系统集成的**赋能平台**
- 某些封装形式**本身就是功能的一部分**（功率半导体、LED、CIS、MEMS、CPO）
- 缩短了互连距离（如 MCM 多芯片模块）、扩大了布线面积（如 Fan-Out 晶圆级封装）
- 封装的作用取决于它是否仅承担互连与散热功能，还是进一步参与系统集成、功能扩展与架构重构

### 1.2. IC制造的极限与新路径

IC制造面临多重极限约束：

| 极限 | 表现 |
|------|------|
| **物理极限** | 短沟道效应、量子隧穿、漏电流增加、器件参数波动 |
| **互连延迟与功耗** | 性能受片上/片间互连制约，而非晶体管速度 |
| **制造复杂度与成本** | 光刻/材料/工艺控制/良率压力巨大 |

**新路径——五个协同创新方向**：

```
新器件结构 (FinFET, GAA)
    ↓
新材料与新工艺 (沟道/介质/金属化/热管理)
    ↓
设计与架构优化 (专用加速器、近存计算、异构计算)
    ↓
先进封装与三维集成 (2.5D/3D, Chiplet, HBM)——缩短互连、提高带宽
    ↓
异构集成 (逻辑+存储+射频+传感+电源)
```

**IC制造的极限意味着发展范式的转变。未来集成电路的进步，将不再仅以线宽缩小为唯一标志！**

## 2. 立体集成概述

### 2.1. 立体集成思想

**历史渊源**：Richard Feynman 1959年演讲《There's Plenty of Room at the Bottom》已预见三维集成 —— 一层一层蒸发导体和绝缘材料，形成立体结构。

**立体集成的本质**：
- 通过垂直堆叠与层间互连，将二维平面的长距离通信转化为**短距离垂直传输**
- 处理器与存储器的垂直堆叠可大幅缩短数据路径，降低延迟和功耗
- **并非单纯的层数增加，而是一种面向高性能、小型化与多功能融合的系统级集成范式**

**立体集成的层级**：
板级 → 封装级(2.5D/3D封装) → 芯片级(3D IC) → 芯片内部(W2W)

### 2.2. 2.5D/3D集成的分类及应用

**分类体系**：

```
立体集成
├── 3D Packaging（三维封装）
│   └── 芯片堆叠，通过WB/FC/TAB实现互连
│
├── 3D Integration with TSV（三维集成）
│   └── 芯片通过TSV直接垂直互连
│   └── 典型产品：AMD 3D V-Cache, Sony IMX400
│
└── 2.5D Integration（2.5D集成）
    └── 芯片并排放置在硅中介层上，TSV穿过中介层
    └── 典型产品：AMD R9 Fury(HBM), NVIDIA Tesla, Intel Arrow Lake
```

**产品应用案例**：

| 产品 | 技术类型 | 说明 |
|------|---------|------|
| **AMD R9 Fury** (2015) | 2.5D | 首款大规模零售的含HBM GPU |
| **NVIDIA Tesla** | 2.5D | 使用HBM的AI/数据中心GPU（vs GeForce无HBM） |
| **Intel Arrow Lake** (2024) | 2.5D | 与Raptor Cove对比，2.5D架构面积更优 |
| **Xilinx FPGA** | 2.5D | 通过硅中介层实现多die集成 |
| **AMD 3D V-Cache** | 3D | CPU层上堆叠L3 Cache，通过Hybrid Bonding互连 |
| **Sony IMX400** (2017) | 3D | 首个量产3D堆叠CIS（像素+电路+DRAM） |

**2.5D/3D与FCBGA结构对比**：
- Case 1 (2.5D)：SoC + HBM通过硅中介层连接
- Case 2 (3D)：芯片直接垂直堆叠
- Case 3：介于两者之间的混合结构

## 3. TSV技术总览

### 3.1. TSV的发展历史

| 年份 | 里程碑 |
|------|--------|
| **1958** | William Shockley提出TSV结构概念（deep pits） |
| **1976** | HP在共面GaAs RF MMIC中使用通孔接地技术 |
| **2008** | Toshiba利用TCV技术量产CMOS图像传感器——**首个量产3D集成产品** |

### 3.2. TSV的基本结构

TSV的典型结构由多层材料从内到外组成：

```
Cu导体         ← 填充在通孔中心的导电材料（主流），也可用多晶硅或W
   ↓
种子层         ← Cu或Cu合金，为电镀提供导电基底
   ↓
阻挡层         ← Ti/TiW/Ta/TaN，阻止Cu向Si扩散
   ↓
绝缘层         ← SiO₂（PECVD沉积），使TSV与Si衬底电隔离
   ↓
硅衬底
```

**各层功能详解**：

| 层 | 材料 | 功能 | 说明 |
|:--|:----|:----|:-----|
| **绝缘层** (liner) | SiO₂（PECVD）、SiN、聚合物 | 电隔离TSV与硅衬底；决定TSV的寄生电容 | 绝缘层厚度直接影响TSV的高频性能 |
| **阻挡层** (barrier) | Ti、TiW、Ta、TaN | 防止Cu向绝缘层及硅衬底中扩散 | Cu在Si中扩散速度快，会形成深能级陷阱，恶化器件性能 |
| **种子层** (seed layer) | Cu、Cu合金 | 作为电镀金属填充的导电基底（即阴极） | 种子层导电性优于阻挡层，为后续电镀过程提供均匀的电流分布 |
| **导体** (conductor) | Cu（主流）、多晶硅、W | 提供垂直互连的导电通道 | Cu电阻率最低（~1.7μΩ·cm），但热膨胀系数与Si不匹配 |

**TSV的深宽比**（aspect ratio）：3:1 ~ 20:1，取决于应用场景和工艺能力。高深宽比TSV（>10:1）对刻蚀和电镀填充的工艺控制提出了极高要求。

**TSV的尺寸参数**：典型TSV直径为5~50μm，深度为20~200μm（取决于晶圆厚度）。直径越小、深宽比越大，集成密度越高，但工艺难度也越大。

**TSV在2.5D与3D集成中的不同角色**：
- **2.5D集成**：TSV位于硅中介层（Si interposer）中，负责将上方的微凸点高密度互连过渡到下方的C4凸点和封装基板。TSV在这里承担**尺寸转换**和**垂直互连**的双重功能。
- **3D集成**：TSV直接穿过芯片衬底，承担芯片层间的直接电连接。TSV在这里承担**层间信号/电源传输**的核心功能，使存储器堆叠、逻辑-存储融合成为可能。

### 3.3. TSV单步工艺

TSV的单步工艺可分解为以下几个核心子步骤：

```
┌─────────────────────────────┐
│  1. TSV刻蚀 (DRIE/Bosch工艺) │ ← 形成高深宽比通孔
├─────────────────────────────┤
│  2. 绝缘层沉积 (PECVD SiO₂)  │ ← 电隔离Si与Cu导体
├─────────────────────────────┤
│  3. 阻挡层沉积 (PVD Ti/Ta)   │ ← 阻止Cu扩散
├─────────────────────────────┤
│  4. 种子层沉积 (PVD Cu)      │ ← 提供电镀导电基底
├─────────────────────────────┤
│  5. 电镀Cu填充               │ ← 无空洞填充核心步骤
├─────────────────────────────┤
│  6. 退火                     │ ← 释放应力，稳定晶粒
├─────────────────────────────┤
│  7. CMP平坦化                │ ← 去除表面过镀Cu
└─────────────────────────────┘
```

**各步详细说明**：

1. **TSV刻蚀**：一般采用深反应离子刻蚀（DRIE），Bosch工艺交替使用SF₆（刻蚀）和C₄F₈（钝化），形成侧壁光滑的高深宽比孔。刻蚀质量直接决定后续填充的均匀性和无空洞率。

2. **绝缘层沉积**：采用PECVD在孔内壁沉积SiO₂薄膜（典型厚度0.5~2μm），使TSV导体与硅衬底电学隔离。绝缘层的厚度和质量决定了TSV的寄生电容和漏电流。

3. **阻挡层沉积**：采用PVD或ALD在绝缘层上沉积Ti/Ta/TiW等金属薄膜（典型厚度50~200nm），防止Cu在后续高温工艺中向Si中扩散，后者会形成深能级复合中心，恶化器件性能。

4. **种子层沉积**：采用PVD沉积一薄层Cu（典型厚度100~500nm），作为后续电镀的导电阴极。种子层的均匀性和连续性对实现无空洞的电镀填充至关重要。在绝缘层和阻挡层之间有时还使用粘附层（adhesion layer）以改善结合力。

5. **电镀Cu填充**：通过电化学沉积（ECD）从孔底部向上填充Cu。这是TSV制造中最关键的步骤——必须保证从底部向上填充（bottom-up fill），避免在孔内形成空洞。电镀添加剂（加速剂、抑制剂、整平剂）的配比是关键。

6. **退火**：电镀后的Cu在150~400°C下退火，以释放电镀过程中产生的内应力、稳定晶粒结构、降低Cu电阻率。

7. **CMP平坦化**：化学机械抛光去除硅片表面的过镀Cu层、阻挡层和绝缘层，使TSV与硅片表面齐平，为后续工艺提供平坦表面。

### 3.4. TSV工序策略——完整权衡分析

TSV在工艺流中的插入位置有四个选项，从最前到最后依次为：

```
IC制造时间线 ──────────────────────────────────────►
  │                                               │
  FEoL (晶体管形成)              BEoL (金属互连)
  │    │                           │              │
  ▼    ▼                           ▼              ▼
Via-First  Via-Middle          Via-Last    Via-After-Bonding
```

**四种策略的详细对比**：

| 策略 | 工艺顺序 | 热预算 | 适合填充材料 | 优点 | 缺点 | 应用场景 |
|:----|:---------|:-----:|:----------:|:----|:----|:---------|
| **Via First**（先通孔） | TSV在CMOS器件形成**之前**制作 | 最高 | Poly-Si、掺杂多晶硅（Cu不适合——高温下扩散污染） | 高温工艺自由 | FEoL洁净度要求极高；Cu污染风险；硅片翘曲严重 | 对前端热预算要求极高的特殊应用（某些RF/功率器件） |
| **Via Middle**（中通孔） | TSV在晶体管形成**之后**、BEoL金属互连**之前**制作 | 中高 | Cu（避开FEoL最敏感阶段但仍可承受部分BEoL温度） | **综合折中最好**——避免FEoL污染风险，兼顾电性能与工艺集成 | 仍需考虑后续BEoL热预算 | ⭐ **业界最主流的TSV工艺策略** |
| **Via Last**（后通孔） | TSV在FEoL和BEoL全部完成**之后**制作 | 低 | Cu、W（适合后段互连金属） | 对前端器件零影响 | 背面加工、薄晶圆操作和三维光刻难度上升；对准精度要求高 | 存储器堆叠、CIS等 |
| **Via After Bonding**（键合后通孔） | 先键合芯片/晶圆，再在键合后的叠层上制作TSV | **最低** | Cu、W（仅适合低热预算工艺） | 可实现超短层间连接 | 对象是薄而脆、材料组合复杂的叠层结构；高温和强应力工艺严重受限 | 3D IC叠层中的短距离垂直互连 |

**核心权衡逻辑**：

```
越靠前 → 热预算越高 → 越不能用Cu（Cu是BEoL污染源）
越靠后 → 热预算越低 → 越适合Cu这类后段互连金属
越靠后 → 机械与对准问题越突出
```

- **Via First**：与FEoL兼容能力要求最高，适合高温绝缘和Poly-Si填充，但不适合Cu。TSV需要承受后续所有FEoL高温工艺，可能导致严重硅片翘曲。
- **Via Middle**：综合折中最好——既避免最严苛的FEoL污染风险，又能较好兼顾TSV电性能与工艺集成，是目前业界最主流的选择。
- **Via Last**：热预算低，适合Cu/W等后段填充，但背面加工、薄晶圆操作和三维光刻难度上升。已完成的器件与金属层限制热预算。
- **Via After Bonding**：仅适合低热预算工艺，热稳定性、对准精度和三维加工复杂性最为困难。先键合再制作TSV有利于超短层间连接，但操作对象已成为薄而脆、材料组合复杂的叠层。

## 本讲核心要点

1. **封装正从"性能保障"走向"系统赋能"**——先进封装可主动提升系统性能，某些封装形式本身就是功能的一部分（CIS、MEMS、CPO等）
2. **IC制造面临物理/互连/成本三重极限**，先进封装是延续性能提升的关键路径之一
3. **立体集成**通过垂直堆叠缩短互连距离，降低延迟和功耗，提高带宽密度——并非单纯的层数增加，而是系统级集成范式转变
4. **2.5D集成**（硅中介层+TSV）和**3D集成**（TSV+混合键合）各有适用场景——2.5D侧重于尺寸过渡和异构集成，3D侧重于层间直接互连
5. **TSV结构**由绝缘层→阻挡层→种子层→导体四层构成，每层各有功能，共同决定TSV的电性能和可靠性
6. **TSV在2.5D和3D中的角色不同**——2.5D中TSV位于中介层做尺寸过渡，3D中TSV直接穿过芯片做层间互连
7. **四种TSV工序策略**：Via First（FEoL前，Poly-Si填充）→ Via Middle（FEoL后BEoL前，Cu填充，**业界主流**）→ Via Last（全部完成后，工艺难度上升）→ Via After Bonding（热预算最低，加工最困难）
8. **工序选择的核心权衡**：越靠前的TSV工序越不能用Cu（高温扩散污染），越靠后的TSV工序越不能耐高温（但越适合Cu）
9. **典型产品案例**：AMD R9 Fury (2015, 首款HBM GPU)、NVIDIA Tesla (2.5D HBM)、Intel Arrow Lake (2.5D tile架构)、AMD 3D V-Cache (3D Hybrid Bonding)、Sony IMX400 (2017, 首个量产3D CIS)
10. **TSV的发展**：从Shockley(1958)的概念→HP(1976)的MMIC通孔接地→Toshiba(2008)的首个量产3D集成产品
