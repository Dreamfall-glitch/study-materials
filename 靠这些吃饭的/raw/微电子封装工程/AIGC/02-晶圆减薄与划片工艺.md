# 02-晶圆减薄与划片工艺

## 知识地图

在芯片制造的完整流程中，晶圆减薄和划片处于**制造结束、封装开始**的关键交界点：

```
芯片设计 → 光罩制造 → 芯片制造 → 晶圆测试 → [减薄 → 划片] → 封装 → 终测
                                              ↑ 本讲核心内容 ↑
```

为什么要在这个环节停下来思考？因为从晶圆到单个芯片（die）的转变，需要解决两个根本问题：
1. **晶圆太厚**——几百微米厚的硅片装不进薄薄的手机里
2. **晶圆是一整片**——上百颗芯片连在一起，需要切分开

这就是本讲的**减薄（Back Grinding）**和**划片（Wafer Sawing）**工艺要回答的问题。

---

## 1. 晶圆处理工艺

### 1.1. 先回顾：芯片从设计到封装的完整旅程

在深入减薄和划片之前，我们先回顾一下芯片是如何诞生的：

```
IC Design (设计)  →  Mask Fabrication (光罩制造)  →  Wafer Fabrication (晶圆制造)  
    ↓
Wafer Testing (晶圆测试)  →  Back Grinding (减薄)  →  Wafer Saw (划片)  
    ↓
Die Attach (贴片)  →  Wire Bonding (引线键合)  →  Molding (塑封)  
    ↓
Final Test (终测)
```

**晶圆形态 → 经过减薄划片 → 封装体形态**

### 1.2. 封装的作用（复习）

封装是连接芯片与系统的桥梁，五个核心功能：

```
           ┌─────────────────────────────────────┐
           │           封装（Package）            │
           │                                     │
  芯片 ────┤  • 电源分配 / 输入信号                 ├──── 系统
  (Die)    │  • 信号传输                           │  (PCB/系统)
           │  • 机械支撑                           │
           │  • 环境保护                           │
           │  • 散热（热耗/输出信号）               │
           └─────────────────────────────────────┘
```

封装还在**尺度放大**中扮演关键角色：
- 芯片内部互连：**纳米级**（< 100-101 nm）
- 芯片级封装：**微米级**（> 10¹ nm → μm级）
- 封装体→PCB：**毫米/厘米级**（> 10² μm → mm/cm）

### 1.3. 封装层次（Packaging Hierarchy）：

- Level 0: Wafer → Die      ─── 晶圆级（微细加工）
- Level 1: Chip Level        ─── 单芯片/多芯片模块（一级封装）
- Level 2: Card Level        ─── PTH & SMT（子板/卡级）
- Level 3: Board Level       ─── 母板级
- Level 4: System Level      ─── 系统级


### 1.4. 一级封装的基本流程

```
Wafer → Back Grinding (磨片) → Wafer Mount (晶圆安装) 
    → Wafer Saw (晶圆切割) → Wash (清洗) 
    → Die Attach (芯片粘接) → Wire Bond (引线焊接) → 加盖子
```

芯片与框架的互连方式主要有三种：
- **WB (Wire Bonding)**：引线键合
- **TAB (Tape Auto-Bonding)**：载带自动键合
- **FC (Flip Chip)**：倒装芯片

## 2. 晶圆减薄工艺

### 2.1. 什么是晶圆？

在进入减薄之前，我们先明确几个基础概念：

| 术语 | 英文 | 解释 |
|------|------|------|
| **晶圆** | Wafer | 一种单晶硅薄片，用作IC制造的基本衬底。在直径4-6-8-12英寸的单个晶圆上可以同时制作数百甚至数千个芯片 |
| **晶圆缺口** | Wafer Notch | 用于贴装、切割和工艺过程中定位晶圆 |
| **芯片/管芯** | Die / Chip | 单个半导体元件或集成电路 |

### 2.2. 为什么需要减薄？

#### 2.2.1. 基本定义

**晶圆研磨（Back Grinding）**，顾名思义，是将晶圆通过背面打磨使之厚度控制在一定范围。

#### 2.2.2. 厚度问题

| 参数 | 数值 |
|------|------|
| 8英寸晶圆原始厚度 | ≈ **750 μm** |
| 工业应用厚度 | 一般在 **200-300 μm** |
| 机器能力下限 | 可达 **25 μm** |
| 硅片上电路层有效厚度 | 仅 **5-10 μm** |

#### 2.2.3. 为什么不能一开始就做薄？

这是一个需要层层追问的问题：

**问**：如果最终需要薄芯片，为什么不在制造阶段就用薄晶圆？

> **答**：硅衬底的主要作用不是电路功能，而是**机械支撑**。较厚的硅片在制造、测试和运送过程中有足够的强度，能防止碎裂。电路功能层仅需5-10μm的厚度即可，但为了支撑它，原始硅片必须足够厚（≈750μm）。

**问**：减薄了有什么好处？

> **答**：
> 
> 1.  **满足封装厚度要求**——芯片最终要装进越来越薄的电子设备中
> 2.  **提高散热性能**——更薄的芯片热阻更小，散热更有效
> 3.  **改善电学性能**——降低功率器件的电阻
> 4.  **适应高密度封装**——薄芯片可以堆叠，实现3D封装

**一句话总结：原始晶圆厚是为了"扛得住制造"，减薄是为了"装得进封装、散得了热"。**

### 2.3. 减薄工艺的作业流程

```
旋转研磨 → 抛光 → 清洗
```

### 2.4. 减薄设备简介

减薄涉及专用设备，主流的全自动减薄机如DISCO DGP8761+DFM2800一体机，以及中电科晶圆减薄设备等。> *商业设备一笔带过，重点理解工艺原理。*

### 2.5. 减薄工艺的详细流程（以DGP8761为例）

以DISCO DGP8761机台为例，减薄工艺的全自动作业流程如下：

1. Pick wafer from FOUP              → 从晶圆盒取片
2. Transfer wafer with robot pick     → 机械臂传送
3. Alignment at positioning table      → 对准定位
4. Transfer wafer to C/T with Arm 1   → 传送至卡盘
5. Vacuum C/T                         → 真空吸附
6. Rough grind on Z1-axis             → 粗磨（Z1轴）
7. Fine grind on Z2-axis              → 精磨（Z2轴）
8. Stress relief on Z3-axis           → 应力释放（Z3轴）
9. Clean with wafer on C/T            → 清洗
10. Transfer wafer to spinner          → 传送至旋转清洗台
11. Clean and dry wafer at spinner     → 旋转清洗干燥
12. Transfer to mounter cassette       → 传送到贴膜盒
13. Place wafer to FOUP/Cassette       → 放回晶圆盒

### 2.6. 磨轮（Grinding Wheel）的核心原理

减薄靠的是磨轮，而磨轮的工作原理说起来并不复杂——本质上和锉刀类似。

#### 2.6.1. 磨轮的结构

磨轮的核心由两部分组成：

```
        ┌──────────────────────┐
        │     Grit (磨粒)       │ ← 实际进行切削工作的部分
        │                      │
        │    Bond (结合剂)      │ ← 固定磨粒的基体
        └──────────────────────┘
```

**磨粒**就是切割的"牙齿"，而**结合剂**像水泥一样把这些"牙齿"固定住。

#### 2.6.2. 气孔/容屑槽的关键作用

磨轮和锉刀一样，磨粒之间的**空隙（气孔/容屑槽，Porosity/Chip Pocket）**至关重要：

- **排屑作用**：暂时容纳切屑并将其排出
- **冷却作用**：储存冷却水，降低加工点的温度

如果没有气孔，磨轮就无法正常加工。就像锉刀如果没有齿槽，锉下来的碎屑就会堵住，再也无法切削。

#### 2.6.3. 磨粒的类型对比

| 分类 | 类型 | 硬度 (kg/mm²) | 特点 |
|------|------|---------------|------|
| **超硬磨粒** | 钻石 (Diamond) | 7000 | 最硬，但对热敏感（高温下硬度下降快） |
| **超硬磨粒** | CBN (立方氮化硼) | 4700 | 适合切割含金属材料 |
| **普通磨粒** | GC (SiC, 碳化硅) | 2480 | 常见磨料 |
| **普通磨粒** | WA (Al₂O₃, 氧化铝) | 2100 | 常见磨料 |

**温度对磨粒硬度的影响**：钻石在高温下硬度会显著下降，而CBN的高温性能较好。这一特性决定了不同磨粒的适用场景。

#### 2.6.4. 磨粒尺寸（Grit Size / Mesh \#）

磨粒尺寸用"目数（\#）"表示——目数越大，磨粒越小：

| 目数 | 磨粒尺寸 |
|------|---------|
| #320 | ≈ 45 μm |
| #1000 | ≈ 12 μm |
| #2000 | ≈ 4 μm |

**目数含义**：1平方英寸内有多少个网孔。例如#320意味着磨粒能通过325×325的网孔，但不能通过400×400的网孔。

**磨粒尺寸与效果的关系**：
- **大磨粒** → 切削力强，但表面粗糙度大
- **小磨粒** → 表面光洁度好，但切削力弱，寿命短

这就是为什么减薄要**先粗磨（大磨粒）再精磨（小磨粒）**——先用大磨粒快速去除大部分材料，再用小磨粒达到所需的表面质量。

#### 2.6.5. 结合剂的类型

| 类型 | 材料 | 特点 | 用途 |
|------|------|------|------|
| **金属结合剂** | Sn等 | 保持力强、寿命长 | 不适用于高质量研磨 |
| **树脂结合剂** | 热固化塑料 | 自锐性好 | 精磨；粗磨中用于减少边缘崩裂 |
| **陶瓷结合剂** | 玻璃/长石 | 刚性高 | 粗磨 |

### 2.7. BG膜（Back Grinding Tape）

#### 2.7.1. BG膜的作用

减薄时，晶圆的正面（有电路的一面）需要保护：

- 防止研磨液和研磨碎屑侵入晶圆表面造成污染
- 撕离后几乎无粘着剂残留
- 优良的厚度精度，确保研磨后晶圆厚度均匀

#### 2.7.2. BG膜的分类与选用

| 型号 | 厚度 | 适用范围 |
|------|------|----------|
| ELP UB-3205AC | 207 μm | Bump高度 ≤ 100 μm |
| E-4141A | 140 μm | Normal wafer（普通晶圆） |
| HT-440HBA-PE2 | 440 μm | Bump高度 > 100 μm |
| E-8310LS342F | 310 μm | 0 < Bump高度 ≤ 100 μm 且 Bump pitch ≥ 300 μm |

### 2.8. 减薄工艺的关键参数

减薄质量受三个核心参数影响：

| 参数                    | 影响        | 趋势               |
| --------------------- | --------- | ---------------- |
| **主轴转速（Spindle RPM）** | 表面粗糙度     | 转速越高，表面越光洁       |
| **进给速度（Feed Speed）**  | 产量、翘曲、粗糙度 | 速度越高→产量↑但粗糙度↑翘曲↑ |
| **卡盘转速（Chuck RPM）**   | 翘曲、粗糙度    | 转速越高，表面越光洁       |

三者的最佳区域需要在实际工艺中权衡选择。一个典型的质量指标是**TTV（Total Thickness Variation，总厚度偏差）**——200mm晶圆的TTV可控制在2μm以内。

### 2.9. 减薄过程中的质量检验

| 检验项目 | 抽样方案 |
|----------|----------|
| **减薄厚度** | 每die 2点，每wfr 5 die，每lot 3 wfr（试制阶段） |
| **粗糙度** | 每wfr 5点，2 wfr（试制阶段） |
| **平整度** | 2 wfr（试制阶段） |
| **背面外观** | 每片检验 |
| **减薄膜残留** | 每wfr 9点+边缘环 |

## 3. 晶圆划片工艺

### 3.1. 什么是晶圆划片？

**晶圆划片（Wafer Sawing/Cutting）**是将完整的晶圆按芯片大小分割成单一晶粒（die）的过程。

划片属于**后道封装测试工艺**，是半导体芯片制造工艺流程的重要一步。

```
划片作业过程：
    先横向切割所有行 → 再纵向切割所有列
    
    ┌────┬────┬────┬────┐
    │ D1 │ D2 │ D3 │ D4 │  ← 刀片沿切割道 (scribe line)
    ├────┼────┼────┼────┤
    │ D5 │ D6 │ D7 │ D8 │    先切水平方向
    ├────┼────┼────┼────┤
    │ D9 │D10 │D11 │D12 │    再切垂直方向
    └────┴────┴────┴────┘
```

### 3.2. 划片方法的演进

目前**机械切割（刀片切割）**仍然是优先选择——成本低、工艺条件成熟。

但随着Low-K（低介电常数）材料的广泛应用，机械切割已无法满足品质需求，于是**Laser Grooving（激光开槽）+ Blade Saw（刀片切割）**的组合工艺应运而生。

### 3.3. 机械切割（Blade Saw）工艺

#### 3.3.1. 划片设备

划片机使用刀片对硅、玻璃、陶瓷等材料进行高精度（微米级）切割加工。全自动划片机可实现从装片、位置校准、切割、清洗/干燥到卸片的全部自动化。

主流设备：DISCO DFD6560 / DFD6362、TSK等，以及国产CEC/ADT 8230等。

#### 3.3.2. 机台作业条件

划片机台作业需要三种基本条件：

| 条件 | 作用 |
|------|------|
| **电** | 工业用电 |
| **气（氮气/压缩空气）** | 主轴气悬浮结构，减少摩擦；气帘吹干产品表面 |
| **水（超纯水）** | 冷却主轴；水帘冲刷切割产生的硅屑 |

#### 3.3.3. 切割刀片（Blade）的结构

划片刀片主要分为两类：

**（1）轮毂型硬刀（Hub Blade）**

- 刀刃由**金刚石（Grit）**和**结合剂（Bond）**组成
- **集中度（Concentration）**：指磨粒层中金刚石磨粒所占的体积比例。例如集中度100 = 金刚石体积占25%

**（2）软刀（Soft Blade）**

- 根据结合剂种类分类

#### 3.3.4. 刀片切割的影响因素

**（1）暴露量（刀刃长度）**
刀刃长度必须 > wafer厚度 + 切入tape量（1mil）+ 安全余量（2mil）。
切割bump wafer还需考虑bump高度，DAF wafer需加上DAF的厚度。

**（2）刀片宽度**
由Scribe Line（切割道）宽度决定：

| Scribe Line宽度 | 15-20 μm | 20-25 μm | 25-30 μm | 30-40 μm |
|-----------------|----------|----------|----------|----------|
| 刀片厚度 | 15-20 μm | 20-25 μm | 25-30 μm | 30-40 μm |

**（3）金刚石集中度**

| 集中度 | 优点 | 缺点 |
|--------|------|------|
| **低集中度** | 降低背崩（backside chipping） | 刀片磨耗量大 |
| **高集中度** | 刀片磨耗小、寿命长、速度快、品质好 | 刀片强度弱，易断刀 |

**（4）金刚石颗粒大小**

| 颗粒大小 | 优点 | 缺点 |
|----------|------|------|
| **小颗粒**（#2000-#4000，≈2-6 μm） | 切割品质好 | 速度不宜太快，磨耗大 |
| **大颗粒** | 磨耗小、速度快、负载电流小 | 品质较差 |

**（5）结合剂硬度**

| 结合剂 | 特点 |
|--------|------|
| **硬结合剂** | 自我再生能力弱、切割品质差、寿命长、不易断刀 |
| **软结合剂** | 自我再生能力强、切割品质好、寿命短、易断刀 |

#### 3.3.5. 划片胶膜（Dicing Tape）

**胶膜的作用**：切割时将晶圆固定，切割后支撑分割开的die以便拾取。

**UV tape的工作原理：**

> UV tape结构：
> 离型膜（Release Film）
> 胶层（Adhesive Layer）
> 基材（Base Material）
> 未照射UV → 高粘性（切割时固定晶圆）
> 照射UV后 → 粘性降低（拾取芯片时容易取下）

> UV tape的胶层含有对365nm波长UV射线敏感的物质。受UV照射时，胶层吸收能量产生"缩水"现象，使粘度降低。

**Dicing tape对划片质量的影响：**

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **胶丝残留** | 刀片摩擦生热融化基材 | 提升主轴转速、增加冷却水流量、抬高划片高度 |
| **飞die** | 胶膜与晶圆粘着力不够 | 降低切割水流量、使用更高粘性tape |
| **Chipping（崩边）** | 切割深度控制不当 | 切入tape深度设定20-30 μm |

#### 3.3.6. 切割水

切割水在划片工艺中扮演着冷却和清洁的双重角色。

**切割水的组成：**

```
DI Water (去离子水) + CO₂ (二氧化碳) + Diamaflow (清洁剂)
        │                    │                    │
        ▼                    ▼                    ▼
    冷却刀片            降低水电阻率          帮助清除硅屑
    清洗硅屑            消除静电
```

**DI Water的静电问题：**
- DI water水阻值高（> 10 MΩ·cm），导电性差
- 高速冲击下易产生静电 → **ESD风险**
- 静电危害：①击穿芯片电路 ②硅屑静电吸附不易清洗

**CO₂的作用：**
- CO₂溶解在水中形成H⁺和HCO₃⁻离子，降低水电阻率
- 将静电及时导出
- 目标：切割水电阻率控制在 **0.2-1 MΩ·cm**
- 缺点：CO₂过量会产生酸性腐蚀，***降低刀片寿命***

**Diamaflow的作用：**
- 亲油性分子：被硅屑吸引并吸附，使硅屑从表面脱离
- 亲水性分子：带走悬浮粒子，使表面不再有残留物

#### 3.3.7. 切割模式

| 模式 | 方法 | 特点 | 适用场景 |
|------|------|------|----------|
| **单切 (Single Cut)** | 一刀切穿 | UPH高，但chipping较大 | 薄片切割 |
| **双切-分步切 (Step Cut)** | 宽刀开槽 + 窄刀切穿 | UPH低，切割品质佳 | **主流方法** |
| **双切-同刀 (Double Cut)** | 同一刀片先开槽后切穿 | UPH低，易产生chipping | 较少使用 |

### 3.4. 激光开槽（Laser Grooving）工艺

#### 3.4.1. 为什么需要激光开槽？

随着芯片集成度提高，**Low-K（低介电常数）材料**被引入以减少RC延迟。但Low-K材料结构蓬松，机械强度远弱于SiO₂——直接用刀片切割会导致**碎片、崩边（chipping）、剥离（peeling）**等问题。

**解决方案**：**Laser Grooving + Blade Saw**组合工艺
1. 先用激光在切割道上开槽，烧解掉金属和Low-K层
2. 再用刀片沿激光槽切穿晶圆

这样避免了刀片直接切割Low-K层造成的peeling和chipping。

#### 3.4.2. 激光切割原理

```
激光能量（光子）
    ↓ 极短时间内
传递给电子
    ↓ 极短时间内
转换为晶格热（光能→热能）
    ↓
温度急剧上升 → 材料熔化/汽化
    ↓
辅助气体吹离熔化物 → 形成切割槽
```

激光功率密度可达 **10⁶ ~ 10⁹ W/cm²**，可在极短时间内使材料达到熔化或汽化温度。

#### 3.4.3. 工艺适用性

| 工艺节点 | 推荐工艺 |
|----------|----------|
| **< 65 nm**（Low-K wafer） | **Laser Grooving + Blade Saw** |
| **≥ 65 nm** | 传统Blade Saw（参数需优化） |

#### 3.4.4. Coating液（保护涂层）的作用

激光加工时不能使用水，产生的残渣温度很高，喷溅到产品上冷却后难以去除。

**Coating液**的作用：
- 在激光前涂布于产品表面
- 将喷溅的残渣与产品隔离开
- 激光后用纯水清洗即可将coating液和残渣一起洗掉

主流产品：DISCO Hogomax-003系列（-10和-15两种型号）

## 本讲核心要点

1. **为什么要减薄**：原始晶圆厚是为了制造过程中的机械强度，减薄是为了满足封装厚度要求并改善散热和电学性能
2. **减薄的本质**：通过磨轮的磨粒切削作用，从晶圆背面去除硅材料，达到目标厚度
3. **粗磨→精磨→应力释放**的工艺顺序，通过不同磨粒尺寸的磨轮逐步实现
4. **为什么要划片**：将一整片晶圆上的数百颗芯片分割成独立的die
5. **机械切割仍是主流**，但对于65nm以下的Low-K工艺，需要Laser Grooving + Blade Saw的组合方案
6. **切割水不是简单的水**——它是DI Water + CO₂ + Diamaflow的精密配方，兼顾冷却、清洁和防静电
7. **划片胶膜的选择**直接影响切割质量和后续的芯片拾取
