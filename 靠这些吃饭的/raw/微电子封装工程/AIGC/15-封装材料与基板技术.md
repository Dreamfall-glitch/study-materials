# 15-封装材料与基板技术

## 知识地图

前面各讲从工艺维度深入了封装的全流程——减薄、划片、贴片、键合、TSV、RDL、凸点。本讲从**材料**维度出发，回答一个根本问题：**支撑这些工艺的物质基础是什么？**

```
工艺   ←  材料
↓          ↓
怎么做   用什么做
		│
	    ├── 中道材料（晶圆级）
	    │   电介质、靶材、CMP液、键合胶
	    │
	    ├── 后道材料（封装级）
	    │   基板、底填、TIM、焊球、引线框架
	    │
	    └── 基板技术（核心载体）
	        FCBGA基板、陶瓷基板
```

**本讲核心**：封装材料的分类与性能要求，以及封装基板（尤其是FCBGA和陶瓷基板）的完整制造工艺。

## 1. 集成电路材料产业格局

### 1.1. 材料的战略地位

一代技术依赖于一代工艺，一代工艺依赖一代设备和材料来实现。

按照产业链，集成电路材料分为三部分：

| 分类 | 内容 | 代表性材料 |
|------|------|-----------|
| **衬底材料** | 晶圆基底 | 第一代：Si、Ge；第二代：GaAs、InP；第三代：GaN、SiC（宽禁带） |
| **工艺材料** | 制造过程消耗品 | 光刻胶、掩膜版、工艺化学品、电子气体、抛光材料、靶材 |
| **封装材料** | 封装阶段材料 | **封装基板**、引线框架、键合丝、塑封料 |

**我国现状**：材料自主可控能力不足，主要产品集中在中低端，高端产品严重依赖进口。

### 1.2. 未来三维系统封装的关键材料挑战

| 技术挑战           | 材料解决方案                    |
| :------------- | :------------------------ |
| TSV深孔清洗        | TSV抛光液/清洗液                |
| TSV转接板及TSV减薄工艺 | 晶圆减薄临时粘接剂                 |
| 高密度多芯片堆叠热管理    | 热界面材料(TIM)                |
| 无铅Low-K芯片TCB工艺 | 用于无铅 &<br>Low-K 的UF和MUF工艺 |
| 大功率高速厚膜溅射      | 高效能溅射靶材                   |
| 高密度多芯片系统集成     | 高密度封装基板                   |
| RLC共封装         | 埋入功能器件的基板                 |

## 2. 晶圆级封装材料（中道工艺材料）

### 2.1. 电介质材料

用于RDL和钝化层的有机电介质材料：

| 材料 | 特点 |
|------|------|
| **PI（感光性聚酰亚胺）** | 正胶和负胶；水溶剂和有机溶剂 |
| **PBO（聚苯并恶唑）** | 低吸湿、高稳定性 |
| **BCB（苯并环丁烷）** | 低介电常数 |

**材料需求**（7项）：
- 低固化温度(≤200°C)高Tg
- 良好的热/化学稳定性
- 优良的粘附性
- 优良的机械性能(CTE/模量/延展率/收缩率)
- 低吸湿性
- 低介电常数
- 大工艺窗口的水溶性化学物质

### 2.2. 高效能溅射靶材

用于RDL、Bumping、TSV的薄膜沉积。

**技术难点**：
- 高密度封装应用大功率快速厚膜沉积
- 薄膜的杂质含量、粘附性、应力要求
- 薄膜均匀性、稳定性
- 大尺寸靶材的快速消耗导致的长寿命需求

**关键指标**：
- 纯度：镍钒≥4N，钨钛≥4N5，铝系合金≥5N5
- 成分均匀性≤±10%
- 晶粒尺寸≤100μm，第二相均匀分布
- 焊接率：钎焊≥95%，扩散焊≥98%
- 长寿靶材比普通靶材寿命提高15%以上

### 2.3. TSV清洗液

- 表面活性剂兼顾低表面张力、低气泡、低金属离子
- 快速扩散，同时对亲水性氧化硅以及憎水性硅表面皆具有优异的润湿性能
- TSV刻蚀清洗后无残留，对金属、硅及氧化硅的蚀刻速率小于2 nm/min

### 2.4. TSV抛光液

- 铜/阻挡层/绝缘层的抛光选择比 SiO₂/Si₃N₄ 1:2 到 1:20，快速平坦化，凹凸<100nm
- 铜/硅的抛光避免Cu对硅的沾污（硅表面Cu浓度<10¹⁰/cm²），硅表面颗粒<200@0.2μm

### 2.5. 晶圆减薄临时键合胶

为TSV芯片减薄提供关键材料。

**材料结构**：2~3层（粘附层 + 牺牲层 + 保护层）+ 清洗用化学品

**粘附层要求**：
低杨氏模量
高热稳定性
兼容不同衬底的高粘附性
低吸湿性
对酸/碱/有机溶剂抗腐蚀
清洗后无残胶

**牺牲层要求**：
对UV激光敏感、室温下解键合、高产率(UPH高)

**关键指标**：
涂覆平整度：8"，10μm凸点，±6%
粘度：>500,000cps (r.t ~ 200°C)；<5,000cps (300°C)
耐溶剂性：4小时变化<2%；剥离后溶剂清洗无残留

| **底部填充材料**     | CUF、MUF、NCP/NCF                                   |
| **环氧塑封料(EMC)** | 模冲底填(20μm top cut)、MAR树脂、联苯树脂、low alpha、晶圆级压缩模压材料 |
| **键合丝**        | 金、铜、银、铝、镀Pt铜                                      |
| **焊球**         | C4微焊球、BGA                                         |

### 3.2. FCBGA封装材料体系

以FCBGA为例的基板类封装材料包括：

- **底填料**(CUF, PA-UF)
- **非导电银浆/非导电膜**(NCP/NCF)
- **模塑底填料**(MUF)
- **散热盖**(Heat Spreader/Lid)
- **加强肋**(Stiffener)
- **热界面材料**(PTIM/STIM)
- **散热盖密封胶/粘合剂**
- **助焊剂和焊锡膏**
- **焊球**(μ-ball)
- **无源器件**(电容/电感/电阻)
- **原材料**(填料/纳米填料/高纯环氧树脂)
- **封装基板**

### 3.3. 底部填充材料（Underfill）

**组装工艺要求**：
低粘度、可完全填充芯片下方、无孔洞、可调整的凝胶时间、没有或较少的挥发物

**可靠性要求**：
优异的芯片和基板粘附性、热稳定性高、可靠性试验中无倒角裂纹/分层/其他失效形式、吸湿性低、辐射率低

**UF的功能**：缓解组装和使用过程中的CTE不匹配

**用于TCB Low-K工艺的底填材料**：
- 环氧/酸酐体系为主
- 非流动底填——固化时间的优化对凸点键合时高电气互连良率和低气孔率至关重要

**关键指标**：
粘度：15,000~25,000 mPa/s (r.t, 5rpm)
Tg：>150°C (TMA)
CTE：CTE1<35, CTE2<65 ppm
Modulus：<8.0 GPa (DMA)
芯片级电气互连良率>95%

**FC底填材料的挑战**（以Intel Stratix 10 FPGA为例）：
- Co-EMIB + ODI + MDIO的多芯片集成对NCF的要求提高

### 3.4. 高性能热界面材料（TIM）

**TIM1应用类型**：
> PTIM（硅胶基）、STIM（铟焊料预制件）、碳基材料（石墨纤维/石墨烯）、金属（合金/相变材料）

**TIM1需求**：
良好的分散性或成型能力、没有或仅有少量挥发性物质、对芯片和散热片的润湿性好、热导率高、适当的模量和延伸率、良好的压缩性/BLT控制、良好的热稳定性和可靠性

**三类TIM产品**：

| 类型 | 导热系数 | 特点 |
|------|----------|------|
| **导热垫片** | 1~5 W/mK，薄至0.2mm | 超软、表面自粘性，保护器件表面 |
| **导热膏** | 1~3 W/mK，热阻<0.05°C-in²/W | 粘度100,000~300,000可调 |
| **导热相变材料** | 1~3 W/mK，薄至0.25μm | 相变温度低，无pumpout |

**研究目标**：导热系数 >5~8 W/mK，热阻值 <0.05°C-in²/W，厚度25~75μm

## 4. 封装基板技术

### 4.1. 基板的定位与作用

基板为芯片提供电连接、保护、支撑、散热与组装，是支持先进工艺下巨量I/O提升以及系统级封装(SiP)的核心载体。

**封装层级**：
0级封装：Die/Wafer级 → 1级封装：元器件/模块级 → 2级封装：板级 → 3级封装：设备级

**高端基板的技术特点**：大幅度降低线宽线距，提升布线密度，减小尺寸与重量，改善热性能，实现3D-SiP系统级集成。

### 4.2. 市场现状

- 2020年全球基板市场规模101.88亿美元，年增长>25%，未来5年CAGR>9.7%
- FCBGA基板在封装基板中占比超过45%，未来5年CAGR达10.8%
- 2025年基板市场将达161亿美元
- 国内制造企业品类集中于WBBGA、FCCSP、Coreless，**大尺寸/高叠层/精细线路的高端FCBGA基板在国内仍处蓝海市场**

### 4.3. 技术路线规划

高端基板技术沿**细线路、高层数、窄节距I/O与更大的布线空间**方向演进：

| 参数 | 2016~2017 | 2018~2019 | 2020~2021 | 2022~2024 |
|------|-----------|-----------|-----------|-----------|
| 层数(RDL) | 10x~16x | >>10x | | |
| 凸点中心距(μm) | >110 | >80 | ≤60 |
| 球径(μm) | >400 | >350 | >250 |
| 焊盘/过孔(μm) | 95/65 | 85/60 | 80/55 | 75/50 |
| 线宽线距(μm) | 12/12 | 10/10 | 8/8 | ≥5/5 |
| 工艺 | mSAP, SAP | SAP, SAP+FO | RDL based (<5/5μm) |

### 4.4. 基板先进制造工艺对比

**三种工艺路线**：

| 工艺 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **Subtractive（减成法）** | 蚀刻掉多余铜 | 稳定的表面形态 | 不利于做精细线路，线形不佳 |
| **mSAP（改良半加成法）** | 薄铜箔+电镀加厚+蚀刻 | 利于做精细线路，线形佳 | — |
> | **SAP（半加成法）** | 无铜箔基材，全加成 | 最细线路 | 精细工艺需优化(固化/除胶条件) |

### 4.5. FCBGA基板完整制造流程（以3+2+3结构为例）

**结构**：中间2层Core（核心层）+ 上下各3层Build-up（增层）

#### 4.5.1. 下料
选用指定芯板、半固化片(Prepreg-PP)、铜箔按MI尺寸切割
控制要点：规格与型号(板厚/铜厚)、烘板温度与时间(如150°C/2h)、铜箔裁切

#### 4.5.2. 芯板
铜箔和绝缘层压合而成。FCBGA芯板特点：**Ultra Low CTE、Low Dk、Low Df、High Tg、High Modulus、Thick Core**

#### 4.5.3. 铜箔与PP（半固化片）
- **Prepreg**：玻纤布经上胶烘干至"B"阶（可溶可熔态），用于多层板压合
- **铜箔**：压延铜箔（多次辊轧，适于柔性板）和电解铜箔（电沉积制成）

#### 4.5.4. 钻孔（Drilling）
数控钻床加工芯板得到所需孔径
物料：钻头(碳化钨/钴/有机粘着剂、φ0.1~3.0mm)、铝板(定位/散热/减少毛头)、垫板(保护台面/降温/清洁胶渣)
控制：叠板层数、钻头规格、主轴转速/进给速度/退刀速度、毛刺/漏钻

#### 4.5.5. PTH（孔金属化）

**目的**：使孔壁上的非导体部分（树脂/玻璃纤维）金属化

**流程**：
```
钻孔来料→刷板→超声波水洗→蓬松→水洗→除胶(Desmear)→水洗→中和→水洗→调整
    →水洗→微蚀→水洗→预浸→活化→还原→化学沉铜→水洗→电镀
```

**关键步骤**：

| 步骤 | 作用 |
|------|------|
| **蓬松** | 渗入树脂钻污中令其蓬松，为去钻污作准备 |
| **除胶(Desmear)** | 高锰酸钾强氧化去除孔壁钻污；碱性高锰酸盐蚀刻除去内层铜表面钻污并粗化环氧树脂表面 |
| **中和** | 还原清洗孔壁表面Mn残余物 |
| **调整** | 清洁板面和孔壁，使孔壁呈正电性，增强吸收活化剂能力 |
| **微蚀** | 蚀刻孔壁内层及板面的铜氧化膜，增强结合力 |
| **活化** | 离子钯或胶体钯吸附于孔壁表面，在沉铜过程中引发金属铜沉积 |
| **还原** | 去除胶体钯上多余的锡，使活化钯金属外露 |
| **沉铜** | 氧化还原反应，在非导电表面建立一层能导电的铜 |

**表面去污（Desmear）**：
蓬松：打散C-C键，降低键能，形成蜂窝状结构，使树脂易受蚀刻
除胶：碱性高锰酸盐去除钻污，清洁孔壁，粗化环氧树脂表面
中和：除去MnO₂残留，对玻璃纤维进行前处理

**化学沉铜（Electroless Copper）**：
调整（清洁表面）→ 微蚀（过硫酸钠体系粗化铜面）→ 预浸（避免污染活化）→ 活化（离子钯吸附于树脂表面）→ 还原（将离子钯还原为金属钯）→ 化学沉铜（钯激活自催化反应，铜沉积）

**电镀（PTH电镀）**：清洁→微蚀→酸浸→电镀
**酸浸**：产生均匀扩散层，活化和湿润铜表面，确保快速起镀
**电镀**：在化学沉铜层上电解沉积金属铜，提供足够导电性和厚度

**电镀槽液组成**：
硫酸铜(CuSO₄·5H₂O) + 硫酸(H₂SO₄) + 氯离子(Cl⁻) + **载运剂** + **整平剂** + **光亮剂**

- **载运剂**：形成极化层，控制光亮剂/整平剂/Cl⁻形成最佳Cu还原环境，改善湿润性
- **整平剂**：带正电，在高电流区阻碍铜沉积
- **光亮剂**（加速剂/催化剂）：与载运剂/Cl⁻共同作用，加速Cu²⁺→Cu⁺→Cu⁰转化，确保延展性

#### 4.5.6. 树脂塞孔

**目的**：用树脂将导通孔塞住，孔表面镀铜
**作用**：缩小孔间距→减小板面积；提高布线密度；提高埋孔可靠性→避免爆板
**特点**：大孔径、高纵横比、孔数多
**流程**：塞孔前处理→塞孔→烘烤→磨平(压平)

#### 4.5.7. 内层图形工艺（Subtractive）

**流程**：前处理→压膜→曝光→显影→蚀刻→剥膜→AOI→AOS

**前处理（三种方法）**：
- 磨板机（喷砂研磨法）：纯尼龙刷+火山灰/氧化铝
- 刷板机（机械研磨法）：针刷（含碳化硅/氧化铝的尼龙刷）
- 化学清洗机（化学前处理法）：过硫酸钠+硫酸微蚀

**粗糙度控制**：Ra 0.2~0.4μm，Rz 2~3μm，Wt<4μm

**压膜**：干膜光刻胶以热压方式贴附在清洁铜面上
温度：滚轮110±10°C，铜面50±5°C
控制要点：温度太高→干膜变脆耐镀力差；温度太低→结合力不好渗镀；压力太大→膜皱盖孔破

**干膜结构**：
**PE隔膜层**（贴膜时撕去）+ **感光阻剂层**（光聚反应主体）+ **PET盖膜层**（保护防氧化/防氧气进入）
种类：正胶（感光部分分解被洗掉）vs 负胶（感光部分聚合硬化，未感光部分被洗掉）

**曝光（LDI, Laser Direct Imaging）**：
直接将CAM资料成像在干膜上，无需底片
优点：无底片缺陷→良率高；分区自动测量涨缩与图形修正→对位精度±5μm；自动对焦测量板厚；图像解析度高→精细线路可达7μm
控制：能量控制解析能力；优化曝光可改善线形(如8/12μm线路干膜边缘粗糙度)

**显影残足处理**：水洗中添加特殊药水；显影吹干后做等离子处理

**AOI（Automated Optical Inspection）**：光学反射原理将图像与逻辑判断原则比较，找出缺陷

**AOS（Automated Optical Shaping）**：利用激光去除多余铜/填补缺失区域；3DS（3D Shaping）技术→最大良率最少报废

#### 4.5.8. ABF（Ajinomoto Build-up Film）

ABF是一种在合成树脂类材料中加入玻璃微粉填料做成的绝缘介质薄膜。
> 优势：不含玻纤，适用于SAP工艺；广泛应用于CPU/GPU/芯片组等大型高端芯片基板；作为增层材料直接在铜箔基板上附着，不需高温热压合

**ABF性能调控**：增加filler含量→杨氏模量/Dk增加，CTE/伸长率降低；Tg变化不大

**GZ系列**：面向faster signal speeds/lower loss应用。氰酸酯缩聚形成三嗪环结构→低Dk、低Df；Tg高、模量高

#### 4.5.9. 超粗化

在铜表面形成独特凹凸形状，增强铜和树脂间的物理结合力

**过程**：入料→前处理→水洗→微蚀→水洗→盐酸洗→水洗→有机膜→水洗→烘干→出料
**反应原理**：盐酸→去污剂去除铜化合物；CL-8300→防锈剂，在粗化面上形成有机皮膜，提高铜与树脂间的化学结合力

#### 4.5.10. 真空压膜

真空下用静压对基板表面凹凸状物体均一加压
最高温度≤150°C±2°C，整平精度≤20μm

#### 4.5.11. 激光钻孔（Laser Drill）

**两种激光**：

| 类型 | 原理 | 特点 |
|------|------|------|
| **CO₂激光** | 光热烧蚀，材料吸收高能量激光熔化蒸发成孔 | 孔壁有炭化残渣，孔化前需清理 |
| **UV激光** | 光化学烧蚀，高能光子破坏有机材料长分子链 | 孔壁无碳化 |

**材料吸光特性**：铜箔/玻璃布在UV区吸收率高；有机树脂在三段光谱都能维持高吸收率

**控制要点**：板面平整介质均匀、对位靶点清晰、孔真圆度/锥形度、孔底干净

#### 4.5.12. ABF Desmear

**控制要点**：药液浓度/温度/时间、除胶量(称重法)、粗糙度(白光干涉)、表面形貌(SEM)、孔口真圆度(二次元)

#### 4.5.13. 前处理（图形电镀前）

有机膜做附着力促进剂——双功能分子团将铜面和干膜结合；紫外光照射区域发生聚合反应增加附着力

#### 4.5.14. 图形电镀

**控制要点**：盲孔电镀药水浓度/温度/添加剂含量、电流密度/电镀时间、盲孔Dimple≤10μm

**Throwing Power（均镀能力）**：消除树脂粗糙度影响；第二次电镀消除树脂缝隙影响

**QVP（Quick Via Pull Test）**：盲孔除胶→化铜→整板电镀→抗剥测试，每种孔径检查~1000个盲孔无不合格

#### 4.5.15. ABF细线路制备

关键：**lower profile（光滑表面）+ high peel strength（高抗剥强度）**

**Peel Strength测试**：ABF压合→除胶→化铜→全板镀(25~30μm)→烘烤→取样(10mm×50mm)→50mm/min速度垂直拉力→记录最小负载

#### 4.5.16. 闪蚀（Flash Etching）

去除线路间种子层，形成和设计一致的线路图形

#### 4.5.17. 阻焊（Solder Mask）

**目的**：
- 开窗：留出焊盘，覆盖线路和铜面，防止波焊短路、节省焊锡
- 护板：防止湿气/电解质侵害，防止外来机械伤害

#### 4.5.18. 表面处理

保护基板PAD不发生氧化/磨损，提供良好焊接界面

#### 4.5.19. 电测

基于欧姆定律侦测线路通断。
测试条件：OPEN 5~15V / 50Ω，SHORT 150V / 2MΩ
三种测试：专用型(dedicated)、通用型(Universal on Grid)、飞针测试(Moving probe)

#### 4.5.20. 成型

以铣刀切割成型，裁切成客户所需规格尺寸（Panel → Strip → Unit）

#### 4.5.21. SOP（Solder on Pad）

在焊盘上形成平整锡膏表面。流程：印锡膏→回流焊→助焊剂清洗→整平
钢网印刷：满足diameter/pitch=75/150μm
Micro Ball Printer：实现diameter/pitch=30/60μm

#### 4.5.22. 检验及包装

**符合性项目**：外形尺寸、板厚、孔径、线宽、孔环大小、板弯翘、镀层厚度
**可靠性项目**：Peel strength、Solderability、Micro Section、S/M Adhesion、Gold附着力、Thermal Shock、Impedance

## 5. 陶瓷基板

### 5.1. 对封装基板的6项基本要求

1. **高热导率**——器件产生的热量需通过封装传播出去
2. **CTE匹配**——与芯片材料热膨胀系数匹配，降低热应力
3. **耐热性好**——满足功率器件高温使用需求
4. **绝缘性好**
5. **机械强度高**——满足加工/封装/应用强度要求
6. **价格适中**——适合大规模生产

### 5.2. 陶瓷的性能

**力学性能**：硬度极高、高弹性模量、高脆性、高抗压强度、低抗拉强度、低塑性/韧性

**物理化学性能**：高熔点(Tm>2000°C)、低热膨胀系数、良好绝缘性、结构稳定、化学稳定高

### 5.3. 基板材质类型

| 应用方向 | 基板材料 |
|----------|----------|
| **高速器件**（低Dk/易多层化） | Al₂O₃基板、玻璃陶瓷共烧基板 |
| **高散热要求**（高热导率） | **AlN基板**、BeO基板 |

**使用量最大的**：Al₂O₃、AlN

### 5.4. 陶瓷基板多层化技术

| 技术 | 工艺 | 特点 |
|------|------|------|
| **厚膜印刷多层** | 在烧结氧化铝基片上交互印刷导体浆料/电介质浆料，850~950°C烧成 | 导体电阻率最低，设计灵活，适合多品种小批量 |
| **生片积层多层（HTCC）** | 未烧结氧化铝生片上形成通孔→印刷W/Mo等高熔点金属导体→叠层→还原气氛一体烧结 | 结构致密无针孔，耐压高、电阻率低、散热好，层数可达数十层，**最常用** |
| **生片印刷多层** | 生片上交互印刷导体/电介质→一体烧结 | 介于两者之间，设计改变容易，适合中小批量 |

### 5.5. HTCC（高温共烧陶瓷）的缺点

1. 需在还原性气氛中烧结（工艺难度大、需特殊烧结炉）
2. Mo/W电阻率高→布线电阻大→信号失真/损耗大，布线微细化受限
3. 介质Dk偏大→信号传输延迟大，不适用于超高频电路
4. Al₂O₃的CTE(7×10⁻⁶/°C)与Si(3×10⁻⁶/°C)相差太大→热循环热应力
5. 只有W/Mo等高熔点金属能耐1500°C，但电阻率高→电压降大→动态范围变小

### 5.6. LTCC（低温共烧陶瓷）

**要求**：
烧成温度<1000°C、低Dk、CTE与芯片接近、足够机械强度

**特点**：将多个被动组件（电容/电阻/滤波器/耦合器）埋入多层陶瓷基板中，叠压后在900°C烧结，制成三维高密度电路。内外电极可使用Ag/Cu/Au等金属。

**三类LTCC基片**：

| 类型 | 烧成气氛 | 导体材料 |
|------|----------|----------|
| (1) 硼酸锡钡系 | 大气 | Au, Ag系 |
| (2) 氧化铝-硼硅酸铅玻璃系 | 大气 | Au, Ag系 |
| (3) 氧化铝-非玻璃质添加物系 | 中性/还原气氛 | Cu系, Ni系 |

### 5.7. 基板发展趋势

1. **氧化铝基片**——工艺最成熟/价格低，改进方向为多层化技术
2. **高热导性陶瓷基片**（AlN/SiC/BeO）——大功率集成电路需求，**AlN最有发展前途**
3. **LTCC基片**——可与Au/Ag/Cu等低熔点导体同时烧成，发展前途大
4. **非陶瓷质基片**——价格低廉/热导率高/脆性小，适用于低要求日用电子产品

## 本讲核心要点

1. **封装材料分为中道（晶圆级）和后道（封装级）两大类**——中道材料如电介质/靶材/CMP液/键合胶，后道材料如基板/底填/TIM/焊球/引线框架
2. **临时键合胶**是TSV减薄的关键材料，三层结构（粘附层+牺牲层+保护层），需要>500,000cps的粘度和UV激光/热滑移解键合能力
3. **底部填充材料(UF)**需同时满足组装工艺要求和可靠性要求——TCB Low-K工艺要求非流动底填(NUF)实现助焊与填充一体化
4. **热界面材料(TIM)**是热管理的关键，导热系数>5~8 W/mK，目标热阻<0.05°C-in²/W
5. **FCBGA基板**制造是封装材料技术的核心——3+2+3结构的完整流程涵盖下料→芯板→钻孔→PTH→电镀→树脂塞孔→内层图形→ABF→激光钻孔→超粗化→真空压膜→闪蚀→阻焊→电测等20余道工序
6. **ABF（味之素堆积膜）**是FCBGA基板的关键绝缘介质材料，不含玻纤，适用于SAP精细线路工艺
7. **陶瓷基板**中HTCC最常用（结构致密/耐压高），LTCC可埋入无源器件（900°C烧结/Ag/Cu电极）
8. **国内高端基板**（大尺寸/高叠层/细线路）处于蓝海市场，日韩台企业为主要供应商
