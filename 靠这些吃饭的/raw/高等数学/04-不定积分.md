# 04-不定积分

## 知识地图

```
导数与微分（已学）—— 已知函数求变化率
    ↓
【不定积分】—— 已知导函数求原函数，微分的逆运算
    ↓
定积分、微分方程
```

**本讲回答的核心问题**：已知一个函数的导函数，能否恢复出原来的函数？如果可以，结果是否唯一？

---

## 1. 不定积分的概念

### 1.1. 原函数

若 $F'(x) = f(x)$，则称 $F(x)$ 是 $f(x)$ 的一个**原函数**。

关键性质：如果 $F(x)$ 是 $f(x)$ 的原函数，那么 $F(x) + C$（$C$ 为任意常数）也是 $f(x)$ 的原函数——原函数**不唯一**，彼此相差一个常数。

几何意义：原函数的图像是一族"平行"曲线（沿 $y$ 轴方向平移）。

### 1.2. 不定积分的定义

$f(x)$ 的所有原函数的全体称为 $f(x)$ 的**不定积分**，记作：

$$
\int f(x)\,dx = F(x) + C
$$

其中 $f(x)$ 称为**被积函数**，$x$ 称为**积分变量**，$C$ 称为**积分常数**，$dx$ 表示对 $x$ 积分。

### 1.3. 微分与积分的关系

$$
\frac{d}{dx} \left[ \int f(x)\,dx \right] = f(x)
$$

$$
\int F'(x)\,dx = F(x) + C
$$

理解：微分和积分是互逆运算——就像加法和减法、乘法和除法的关系。先积分再微分，回到原函数；先微分再积分，回到原函数加常数。

---

## 2. 基本积分公式

以下公式由基本求导公式反向推导得到，需要熟练掌握：

| 分类          | 公式                                                            |
| ----------- | ------------------------------------------------------------- |
| 常数          | $\int 0\,dx = C$                                              |
| 幂函数         | $\int x^\mu\,dx = \frac{x^{\mu+1}}{\mu+1} + C\;(\mu \neq -1)$ |
| 倒数          | $\int \frac{1}{x}\,dx = \ln\|x\| + C$                         |
| 指数          | $\int a^x\,dx = \frac{a^x}{\ln a} + C$                        |
|             | $\int e^x\,dx = e^x + C$                                      |
| 正弦          | $\int \sin x\,dx = -\cos x + C$                               |
| 余弦          | $\int \cos x\,dx = \sin x + C$                                |
| 正切          | $\int \tan x\,dx = -\ln\|\cos x\| + C$                        |
| 余切          | $\int \cot x\,dx = \ln\|\sin x\| + C$                         |
| 正割          | $\int \sec x\,dx = \ln\|\sec x + \tan x\| + C$                |
| 余割          | $\int \csc x\,dx = \ln\|\csc x - \cot x\| + C$                |
| $\sec^2$    | $\int \sec^2 x\,dx = \tan x + C$                              |
| $\csc^2$    | $\int \csc^2 x\,dx = -\cot x + C$                             |
| $\sec \tan$ | $\int \sec x \tan x\,dx = \sec x + C$                         |
| $\csc \cot$ | $\int \csc x \cot x\,dx = -\csc x + C$                        |
| 平方倒数        | $\int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + C$             |
|             | $\int \frac{1}{1+x^2}\,dx = \arctan x + C$                    |
| 双曲          | $\int \sinh x\,dx = \cosh x + C$                              |
|             | $\int \cosh x\,dx = \sinh x + C$                              |

**关于绝对值**：$\int \frac{1}{x}\,dx = \ln|x| + C$ 中绝对值不能丢——$x$ 可能取负值，$\ln x$ 在 $x<0$ 时无意义。

## 3. 线性性质

不定积分具有线性性质：

$$
\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx
$$

$$
\int k f(x)\,dx = k \int f(x)\,dx \quad (k \text{为常数})
$$

这两条性质允许我们将复杂积分拆成多个简单积分的和，分别积分后再合并。

## 4. 第一类换元法（凑微分法）

### 4.1. 基本原理

核心思想：将被积函数拆成一个复合函数 $f(g(x))$ 乘上 $g'(x)$ 的形式，然后令 $u = g(x)$：

$$
\int f(g(x)) \cdot g'(x)\,dx = \int f(u)\,du = F(u) + C = F(g(x)) + C
$$

### 4.2. 常见凑微分形式

| 被积形式 | 凑微分 | 换元 |
|----------|--------|------|
| $\int f(ax+b)\,dx$ | $dx = \frac{1}{a}d(ax+b)$ | $u = ax+b$ |
| $\int x^{n-1} f(x^n)\,dx$ | $x^{n-1}dx = \frac{1}{n}d(x^n)$ | $u = x^n$ |
| $\int f(\sin x)\cos x\,dx$ | $\cos x\,dx = d(\sin x)$ | $u = \sin x$ |
| $\int f(\cos x)\sin x\,dx$ | $\sin x\,dx = -d(\cos x)$ | $u = \cos x$ |
| $\int f(\tan x)\sec^2 x\,dx$ | $\sec^2 x\,dx = d(\tan x)$ | $u = \tan x$ |
| $\int f(e^x)e^x\,dx$ | $e^x\,dx = d(e^x)$ | $u = e^x$ |
| $\int f(\ln x)\frac{1}{x}\,dx$ | $\frac{1}{x}dx = d(\ln x)$ | $u = \ln x$ |
| $\int f(\sqrt{x})\frac{1}{\sqrt{x}}\,dx$ | $\frac{1}{\sqrt{x}}dx = 2d(\sqrt{x})$ | $u = \sqrt{x}$ |
| $\int f(\arcsin x)\frac{1}{\sqrt{1-x^2}}\,dx$ | $\frac{1}{\sqrt{1-x^2}}dx = d(\arcsin x)$ | $u = \arcsin x$ |
| $\int f(\arctan x)\frac{1}{1+x^2}\,dx$ | $\frac{1}{1+x^2}dx = d(\arctan x)$ | $u = \arctan x$ |

### 4.3. 例题

**例1**：$\int \cos(3x+2)\,dx$

令 $u = 3x+2$，$du = 3dx$，则 $dx = \frac{1}{3}du$：

$$
\int \cos(3x+2)\,dx = \frac{1}{3}\int \cos u\,du = \frac{1}{3}\sin(3x+2) + C
$$

**例2**：$\int \frac{1}{x\ln x}\,dx$

令 $u = \ln x$，$du = \frac{1}{x}dx$：

$$
\int \frac{1}{x\ln x}\,dx = \int \frac{1}{u}\,du = \ln|\ln x| + C
$$

## 5. 第二类换元法

### 5.1. 基本原理

当被积函数含有根号等复杂结构时，令 $x = \psi(t)$，其中 $\psi(t)$ 单调可导：

$$
\int f(x)\,dx = \int f(\psi(t)) \cdot \psi'(t)\,dt
$$

### 5.2. 三角代换

处理含 $\sqrt{a^2 \pm x^2}$ 和 $\sqrt{x^2 \pm a^2}$ 的积分：

| 被积表达式 | 代换 | 微分 | 说明 |
|-----------|------|------|------|
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$ | $dx = a\cos t\,dt$ | $t \in [-\pi/2, \pi/2]$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$ | $dx = a\sec^2 t\,dt$ | $t \in (-\pi/2, \pi/2)$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$ | $dx = a\sec t\tan t\,dt$ | $t \in [0,\pi/2)$ 或 $[\pi, 3\pi/2)$ |

代换后的积分通常化为三角函数积分，最后用直角三角形将 $t$ 回代为 $x$。

### 5.3. 根式代换

当被积函数含 $\sqrt[n]{ax+b}$ 时，令 $t = \sqrt[n]{ax+b}$，则 $x = \frac{t^n - b}{a}$。

**例**：$\int \frac{1}{\sqrt{x} + \sqrt[3]{x}}\,dx$

令 $t = \sqrt[6]{x}$（取根指数的最小公倍数），则 $x = t^6$，$dx = 6t^5 dt$：

$$
\int \frac{1}{t^3 + t^2} \cdot 6t^5\,dt = 6\int \frac{t^3}{t+1}\,dt
$$

化为有理函数积分。

## 6. 分部积分法

### 6.1. 基本原理

由乘积法则 $(uv)' = u'v + uv'$ 两边积分得到：

$$
\int u\,dv = uv - \int v\,du
$$

其中 $u = u(x)$，$v = v(x)$。

### 6.2. 选取 $u$ 和 $dv$ 的原则

口诀：**反对幂指三**

按此顺序，排名靠前的选为 $u$（求导后变简单），靠后的选为 $dv$（容易积出 $v$）：

| 顺序 | 类型 | 示例 |
|------|------|------|
| 1 | 反三角函数 | $\arcsin x, \arctan x$ |
| 2 | 对数函数 | $\ln x, \log_a x$ |
| 3 | 幂函数 | $x^n$ |
| 4 | 指数函数 | $e^x, a^x$ |
| 5 | 三角函数 | $\sin x, \cos x$ |

### 6.3. 常见类型

**类型1**：$\int x^n e^x\,dx$——$u = x^n$，$dv = e^x dx$

$$
\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + C
$$

**类型2**：$\int x^n \ln x\,dx$——$u = \ln x$，$dv = x^n dx$

$$
\int x \ln x\,dx = \frac{1}{2}x^2 \ln x - \frac{1}{2}\int x\,dx = \frac{1}{2}x^2 \ln x - \frac{1}{4}x^2 + C
$$

**类型3**：$\int e^x \sin x\,dx$——可任意选，但需要两次分部，最后得到循环方程

设 $I = \int e^x \sin x\,dx$，两次分部后得到 $I = e^x\sin x - e^x\cos x - I$，解得：

$$
I = \frac{1}{2}e^x(\sin x - \cos x) + C
$$

**类型4**：$\int \arctan x\,dx$——$u = \arctan x$，$dv = dx$

$$
\int \arctan x\,dx = x\arctan x - \int \frac{x}{1+x^2}\,dx = x\arctan x - \frac{1}{2}\ln(1+x^2) + C
$$

**类型5**：$\int \ln x\,dx$——$u = \ln x$，$dv = dx$

$$
\int \ln x\,dx = x\ln x - \int x \cdot \frac{1}{x}\,dx = x\ln x - x + C
$$

## 7. 有理函数的积分

### 7.1. 有理真分式的分解

有理函数 $\frac{P(x)}{Q(x)}$，若分子次数小于分母次数，称为**真分式**。真分式可以分解为**部分分式之和**。

**情形1**：分母有单根因子

$$
\frac{P(x)}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b}
$$

**情形2**：分母有重根因子

$$
\frac{P(x)}{(x-a)^k} = \frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k}
$$

**情形3**：分母有二次不可约因子

$$
\frac{P(x)}{(x^2+px+q)} = \frac{Ax+B}{x^2+px+q}
$$

### 7.2. 积分步骤

1. 若为假分式（分子次数 $\geq$ 分母次数），先用多项式除法化为"多项式 + 真分式"
2. 分母因式分解
3. 将真分式分解为部分分式
4. 逐项积分

## 8. 可化为有理函数的积分

### 8.1. 三角函数有理式

形如 $\int R(\sin x, \cos x)\,dx$ 的积分，可通过**万能公式**（半角代换）化为有理函数积分。

令 $t = \tan\frac{x}{2}$，则：

$$
\sin x = \frac{2t}{1+t^2},\quad \cos x = \frac{1-t^2}{1+t^2},\quad dx = \frac{2}{1+t^2}dt
$$

代入后原积分化为关于 $t$ 的有理函数积分。

**例**：$\int \frac{1}{1+\sin x}\,dx$

令 $t = \tan\frac{x}{2}$，得 $\sin x = \frac{2t}{1+t^2}$，$dx = \frac{2}{1+t^2}dt$：

$$
\int \frac{1}{1+\frac{2t}{1+t^2}} \cdot \frac{2}{1+t^2}\,dt = 2\int \frac{1}{(1+t)^2}\,dt = -\frac{2}{1+t} + C = -\frac{2}{1+\tan\frac{x}{2}} + C
$$

> 注意：万能公式虽然通用，但计算量较大。特殊情况下优先采用更简单的方法（如凑微分）。

### 8.2. 根式代换

对于含有 $\sqrt[n]{ax+b}$ 的有理函数，令 $t = \sqrt[n]{ax+b}$ 化为有理函数积分。

## 本讲核心要点

1. **不定积分是微分的逆运算**——原函数族 $F(x) + C$，$C$ 不能漏
2. **基本积分公式**（17组）由导数公式反向推导得到，必须熟练记忆
3. **凑微分法（第一换元）**以 $u = g(x)$ 为变量，将积分化为已知公式形式——识别 $f(g(x))g'(x)$ 的结构是关键
4. **第二类换元法**以 $x = \psi(t)$ 换变量——三角代换处理根号，根式代换处理 $\sqrt[n]{ax+b}$
5. **分部积分法**的口诀"反对幂指三"决定 $u$ 的选择顺序
6. **有理函数积分**的核心策略是把真分式分解为部分分式再积分
7. **三角函数有理式**用万能公式 $t = \tan\frac{x}{2}$ 化为有理函数——通用但计算量大，特殊情形优先用简单方法
