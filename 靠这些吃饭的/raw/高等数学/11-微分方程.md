# 11-微分方程

## 知识地图

```
微积分（已学）—— 寻找函数的导数/积分
    ↓
【微分方程】—— 含有未知函数及其导数的方程，描述动态系统的演化
    ↓
在物理、电路、控制、振动等领域的广泛应用
```

**本讲回答的核心问题**：已知物理规律（表现为导数的关系），如何求出描述系统状态的函数？

---

## 1. 微分方程的基本概念

### 1.1. 什么是微分方程

含有未知函数及其导数的方程称为**微分方程**。

**示例**：
- $y' = 2x$：最简单的一阶微分方程
- $y'' + y = 0$：二阶齐次微分方程
- $y' = y(1 - y)$：一阶非线性（Logistic 方程）

### 1.2. 微分方程的阶

方程中出现的最高阶导数的阶数称为微分方程的**阶**。

- 一阶：$y' = f(x, y)$
- 二阶：$y'' = f(x, y, y')$
- $n$ 阶：$y^{(n)} = f(x, y, y', \dots, y^{(n-1)})$

### 1.3. 解的概念

| 术语 | 含义 | 示例 |
|------|------|------|
| **通解** | 含任意常数的解，常数个数等于阶数 | $y = Ce^{x}$ |
| **特解** | 通过初始条件确定常数得到的解 | $y = 2e^{x}$（给定 $y(0)=2$） |
| **初值问题** | 微分方程 + 初始条件 | $y' = y,\ y(0) = 1$ |

## 2. 一阶微分方程

### 2.1. 可分离变量方程

**形式**：$\frac{dy}{dx} = f(x)g(y)$

**解法**：分离变量后两边积分

$$
\frac{dy}{g(y)} = f(x)\,dx \implies \int \frac{dy}{g(y)} = \int f(x)\,dx + C
$$

**例**：求解 $y' = 2xy$

分离变量：$\frac{dy}{y} = 2x\,dx$

两边积分：$\ln|y| = x^2 + C \implies y = \pm e^{C} e^{x^2} = C_1 e^{x^2}$

### 2.2. 齐次方程

**形式**：$\frac{dy}{dx} = \varphi\left(\frac{y}{x}\right)$

**解法**：令 $u = \frac{y}{x}$，则 $y = ux$，$y' = u + xu'$，代入后化为可分离变量方程。

**例**：求解 $y' = \frac{y}{x} + \frac{x}{y}$

令 $u = y/x$，则 $y = ux$，$y' = u + xu'$，代入：

$u + xu' = u + \frac{1}{u} \Rightarrow xu' = \frac{1}{u} \Rightarrow u\,du = \frac{dx}{x}$

积分：$\frac{1}{2}u^2 = \ln|x| + C \Rightarrow u^2 = 2\ln|x| + C_1$

回代：$\left(\frac{y}{x}\right)^2 = 2\ln|x| + C_1 \Rightarrow y^2 = x^2(2\ln|x| + C_1)$

### 2.3. 一阶线性微分方程

**标准形式**：

$$
\boxed{y' + P(x)y = Q(x)}
$$

- 当 $Q(x) \equiv 0$ 时为**齐次**
- 当 $Q(x) \not\equiv 0$ 时为**非齐次**

**解法（常数变易法）**：

**步骤1**：解齐次方程 $y' + P(x)y = 0$

分离变量：$\frac{dy}{y} = -P(x)\,dx \implies \ln|y| = -\int P(x)\,dx + C$

齐次通解：$y = Ce^{-\int P(x)\,dx}$

**步骤2**：将常数 $C$ 换为函数 $u(x)$，代入原非齐次方程

设 $y = u(x)e^{-\int P(x)\,dx}$，代入 $y' + P(x)y = Q(x)$ 解出 $u(x)$。

**通解公式**：

$$
\boxed{y = e^{-\int P(x)\,dx} \left( \int Q(x)e^{\int P(x)\,dx}\,dx + C \right)}
$$

**例**：求解 $y' + y = e^{-x}$

$P(x) = 1$，$Q(x) = e^{-x}$

$$
y = e^{-\int 1\,dx} \left( \int e^{-x} e^{\int 1\,dx}\,dx + C \right) = e^{-x} \left( \int e^{-x} e^{x}\,dx + C \right) = e^{-x}(x + C)
$$

### 2.4. 伯努利方程

**形式**：

$$
\boxed{y' + P(x)y = Q(x)y^n} \quad (n \neq 0, 1)
$$

**解法**：令 $z = y^{1-n}$，化为 $z$ 的一阶线性方程。

推导：$z' = (1-n)y^{-n}y'$，代入原方程得：

$z' + (1-n)P(x)z = (1-n)Q(x)$

**例**：求解 $y' + y = xy^2$（$n=2$）

令 $z = y^{-1}$，则 $z' = -y^{-2}y'$，代入得 $-z' + z = x$，即 $z' - z = -x$。

由一阶线性公式得：$z = e^{x}\left(-\int x e^{-x}\,dx + C\right) = e^{x}\left(xe^{-x} + e^{-x} + C\right) = x + 1 + Ce^{x}$

所以 $y = \frac{1}{x + 1 + Ce^{x}}$。

## 3. 全微分方程

### 3.1. 全微分方程的条件

若微分方程 $P(x,y)\,dx + Q(x,y)\,dy = 0$ 满足：

$$
\boxed{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}}
$$

则存在函数 $u(x,y)$，使得 $du = P\,dx + Q\,dy$，称为**全微分方程**。

### 3.2. 全微分方程的解法

**两种方法**：

**方法一（曲线积分法）**：

$$
u(x,y) = \int_{(x_0,y_0)}^{(x,y)} P\,dx + Q\,dy
$$

通常取 $(x_0,y_0) = (0,0)$ 简化计算，分两段积分。

**方法二（不定积分法）**：

由 $u_x = P$ 得 $u = \int P\,dx + \varphi(y)$，代入 $u_y = Q$ 确定 $\varphi(y)$。

**例**：求解 $(2x + y)\,dx + (x + 2y)\,dy = 0$

$P_y = 1$，$Q_x = 1$，相等，是全微分方程。

$u = \int (2x + y)\,dx = x^2 + xy + \varphi(y)$

由 $u_y = x + \varphi'(y) = Q = x + 2y \Rightarrow \varphi'(y) = 2y \Rightarrow \varphi(y) = y^2$

所以 $u = x^2 + xy + y^2 = C$ 为隐式通解。

### 3.3. 积分因子法

当 $\frac{\partial P}{\partial y} \neq \frac{\partial Q}{\partial x}$ 时，可寻找**积分因子** $\mu(x,y)$ 使 $\mu P\,dx + \mu Q\,dy = 0$ 成为全微分方程。

常见积分因子：

| 条件 | 积分因子 $\mu$ |
|------|---------------|
| $\frac{P_y - Q_x}{Q}$ 仅与 $x$ 有关 | $\mu = e^{\int \frac{P_y - Q_x}{Q}\,dx}$ |
| $\frac{Q_x - P_y}{P}$ 仅与 $y$ 有关 | $\mu = e^{\int \frac{Q_x - P_y}{P}\,dy}$ |

---

## 4. 可降阶的高阶微分方程

### 4.1. $y^{(n)} = f(x)$ 型

直接逐次积分 $n$ 次即可。

### 4.2. $y'' = f(x, y')$ 型（不含 $y$）

令 $p = y'$，则 $y'' = p'$，原方程化为 $p' = f(x, p)$（一阶方程）。

### 4.3. $y'' = f(y, y')$ 型（不含 $x$）

令 $p = y'$，则 $y'' = \frac{dp}{dx} = \frac{dp}{dy}\cdot\frac{dy}{dx} = p\frac{dp}{dy}$，原方程化为 $p\frac{dp}{dy} = f(y, p)$。

---

## 5. 二阶线性微分方程

### 5.1. 解的结构

二阶线性微分方程的一般形式：

$$
y'' + P(x)y' + Q(x)y = f(x)
$$

- 当 $f(x) \equiv 0$ 时为**齐次**方程
- 当 $f(x) \not\equiv 0$ 时为**非齐次**方程

**齐次方程解的结构**：
若 $y_1, y_2$ 是齐次方程的两个**线性无关**的解，则通解为：

$$
y = C_1 y_1 + C_2 y_2
$$

**非齐次方程解的结构**：
非齐次通解 = 齐次通解 + 非齐次特解：

$$
y = \bar{y} + y^*
$$

其中 $\bar{y}$ 为齐次通解，$y^*$ 为非齐次特解。

**叠加原理**：若 $y_1^*$ 是 $y'' + Py' + Qy = f_1(x)$ 的特解，$y_2^*$ 是 $y'' + Py' + Qy = f_2(x)$ 的特解，则 $y_1^* + y_2^*$ 是 $y'' + Py' + Qy = f_1(x) + f_2(x)$ 的特解。

## 6. 二阶常系数齐次线性微分方程

### 6.1. 标准形式

$$
\boxed{y'' + py' + qy = 0}
$$

其中 $p, q$ 为常数。

### 6.2. 特征方程法

设 $y = e^{rx}$，代入得特征方程：

$$
\boxed{r^2 + pr + q = 0}
$$

特征根的情况决定通解形式：

| 特征根情况 | 通解形式 |
|-----------|----------|
| **两个不等实根** $r_1 \neq r_2$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| **重根** $r_1 = r_2 = r$ | $y = (C_1 + C_2 x)e^{rx}$ |
| **共轭复根** $r = \alpha \pm i\beta$ | $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ |

**例1**：$y'' - 3y' + 2y = 0$

特征方程 $r^2 - 3r + 2 = 0$，根 $r_1 = 1, r_2 = 2$。

通解：$y = C_1 e^{x} + C_2 e^{2x}$

**例2**：$y'' + 2y' + y = 0$

特征方程 $r^2 + 2r + 1 = 0$，根 $r_1 = r_2 = -1$（重根）。

通解：$y = (C_1 + C_2 x)e^{-x}$

**例3**：$y'' + y = 0$

特征方程 $r^2 + 1 = 0$，根 $r = \pm i$（$\alpha = 0, \beta = 1$）。

通解：$y = C_1 \cos x + C_2 \sin x$

---

## 7. 二阶常系数非齐次线性微分方程

### 7.1. 标准形式

$$
\boxed{y'' + py' + qy = f(x)}
$$

解：$y = \bar{y} + y^*$（齐次通解 + 非齐次特解）。

### 7.2. 待定系数法（$f(x)$ 为特殊形式）

根据 $f(x)$ 的形式设定特解 $y^*$ 的形式：

**类型Ⅰ**：$f(x) = P_m(x)e^{\lambda x}$

设特解为：

$$
y^* = x^k Q_m(x) e^{\lambda x}
$$

其中 $Q_m(x)$ 为 $m$ 次待定多项式，$k$ 为 $\lambda$ 在特征根中出现的**重数**：
- $\lambda$ 不是特征根 → $k = 0$
- $\lambda$ 是单根 → $k = 1$
- $\lambda$ 是重根 → $k = 2$

**例**：$y'' - 3y' + 2y = e^{2x}$

特征根 $r_1 = 1, r_2 = 2$，$\lambda = 2$ 是单根，故 $k = 1$。

设 $y^* = Ax e^{2x}$，代入得 $A = 1$，故 $y^* = x e^{2x}$。

通解：$y = C_1 e^{x} + C_2 e^{2x} + x e^{2x}$

**类型Ⅱ**：$f(x) = e^{\lambda x}[P_l(x)\cos\omega x + Q_n(x)\sin\omega x]$

设特解为：

$$
y^* = x^k e^{\lambda x}[R_m(x)\cos\omega x + S_m(x)\sin\omega x]
$$

其中 $m = \max\{l, n\}$，$k = \begin{cases} 0, & \lambda + i\omega \text{ 不是特征根} \\ 1, & \lambda + i\omega \text{ 是特征根} \end{cases}$

## 8. 欧拉方程

### 8.1. 欧拉方程的形式

**欧拉方程**（也称为**欧拉-柯西方程**）是一类特殊的变系数线性微分方程：

$$
\boxed{x^n y^{(n)} + a_1 x^{n-1} y^{(n-1)} + \cdots + a_{n-1} x y' + a_n y = f(x)}
$$

其中 $a_1, a_2, \dots, a_n$ 为常数。

最常见的二阶形式：

$$
\boxed{x^2 y'' + p x y' + q y = f(x)}
$$

### 8.2. 欧拉方程的解法（变量代换法）

令 $x = e^t$（即 $t = \ln x$），则：

$$
xy' = \frac{dy}{dt}
$$

$$
x^2 y'' = \frac{d^2 y}{dt^2} - \frac{dy}{dt}
$$

代入后将原方程转化为关于 $t$ 的**常系数**线性微分方程，再用特征方程法求解。

记微分算子 $D = \frac{d}{dt}$，则：
- $xy' = Dy$
- $x^2 y'' = D(D-1)y$

**例**：求解 $x^2 y'' - 2xy' + 2y = 0$

令 $x = e^t$，则 $x^2 y'' = D(D-1)y$，$xy' = Dy$，代入得：

$[D(D-1) - 2D + 2]y = 0 \Rightarrow (D^2 - 3D + 2)y = 0$

特征方程 $r^2 - 3r + 2 = 0$，根 $r_1 = 1, r_2 = 2$。

关于 $t$ 的通解：$y = C_1 e^t + C_2 e^{2t}$

回代 $x = e^t$：$y = C_1 x + C_2 x^2$

### 8.3. 欧拉方程的特征方程

对于齐次欧拉方程 $x^2 y'' + p x y' + q y = 0$，设 $y = x^r$，代入得：

$$
r(r-1) + pr + q = 0 \quad \Rightarrow \quad r^2 + (p-1)r + q = 0
$$

这就是欧拉方程的**特征方程**。特征根三种情况的通解对应：

| 特征根情况                        | 通解形式                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------- |
| 两个不等实根 $r_1 \neq r_2$        | $y = C_1 x^{r_1} + C_2 x^{r_2}$                                              |
| 重根 $r_1 = r_2 = r$           | $y = (C_1 + C_2 \ln x) \, x^{r}$                                             |
| 共轭复根 $r = \alpha \pm i\beta$ | $y = x^{\alpha} \bigl[ C_1 \cos(\beta \ln x) + C_2 \sin(\beta \ln x) \bigr]$ |

## 9. 微分算子法

### 9.1. 微分算子定义

记 $D = \frac{d}{dx}$，则：
- $Dy = y'$
- $D^2 y = y''$
- $D^n y = y^{(n)}$
- $F(D) = D^n + a_1 D^{n-1} + \cdots + a_n$（算子多项式）

微分方程 $y'' + py' + qy = f(x)$ 可写为：

$$
(D^2 + pD + q)y = f(x) \quad \text{或} \quad F(D)y = f(x)
$$

### 9.2. 算子法的基本运算

**性质**：
- $F(D)e^{\lambda x} = F(\lambda)e^{\lambda x}$
- $F(D^2)\sin\omega x = F(-\omega^2)\sin\omega x$（类似对 $\cos$）

**逆算子**：如果 $F(D) \neq 0$，则 $y = \frac{1}{F(D)}f(x)$ 表示一个特解。

**常用公式**：

$$
\frac{1}{D - \lambda} f(x) = e^{\lambda x} \int f(x) e^{-\lambda x}\,dx
$$

$$
\frac{1}{F(D)} e^{\lambda x} = \frac{1}{F(\lambda)} e^{\lambda x} \quad (F(\lambda) \neq 0)
$$

若 $F(\lambda) = 0$（即 $\lambda$ 为 $k$ 重特征根），则：

$$
\frac{1}{F(D)} e^{\lambda x} = \frac{x^k}{F^{(k)}(\lambda)} e^{\lambda x}
$$

## 本讲核心要点

1. **微分方程**是描述动态系统的数学工具，阶数由最高阶导数决定
2. **一阶微分方程**的四种类型：可分离变量、齐次、一阶线性（常数变易法）、伯努利（化为线性）
3. **全微分方程** $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$，可通过曲线积分法或不定积分法求原函数
4. **积分因子法**将非全微分方程化为全微分方程
5. **二阶线性微分方程**的通解结构：齐次通解 + 非齐次特解
6. **常系数齐次方程**的特征方程法：特征根的三种情况对应三种通解形式
7. **常系数非齐次方程**的待定系数法：根据 $f(x)$ 的形式（指数/多项式/三角）设定特解形式
8. **欧拉方程** $x^2y'' + pxy' + qy = f(x)$ 通过 $x = e^t$ 化为常系数方程
9. **微分算子法** $F(D)y = f(x)$ 用算子代数简化特解求解过程
