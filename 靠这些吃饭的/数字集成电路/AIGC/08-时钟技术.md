# 08-时钟技术

## 知识地图

```
第07章（时序逻辑）→ 寄存器的时序参数（setup/hold/t_cq）
    ↓
【时钟技术】—— 让所有寄存器"踩在同一节拍上"
    ↓
时钟偏差(skew)与抖动(jitter) → 时钟分布网络(H-tree/网格) → PLL → 同步/异步
```

**本讲回答的核心问题**：如何产生、分配和控制时钟信号，使芯片上所有寄存器同步工作？时钟偏差和抖动如何影响系统性能？

---

## 1. 同步时序逻辑的时钟

### 1.1. 为什么需要时钟？

同步数字系统中，时钟信号定义了所有存储单元的更新时刻。如果不这样做，错误的数据可能被写入存储元件，导致操作出错。

**同步系统方法**：采用全局分布的周期性同步信号（时钟），使系统中所有存储单元同时更新。时钟的功能是**保持正确的开关事件顺序**。

### 1.2. 时钟约束回顾

结合第07章的时序参数，两级寄存器之间的时序约束：

**Setup 约束**（决定最高工作频率）：

$$
T_{clk} \geq t_{c-q,max} + t_{logic,max} + t_{su} + t_{skew}
$$

**Hold 约束**（必须始终满足）：

$$
t_{cd,min} + t_{logic,min} \geq t_h + t_{skew}
$$

其中：
- $t_{skew}$ 是时钟偏差（可为正或负）
- setup 约束限制频率，hold 约束与频率无关

## 2. 时钟偏差和时钟抖动

### 2.1. 时钟偏差（Clock Skew）

**时钟偏差**是指同一时钟信号到达不同寄存器的**时间差**。它是由时钟路径的静态不匹配以及时钟负载的差异造成的。

**性质**：每个周期的偏差是相同的——如果一个周期 CLK₁ 落后于 CLK₂ 一个 $\delta$，那么下一个周期也落后同一数量。时钟偏差**不造成时钟周期变化**，只造成相位偏移。

#### 偏差对性能的影响

考虑两级寄存器 $R_1 \to R_2$ 的路径：

- **正偏差**（$\delta > 0$，CLK₂ 晚于 CLK₁）：信号从 $R_1$ 传播到 $R_2$ 的可用时间增加了 $\delta$，有利于 setup，但危害 hold
- **负偏差**（$\delta < 0$，CLK₂ 早于 CLK₁）：可用时间减少 $\delta$，不利于 setup，有利于 hold

#### 偏差预算

**最大正偏差**（受 hold 约束）：

$$
\delta_{max} = t_{cd,min}(R_1) + t_{cd,logic,min} - t_h(R_2)
$$

**最大负偏差**（受 setup 约束）：

$$
|\delta_{max}| = T_{clk} - t_{c-q,max}(R_1) - t_{logic,max} - t_{su}(R_2)
$$

### 2.2. 时钟抖动（Clock Jitter）

**时钟抖动**是指时钟边沿在时间上的**随机变化**——与偏差不同，抖动是周期性的随机量，导致**时钟周期的变化**。

**抖动的来源**：
- 电源噪声（影响时钟缓冲器的延时）
- 热噪声
- PLL 的相位噪声
- 衬底噪声耦合

**抖动的分类**：
- **周期抖动**（Cycle-to-cycle jitter）：相邻时钟周期长度之差
- **长期抖动**（Long-term jitter）：经过多个周期后的累积偏差

**抖动对时序的影响**：抖动减少了一个周期内可用的时间裕量——实际可用的时钟周期为 $T_{clk} - t_{jitter}$。

### 2.3. 偏差与抖动的对比

| 性质 | 时钟偏差（Skew） | 时钟抖动（Jitter） |
|:----|:---------------:|:----------------:|
| **本质** | 确定性偏差 | 随机变化 |
| **对周期的影响** | 无 | 使周期变化 |
| **产生原因** | 路径不匹配、负载差异 | 电源噪声、热噪声、PLL噪声 |
| **频率相关性** | 与频率无关 | 随频率变化 |
| **对时序的影响** | 改变可用时间 | 减少可用时间裕量 |

## 3. 时钟分布网络

### 3.1. 设计要求

时钟分布网络的设计目标：**使到达所有寄存器的时钟边沿尽可能同时**——即最小化时钟偏差。

**设计难点**：
- 时钟信号具有**最大扇出**（连接到所有寄存器）
- 通过**最长距离**（从芯片中心到角落）
- 以**最高速度**运行（通常是芯片最快信号）
- 功耗大（时钟树功耗可占总功耗的 30%~40%）

### 3.2. H 树分布

**H 树**（H-Tree）是一种对称的时钟分布结构，从中心点出发，以 H 形逐级分叉到芯片各区域：

- **优点**：路径匹配性好，偏差小
- **缺点**：不适用于非均匀分布的寄存器；灵活性差
- **适用**：规则排列的芯片（如存储器阵列）

### 3.3. 网格分布（Clock Mesh）

通过在整个芯片上铺设金属网格，将时钟信号同时驱动到所有区域：

- **优点**：偏差极小，对局部负载差异不敏感
- **缺点**：功耗大，短路电流多
- **适用**：高性能微处理器

### 3.4. 时钟树综合（Clock Tree Synthesis, CTS）

在 EDA 流程中，时钟树综合是物理设计的核心步骤之一。它以**寄存器时钟端**为叶节点，构建平衡的缓冲器树状网络：

**CTS 的目标**：
- 最小化时钟偏差（通常目标 $\pm 20\text{ps}$ 以内）
- 满足 setup/hold 时序约束
- 最小化时钟功耗

**CTS 的步骤**：
1. 指定时钟源（PLL 输出或芯片输入引脚）
2. 识别所有同步元件（寄存器时钟端）
3. 插入时钟缓冲器，构建平衡树
4. 优化偏差和插入延时

### 3.5. 时钟分布中的关键参数

- **插入延时**（Insertion Delay）：时钟从源点到叶节点的传播时间
- **偏差**（Skew）：各叶节点到达时间的最大差值
- **功耗**：时钟缓冲器 + 互连线的动态功耗

## 4. 锁相环（PLL）

### 4.1. PLL 的作用

锁相环（Phase-Locked Loop）用于：
- **片内时钟产生**：将外部低频参考时钟倍频为片内高频时钟
- **时钟同步**：消除片内时钟与外部时钟的相位差
- **时钟去歪斜**（De-skew）：通过反馈消除时钟分布网络的插入延时

### 4.2. PLL 的基本组成

PLL 由四个主要功能块构成：

```
参考时钟 → 鉴频鉴相器(PFD) → 电荷泵(CP) → 环路滤波器(LPF) → 压控振荡器(VCO)
    ↑                                                              │
    └────────────────── 分频器(÷N) ←───────────────────────────────┘
```

- **鉴频鉴相器**（PFD）：比较参考时钟和反馈时钟的相位差，输出 Up/Down 脉冲
- **电荷泵**（CP）：将数字 Up/Down 信号转换为模拟电流
- **环路滤波器**（LPF）：平滑电荷泵输出，滤除高频噪声
- **压控振荡器**（VCO）：根据控制电压产生输出时钟频率
- **分频器**：将输出时钟分频后反馈回 PFD

### 4.3. PLL 的关键参数

- **锁定时间**（Lock Time）：PLL 从启动到频率稳定的时间
- **抖动**（Jitter）：VCO 的相位噪声引起的时钟边沿随机变化
- **带宽**（Bandwidth）：环路滤波器的截止频率——影响锁定时间和抖动抑制

## 5. 同步设计方法

### 5.1. 同步互连

标准同步设计，所有寄存器由同一时钟驱动。最常用的方法。

### 5.2. 中等同步互连

不同时钟域之间通过 FIFO（先进先出寄存器）进行数据交换——FIFO 缓冲数据，解决不同时钟域之间的频率差异。

### 5.3. 异步互连——自定时逻辑

**自定时逻辑**（Self-Timed Logic）不需要全局时钟，而是通过**握手协议**（request/acknowledge）在模块之间传递数据。

**完成信号产生**：使用**双轨编码**（dual-rail encoding）或**柏然编码**（Berger code）检测计算完成。

**优点**：
- 无时钟偏差问题
- 平均性能（而非最坏情况性能）
- 低功耗（无时钟翻转功耗）

**缺点**：
- 设计复杂
- 面积大
- EDA 工具支持不足

### 5.4. 同步器和亚稳态

当异步信号进入同步时钟域时，可能违反寄存器的 setup/hold 时间，导致**亚稳态**（metastability）——输出在一段不确定时间内处于中间电平。

**同步器**：两级或更多级寄存器级联，将异步信号同步到时钟域。每增加一级，亚稳态概率指数下降。

## 本讲核心要点

1. **时钟偏差**是确定性的路径延迟差，**时钟抖动**是随机的边沿变化——偏差改变可用时间，抖动减少周期裕量
2. **Setup 约束** $T \geq t_{c-q}+t_{logic}+t_{su}+t_{skew}$ 决定最高频率，**Hold 约束** $t_{cd}+t_{cd,logic} \geq t_h+t_{skew}$ 必须始终满足
3. 最大正偏差由**最短路径**（hold）约束，最大负偏差由**最长路径**（setup）约束
4. 时钟偏差**不改变时钟周期**，但抖动会使实际周期小于标称周期
5. **H 树**提供良好的路径匹配，适合规则阵列；**网格分布**偏差最小但功耗大；**时钟树综合（CTS）** 是 EDA 流程中的标准方法
6. **PLL** 用于片内时钟产生、倍频和去歪斜——四个基本组件（PFD/CP/LPF/VCO）构成反馈环路
7. **插入延时**和**偏差**是时钟分布的两个关键参数——前者影响时序裕量，后者决定可用时间
8. 时钟信号具有最大扇出、最长距离和最高速度——时钟功耗可达芯片总功耗的 30%~40%
9. **自定时逻辑**消除了时钟问题但设计复杂，适用于特定低功耗或高速场景
10. **同步器**（两级寄存器）用于处理跨时钟域的异步信号，是避免亚稳态的基本手段
