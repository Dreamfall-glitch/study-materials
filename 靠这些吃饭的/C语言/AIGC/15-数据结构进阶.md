# 15-数据结构进阶

## 知识地图

```
链表：动态增删，非连续存储（头部插入 O(1)）
    ↓
二叉搜索树：左小右大，递归结构（查找 O(log n)）
    ↓
哈希表：哈希函数 → 拉链法（平均 O(1)）
    ↓
三种结构的对比与选择
```

**本讲回答的核心问题**：链表相对数组有什么优势？二叉树如何实现快速查找？哈希表为什么能平均 O(1) 操作？

---

## 1. 链表

### 1.1. 为什么需要链表

数组的痛点：
- 插入/删除元素需要移动大量数据（O(n)）
- 大小固定，动态扩展需重新分配

链表用**非连续存储** + **指针串联**解决了这些问题：

```c
struct node {
    int data;
    struct node *next;
};
```

### 1.2. 基本操作

```c
#include <stdlib.h>
#include <stdio.h>

/* 创建节点 */
struct node *new_node(int value)
{
    struct node *p = malloc(sizeof(struct node));
    if (p) { p->data = value; p->next = NULL; }
    return p;
}

/* 头部插入 */
struct node *prepend(struct node *head, int value)
{
    struct node *p = new_node(value);
    p->next = head;
    return p;           /* 新的链表头 */
}

/* 遍历 */
void print_list(struct node *head)
{
    for (struct node *p = head; p; p = p->next)
        printf("%d -> ", p->data);
    printf("NULL\n");
}

/* 查找 */
struct node *search(struct node *head, int target)
{
    for (struct node *p = head; p; p = p->next)
        if (p->data == target) return p;
    return NULL;
}

/* 删除 */
struct node *delete(struct node *head, int target)
{
    struct node *prev = NULL;
    for (struct node *cur = head; cur; prev = cur, cur = cur->next) {
        if (cur->data == target) {
            if (prev == NULL)
                head = cur->next;          /* 删除头节点 */
            else
                prev->next = cur->next;
            free(cur);
            return head;
        }
    }
    return head;         /* 未找到 */
}

/* 释放整个链表 */
void free_list(struct node *head)
{
    while (head) {
        struct node *next = head->next;
        free(head);
        head = next;
    }
}
```

### 1.3. 数组 vs 链表

| 操作 | 数组 | 链表 |
|------|:--:|:--:|
| 随机访问 | O(1) | O(n) |
| 头部插入/删除 | O(n) | O(1) |
| 尾部插入（已知尾指针） | O(1) | O(1) |
| 空间效率 | 紧凑（无额外指针） | 每节点额外 `sizeof(指针)` |
| 动态长度 | 需 realloc | 自然支持 |

**选择**：频繁随机访问 → 数组；频繁增删 → 链表。两全其美的办法也有：用数组存、标记"已删除"的懒惰策略。

## 2. 二叉树

### 2.1. 二叉搜索树（BST）定义

每个节点满足：左子树所有节点 < 本节点 < 右子树所有节点。

```c
struct tnode {
    int data;
    struct tnode *left;
    struct tnode *right;
};
```

### 2.2. 插入

```c
struct tnode *insert(struct tnode *root, int value)
{
    if (root == NULL) {
        root = malloc(sizeof(struct tnode));
        root->data = value;
        root->left = root->right = NULL;
        return root;
    }
    if (value < root->data)
        root->left = insert(root->left, value);
    else if (value > root->data)
        root->right = insert(root->right, value);
    /* 已存在：不重复插入 */
    return root;
}
```

### 2.3. 查找

```c
struct tnode *search(struct tnode *root, int target)
{
    if (root == NULL || root->data == target)
        return root;
    if (target < root->data)
        return search(root->left, target);
    else
        return search(root->right, target);
}
```

平衡的 BST 每次比较排除一半子树，查找效率 O(log n)。但最差（插入顺序有序时）退化为链表 O(n)。

### 2.4. 遍历

```c
void inorder(struct tnode *root)        /* 中序：左→根→右——有序输出 */
{
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

void preorder(struct tnode *root)       /* 先序：根→左→右——用于复制树 */
{
    if (root == NULL) return;
    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}

void postorder(struct tnode *root)      /* 后序：左→右→根——用于释放树 */
{
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->data);
}
```

**三种遍历各自用途**：
- **先序**：创建或复制树（先创建根节点，再递归左右子树）
- **中序**：有序输出——BST 的中序遍历就是升序序列
- **后序**：释放树——先释放子树，最后释放根节点

## 3. 哈希表

### 3.1. 核心思想

通过**哈希函数**将 key 映射为数组下标，**直接"跳"到目标位置**——因此平均 O(1)。

```c
#define TABLE_SIZE 100

struct hashnode {
    int key;
    int value;
    struct hashnode *next;    /* 冲突时链到同位置 */
};

struct hashnode *table[TABLE_SIZE] = {NULL};
```

### 3.2. 哈希函数

```c
int hash(int key) {
    return key % TABLE_SIZE;           /* 取模法——简单但可能聚集 */
}

int hash_str(const char *str) {        /* 字符串哈希 */
    unsigned long h = 0;
    while (*str)
        h = h * 31 + (unsigned char)*str++;    /* 类似 31 进制 */
    return h % TABLE_SIZE;
}
```

### 3.3. 基本操作

```c
void insert(int key, int value)
{
    int idx = hash(key);
    struct hashnode *p = malloc(sizeof(struct hashnode));
    p->key = key; p->value = value;
    p->next = table[idx];
    table[idx] = p;                      /* 头插法（拉链法） */
}

int *lookup(int key)
{
    int idx = hash(key);
    for (struct hashnode *p = table[idx]; p; p = p->next)
        if (p->key == key)
            return &p->value;
    return NULL;
}

int delete(int key)
{
    int idx = hash(key);
    struct hashnode *prev = NULL;
    for (struct hashnode *cur = table[idx]; cur; prev = cur, cur = cur->next) {
        if (cur->key == key) {
            if (prev == NULL)
                table[idx] = cur->next;
            else
                prev->next = cur->next;
            free(cur);
            return 1;
        }
    }
    return 0;
}
```

### 3.4. 性能要素

**负载因子** = 元素数 / 表大小。负载因子过高时冲突变多，需要扩容（rehash）——重新分配更大的表，重新计算每个元素的哈希再插入。

**哈希函数的选择**直接影响分布均匀程度。好的哈希函数应让不同 key 尽量散落到不同槽位。

---

## 本讲核心要点

1. **链表**的增删是 O(1)（已知位置时），随机访问是 O(n)；数组反之
2. 链表的每个节点独立 `malloc`，因此需要**额外管理内存**
3. **二叉搜索树**左小右大，平衡时查找 O(log n)，最差退化为 O(n)
4. **中序遍历 BST**得到有序序列；先序/中序/后序遍历各有用途
5. **哈希表**通过哈希函数映射到数组下标，拉链法解决冲突，平均 O(1)
6. 负载因子过高需 rehash 扩容；哈希函数的选择影响冲突率
7. 三种结构各有适用场景：频繁查用哈希表，有序数据用 BST，实时增删用链表

## 习题

**1. 反转单链表（迭代方式）。**

```c
struct node *reverse(struct node *head)
{
    struct node *prev = NULL, *cur = head;
    while (cur) {
        struct node *next = cur->next;    /* 先保存下一个 */
        cur->next = prev;                 /* 反转指向 */
        prev = cur; cur = next;
    }
    return prev;                           /* 新的头 */
}
```

**2. 释放整棵二叉树的函数。**

```c
void free_tree(struct tnode *root)
{
    if (root == NULL) return;
    free_tree(root->left);      /* 先释放左子树 */
    free_tree(root->right);     /* 再释放右子树 */
    free(root);                 /* 最后释放根节点 */
}
```
